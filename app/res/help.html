PostalExpress Help

PostalExpress reads and sends e-mail from IMAP and SMTP accounts: Gmail, Outlook.com, Fastmail, your company's mail server and most others. It keeps a copy of your mail on this computer, so you can read what was already downloaded without a connection.

1. Adding an account

The first time PostalExpress starts it asks for an account. To add another one later, choose File > New Account or click New Account on the toolbar.

  1. Type your name as others should see it, your e-mail address and your password, and click OK.
  2. PostalExpress looks up the settings of your mail provider: from the provider that handles your domain's mail, your domain's DNS records, your provider's settings file, Thunderbird's list of providers and, for Exchange, Microsoft Autodiscover. This takes a few seconds; Cancel skips it. Your password is sent only to an Exchange server of your own domain that asks for it, over an encrypted connection.
  3. If your provider wants an app password instead of your normal one, PostalExpress says so and offers to open its instructions.
  4. Check the server settings it found and click OK. If it found nothing it fills in the usual names (imap. and smtp. followed by your domain); compare them with what your provider tells you.

Changing or removing an account

File > Accounts lists your accounts. Properties (or a double click) changes the name, address, servers and password of one; leave the password empty to keep it. Remove takes the account out of PostalExpress with the mail downloaded for it and its saved password; the mail on the server stays. Add adds another account.

Gmail and Outlook.com

These providers do not take your normal password from mail programs. Either:

  • sign in through your web browser, when PostalExpress offers it: your password is typed into Google's or Microsoft's own page and PostalExpress never sees it; or
  • create an app password in your account's security settings (Google: Security > 2-Step Verification > App passwords; Microsoft: Security > Advanced security options > App passwords) and type that instead of your password.

Security settings

Setting Meaning
SSL/TLS The connection is encrypted from the start. Usually port 993 for IMAP and 465 for SMTP.
STARTTLS The connection is encrypted right after it opens. Usually port 143 for IMAP and 587 for SMTP. PostalExpress refuses to continue if the server does not offer encryption.
None (unencrypted) Your password and mail travel readable by anyone on the network. Use it only for a server on your own computer or network; PostalExpress warns before using it.

2. Reading mail

The window has three parts: your accounts and folders on the left, the messages of the selected folder at the top right, and the selected message below them. Drag the borders between them to change their sizes.

  • Folders with unread messages are shown in bold, with the number of unread messages after the name.
  • Unread messages are bold in the list. A message is marked read after it has been shown for a second. Use Mark Read and Mark Unread (Ctrl+Q marks read) to change it yourself.
  • In the ! column, ! means the message is flagged and @ that it has attachments.
  • Click a column heading to sort by it; click it again to reverse the order.
  • The Find box at the right of the toolbar (Ctrl+Shift+F) narrows the list of the folder to the messages with what you type in their subject, sender or recipients; the status bar says how many it found. Esc or emptying the box shows the whole folder again, and so does choosing another folder.
  • Delete (the toolbar, Edit > Delete Message or the Del key in the list) moves the message to Deleted Items; deleting it there removes it for good, after asking. (On a server without the UIDPLUS extension, deleting for good also removes the other messages of that folder that another mail program marked as deleted.) Edit > Move to Folder (Ctrl+Shift+V) moves it to another folder of the account. Message > Flag Message flags it (! in the list) or takes the flag away. All of this happens on the server too, so your other mail programs see it.
  • File > Folder, or a right click in the folder list, makes a New Folder in the selected folder (at the top of an account when the account is selected), and Renames or Deletes the selected folder. Deleting a folder deletes the messages in it, after asking. The Inbox and the special folders (Sent Items, Drafts, Deleted Items and the like) stay as they are.
  • Above the message are its sender, date, recipients and subject.

Earlier messages in replies

A reply often carries the messages before it. PostalExpress folds them away behind a ••• button under what the sender wrote; click it to see them. Only text that is clearly an earlier message is folded, anything uncertain stays in view.

3. Pictures, links and attachments

Pictures

Pictures that the sender keeps on the internet are not downloaded, because downloading them tells the sender that you opened the message, when, and from where. Pictures sent inside the message are shown. To see the others for a message you trust, click Download pictures (or View > Download Pictures).

Links and scripts

Scripts in messages never run. Clicking a link opens it in your web browser, never inside PostalExpress. Before you type a password on a page you reached from an e-mail, check the address in your browser.

Attachments

When a message has attachments, an Attachments button appears next to the message header. Click it and choose the file to save. PostalExpress suggests a safe file name: folder names, characters Windows does not allow and characters that can make a name look different from what it is are removed.

Open attachments only from people you expect them from. A program (.exe, .js, .vbs, .msi, .bat, .scr) or a document that asks you to "enable content" can take over your computer.

Saving, printing and importing messages

  • File > Save As saves the message shown as an .eml file, which other mail programs open.
  • File > Import Messages puts .eml files into the selected folder, on the server too. A file that is not a message is not imported.
  • File > Print (Ctrl+P) prints the message shown, with its sender, date, recipients and subject.

4. Writing, replying and forwarding

  • Create Mail (Ctrl+N) starts a new message from the account of the selected folder.
  • Reply (Ctrl+R) answers the sender, Reply All (Ctrl+Shift+R) everyone the message went to, Forward (Ctrl+F) sends it on.
  • In a reply the original message is folded away behind a ••• button under your text, so you see only what you write. Click it (or select all with Ctrl+A) to put it into your text, where you can shorten it; it is sent with your answer either way. In a forward the original is in the text from the start, since it is what you send.
  • The bar above the text formats it: the font and its size, Bold, Italic, Underline (or Ctrl+B, Ctrl+I, Ctrl+U), Color, numbered and bulleted lists, less and more indent (« and »), alignment, Link for a web address on the selected text, Line for a dividing line and Picture to put a picture in the text. The message goes as formatted HTML with a plain text copy for mail programs that show only text.
  • Misspelled words are underlined; right-click one for suggestions. Cut, copy and paste work as everywhere.
  • Separate several addresses in To, Cc and Bcc with commas, for example Mary Smith <mary@example.com>, john@example.com. Put a name that has a comma in it in quotes: "Smith, Mary" <mary@example.com>.
  • People in Bcc get the message, but the other recipients do not see them.
  • Attach adds files; the files are read when the message is sent.
  • Send puts the message in the Outbox and sends it right away. When it can not go (no connection, the server refuses it) it stays in the Outbox and goes with the next Send/Recv; nothing you wrote is lost. Send Later only puts it in the Outbox. The status bar says how many wait there; Tools > Outbox lists them, with why they did not go, and sends or deletes them.
  • Ctrl+Enter sends from the text.
  • Save (or Ctrl+S) keeps the message in the Drafts folder of the account, on the server, to finish later; saving again replaces the copy saved before. Closing a message with changes asks whether to save them: Yes saves it in Drafts, No throws it away, Cancel goes back to it. To go on writing, double-click the draft in Drafts (or select it and press Enter): it opens with its recipients, text and attached files. Once it is sent, the draft is removed from Drafts.
  • Send sends the message. If an address is mistyped or a file is gone, PostalExpress says so and keeps the message open so you can fix it. A copy of each sent message is kept in Sent Items.

5. Getting new mail

PostalExpress checks every account when it starts and every ten minutes after that. Click Send/Recv or press F5 to check now. The status bar at the bottom shows what it is doing and the last problem it had.

7. When something does not work

"authentication failed" or PostalExpress asks for the password again

The server refused the password. Type it again; for Gmail and Outlook.com use an app password or sign in through the browser (see Adding an account). If your provider asks for a second step when you log in on the web, it needs an app password for mail programs too. For an account that signs in through the browser, PostalExpress offers to sign in again.

"TLS error" or a certificate error

PostalExpress could not confirm that it is talking to the real server, so it did not send your password. Check the server name in the account settings: it has to be the name the server's certificate is made for (often imap.provider.com, not your own domain). On a network that inspects encrypted traffic, ask its administrator.

"the server does not offer STARTTLS"

The account is set to STARTTLS but the server did not offer encryption. Try SSL/TLS on port 993 (IMAP) or 465 (SMTP). If nothing else works the server cannot be used safely.

"the server takes the password only over an encrypted connection"

The outgoing (SMTP) server is set to None (unencrypted). Your password is fine; change the SMTP security to STARTTLS (port 587) or SSL/TLS (port 465).

"connection error" or "the server did not answer in time"

Check your internet connection, the server name and the port. Firewalls sometimes block the mail ports, port 25 in particular; use 465 or 587 for sending. PostalExpress tries again at the next check.

A message that cannot be shown

Some messages are damaged or built in ways no mail program can read. PostalExpress shows a note instead of the message; the rest of your mail is not affected.

8. Where your mail and passwords are kept

  • Downloaded mail and account settings: %LOCALAPPDATA%\PostalExpress\store.db. Your mail stays on the server too; the copy here is for reading quickly and offline.
  • Passwords and browser sign-ins: the Windows Credential Manager, under PostalExpress. They are encrypted for your Windows account.
  • Uninstalling PostalExpress asks whether to remove the mail it downloaded. The mail on your servers is never removed.

For testing, PostalExpress.exe --store <file> uses another mail store, --memory-passwords keeps passwords for the current run only, and --pin-certificate <file> accepts only the server certificate in that file (PEM or DER) instead of the ones Windows trusts, for a test server with a self-signed certificate.
