Aide d'Inbox Classic

Inbox Classic lit et envoie le courrier de comptes IMAP et SMTP : Gmail, Outlook.com, Fastmail, le serveur de messagerie de votre entreprise et la plupart des autres. Il garde une copie de votre courrier sur cet ordinateur, pour que vous puissiez lire ce qui a déjà été téléchargé sans connexion.

1. Ajouter un compte

Au premier démarrage, Inbox Classic demande un compte. Pour en ajouter un autre plus tard, choisissez Fichier > Nouveau compte. À chaque démarrage, il ouvre la Boîte de réception du premier compte avec son message le plus récent sélectionné, ou avec deux comptes ou plus Toutes les boîtes avec le message le plus récent de l'ensemble.

  1. Pour Gmail, Google Workspace, Outlook.com ou Microsoft 365, cliquez sur Se connecter avec Google ou Se connecter avec Microsoft et connectez-vous dans la fenêtre du navigateur qui s'ouvre. C'est tout : le compte est celui auquel vous vous êtes connecté, nommé comme chez Google ou Microsoft sauf si vous avez saisi un nom. Voir Gmail et Outlook.com ci-dessous. Un bouton grisé est désactivé sur cet ordinateur ; Pourquoi ? en dessous en donne la raison.
  2. Pour vous connecter avec votre propre application de connexion (voir Votre propre application de connexion ci-dessous), cliquez sur Autres options de connexion et choisissez-la, ou sur Ajouter une application de connexion. Saisissez d'abord votre adresse et la page du fournisseur commence par elle.
  3. Pour tout autre compte, saisissez votre nom tel que les autres doivent le voir et votre adresse de messagerie, puis cliquez sur Suivant.
  4. Inbox Classic recherche les paramètres de votre fournisseur de messagerie : auprès du fournisseur qui gère le courrier de votre domaine, dans les enregistrements DNS de votre domaine, dans le fichier de paramètres de votre fournisseur, dans la liste des fournisseurs de Thunderbird et, pour Exchange, via Microsoft Autodiscover. Cela prend quelques secondes ; Annuler l'ignore. Une adresse chez Google ou Microsoft se voit aussi proposer ici leur bouton de connexion.
  5. Si votre fournisseur veut un mot de passe d'application au lieu de votre mot de passe habituel, Inbox Classic le dit et propose d'ouvrir ses instructions.
  6. Saisissez votre mot de passe, vérifiez les paramètres de serveur trouvés et cliquez sur Terminer. S'il n'a rien trouvé, il remplit les noms habituels (imap. et smtp. suivis de votre domaine) ; comparez-les avec ce que vous indique votre fournisseur.

Modifier ou supprimer un compte

Fichier > Comptes liste vos comptes. Propriétés (ou un double-clic) modifie le nom, l'adresse, les serveurs et le mot de passe d'un compte ; laissez le mot de passe vide pour le conserver. Supprimer (ou la touche Del) retire le compte d'Inbox Classic avec le courrier téléchargé pour lui et son mot de passe enregistré ; le courrier sur le serveur reste. Ajouter ajoute un autre compte.

Gmail et Outlook.com

Ces fournisseurs n'acceptent pas votre mot de passe habituel venant de programmes de messagerie. Au choix :

  • connectez-vous via votre navigateur avec Se connecter avec Google ou Se connecter avec Microsoft : votre mot de passe est saisi sur la page de Google ou de Microsoft et Inbox Classic ne le voit jamais (une organisation Microsoft 365 devra peut-être d'abord autoriser Inbox Classic : Microsoft affiche alors Approbation de l'administrateur nécessaire, et Inbox Classic vous indique l'adresse où votre administrateur l'approuve) ; ou
  • créez un mot de passe d'application dans les paramètres de sécurité de votre compte (Google : Sécurité > Validation en deux étapes > Mots de passe des applications ; Microsoft : Sécurité > Options de sécurité avancées > Mots de passe d'application), saisissez votre adresse, cliquez sur Suivant, puis sur Utiliser un mot de passe d'application, et saisissez le mot de passe d'application au lieu de votre mot de passe habituel.

Votre propre application de connexion

La connexion via le navigateur utilise un client OAuth enregistré auprès du fournisseur. Inbox Classic a les siens pour Google et Microsoft. Google ne laisse se connecter que les utilisateurs de test d'Inbox Classic tant qu'il n'a pas vérifié l'application, c'est pourquoi Se connecter avec Google est désactivé au départ. Vous pouvez enregistrer votre propre client (avec votre propre projet Google Cloud, votre locataire Microsoft Entra ou tout fournisseur compatible OpenID Connect) et l'ajouter comme application de connexion :

  1. Ouvrez Fichier > Comptes et cliquez sur Applications de connexion, puis sur Ajouter.
  2. Cliquez sur Google ou Microsoft après Préremplir pour pour remplir l'émetteur, les autorisations et les serveurs, ou saisissez-les pour un autre fournisseur. La zone du bas indique comment y enregistrer un client et l'adresse de redirection à enregistrer ; Copier la copie.
  3. Saisissez l'ID client, et le secret client si le fournisseur vous en a donné un (il est conservé dans le Gestionnaire d'identification Windowsvotre trousseauvotre trousseau, et n'est plus jamais affiché). Vérifier lit les paramètres du fournisseur pour voir si l'émetteur est correct ; OK le fait aussi avant d'enregistrer.
  4. Ajoutez le compte avec Autres options de connexion sur la première page de Fichier > Nouveau compte.

Dans Applications de connexion, la case de chaque application, intégrées comprises, indique si elle est proposée pour les nouveaux comptes. Une application non cochée est laissée de côté ; les comptes qui se connectent déjà avec elle continuent de fonctionner. Une application peut être supprimée dès qu'aucun compte ne l'utilise. Les Propriétés d'un compte indiquent avec quoi il se connecte. Si le serveur de messagerie refuse le jeton d'une application de connexion, vérifiez que ses autorisations (scopes) donnent accès à la messagerie.

Paramètres de sécurité

Paramètre Signification
SSL/TLS La connexion est chiffrée dès le début. Généralement port 993 pour IMAP et 465 pour SMTP.
STARTTLS La connexion est chiffrée juste après son ouverture. Généralement port 143 pour IMAP et 587 pour SMTP. Inbox Classic refuse de continuer si le serveur ne propose pas de chiffrement.
Aucune (non chiffrée) Votre mot de passe et votre courrier circulent lisibles par quiconque sur le réseau. Ne l'utilisez que pour un serveur sur votre propre ordinateur ou réseau ; Inbox Classic avertit avant de l'utiliser.

2. Lire le courrier

La fenêtre a trois parties : vos comptes et dossiers à gauche, les messages du dossier sélectionné en haut à droite, et le message sélectionné en dessous. Faites glisser les bordures entre elles pour changer leur taille.

  • Chaque dossier a son icône, et les dossiers contenant des messages non lus sont affichés en gras, avec le nombre de messages non lus après le nom. Un compte réduit, ou un dossier réduit contenant des dossiers, est en gras avec les messages non lus des dossiers qu'il cache (Courrier indésirable et Éléments supprimés ne comptent pas), pour que le nouveau courrier ne soit jamais hors de vue. La barre grise au-dessus des volets et le titre de la fenêtre nomment le dossier sélectionné.
  • Avec deux comptes ou plus, Toutes les boîtes en haut de la liste des dossiers montre le courrier de la Boîte de réception de chaque compte dans une seule liste, le plus récent d'abord, avec une colonne Compte qui nomme le compte de chaque message. Répondre, Transférer, Déplacer et Supprimer agissent sur un message dans son propre compte, et un nouveau message part du compte du message sélectionné. Marquer tous les messages comme lus y marque chaque Boîte de réception comme lue. Son menu contextuel n'a que Marquer tous les messages comme lus : on ne peut pas y créer de dossiers ni y importer de messages, car ce n'est pas un dossier d'un seul compte.
  • Les messages non lus sont en gras dans la liste. Un message est marqué comme lu après avoir été affiché une seconde. Utilisez Marquer comme lu et Marquer comme non lu (Ctrl+Q marque comme lu) pour le changer vous-même. Édition > Marquer tous les messages comme lus (Ctrl+Shift+A), ou Marquer tous les messages comme lus dans le menu contextuel d'un dossier, marque comme lu chaque message du dossier.
  • La colonne du trombone montre les messages qui ont des pièces jointes, la colonne de l'indicateur ceux qui ont un indicateur.
  • Dans Éléments envoyés et Brouillons, la liste indique dans la colonne À à qui chaque message est adressé, au lieu de son expéditeur.
  • Double-cliquez sur un message (ou sélectionnez-le et appuyez sur Enter) pour l'ouvrir dans une fenêtre à lui, tel que le volet de lecture le montre, avec Répondre, Répondre à tous, Transférer, Imprimer, Supprimer, Archiver et Indésirable. Précédent et Suivant parcourent la liste d'où il a été ouvert. Un brouillon s'ouvre plutôt pour être terminé.
  • Affichage > Message suivant et Message précédent descendent et remontent la liste sans la souris ; Message non lu suivant (ou N dans la liste) trouve le prochain message que vous n'avez pas lu et, quand le dossier n'en a plus, propose le dossier suivant qui en a. Affichage > Aller au dossier ouvre n'importe quel dossier de n'importe quel compte, trouvé en tapant une partie de son nom. Édition > Rechercher dans ce message trouve des mots dans le message affiché.
  • Un avis de non-remise (un message revenu) porte dans la liste une marque de non-distribution, et l'ouvrir affiche au-dessus une carte : si le message n'a pas été distribué ou est seulement retardé, chaque destinataire avec la raison en termes simples et ce que vous pouvez faire, et les mots du serveur sous Détails. Afficher le message revenu sélectionne le message que vous avez envoyé. La raison est trouvée sur votre ordinateur ; rien n'est envoyé nulle part.
  • Le courrier d'une marque qui publie un logo (BIMI) affiche ce logo à côté de l'en-tête, mais seulement si votre serveur de messagerie a vérifié que le courrier vient bien du domaine de la marque (DMARC) et a approuvé le logo. Le logo vient avec le message ou, sinon, de l'adresse https de la marque une fois par session ; il est dessiné sur cet ordinateur à partir d'un fichier SVG vérifié, et rien d'autre n'en est chargé.
  • Une invitation de calendrier (un .ics dans le message) affiche son événement au-dessus du texte : ce que c'est (une invitation, une mise à jour ou une annulation), quand dans votre propre fuseau horaire, où, qui l'organise et comment il se répète. Ouvrir dans le calendrier l'ouvre dans votre programme de calendrier, où vous pouvez l'accepter.
  • Un message d'une liste de diffusion qui indique comment la quitter a Se désabonner à droite de son en-tête. Cliquer dessus dit ce qui va se passer et demande d'abord. Quand le serveur de la liste a signé le message pour cela (DKIM, comme le demande la RFC 8058), Inbox Classic demande à la liste d'arrêter, sans page ni message ; sinon il écrit le message que la liste attend pour que vous l'envoyiez, ou ouvre la page de la liste dans votre navigateur.
  • Fichier > Propriétés (Alt+EnterCtrl+Alt+U) affiche les en-têtes Internet du message : qui l'a envoyé, par quels serveurs, et quand. Affichage > Code source du message (Ctrl+U) affiche le message entier tel que le serveur le conserve : chaque en-tête et chaque partie, sous forme de texte. Enregistrer sous dans cette fenêtre l'enregistre comme fichier .eml.
  • Cliquez avec le bouton droit sur un message (ou appuyez sur la touche menu) pour voir ce que vous pouvez en faire : répondre, transférer, le marquer comme lu ou non lu, lui ajouter un indicateur, le marquer comme indésirable, le déplacer vers un dossier, le supprimer, l'enregistrer ou l'imprimer, et voir sa source ou ses propriétés.
  • Cliquez sur un en-tête de colonne pour trier selon celle-ci ; cliquez de nouveau pour inverser l'ordre.
  • Le champ de recherche à droite de la barre d'outils (Ctrl+Shift+F) trouve, au fil de la frappe, des messages dans chaque dossier de chaque compte d'après les mots de leur objet, les personnes qui les envoient et les reçoivent, les noms de leurs fichiers et leur texte. Une barre jaune au-dessus de la liste indique combien il en a trouvé pour quels mots, avec Effacer la recherche à sa droite, et la barre du dossier indique où il cherche. Les résultats forment une seule liste, avec une colonne Dossier indiquant où se trouve chaque message. Les mots correspondent là où les mots commencent (budg trouve budget), et les accents et la casse ne comptent pas. Esc, le × au bout du champ ou le fait de le vider affiche de nouveau le dossier, tout comme le choix d'un dossier.
  • La recherche accepte ce qu'accepte la zone de recherche de Gmail, ainsi is:unread liste les messages non lus et in:inbox ne cherche que dans la Boîte de réception : "expression exacte", -mot pour exclure, ceci OR cela, from:, to: (aussi cc:, bcc:), subject:, filename:, is:unread, is:read, is:starred, is:answered, is:bounce, has:attachment, in:inbox, in:sent, in:drafts, in:trash, in:spam, in:anywhere ou in: et le nom d'un dossier, before:2025/01/31, after:2025/01/01, older_than:2d (ou 3m, 1y), newer_than:1m, larger:5M et smaller:100k. Pointez le champ de recherche pour les voir.
  • La recherche fonctionne sur cet ordinateur, sans interroger le serveur. Inbox Classic lit pour elle le texte de chaque message en arrière-plan, les plus récents d'abord, en ne récupérant que le texte (ni pièces jointes ni images, et les messages restent non lus). Juste après l'ajout d'un compte, les messages sont trouvés tout de suite par leur objet, leurs personnes et leurs noms de fichiers, et par leur texte au fur et à mesure de sa lecture ; la barre du dossier indique combien il en reste à lire.
  • Supprimer (la barre d'outils, Édition > Supprimer le message ou la touche Del dans la liste) déplace le message vers Éléments supprimés ; le supprimer de là l'efface définitivement, après confirmation. (Sur un serveur sans l'extension UIDPLUS, la suppression définitive efface aussi les autres messages de ce dossier qu'un autre programme de messagerie a marqués comme supprimés.) Édition > Déplacer vers un dossier (Ctrl+Shift+V) le déplace vers un autre dossier, du même compte ou d'un autre, et Édition > Copier vers un dossier l'y copie. Les deux montrent les dossiers de tous les comptes dans une arborescence : tapez une partie d'un nom dans la zone au-dessus pour trouver un dossier, les dossiers utilisés en dernier sont en haut sous Récents, et Nouveau dossier en crée un. Le faire glisser de la liste sur un dossier de l'arborescence le déplace aussi ; maintenez Ctrl en le relâchant pour le copier à la place. Un message qui va vers un autre compte est d'abord copié sur le serveur de ce compte, avec ses indicateurs et sa date, et seulement ensuite retiré de son propre serveur, de sorte qu'il ne se perd jamais en chemin : la barre d'état indique où en est le transfert, et si la connexion tombe ou si vous quittez, il reprend à la prochaine relève du courrier. (Un message déplacé hors d'un dossier Gmail reste dans Tous les messages de Gmail, car Gmail y garde chaque message.) Un dossier au-dessus duquel vous le maintenez un instant s'ouvre, et l'arborescence défile à ses bords haut et bas ; Esc annule le glisser. Indésirable dans la barre d'outils (Message > Marquer comme indésirable, Ctrl+J) déplace un message vers Courrier indésirable et indique au serveur qu'il est indésirable (le mot-clé $Junk, dont les filtres anti-spam apprennent) ; dans Courrier indésirable, le bouton est Non indésirable, qui le remet dans la Boîte de réception. Message > Ajouter un indicateur au message lui ajoute un indicateur (! dans la liste) ou le retire. Message > Indicateur lui met un indicateur de couleur : rouge, orange, jaune, vert, bleu, violet ou gris, comme Apple Mail, de sorte qu'une couleur mise dans l'un apparaît dans l'autre (les autres programmes de messagerie montrent un indicateur simple). Effacer l'indicateur retire l'indicateur et sa couleur. Tout cela se fait aussi sur le serveur, pour que vos autres programmes de messagerie le voient.
  • Archiver dans la barre d'outils (Message > Archiver, ou A dans la liste des messages) sort un message de la Boîte de réception, ou d'un de vos dossiers, et le range dans Archives ; la première fois, ce dossier est créé si le compte n'en a pas. Avec Gmail, tous les libellés sont retirés à la place, et le message ne reste que dans Tous les messages (envoyé, suivi et important restent). Édition > Annuler le remet en place, avec ses libellés.
  • Pour travailler sur plusieurs messages à la fois, maintenez Ctrl et cliquez sur chacun d'eux, ou cliquez sur le premier et maintenez Shift en cliquant sur le dernier (Shift avec les flèches fait de même) ; Édition > Sélectionner tout (Ctrl+A) sélectionne chaque message de la liste. Le volet de lecture indique alors combien sont sélectionnés et combien d'entre eux sont non lus ou ont un indicateur, et la barre d'état les compte aussi. Marquer comme lu ou non lu, l'indicateur, Indésirable, Supprimer et Déplacer vers un dossier agissent sur tous, et en faire glisser un les fait tous glisser ; Répondre, Imprimer et les commandes de ce genre n'agissent que sur un seul message.
  • Édition > Annuler (Ctrl+Z) annule le dernier déplacement, la dernière suppression ou le dernier marquage comme indésirable, quel que soit le nombre de messages : ils retournent dans les dossiers d'où ils venaient, et y sont sélectionnés une fois revenus. Le menu indique ce qu'il annule (Annuler le déplacement), et la barre d'état indique ce qui a été fait. Un message supprimé définitivement ne peut pas revenir.
  • Fichier > Dossier, ou un clic droit dans la liste des dossiers, crée un Nouveau dossier dans le dossier sélectionné (en haut d'un compte quand le compte est sélectionné), et Renomme ou Supprime le dossier sélectionné. Supprimer un dossier supprime les messages qu'il contient, après confirmation. La Boîte de réception et les dossiers spéciaux (Éléments envoyés, Brouillons, Éléments supprimés et autres) restent tels quels. Fichier > Dossier > Vider le dossier, ou Vider le dossier dans le menu contextuel d'Éléments supprimés ou de Courrier indésirable, supprime définitivement tous les messages qu'il contient, après avoir demandé combien partent ; on ne peut pas l'annuler.
  • Au-dessus du message figurent son expéditeur, sa date, ses destinataires et son objet.

Messages précédents dans les réponses

Une réponse emporte souvent les messages qui la précèdent. Inbox Classic les replie derrière un bouton ••• sous ce que l'expéditeur a écrit ; cliquez dessus pour les voir. Seul le texte qui est clairement un message précédent est replié, tout ce qui est incertain reste visible.

Messages pas encore téléchargés

Un message est téléchargé la première fois que vous l'ouvrez, donc juste après l'ajout d'un compte la plupart des messages ne sont pas encore là. Son expéditeur et son objet s'affichent tout de suite ; si le message met plus d'un instant, le volet indique qu'il est en cours de téléchargement. Si le serveur de messagerie est inaccessible, le volet indique pourquoi, et le message est téléchargé tout seul dès que le compte est de nouveau en ligne. Pour essayer tout de suite, cliquez sur la barre au-dessus du messagecliquez sur Réessayer.

3. Images, liens et pièces jointes

Images

Les images que l'expéditeur garde sur Internet ne sont pas téléchargées, car les télécharger indique à l'expéditeur que vous avez ouvert le message, quand et d'où. Les images envoyées dans le message sont affichées. Quand un message contient de telles images, une barre jaune indique qu'elles ont été bloquées ; pour les voir dans un message de confiance, cliquez sur la barre (ou Affichage > Télécharger les images).

Liens et scripts

Les scripts des messages ne s'exécutent jamais. Cliquer sur un lien l'ouvre dans votre navigateur web, jamais dans Inbox Classic. Avant de saisir un mot de passe sur une page atteinte depuis un courrier, vérifiez l'adresse dans votre navigateur.

Pièces jointes

Quand un message a des pièces jointes, un trombone avec le nombre de fichiers apparaît à droite de l'en-tête du message. Cliquez dessus et choisissez un fichier pour l'enregistrer, ou Enregistrer les pièces jointes pour les enregistrer toutes dans un dossier (un fichier de même nom déjà présent est conservé, et le nouveau reçoit un numéro). Les fichiers sont enregistrés, jamais ouverts depuis Inbox Classic. Il propose un nom de fichier sûr : les noms de dossiers, les caractères que Windows n'autoriseWindows et d'autres systèmes n'autorisent pas et les caractères qui peuvent faire paraître un nom autre qu'il n'est sont retirés.

N'ouvrez des pièces jointes que de personnes dont vous les attendez. Un programme (.exe, .js, .vbs, .msi, .bat, .scr) ou un document qui vous demande d'« activer le contenu » peut prendre le contrôle de votre ordinateur.

Enregistrer, imprimer et importer des messages

  • Fichier > Enregistrer sous enregistre le message affiché comme fichier .eml, que les autres programmes de messagerie ouvrent. Avec plusieurs messages sélectionnés, il demande un dossier et y enregistre chacun, nommé d'après son objet ; un fichier déjà présent n'est jamais remplacé (le nouveau s'appelle alors Déjeuner (2).eml).
  • Faites glisser des messages de la liste sur le bureau ou dans une fenêtre de dossier du Finder pour les y enregistrer de la même façon comme fichiers .eml. Un message pas encore téléchargé est téléchargé pour cela.
  • Fichier > Importer des messages place des fichiers .eml dans le dossier sélectionné, sur le serveur aussi. Faire glisser des fichiers .eml sur un dossier de la liste des dossiers fait de même. Un fichier qui n'est pas un message n'est pas importé.
  • Fichier > Imprimer (Ctrl+P) ouvre l'aperçu avant impression du message affiché dans une fenêtre au-dessus d'Inbox Classic : choisissez l'imprimante (ou l'enregistrement en PDF), les copies et les pages, et le message s'imprime avec son expéditeur, sa date, ses destinataires et son objet. La fenêtre se ferme une fois l'impression faite ou annulée.

4. Écrire, répondre et transférer

  • Écrire (Ctrl+N) commence un nouveau message depuis le compte du dossier sélectionné.
  • Cc et Cci n'apparaissent que lorsqu'ils contiennent quelqu'un ; les boutons Cc et Cci au bout de la ligne À (Alt+C, Alt+B) les ouvrent. La ligne Joindre apparaît dès qu'un fichier est joint.
  • Vous écrivez toujours avec la mise en forme à portée de main. Un message sans aucune mise en forme (ni gras, ni couleurs, listes, liens ou images) part en texte brut, que tous les programmes de messagerie affichent de la même façon ; avec une mise en forme, il part en HTML avec une copie en texte brut. Une réponse ou un transfert suit l'original : à un message en texte brut, il est aussi en texte brut (l'original cité avec >) sauf si vous mettez quelque chose en forme ; à un message HTML, il est en HTML.
  • Transférer avec plusieurs messages sélectionnés écrit un seul nouveau message avec tous joints comme fichiers .eml, son objet celui du premier.
  • De, en haut du message, indique de qui il part : le nom et l'adresse du compte. Une réponse ou un transfert part du compte où se trouve le message d'origine. Avec plusieurs comptes, choisissez-en un autre ici ; le message est alors envoyé avec les serveurs de ce compte et conservé dans ses Éléments envoyés (ou Brouillons). Le nom que les autres voient est le nom d'affichage du compte, modifiable dans Fichier > Comptes > Propriétés.
  • Répondre (Ctrl+R) répond à l'expéditeur, Répondre à tous (Ctrl+Shift+R) à tous ceux à qui le message a été envoyé, Transférer (Ctrl+F) le fait suivre.
  • Dans une réponse, le message d'origine est replié derrière un bouton ••• sous votre texte, pour que vous ne voyiez que ce que vous écrivez. Cliquez dessus (ou sélectionnez tout avec Ctrl+A) pour le mettre dans votre texte, où vous pouvez le raccourcir ; il est envoyé avec votre réponse dans tous les cas. Dans un transfert, l'original est dans le texte dès le début, puisque c'est ce que vous envoyez.
  • La barre au-dessus du texte le met en forme : la police et sa taille, Gras, Italique, Souligné (ou Ctrl+B, Ctrl+I, Ctrl+U), Couleur, listes numérotées et à puces, retrait réduit et augmenté (« et »), alignement, Lien pour une adresse web sur le texte sélectionné, Ligne pour une ligne de séparation et Image pour placer une image dans le texte (ou faites glisser un fichier image depuis l'Explorateurle Finderle gestionnaire de fichiers dans le texte : elle se place là où vous la déposez). Les images partent dans le message, pas comme des pièces jointes séparées. Le message part en HTML mis en forme avec une copie en texte brut pour les programmes de messagerie qui n'affichent que du texte.
  • Liens : avec le curseur dans un lien, ou la souris au-dessus, la barre d'état en bas indique où il mène. Ctrl+clic sur un lien l'ouvre dans votre navigateur. Lien (ou Ctrl+K) sur un lien affiche son adresse à modifier ; videz l'adresse pour retirer le lien et garder son texte. Cliquez avec le bouton droit sur un lien pour Ouvrir le lien, Modifier le lien et Supprimer le lien.
  • Les mots mal orthographiés sont soulignés ; cliquez dessus avec le bouton droit pour des suggestions. Couper, copier et coller fonctionnent comme partout.
  • Séparez plusieurs adresses dans À, Cc et Cci par des virgules, par exemple Marie Martin <marie@example.com>, jean@example.com. Mettez entre guillemets un nom contenant une virgule : "Martin, Marie" <marie@example.com>.
  • Les personnes en Cci reçoivent le message, mais les autres destinataires ne les voient pas.
  • Joindre ajoute des fichiers, tout comme les faire glisser depuis l'Explorateurle Finderle gestionnaire de fichiers sur les champs d'adresse, ou un fichier qui n'est pas une image sur le texte. Ils sont listés dans la ligne Joindre avec leur taille ; pour en retirer un, sélectionnez-le et appuyez sur Del, ou cliquez dessus avec le bouton droit et choisissez Supprimer. Les fichiers sont lus au moment de l'envoi du message.
  • Envoyer place le message dans la Boîte d'envoi et l'envoie aussitôt. S'il ne peut pas partir (pas de connexion, le serveur le refuse), il reste dans la Boîte d'envoi et part au prochain Envoyer/Recevoir ; rien de ce que vous avez écrit n'est perdu. Envoyer/Recevoir s'exécute aussi tout seul toutes les dix minutes. Le milieu de la barre d'état de la fenêtre principale indique ce qui se passe avec le courrier que vous envoyez : Envoi pendant qu'il part, Envoyé avec son objet et l'heure une fois que le serveur l'a pris, ou qu'il attend dans la Boîte d'envoi. Outils > Boîte d'envoi liste ce qui attend, avec la raison pour laquelle cela n'est pas parti, et l'envoie ou le supprime.
  • Ctrl+Enter envoie depuis le texte.
  • Enregistrer (ou Ctrl+S) garde le message dans le dossier Brouillons du compte, sur le serveur, pour le terminer plus tard ; enregistrer de nouveau remplace la copie enregistrée avant. La barre d'état du message indique Enregistré dans Brouillons avec l'heure une fois que le serveur l'a, ou pourquoi il n'a pas été enregistré. Fermer un message modifié demande s'il faut enregistrer les modifications : Oui l'enregistre dans Brouillons, Non le jette, Annuler revient au message. Pour continuer à écrire, double-cliquez sur le brouillon dans Brouillons (ou sélectionnez-le et appuyez sur Enter) : il s'ouvre avec ses destinataires, son texte et ses fichiers joints. Une fois envoyé, le brouillon est retiré des Brouillons. Un message que vous écrivez est une fenêtre à part dans la barre des tâches : vous pouvez revenir à la fenêtre principale et lire du courrier pendant qu'il reste ouvert. Fermer Inbox Classic ferme d'abord les messages que vous écrivez, en demandant pour ceux qui ont des modifications.
  • Envoyer envoie le message. Si une adresse est mal saisie ou qu'un fichier a disparu, Inbox Classic le dit et garde le message ouvert pour que vous puissiez corriger. Une copie de chaque message envoyé est conservée dans Éléments envoyés.
  • Les liens de messagerie (mailto:) sur les pages web et dans d'autres programmes ouvrent un nouveau message dans Inbox Classic une fois qu'il est votre programme de messagerie par défaut : Outils > Définir comme programme de messagerie par défaut ouvre la page des Paramètres Windows où vous le choisissez.en fait celui par défaut. Les adresses, l'objet et le texte du lien sont remplis ; rien d'autre du lien n'est utilisé.
  • Taper dans À, Cc ou Cci liste les personnes possibles, celles à qui vous écrivez le plus d'abord, puis celles qui vous écrivent ; la liste connaît tout le monde dans le courrier qu'a Inbox Classic (pas le Courrier indésirable). Choisissez avec les flèches et prenez-en une avec Enter ou Tab (ou un clic) ; Esc ferme la liste, et Shift+Del en retire définitivement la personne choisie.
  • Une signature pour chaque compte : Fichier > Comptes, sélectionnez le compte, puis Signature. Elle s'écrit avec la même mise en forme qu'un message (gras, couleurs, liens, une image). Les nouveaux messages, réponses et transferts du compte commencent par elle, sous une ligne vide pour écrire et la ligne habituelle --, au-dessus du message cité. Choisir un autre compte dans De met la signature de ce compte à sa place.

5. Recevoir le nouveau courrier

Inbox Classic vérifie chaque compte au démarrage puis toutes les dix minutes. Cliquez sur Envoyer/Recevoir ou appuyez sur F5Ctrl+Shift+N pour vérifier maintenant ; la flèche à côté de Envoyer/Recevoir vérifie un seul compte, et celle à côté de Écrire commence un message depuis le compte de votre choix. La barre d'état en bas indique ce qu'il fait et le dernier problème rencontré.

Il surveille aussi la Boîte de réception de chaque compte, pour que le nouveau courrier apparaisse dès son arrivée, pas seulement à la prochaine vérification. Tant que sa fenêtre n'est pas au premier plan, une notification indique qui a écrit et à quel sujet ; cliquez dessus pour ouvrir le message. Outils > Signaler les nouveaux messages désactive et active les notifications.

Fermer la fenêtre laisse Inbox Classic tourner dans la zone de notification, où il continue de relever le courrier ; son icône y indique combien de messages sont non lus, tout comme un nombre sur son bouton de la barre des tâches. Cliquez sur l'icône pour le rouvrir ; cliquez avec le bouton droit pour Vérifier les nouveaux messages et Quitter. Fichier > Quitter le ferme.

Fermer la fenêtre laisse Inbox Classic tourner dans le Dock, où il continue de relever le courrier ; l'icône du Dock indique combien de messages sont non lus dans les Boîtes de réception. Cliquez sur l'icône du Dock pour rouvrir la fenêtre. Inbox Classic > Quitter Inbox Classic (Ctrl+Q) le ferme.

Fermer la fenêtre laisse Inbox Classic tourner dans la barre supérieure (Ubuntu y affiche son icône), où il continue de relever le courrier ; le menu de l'icône contient Ouvrir Inbox Classic, Vérifier les nouveaux messages et Quitter, et le dock indique combien de messages sont non lus dans les Boîtes de réception. Là où le bureau n'a pas de place pour l'icône, fermer la fenêtre ferme Inbox Classic. Quitter dans le menu principal le ferme.

Options et langue

  • Outils > OptionsInbox Classic > RéglagesPréférences dans le menu principal choisit la langue des fenêtres : Langue du système (celle de votre système, l'anglais si Inbox Classic ne l'a pas), ou English, Deutsch, Eesti, Español ou Français. 7. Agents d'IA

Si vous utilisez un agent d'IA (Claude, Cursor ou un autre programme qui parle le Model Context Protocol, MCP), vous pouvez le laisser lire et organiser votre courrier ici. Il n'y a pas d'IA dans Inbox Classic et rien n'est envoyé à un service d'IA : un agent ne travaille que lorsque vous laissez entrer son programme, et seulement avec les comptes que vous choisissez.

  • Connexion. Outils > Agents d'IA > Comment connecter un agent donne les lignes à ajouter aux paramètres de votre agent (pour Claude Desktop : Settings > Developer > Edit Config). L'agent lance Inbox Classic avec --mcp, ce qui le relie à l'Inbox Classic en cours d'exécution, ou en démarre un en arrière-plan. Seuls les programmes exécutés sous votre compte sur cet ordinateur peuvent l'atteindre.
  • La première fois que l'agent d'un programme se connecte, Inbox Classic vous demande, en nommant le programme, ce qu'il peut faire : lire le courrier ; l'organiser (marquer comme lu, indicateur, indésirable, déplacer, archiver, supprimer vers Éléments supprimés) ; écrire des brouillons que vous enverrez ; et envoyer du courrier, chaque message seulement après votre accord. Choisissez les comptes qu'il peut voir. Ne pas autoriser refuse le programme, et la question ne vous est plus posée.
  • Envoi. Chaque message qu'un agent veut envoyer vous est d'abord montré, avec chaque destinataire par son adresse et les adresses auxquelles vous n'avez jamais écrit marquées. Envoyer s'active après un instant ; Modifier d'abord l'ouvre dans un nouveau message à changer ; Ne pas envoyer est le choix par défaut. Ce que vous envoyez attend 30 secondes dans la Boîte d'envoi, où vous pouvez encore le supprimer.
  • Ce qui change apparaît aussitôt dans les fenêtres, comme si vous l'aviez fait. Un agent ne supprime jamais rien définitivement et ne modifie jamais les paramètres de vos comptes. Lire un message ne le marque pas comme lu.
  • Outils > Agents d'IA liste les programmes que vous avez laissés entrer ou refusés (Modifier ce que l'un peut faire, ou le Supprimer pour qu'on vous redemande), et tout ce que les agents ont fait, le plus récent d'abord. Annuler reprend un état lu, un indicateur, un déplacement ou une suppression, et un message encore dans la Boîte d'envoi. Laisser les agents d'IA se connecter les désactive tous d'un coup.
  • Faites attention à ce que vous demandez. Le courrier est écrit par d'autres, et un message peut tenter de convaincre un agent de faire quelque chose : transférer votre courrier, le supprimer, écrire à quelqu'un. Inbox Classic cache aux agents le texte qu'un message vous cache et leur dit que le courrier n'est pas une instruction, mais un agent peut tout de même être trompé. Lisez chaque message qu'il veut envoyer avant d'accepter, et ne laissez un agent envoyer que si vous en avez besoin. Un agent qui a aussi d'autres outils (naviguer sur le web, lire vos fichiers) pourrait transmettre ce qu'il lit par leur biais ; Inbox Classic ne peut pas les voir.

8. Quand quelque chose ne fonctionne pas

« authentication failed » ou Inbox Classic redemande le mot de passe

Le serveur a refusé le mot de passe. Saisissez-le de nouveau ; pour Gmail et Outlook.com, utilisez un mot de passe d'application ou connectez-vous via le navigateur (voir Ajouter un compte). Si votre fournisseur demande une deuxième étape quand vous vous connectez sur le web, il lui faut aussi un mot de passe d'application pour les programmes de messagerie. Pour un compte qui se connecte via le navigateur, Inbox Classic propose de se reconnecter.

« TLS error » ou une erreur de certificat

Inbox Classic n'a pas pu confirmer qu'il parle au vrai serveur, il n'a donc pas envoyé votre mot de passe. Vérifiez le nom du serveur dans les paramètres du compte : ce doit être le nom pour lequel le certificat du serveur est établi (souvent imap.fournisseur.fr, pas votre propre domaine). Sur un réseau qui inspecte le trafic chiffré, adressez-vous à son administrateur.

« the server does not offer STARTTLS »

Le compte est réglé sur STARTTLS mais le serveur n'a pas proposé de chiffrement. Essayez SSL/TLS sur le port 993 (IMAP) ou 465 (SMTP). Si rien d'autre ne fonctionne, le serveur ne peut pas être utilisé en toute sécurité.

« the server takes the password only over an encrypted connection »

Le serveur sortant (SMTP) est réglé sur Aucune (non chiffrée). Votre mot de passe est bon ; changez la sécurité SMTP en STARTTLS (port 587) ou SSL/TLS (port 465).

« connection error » ou « the server did not answer in time »

Vérifiez votre connexion Internet, le nom du serveur et le port. Les pare-feu bloquent parfois les ports de messagerie, le port 25 en particulier ; utilisez 465 ou 587 pour l'envoi. Inbox Classic réessaie à la prochaine vérification.

Un message qui ne peut pas être affiché

Certains messages sont endommagés ou construits d'une façon qu'aucun programme de messagerie ne peut lire. Inbox Classic affiche une note à la place du message ; le reste de votre courrier n'est pas concerné.
