Hilfe zu Inbox Classic

Inbox Classic liest und sendet E-Mail von IMAP- und SMTP-Konten: Gmail, Outlook.com, Fastmail, dem Mailserver Ihrer Firma und den meisten anderen. Es behält eine Kopie Ihrer E-Mail auf diesem Computer, sodass Sie bereits Heruntergeladenes auch ohne Verbindung lesen können.

1. Ein Konto hinzufügen

Beim ersten Start fragt Inbox Classic nach einem Konto. Um später ein weiteres hinzuzufügen, wählen Sie Datei > Neues Konto. Bei jedem Start öffnet es den Posteingang des ersten Kontos mit der neuesten Nachricht ausgewählt, oder bei zwei oder mehr Konten Alle Posteingänge mit der neuesten Nachricht aller Konten.

  1. Für Gmail, Google Workspace, Outlook.com oder Microsoft 365 klicken Sie auf Mit Google anmelden oder Mit Microsoft anmelden und melden sich im Browserfenster an, das sich öffnet. Das ist alles: Das Konto ist das, bei dem Sie sich angemeldet haben, und trägt Ihren Namen bei Google oder Microsoft, sofern Sie keinen eingegeben haben. Siehe Gmail und Outlook.com unten. Eine blasse Schaltfläche ist auf diesem Computer ausgeschaltet; Warum? darunter sagt, warum.
  2. Um sich mit einer eigenen Anmelde-App anzumelden (siehe Ihre eigene Anmelde-App unten), klicken Sie auf Weitere Anmeldeoptionen und wählen sie aus, oder auf Anmelde-App hinzufügen. Geben Sie zuerst Ihre Adresse ein, dann beginnt die Seite des Anbieters damit.
  3. Für jedes andere Konto geben Sie Ihren Namen so ein, wie andere ihn sehen sollen, und Ihre E-Mail-Adresse, und klicken auf Weiter.
  4. Inbox Classic sucht die Einstellungen Ihres E-Mail-Anbieters: beim Anbieter, der die E-Mail Ihrer Domäne verarbeitet, in den DNS-Einträgen Ihrer Domäne, in der Einstellungsdatei Ihres Anbieters, in der Anbieterliste von Thunderbird und für Exchange über Microsoft Autodiscover. Das dauert einige Sekunden; Abbrechen überspringt es. Einer Adresse bei Google oder Microsoft wird auch hier deren Anmeldeschaltfläche angeboten.
  5. Wenn Ihr Anbieter statt Ihres normalen Passworts ein App-Passwort verlangt, sagt Inbox Classic das und bietet an, die Anleitung zu öffnen.
  6. Geben Sie Ihr Passwort ein, prüfen Sie die gefundenen Servereinstellungen und klicken Sie auf Fertigstellen. Wurde nichts gefunden, trägt es die üblichen Namen ein (imap. und smtp. gefolgt von Ihrer Domäne); vergleichen Sie sie mit den Angaben Ihres Anbieters.

Ein Konto ändern oder entfernen

Datei > Konten listet Ihre Konten auf. Eigenschaften (oder ein Doppelklick) ändert Namen, Adresse, Server und Passwort eines Kontos; lassen Sie das Passwort leer, um es zu behalten. Entfernen (oder die Taste Del) nimmt das Konto mit der dafür heruntergeladenen E-Mail und seinem gespeicherten Passwort aus Inbox Classic heraus; die E-Mail auf dem Server bleibt. Hinzufügen fügt ein weiteres Konto hinzu.

Gmail und Outlook.com

Diese Anbieter nehmen Ihr normales Passwort von E-Mail-Programmen nicht an. Entweder:

  • Sie melden sich mit Mit Google anmelden oder Mit Microsoft anmelden über Ihren Webbrowser an: Ihr Passwort wird auf der eigenen Seite von Google oder Microsoft eingegeben, und Inbox Classic sieht es nie (eine Microsoft 365-Organisation muss Inbox Classic eventuell erst zulassen: Microsoft zeigt dann Administratorgenehmigung erforderlich, und Inbox Classic nennt Ihnen die Adresse, unter der Ihr Administrator es genehmigt); oder
  • Sie erstellen in den Sicherheitseinstellungen Ihres Kontos ein App-Passwort (Google: Sicherheit > Bestätigung in zwei Schritten > App-Passwörter; Microsoft: Sicherheit > Erweiterte Sicherheitsoptionen > App-Passwörter), geben Ihre Adresse ein, klicken auf Weiter, dann auf App-Passwort verwenden, und geben das App-Passwort statt Ihres normalen ein.

Ihre eigene Anmelde-App

Die Anmeldung über den Browser verwendet einen beim Anbieter registrierten OAuth-Client. Inbox Classic hat eigene für Google und Microsoft. Google lässt nur die Testbenutzer von Inbox Classic damit anmelden, bis Google die App überprüft hat, daher ist Mit Google anmelden anfangs ausgeschaltet. Sie können einen eigenen Client registrieren (mit Ihrem eigenen Google Cloud-Projekt, Ihrem Microsoft Entra-Mandanten oder bei jedem Anbieter, der OpenID Connect unterstützt) und ihn als Anmelde-App hinzufügen:

  1. Öffnen Sie Datei > Konten und klicken Sie auf Anmelde-Apps, dann auf Hinzufügen.
  2. Klicken Sie nach Voreinstellungen für auf Google oder Microsoft, um Aussteller, Berechtigungen und Server einzutragen, oder geben Sie sie für einen anderen Anbieter ein. Das Feld unten sagt, wie Sie dort einen Client registrieren, und nennt die zu registrierende Weiterleitungs-URI; Kopieren kopiert sie.
  3. Geben Sie die Client-ID ein, und das Client-Geheimnis, falls der Anbieter Ihnen eines gegeben hat (es wird in der Windows-AnmeldeinformationsverwaltungIhrem SchlüsselbundIhrem Schlüsselbund aufbewahrt und nie wieder angezeigt). Prüfen liest die Einstellungen des Anbieters, um festzustellen, ob der Aussteller stimmt; OK tut das vor dem Speichern ebenfalls.
  4. Fügen Sie das Konto mit Weitere Anmeldeoptionen auf der ersten Seite von Datei > Neues Konto hinzu.

In Anmelde-Apps sagt das Kontrollkästchen jeder App, auch der eingebauten, ob sie für neue Konten angeboten wird. Eine App ohne Häkchen wird weggelassen; die Konten, die sich bereits damit anmelden, funktionieren weiter. Eine App kann entfernt werden, sobald kein Konto sie mehr verwendet. Eigenschaften eines Kontos sagt, womit es sich anmeldet. Wenn der Mailserver das Token einer Anmelde-App ablehnt, prüfen Sie, ob ihre Berechtigungen (Scopes) Zugriff auf E-Mail geben.

Sicherheitseinstellungen

Einstellung Bedeutung
SSL/TLS Die Verbindung ist von Anfang an verschlüsselt. Meist Port 993 für IMAP und 465 für SMTP.
STARTTLS Die Verbindung wird gleich nach dem Öffnen verschlüsselt. Meist Port 143 für IMAP und 587 für SMTP. Inbox Classic bricht ab, wenn der Server keine Verschlüsselung anbietet.
Keine (unverschlüsselt) Ihr Passwort und Ihre E-Mail sind für jeden im Netzwerk lesbar. Verwenden Sie das nur für einen Server auf Ihrem eigenen Computer oder in Ihrem eigenen Netzwerk; Inbox Classic warnt vorher.

2. E-Mail lesen

Das Fenster hat drei Teile: Ihre Konten und Ordner links, die Nachrichten des ausgewählten Ordners oben rechts und die ausgewählte Nachricht darunter. Ziehen Sie die Grenzen dazwischen, um ihre Größe zu ändern.

  • Jeder Ordner hat sein Symbol, und Ordner mit ungelesenen Nachrichten erscheinen fett, mit der Zahl der ungelesenen Nachrichten nach dem Namen. Ein zugeklapptes Konto oder ein zugeklappter Ordner mit Unterordnern ist fett mit den ungelesenen Nachrichten der Ordner, die er verbirgt (Junk-E-Mail und Gelöschte Objekte zählen nicht), sodass neue E-Mail nie aus dem Blick gerät. Die graue Leiste über den Bereichen und der Fenstertitel nennen den ausgewählten Ordner.
  • Bei zwei oder mehr Konten zeigt Alle Posteingänge oben in der Ordnerliste die E-Mail aller Posteingänge in einer Liste, neueste zuerst, mit einer Spalte Konto, die das Konto jeder Nachricht nennt. Antworten, Weiterleiten, Verschieben und Löschen wirken auf eine Nachricht in ihrem eigenen Konto, und eine neue Nachricht beginnt mit dem Konto der ausgewählten. Alle als gelesen markieren markiert dort jeden Posteingang als gelesen. Sein Kontextmenü hat nur Alle als gelesen markieren: Darin können keine Ordner erstellt und keine Nachrichten importiert werden, da es kein Ordner eines einzelnen Kontos ist.
  • Ungelesene Nachrichten sind in der Liste fett. Eine Nachricht wird als gelesen markiert, nachdem sie eine Sekunde lang angezeigt wurde. Mit Als gelesen markieren und Als ungelesen markieren (Ctrl+Q markiert als gelesen) ändern Sie das selbst. Bearbeiten > Alle als gelesen markieren (Ctrl+Shift+A) oder Alle als gelesen markieren im Kontextmenü eines Ordners markiert jede Nachricht des Ordners als gelesen.
  • Die Spalte mit der Büroklammer zeigt, welche Nachrichten Anlagen haben, die Spalte mit der Fahne, welche gekennzeichnet sind.
  • In Gesendete Objekte und Entwürfe nennt die Liste in der Spalte An, an wen jede Nachricht geht, statt von wem sie kommt.
  • E-Mail einer Marke, die ein Logo veröffentlicht (BIMI), zeigt dieses Logo neben dem Kopf, aber nur, wenn Ihr Mailserver geprüft hat, dass die E-Mail wirklich von der Domäne der Marke kommt (DMARC), und das Logo bestätigt hat. Das Logo kommt mit der Nachricht oder, falls nicht, einmal pro Programmlauf von der https-Adresse der Marke; es wird auf diesem Computer aus einer geprüften SVG-Datei gezeichnet, und sonst wird nichts davon geladen.
  • Eine Kalendereinladung (eine .ics in der Nachricht) zeigt ihren Termin über dem Text: was sie ist (Einladung, Änderung oder Absage), wann in Ihrer Ortszeit, wo, wer sie organisiert und wie sie sich wiederholt. Im Kalender öffnen öffnet sie in Ihrem Kalenderprogramm, wo Sie sie annehmen können.
  • Eine Nachricht einer Mailingliste, die sagt, wie man sie verlässt, hat Abbestellen rechts in ihrem Kopf. Ein Klick darauf sagt, was geschehen wird, und fragt vorher. Hat der Server der Liste die Nachricht dafür signiert (DKIM, wie RFC 8058 es verlangt), bittet Inbox Classic die Liste ohne Seite oder Nachricht, aufzuhören; sonst schreibt es die Nachricht, die die Liste möchte, damit Sie sie senden, oder öffnet die Seite der Liste in Ihrem Browser.
  • Datei > Eigenschaften (Alt+EnterCtrl+Alt+U) zeigt die Internetkopfzeilen der Nachricht: wer sie gesendet hat, über welche Server und wann. Ansicht > Nachrichten-Quelltext (Ctrl+U) zeigt die ganze Nachricht so, wie der Server sie aufbewahrt: jede Kopfzeile und jeden Teil, als Text. Speichern unter in diesem Fenster speichert sie als .eml-Datei.
  • Klicken Sie mit der rechten Maustaste auf eine Nachricht (oder drücken Sie die Menütaste), um zu sehen, was Sie damit tun können: antworten, weiterleiten, als gelesen oder ungelesen markieren, kennzeichnen, als Junk markieren, in einen Ordner verschieben, löschen, speichern oder drucken und ihren Quelltext oder ihre Eigenschaften ansehen.
  • Klicken Sie auf eine Spaltenüberschrift, um danach zu sortieren; ein weiterer Klick kehrt die Reihenfolge um.
  • Das Suchfeld rechts in der Symbolleiste (Ctrl+Shift+F) findet beim Tippen Nachrichten in jedem Ordner jedes Kontos nach den Wörtern im Betreff, den Absendern und Empfängern, den Namen ihrer Dateien und ihrem Text. Eine gelbe Leiste über der Liste sagt, wie viele es für welche Wörter gefunden hat, mit Suche löschen rechts, und die Ordnerleiste sagt, wo es sucht. Die Ergebnisse sind eine Liste mit einer Spalte Ordner, die sagt, wo jede Nachricht ist. Wörter passen dort, wo Wörter beginnen (bud findet Budget), und Akzente sowie Groß- und Kleinschreibung spielen keine Rolle. Esc, das × am Ende des Felds oder das Leeren des Felds zeigt wieder den Ordner, ebenso die Wahl eines Ordners.
  • Die Suche versteht, was das Suchfeld von Gmail versteht, sodass is:unread die ungelesenen Nachrichten auflistet und in:inbox nur im Posteingang sucht: "genaue Wortgruppe", -wort zum Ausschließen, dies OR das, from:, to: (auch cc:, bcc:), subject:, filename:, is:unread, is:read, is:starred, is:answered, has:attachment, in:inbox, in:sent, in:drafts, in:trash, in:spam, in:anywhere oder in: und der Name eines Ordners, before:2025/01/31, after:2025/01/01, older_than:2d (oder 3m, 1y), newer_than:1m, larger:5M und smaller:100k. Zeigen Sie auf das Suchfeld, um sie zu sehen.
  • Die Suche arbeitet auf diesem Computer, ohne den Server zu fragen. Inbox Classic liest dafür im Hintergrund den Text jeder Nachricht, die neuesten zuerst, und holt nur den Text (keine Anlagen oder Bilder, und die Nachrichten bleiben ungelesen). Gleich nach dem Hinzufügen eines Kontos werden Nachrichten sofort nach Betreff, Personen und Dateinamen gefunden und nach ihrem Text, sobald er gelesen ist; die Ordnerleiste sagt, wie viele noch zu lesen sind.
  • Löschen (die Symbolleiste, Bearbeiten > Nachricht löschen oder die Taste Del in der Liste) verschiebt die Nachricht nach Gelöschte Objekte; dort gelöscht, wird sie nach einer Rückfrage endgültig entfernt. (Auf einem Server ohne die Erweiterung UIDPLUS entfernt das endgültige Löschen auch die anderen Nachrichten dieses Ordners, die ein anderes E-Mail-Programm als gelöscht markiert hat.) Bearbeiten > In Ordner verschieben (Ctrl+Shift+V) verschiebt sie in einen anderen Ordner, desselben Kontos oder eines anderen, und Bearbeiten > In Ordner kopieren kopiert sie dorthin. Beide zeigen die Ordner aller Konten in einem Baum: Geben Sie einen Teil eines Namens in das Feld darüber ein, um einen Ordner zu finden; die zuletzt verwendeten Ordner stehen oben unter Zuletzt verwendet, und Neuer Ordner erstellt einen. Auch das Ziehen aus der Liste auf einen Ordner im Baum verschiebt sie; halten Sie beim Loslassen Ctrl gedrückt, um sie stattdessen zu kopieren. Eine Nachricht, die in ein anderes Konto geht, wird zuerst mit ihren Kennzeichnungen und ihrem Datum auf den Server dieses Kontos kopiert und erst dann vom eigenen Server genommen, sodass sie unterwegs nie verloren geht: Die Statusleiste sagt, wie weit es ist, und wenn die Verbindung abbricht oder Sie das Programm beenden, geht es mit dem nächsten Abrufen weiter. (Eine aus einem Gmail-Ordner verschobene Nachricht bleibt in Gmails Alle Nachrichten, da Gmail jede Nachricht dort behält.) Ein Ordner, über dem Sie sie einen Moment halten, klappt auf, und der Baum rollt an seinem oberen und unteren Rand; Esc bricht das Ziehen ab. Junk in der Symbolleiste (Nachricht > Als Junk markieren, Ctrl+J) verschiebt eine Nachricht nach Junk-E-Mail und sagt dem Server, dass sie Junk ist (das Schlüsselwort $Junk, von dem Spamfilter lernen); in Junk-E-Mail heißt die Schaltfläche Kein Junk und verschiebt sie zurück in den Posteingang. Nachricht > Nachricht kennzeichnen kennzeichnet sie (! in der Liste) oder nimmt die Kennzeichnung weg. Nachricht > Kennzeichnung kennzeichnet sie in einer Farbe: Rot, Orange, Gelb, Grün, Blau, Lila oder Grau, wie Apple Mail, sodass eine in einem der beiden gesetzte Farbe im anderen erscheint (andere E-Mail-Programme zeigen eine einfache Kennzeichnung). Kennzeichnung löschen nimmt die Kennzeichnung und ihre Farbe weg. All das geschieht auch auf dem Server, sodass Ihre anderen E-Mail-Programme es sehen.
  • Archivieren in der Symbolleiste (Nachricht > Archivieren oder A in der Nachrichtenliste) nimmt eine Nachricht aus dem Posteingang oder einem eigenen Ordner und legt sie in Archiv ab; beim ersten Mal wird dieser Ordner angelegt, wenn das Konto keinen hat. Bei Gmail werden stattdessen alle Labels entfernt, sodass die Nachricht nur noch in „Alle Nachrichten“ liegt (gesendet, markiert und wichtig bleiben). Bearbeiten > Rückgängig holt sie zurück, mit ihren Labels.
  • Um mit mehreren Nachrichten gleichzeitig zu arbeiten, halten Sie Ctrl gedrückt und klicken Sie jede an, oder klicken Sie die erste an und halten Sie Shift gedrückt, während Sie die letzte anklicken (Shift mit den Pfeiltasten tut dasselbe); Bearbeiten > Alles auswählen (Ctrl+A) wählt jede Nachricht der Liste aus. Der Lesebereich sagt dann, wie viele ausgewählt sind und wie viele davon ungelesen oder gekennzeichnet sind, und die Statusleiste zählt sie ebenfalls. Als gelesen und als ungelesen markieren, Kennzeichnen, Junk, Löschen und In Ordner verschieben wirken auf alle, und das Ziehen einer davon zieht alle; Antworten, Drucken und Ähnliches wirken nur auf eine Nachricht.
  • Bearbeiten > Rückgängig (Ctrl+Z) macht das letzte Verschieben, Löschen oder Markieren als Junk rückgängig, ganz gleich, wie viele Nachrichten es waren: Sie kehren in die Ordner zurück, aus denen sie kamen, und sind dort ausgewählt, sobald sie zurück sind. Das Menü sagt, was es rückgängig macht (Verschieben rückgängig machen), und die Statusleiste sagt, was getan wurde. Eine endgültig gelöschte Nachricht kann nicht zurückkommen.
  • Datei > Ordner oder ein Rechtsklick in der Ordnerliste erstellt einen Neuen Ordner im ausgewählten Ordner (oben in einem Konto, wenn das Konto ausgewählt ist) und benennt den ausgewählten Ordner um oder löscht ihn. Das Löschen eines Ordners löscht nach einer Rückfrage die Nachrichten darin. Der Posteingang und die besonderen Ordner (Gesendete Objekte, Entwürfe, Gelöschte Objekte und dergleichen) bleiben, wie sie sind.
  • Über der Nachricht stehen ihr Absender, Datum, Empfänger und Betreff.

Frühere Nachrichten in Antworten

Eine Antwort trägt oft die Nachrichten vor ihr mit sich. Inbox Classic klappt sie hinter einer Schaltfläche ••• unter dem weg, was der Absender geschrieben hat; klicken Sie darauf, um sie zu sehen. Nur Text, der eindeutig eine frühere Nachricht ist, wird weggeklappt, alles Unsichere bleibt sichtbar.

Noch nicht heruntergeladene Nachrichten

Eine Nachricht wird beim ersten Öffnen heruntergeladen, daher sind gleich nach dem Hinzufügen eines Kontos die meisten Nachrichten noch nicht hier. Absender und Betreff erscheinen sofort; dauert die Nachricht länger als einen Moment, sagt der Bereich, dass sie heruntergeladen wird. Ist der Mailserver nicht erreichbar, sagt der Bereich warum, und die Nachricht wird von selbst heruntergeladen, sobald das Konto wieder online ist. Um es sofort zu versuchen, klicken Sie auf die Leiste über der Nachrichtklicken Sie auf Erneut versuchen.

3. Bilder, Links und Anlagen

Bilder

Bilder, die der Absender im Internet bereithält, werden nicht heruntergeladen, weil das Herunterladen dem Absender verrät, dass Sie die Nachricht geöffnet haben, wann und von wo. Bilder, die in der Nachricht mitgeschickt wurden, werden angezeigt. Hat eine Nachricht solche Bilder, sagt eine gelbe Leiste darüber, dass sie blockiert wurden; um sie bei einer Nachricht zu sehen, der Sie vertrauen, klicken Sie auf die Leiste (oder Ansicht > Bilder herunterladen).

Links und Skripte

Skripte in Nachrichten laufen nie. Ein Klick auf einen Link öffnet ihn in Ihrem Webbrowser, nie in Inbox Classic. Bevor Sie auf einer Seite, die Sie über eine E-Mail erreicht haben, ein Passwort eingeben, prüfen Sie die Adresse in Ihrem Browser.

Anlagen

Hat eine Nachricht Anlagen, erscheint rechts im Nachrichtenkopf eine Büroklammer mit der Zahl der Dateien. Klicken Sie darauf und wählen Sie eine Datei, um sie zu speichern, oder Anlagen speichern, um alle in einem Ordner zu speichern (eine gleichnamige Datei dort bleibt erhalten, und die neue bekommt eine Nummer). Dateien werden gespeichert, nie aus Inbox Classic geöffnet. Es schlägt einen sicheren Dateinamen vor: Ordnernamen, Zeichen, die WindowsWindows und andere Systeme nicht erlauben, und Zeichen, die einen Namen anders aussehen lassen können, als er ist, werden entfernt.

Öffnen Sie Anlagen nur von Personen, von denen Sie sie erwarten. Ein Programm (.exe, .js, .vbs, .msi, .bat, .scr) oder ein Dokument, das Sie bittet, „Inhalte zu aktivieren“, kann Ihren Computer übernehmen.

Nachrichten speichern, drucken und importieren

  • Datei > Speichern unter speichert die angezeigte Nachricht als .eml-Datei, die andere E-Mail-Programme öffnen. Mit mehreren ausgewählten Nachrichten fragt es nach einem Ordner und speichert jede dort, nach ihrem Betreff benannt; eine schon vorhandene Datei wird nie ersetzt (die neue heißt dann Mittagessen (2).eml).
  • Ziehen Sie Nachrichten aus der Liste auf den Schreibtisch oder in ein Ordnerfenster im Finder, um sie dort auf dieselbe Weise als .eml-Dateien zu speichern. Eine noch nicht heruntergeladene wird dafür heruntergeladen.
  • Datei > Nachrichten importieren legt .eml-Dateien in den ausgewählten Ordner, auch auf dem Server. Das Ziehen von .eml-Dateien auf einen Ordner in der Ordnerliste tut dasselbe. Eine Datei, die keine Nachricht ist, wird nicht importiert.
  • Datei > Drucken (Ctrl+P) öffnet die Druckvorschau der angezeigten Nachricht in einem Fenster über Inbox Classic: Wählen Sie den Drucker (oder Als PDF speichern), Exemplare und Seiten, und die Nachricht wird mit Absender, Datum, Empfängern und Betreff gedruckt. Das Fenster schließt sich nach dem Drucken oder Abbrechen.

4. Schreiben, Antworten und Weiterleiten

  • E-Mail erstellen (Ctrl+N) beginnt eine neue Nachricht mit dem Konto des ausgewählten Ordners.
  • Cc und Bcc erscheinen nur, wenn jemand darin steht; die Schaltflächen Cc und Bcc am Ende der Zeile An (Alt+C, Alt+B) öffnen sie. Die Zeile Anhängen erscheint, sobald eine Datei angehängt ist.
  • Sie schreiben immer mit Formatierung zur Hand. Eine Nachricht ohne jede Formatierung (kein Fett, keine Farben, Listen, Links oder Bilder) geht als reiner Text, den jedes E-Mail-Programm gleich zeigt; mit Formatierung geht sie als HTML mit einer Kopie als reiner Text. Eine Antwort oder Weiterleitung folgt dem Original: Auf eine reine Textnachricht ist sie ebenfalls reiner Text (das Original mit > zitiert), außer Sie formatieren etwas, auf eine HTML-Nachricht ist sie HTML.
  • Weiterleiten mit mehreren ausgewählten Nachrichten schreibt eine neue Nachricht mit allen als angehängten .eml-Dateien, ihr Betreff der der ersten.
  • Von oben in der Nachricht zeigt, von wem sie geht: Name und Adresse des Kontos. Eine Antwort oder Weiterleitung geht von dem Konto, in dem die ursprüngliche Nachricht liegt. Mit mehreren Konten wählen Sie dort ein anderes; die Nachricht wird dann über die Server dieses Kontos gesendet und in seinen Gesendeten Objekten (oder Entwürfen) aufbewahrt. Der Name, den andere sehen, ist der Anzeigename des Kontos, geändert in Datei > Konten > Eigenschaften.
  • Antworten (Ctrl+R) antwortet dem Absender, Allen antworten (Ctrl+Shift+R) allen, an die die Nachricht ging, Weiterleiten (Ctrl+F) schickt sie weiter.
  • In einer Antwort ist die ursprüngliche Nachricht hinter einer Schaltfläche ••• unter Ihrem Text weggeklappt, sodass Sie nur sehen, was Sie schreiben. Klicken Sie darauf (oder wählen Sie mit Ctrl+A alles aus), um sie in Ihren Text zu holen, wo Sie sie kürzen können; sie wird so oder so mit Ihrer Antwort gesendet. In einer Weiterleitung steht das Original von Anfang an im Text, denn es ist das, was Sie senden.
  • Die Leiste über dem Text formatiert ihn: Schriftart und -größe, Fett, Kursiv, Unterstrichen (oder Ctrl+B, Ctrl+I, Ctrl+U), Farbe, nummerierte Listen und Aufzählungen, Einzug verkleinern und vergrößern (« und »), Ausrichtung, Link für eine Webadresse auf dem markierten Text, Linie für eine Trennlinie und Bild, um ein Bild in den Text zu setzen (oder ziehen Sie eine Bilddatei aus dem Explorerdem Finderdem Dateimanager in den Text: Es landet dort, wo Sie es ablegen). Bilder gehen in der Nachricht mit, nicht als einzelne Anlagen. Die Nachricht geht als formatiertes HTML mit einer Kopie als reiner Text für E-Mail-Programme, die nur Text zeigen.
  • Links: Steht der Cursor in einem Link oder ist die Maus darüber, zeigt die Statusleiste unten, wohin er führt. Ctrl+Klick auf einen Link öffnet ihn in Ihrem Browser. Link (oder Ctrl+K) auf einem Link zeigt seine Adresse zum Ändern; leeren Sie die Adresse, um den Link zu entfernen und seinen Text zu behalten. Ein Rechtsklick auf einen Link bietet Link öffnen, Link bearbeiten und Link entfernen.
  • Falsch geschriebene Wörter sind unterstrichen; ein Rechtsklick darauf zeigt Vorschläge. Ausschneiden, Kopieren und Einfügen funktionieren wie überall.
  • Trennen Sie mehrere Adressen in An, Cc und Bcc mit Kommas, zum Beispiel Maria Schmidt <maria@example.com>, hans@example.com. Setzen Sie einen Namen mit Komma in Anführungszeichen: "Schmidt, Maria" <maria@example.com>.
  • Personen in Bcc erhalten die Nachricht, aber die anderen Empfänger sehen sie nicht.
  • Anhängen fügt Dateien hinzu, ebenso das Ziehen aus dem Explorerdem Finderdem Dateimanager auf die Adressfelder, oder einer Datei, die kein Bild ist, auf den Text. Sie werden in der Zeile Anhängen mit ihrer Größe aufgeführt; um eine zu entfernen, wählen Sie sie aus und drücken Del, oder klicken mit der rechten Maustaste darauf und wählen Entfernen. Die Dateien werden beim Senden der Nachricht gelesen.
  • Senden legt die Nachricht in den Postausgang und sendet sie sofort. Kann sie nicht gehen (keine Verbindung, der Server lehnt sie ab), bleibt sie im Postausgang und geht beim nächsten Senden/Empfangen; nichts, was Sie geschrieben haben, geht verloren. Senden/Empfangen läuft außerdem alle zehn Minuten von selbst. Die Mitte der Statusleiste des Hauptfensters sagt, was mit der E-Mail geschieht, die Sie senden: Wird gesendet, während sie geht, Gesendet mit Betreff und Uhrzeit, sobald der Server sie angenommen hat, oder dass sie im Postausgang wartet. Extras > Postausgang listet auf, was wartet, und warum es nicht ging, und sendet oder löscht es.
  • Ctrl+Enter sendet aus dem Text heraus.
  • Speichern (oder Ctrl+S) legt die Nachricht im Ordner Entwürfe des Kontos ab, auf dem Server, um sie später fertigzustellen; erneutes Speichern ersetzt die zuvor gespeicherte Kopie. Die Statusleiste der Nachricht sagt In Entwürfen gespeichert mit der Uhrzeit, sobald der Server sie hat, oder warum sie nicht gespeichert wurde. Beim Schließen einer geänderten Nachricht wird gefragt, ob die Änderungen gespeichert werden sollen: Ja speichert sie in Entwürfen, Nein verwirft sie, Abbrechen kehrt zu ihr zurück. Um weiterzuschreiben, doppelklicken Sie auf den Entwurf in Entwürfe (oder wählen Sie ihn aus und drücken Enter): Er öffnet sich mit Empfängern, Text und angehängten Dateien. Sobald er gesendet ist, wird der Entwurf aus Entwürfe entfernt. Eine Nachricht, die Sie schreiben, ist ein eigenes Fenster in der Taskleiste: Sie können zum Hauptfenster zurückkehren und E-Mail lesen, während es offen bleibt. Das Schließen von Inbox Classic schließt zuerst die Nachrichten, die Sie schreiben, und fragt bei geänderten nach.
  • Senden sendet die Nachricht. Ist eine Adresse falsch geschrieben oder eine Datei verschwunden, sagt Inbox Classic das und lässt die Nachricht offen, damit Sie es korrigieren können. Eine Kopie jeder gesendeten Nachricht wird in Gesendete Objekte aufbewahrt.
  • E-Mail-Links (mailto:) auf Webseiten und in anderen Programmen öffnen eine neue Nachricht in Inbox Classic, sobald es Ihr Standard-E-Mail-Programm ist: Extras > Als Standard-E-Mail-Programm festlegen öffnet die Seite der Windows-Einstellungen, auf der Sie es wählen.macht es dazu. Adressen, Betreff und Text des Links werden eingetragen; sonst wird nichts vom Link verwendet.
  • Beim Tippen in An, Cc oder Bcc werden die Personen aufgelistet, die gemeint sein können, zuerst die, denen Sie am meisten schreiben, dann die, die Ihnen schreiben; die Liste kennt jeden in der E-Mail, die Inbox Classic hat (nicht in Junk-E-Mail). Wählen Sie mit den Pfeiltasten und übernehmen Sie mit Enter oder Tab (oder einem Klick); Esc schließt die Liste, und Shift+Del nimmt die gewählte Person endgültig heraus.
  • Eine Signatur für jedes Konto: Datei > Konten, das Konto auswählen, dann Signatur. Sie wird mit derselben Formatierung geschrieben wie eine Nachricht (Fett, Farben, Links, ein Bild). Neue Nachrichten, Antworten und Weiterleitungen des Kontos beginnen damit, unter einer leeren Zeile zum Schreiben und der üblichen Zeile --, über der zitierten Nachricht. Die Wahl eines anderen Kontos in Von setzt die Signatur dieses Kontos an ihre Stelle.

5. Neue E-Mail abrufen

Inbox Classic prüft jedes Konto beim Start und danach alle zehn Minuten. Klicken Sie auf Senden/Empfangen oder drücken Sie F5Ctrl+Shift+N, um jetzt zu prüfen; der Pfeil neben Senden/Empfangen prüft ein einzelnes Konto, und der neben E-Mail erstellen beginnt eine Nachricht mit dem Konto Ihrer Wahl. Die Statusleiste unten zeigt, was es gerade tut und das letzte Problem, das es hatte.

Es beobachtet außerdem den Posteingang jedes Kontos, sodass neue E-Mail beim Eintreffen erscheint, nicht erst bei der nächsten Prüfung. Solange sein Fenster nicht im Vordergrund ist, sagt eine Benachrichtigung, wer worüber geschrieben hat; ein Klick darauf öffnet die Nachricht. Extras > Bei neuer E-Mail benachrichtigen schaltet die Benachrichtigungen aus und ein.

Das Schließen des Fensters lässt Inbox Classic im Infobereich weiterlaufen, wo es weiter E-Mail abruft; sein Symbol dort sagt, wie viele Nachrichten ungelesen sind, ebenso eine Zahl auf seiner Taskleistenschaltfläche. Klicken Sie auf das Symbol, um es wieder zu öffnen; ein Rechtsklick bietet Auf neue E-Mail prüfen und Beenden. Datei > Beenden beendet es.

Das Schließen des Fensters lässt Inbox Classic im Dock weiterlaufen, wo es weiter E-Mail abruft; das Dock-Symbol zeigt, wie viele Nachrichten in den Posteingängen ungelesen sind. Klicken Sie auf das Dock-Symbol, um das Fenster wieder zu öffnen. Inbox Classic > Inbox Classic beenden (Ctrl+Q) beendet es.

Das Schließen des Fensters lässt Inbox Classic in der oberen Leiste weiterlaufen (Ubuntu zeigt sein Symbol dort), wo es weiter E-Mail abruft; das Menü des Symbols hat Inbox Classic öffnen, Auf neue E-Mail prüfen und Beenden, und das Dock zeigt, wie viele Nachrichten in den Posteingängen ungelesen sind. Wo die Arbeitsumgebung keinen Platz für das Symbol hat, beendet das Schließen des Fensters Inbox Classic. Beenden im Hauptmenü beendet es.

Optionen und Sprache

  • Extras > OptionenInbox Classic > EinstellungenEinstellungen im Hauptmenü wählt die Sprache der Fenster: Systemstandard (die Sprache Ihres Systems, Englisch, wenn Inbox Classic sie nicht hat) oder English, Deutsch, Eesti, Español oder Français. Inbox Classic startet dafür neu. Dort ist auch Bei neuer Post benachrichtigen.
  • Das Installationsprogramm fragt bei der ersten Installation nach der Sprache; sie gilt dann als in den Optionen gewählt.
  • Die Sprache lässt sich auch nur für Inbox Classic wählen: Systemeinstellungen > Allgemein > Sprache & Region > Apps.

7. KI-Agenten

Wenn Sie einen KI-Agenten verwenden (Claude, Cursor oder ein anderes Programm, das das Model Context Protocol, MCP, spricht), können Sie ihn hier Ihre E-Mail lesen und ordnen lassen. In Inbox Classic gibt es keine KI, und nichts wird an einen KI-Dienst gesendet: Ein Agent arbeitet nur, wenn Sie sein Programm zulassen, und nur mit den Konten, die Sie wählen.

  • Verbinden. Extras > KI-Agenten > Einen Agenten verbinden gibt die Zeilen an, die Sie in die Einstellungen Ihres Agenten einfügen (für Claude Desktop: Settings > Developer > Edit Config). Der Agent startet Inbox Classic mit --mcp, was ihn mit dem laufenden Inbox Classic verbindet oder eines im Hintergrund startet. Nur Programme, die unter Ihrem Benutzer auf diesem Computer laufen, können es erreichen.
  • Beim ersten Mal, wenn sich der Agent eines Programms verbindet, fragt Inbox Classic Sie unter Nennung des Programms, was es tun darf: E-Mail lesen; sie ordnen (als gelesen markieren, kennzeichnen, Junk, verschieben, archivieren, nach Gelöschte Objekte löschen); Entwürfe schreiben, die Sie senden; und E-Mail senden, jede Nachricht erst nach Ihrer Zustimmung. Wählen Sie die Konten, die es sehen darf. Nicht erlauben weist das Programm ab, und Sie werden nicht mehr danach gefragt.
  • Senden. Jede Nachricht, die ein Agent senden möchte, wird Ihnen zuerst gezeigt, mit jedem Empfänger nach Adresse und den Adressen, an die Sie nie geschrieben haben, markiert. Senden wird nach einem Moment aktiv; Erst bearbeiten öffnet sie in einer neuen Nachricht zum Ändern; Nicht senden ist die Vorgabe. Was Sie senden, wartet 30 Sekunden im Postausgang, wo Sie es noch löschen können.
  • Was sich ändert, zeigt sich sofort in den Fenstern, als hätten Sie es getan. Ein Agent löscht nie etwas endgültig und ändert nie Ihre Kontoeinstellungen. Das Lesen einer Nachricht markiert sie nicht als gelesen.
  • Extras > KI-Agenten listet die Programme auf, die Sie zugelassen oder abgewiesen haben (Ändern, was eines tun darf, oder Entfernen, um wieder gefragt zu werden), und alles, was Agenten getan haben, neueste zuerst. Rückgängig nimmt einen Lesestatus, eine Kennzeichnung, ein Verschieben oder Löschen sowie eine Nachricht, die noch im Postausgang ist, zurück. KI-Agenten verbinden lassen schaltet sie alle auf einmal aus.
  • Überlegen Sie, worum Sie bitten. E-Mail wird von anderen geschrieben, und eine Nachricht kann versuchen, einen Agenten zu etwas zu überreden: Ihre E-Mail weiterzuleiten, sie zu löschen, jemandem zu schreiben. Inbox Classic verbirgt vor Agenten den Text, den eine Nachricht vor Ihnen verbirgt, und sagt ihnen, dass E-Mail keine Anweisungen sind, aber ein Agent kann dennoch getäuscht werden. Lesen Sie jede Nachricht, die er senden möchte, bevor Sie zustimmen, und lassen Sie einen Agenten nur senden, wenn Sie es brauchen. Ein Agent, der auch andere Werkzeuge hat (im Web surfen, Ihre Dateien lesen), könnte das Gelesene über diese weitergeben; Inbox Classic kann diese nicht sehen.

8. Wenn etwas nicht funktioniert

„authentication failed“ oder Inbox Classic fragt erneut nach dem Passwort

Der Server hat das Passwort abgelehnt. Geben Sie es erneut ein; für Gmail und Outlook.com verwenden Sie ein App-Passwort oder melden Sie sich über den Browser an (siehe Ein Konto hinzufügen). Verlangt Ihr Anbieter bei der Anmeldung im Web einen zweiten Schritt, braucht er auch für E-Mail-Programme ein App-Passwort. Bei einem Konto, das sich über den Browser anmeldet, bietet Inbox Classic an, sich erneut anzumelden.

„TLS error“ oder ein Zertifikatfehler

Inbox Classic konnte nicht bestätigen, dass es mit dem echten Server spricht, und hat Ihr Passwort daher nicht gesendet. Prüfen Sie den Servernamen in den Kontoeinstellungen: Er muss der Name sein, für den das Zertifikat des Servers ausgestellt ist (oft imap.anbieter.de, nicht Ihre eigene Domäne). In einem Netzwerk, das verschlüsselten Verkehr untersucht, fragen Sie dessen Administrator.

„the server does not offer STARTTLS“

Das Konto ist auf STARTTLS eingestellt, aber der Server hat keine Verschlüsselung angeboten. Versuchen Sie SSL/TLS mit Port 993 (IMAP) oder 465 (SMTP). Funktioniert nichts anderes, kann der Server nicht sicher verwendet werden.

„the server takes the password only over an encrypted connection“

Der Postausgangsserver (SMTP) ist auf Keine (unverschlüsselt) eingestellt. Ihr Passwort ist in Ordnung; ändern Sie die SMTP-Sicherheit auf STARTTLS (Port 587) oder SSL/TLS (Port 465).

„connection error“ oder „the server did not answer in time“

Prüfen Sie Ihre Internetverbindung, den Servernamen und den Port. Firewalls sperren manchmal die Mail-Ports, besonders Port 25; verwenden Sie zum Senden 465 oder 587. Inbox Classic versucht es bei der nächsten Prüfung erneut.

Eine Nachricht, die nicht angezeigt werden kann

Manche Nachrichten sind beschädigt oder so aufgebaut, dass kein E-Mail-Programm sie lesen kann. Inbox Classic zeigt statt der Nachricht einen Hinweis; Ihre übrige E-Mail ist nicht betroffen.
