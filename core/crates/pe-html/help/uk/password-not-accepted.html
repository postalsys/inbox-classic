Пароль не приймається

Що робити, коли поштовий сервер відхиляє ваш пароль або вхід.

Ви можете побачити одне з таких повідомлень:

  • У рядку стану: «сервер відхилив вхід (…)»
  • В області читання: «Поштовий сервер відхилив вхід (…). Відкрийте параметри облікового запису, перевірте пароль або ввійдіть знову».
  • Вікно, яке просить знову ввести пароль облікового запису

Щоб це виправити:

  1. Введіть пароль знову, коли Inbox Classic попросить, або змініть його у властивостях облікового запису в меню > .
  2. Деякі провайдери, зокрема iCloud і Yahoo, дозволяють поштовим програмам входити лише за допомогою пароля застосунку. Створіть його в параметрах безпеки облікового запису й використовуйте замість звичайного пароля.
  3. Для Gmail увійдіть через браузер або, якщо це дозволено для вашого облікового запису з двоетапною перевіркою, використайте пароль застосунку. Для Outlook.com і Microsoft 365 використовуйте вхід через браузер: паролі застосунків не підтримуються. Див. .

Обліковий запис із входом через браузер

Коли провайдер завершує сеанс, Inbox Classic повідомляє, що вхід відхилено або термін дії сеансу минув. Програма запитує: «» Виберіть й увійдіть ще раз у браузері.

Якщо сервер не приймає токен застосунку для входу, перевірте, чи області доступу (scopes) застосунку охоплюють пошту. Див. .
