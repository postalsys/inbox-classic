Inbox Classic як ваша поштова програма

Відкривайте посилання електронної пошти й файли повідомлень з вебсторінок та інших програм в Inbox Classic.

Посилання електронної пошти (mailto:) відкривають нове повідомлення у вашій типовій поштовій програмі.

Щоб зробити такою програмою Inbox Classic, виберіть > . Windows відкриє параметри «Програми за замовчуванням», де ви виберете Inbox Classic для посилань MAILTO. Там показується лише встановлена копія. Inbox Classic одразу стане типовою поштовою програмою.

Коли ви клацнете посилання електронної пошти, відкриється нове повідомлення. Адреси, тема й текст будуть заповнені за даними з посилання. Інші параметри, зокрема вкладення, ігноруються.

Якщо у вас ще немає облікового запису, Inbox Classic попросить спершу додати його. Додавши, клацніть посилання знову.

Файли повідомлень

Щоб файли .eml відкривалися в Inbox Classic подвійним клацанням, клацніть у розділі . Windows відкриє параметри «Програми за замовчуванням», де ви виберете Inbox Classic для файлів .eml. Inbox Classic одразу стане типовою програмою для цих файлів.
