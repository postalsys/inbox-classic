Параметри безпеки облікового запису

Як захищене з’єднання з поштовими серверами та що означають параметри безпеки.

Кожен обліковий запис має параметр для сервера вхідної пошти й для сервера вихідної. Inbox Classic заповнює їх, коли знаходить параметри вашого провайдера. Щоб змінити їх, відкрийте властивості облікового запису в меню > .

ПараметрЗначення
SSL/TLSЗ’єднання зашифроване від самого початку. Зазвичай порт 993 для вхідної пошти й 465 для вихідної.
STARTTLSЗ’єднання шифрується відразу після відкриття. Зазвичай порт 143 для вхідної пошти й 587 для вихідної. Inbox Classic припиняє з’єднання, якщо сервер не пропонує шифрування.
Ваш пароль і пошта передаються так, що їх може прочитати будь-хто в мережі.
Використовуйте параметр лише тоді, коли з’єднання захищене іншим способом. Локальна мережа сама по собі не шифрує дані. Перед з’єднанням без шифрування Inbox Classic показує попередження.

Для зашифрованих з’єднань Inbox Classic перевіряє справжність кожного сервера за сертифікатами, яким довіряє ваша система. Вимкнути цю перевірку не можна.

За замовчуванням пароль зберігається в Диспетчері облікових даних Windowsу В’язці ключів для входуу системному сховищі ключів (Secret Service), окремо від поштової бази. Якщо сховище недоступне або ввімкнено режим зберігання лише в пам’яті, після перезапуску пароль може знадобитися знову. Для входу через браузер замість пароля зберігається токен оновлення доступу.
