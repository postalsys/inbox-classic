Де зберігаються ваша пошта й паролі

Що Inbox Classic зберігає на вашому комп’ютері і де.

  • Завантажена пошта й параметри облікових записів зберігаються в %LOCALAPPDATA%\InboxClassic\store.db~/Library/Application Support/Inbox Classic/store.db~/.local/share/inbox-classic/store.db. Ваша пошта залишається й на сервері. Копія тут потрібна для швидкого читання без інтернету та для пошуку.
  • Паролі, токени оновлення доступу для входу через браузер і секрети застосунків за замовчуванням зберігаються в Диспетчері облікових даних Windows під назвою InboxClassic, зашифровані для вашого облікового запису Windows.у В’язці ключів для входу під назвою InboxClassic, зашифровані для вашого облікового запису Mac. Їх можна переглянути в програмі «В’язка ключів».у системному сховищі ключів із підтримкою Secret Service під назвою InboxClassic, захищені для вашого облікового запису користувача. Якщо системне сховище недоступне або вибрано режим зберігання лише в пам’яті, ці дані можуть не зберегтися після виходу з програми. У поштову базу вони не записуються.
  • Ключі шифрування зберігаються разом із завантаженою поштою. Ваші закриті ключі зашифровані там ключем, що зберігається поруч із вашими паролями, тому самого файлу поштової бази недостатньо для їх розшифрування.

Якщо ввімкнено пошук у зашифрованих повідомленнях, розшифрований текст і захищені теми зберігаються в локальному індексі без шифрування. Відкриття вкладення в зовнішній програмі також створює незашифровану тимчасову копію.

Пошук, пояснення повернених повідомлень, групування в розмови й пошук кодів входу працюють на вашому комп’ютері. Для цього нічого з вашої пошти нікуди не надсилається.

ШІ-агенти отримують доступ до пошти лише з вашого дозволу й лише для вибраних облікових записів. Див. .
