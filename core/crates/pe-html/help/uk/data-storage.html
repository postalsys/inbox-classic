Де зберігаються ваша пошта й паролі

Що Inbox Classic зберігає на вашому комп’ютері і де.

  • Завантажена пошта й параметри облікових записів зберігаються в %LOCALAPPDATA%\InboxClassic\store.db~/Library/Application Support/Inbox Classic/store.db~/.local/share/inbox-classic/store.db. Ваша пошта залишається й на сервері. Копія тут потрібна для швидкого читання без інтернету та для пошуку.
  • Паролі, дані входу через браузер і секрети застосунків для входу зберігаються в Диспетчері облікових даних Windows під назвою InboxClassic, зашифровані для вашого облікового запису Windows.у вашій зв’язці ключів входу під назвою InboxClassic, зашифровані для вашого облікового запису Mac. Їх показує програма «Зв’язка ключів».у вашій в’язці ключів (GNOME Keyring) під назвою InboxClassic, зашифровані для вашого входу в систему. Без в’язки ключів вони зберігаються лише до виходу з Inbox Classic. У поштовому сховищі їх ніколи немає.
  • Ключі шифрування зберігаються разом із завантаженою поштою. Ваші закриті ключі зашифровані там ключем, що зберігається поруч із вашими паролями, тож сам файл пошти не може їх відкрити.

Пошук, пояснення повернених повідомлень, групування в розмови й пошук кодів входу працюють на вашому комп’ютері. Для цього нічого з вашої пошти нікуди не надсилається.
