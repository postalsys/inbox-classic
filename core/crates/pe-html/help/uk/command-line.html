Параметри командного рядка

Параметри для запуску Inbox Classic з термінала, для тестування й для ШІ-агентів.

Запустіть програму InboxClassic.exe"Inbox Classic.app/Contents/MacOS/Inbox Classic"inbox-classic з такими параметрами:

ПараметрДія
--store <файл>Використовує інше поштове сховище, наприклад тестове
--memory-passwordsВикористовує сховище облікових даних лише в пам’яті; ці дані не читаються із системного сховища й не записуються до нього
--pin-certificate <файл>Дозволяє лише сертифікати, вказані у файлі, наприклад для тестового сервера із самопідписаним сертифікатом. PEM може містити кілька сертифікатів, DER один
--sign-in-page-file <файл>Записує URL-адресу сторінки входу в цей файл замість відкриття браузера; сам HTML-вміст сторінки не зберігається
--language <код>Показує вікна цією мовою на час цього запуску, наприклад uk
--backgroundЗапускається без вікна
--mcpПід’єднує ШІ-агента до Inbox Classic. Це запускає програма агента, а не ви
--versionВиводить версію й завершує роботу
