Bezbednosna podešavanja naloga

Bezbednosna podešavanja servera jednog naloga i šta svako od njih znači.

Svaki nalog ima za server dolazne pošte i za server odlazne pošte. Inbox Classic ih popunjava kada pronađe podešavanja vašeg dobavljača. Da biste ih promenili, otvorite svojstva naloga u meniju > .

PodešavanjeZnačenje
SSL/TLSVeza je šifrovana od samog početka. Obično port 993 za dolaznu i 465 za odlaznu poštu.
STARTTLSVeza se šifruje odmah nakon otvaranja. Obično port 143 za dolaznu i 587 za odlaznu poštu. Inbox Classic prekida vezu ako server ne nudi šifrovanje.
Vaša lozinka i pošta putuju mrežom tako da svako može da ih pročita.
koristite samo za server na sopstvenom računaru ili u lokalnoj mreži. Inbox Classic vas upozorava pre nego što ga upotrebi.

Inbox Classic proverava da li je svaki server zaista onaj za koji se predstavlja, prema sertifikatima kojima vaš sistem veruje. Ne postoji prekidač kojim bi se prihvatio bilo koji sertifikat.
