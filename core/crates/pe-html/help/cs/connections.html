Připojení, která Inbox Classic navazuje

Technický přehled míst, kam se Inbox Classic připojuje, a důvodů těchto připojení.

  • Vaše poštovní servery přes IMAP pro čtení pošty a SMTP pro její odesílání. Připojení jsou šifrována pomocí TLS a certifikát každého serveru se ověřuje pomocí certifikátů, kterým důvěřuje operační systém. Inbox Classic odmítne server bez šifrování, pokud nezvolíte a nepotvrdíte to.
  • Při přidání účtu kvůli vyhledání jeho serverů. Inbox Classic hledá záznamy MX a SRV přes DNS over HTTPS (Cloudflare, pak Google). Běžná připojení k serverům používají systémové vyhledávání DNS. Zkouší také soubor autoconfig poskytovatele a seznam poskytovatelů Thunderbirdu (ISPDB). Požadavky k poskytovateli mohou obsahovat vaši e-mailovou adresu. U Exchange se dotazuje služby Microsoft Autodiscover. Heslo jí odešle jen tehdy, po výzvě k ověření Basic přes HTTPS. Server bez šifrování se nikdy nevybere.
  • Přihlášení v prohlížeči pomocí OAuth 2.0 a PKCE ke Googlu, Microsoftu nebo k poskytovateli vaší přihlašovací aplikace. Výsledek přihlášení se předává zpět aplikaci Inbox Classic přes místní adresu v tomto počítači.
  • Loga značek (BIMI) z adresy HTTPS značky, pokud zpráva logo neobsahuje a nelze použít uloženou kopii. Stažená loga se ukládají a používají znovu, i po restartu aplikace. Stane se to jen tehdy, když váš poštovní server zprávu ověřil kontrolou DMARC a logo schválil.
  • Obrázky z internetu, pokud je stáhnete ručně nebo povolíte jejich automatické stahování. V šifrovaných částech je vždy nutný výslovný souhlas.
  • Odhlášení odběru, až po vašem potvrzení. Přímý požadavek na odhlášení (RFC 8058) se odešle jen při poskytovatelem ověřeném podpisu DKIM, který zahrnuje hlavičky pro odhlášení.
  • Šifrovací klíče hledá Inbox Classic při šifrování zprávy, pokud nemáte klíč příjemce, nebo když sami spustíte hledání. Při hledání podle e-mailové adresy se nejprve dotáže její domény (Web Key Directory). Pokud klíč nenajde a hledání na keys.openpgp.org je zapnuté, odešle adresu i tam. Při hledání podle otisku nebo ID klíče odešle na keys.openpgp.org tento identifikátor místo e-mailové adresy. Při zveřejnění klíče se odesílá veřejný klíč a jeho adresy, které je třeba jednotlivě potvrdit.
  • Aktualizace z inboxclassic.com, když si vyžádáte kontrolu nebo je zapnutá automatická kontrola.

Přihlašovací kódy se nabízejí jen tehdy, když váš poskytovatel potvrdí platný podpis DKIM domény kódu nebo její nadřazené domény. Inbox Classic tento výsledek čte z hlavičky Authentication-Results nebo ARC-Authentication-Results od poskytovatele. K tomu není potřeba žádné další připojení.
