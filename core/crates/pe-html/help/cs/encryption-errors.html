Chyby šifrování

Co dělat, když server nenabízí šifrování nebo vyžaduje šifrované spojení.

„the server does not offer STARTTLS“

Účet je nastaven na STARTTLS, ale server šifrování nenabídl. Inbox Classic spojení ukončil, aniž by odeslal heslo.

  1. Otevřete vlastnosti účtu v nabídce > .
  2. Ověřte údaje u poskytovatele. Pokud podporuje SSL/TLS, zvolte tuto možnost. Běžný port je 993 pro příchozí poštu a 465 pro odchozí poštu.
  3. Klikněte na .

Pokud server nepodporuje žádné šifrované spojení, nelze jej bezpečně používat přes internet.

„the server takes the password only over an encrypted connection“

Server odchozí pošty je nastaven na . Tato chyba nepotvrzuje správnost hesla. Podle pokynů poskytovatele změňte na STARTTLS s portem 587, nebo na SSL/TLS s portem 465.

Upozornění na spojení bez šifrování

Když zvolíte , Inbox Classic upozorní, že kdokoli, kdo zachytí váš síťový provoz, může číst vaše heslo i zprávy. Pokračujte jen u serveru na vlastním počítači nebo v místní síti.
