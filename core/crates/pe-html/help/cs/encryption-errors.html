Chyby šifrování

Co dělat, když server nenabízí šifrování, nebo je vyžaduje tam, kde je vypnuté.

„the server does not offer STARTTLS“

Účet je nastaven na STARTTLS, ale server šifrování nenabídl. Inbox Classic se zastavil, takže vaše heslo nebylo odesláno.

  1. Otevřete vlastnosti účtu v nabídce > .
  2. Nastavte zabezpečení na SSL/TLS s portem 993 pro příchozí poštu nebo 465 pro odchozí poštu.
  3. Klikněte na .

Pokud nic jiného nefunguje, server nelze bezpečně používat.

„the server takes the password only over an encrypted connection“

Server odchozí pošty je nastaven na . Vaše heslo je v pořádku. Změňte na STARTTLS s portem 587, nebo na SSL/TLS s portem 465.

Upozornění na spojení bez šifrování

Když zvolíte , Inbox Classic upozorní, že kdokoli, kdo zachytí váš síťový provoz, může číst vaše heslo i zprávy. Pokračujte jen u serveru na vlastním počítači nebo v místní síti.
