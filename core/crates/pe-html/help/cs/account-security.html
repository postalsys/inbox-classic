Nastavení zabezpečení účtu

Zvolte způsob zabezpečení spojení s poštovními servery a zjistěte, co jednotlivé možnosti znamenají.

U každého účtu nastavujete pro server příchozí pošty a pro server odchozí pošty. Inbox Classic je vyplní, když najde nastavení vašeho poskytovatele. Chcete-li je změnit, otevřete vlastnosti účtu v nabídce > .

NastaveníVýznam
SSL/TLSSpojení je šifrované od samého začátku. Obvykle port 993 pro příchozí poštu a 465 pro odchozí poštu.
STARTTLSPo navázání spojení se zapne šifrování ještě před odesláním přihlašovacích údajů. Obvykle port 143 pro příchozí poštu a 587 pro odchozí poštu. Pokud server šifrování nenabídne, Inbox Classic spojení ukončí.
Heslo i pošta se přenášejí bez šifrování. Může je přečíst kdokoli, kdo zachytí síťový provoz.
Volbu používejte jen při jinak zajištěném bezpečném přenosu. Samotná místní síť spojení nešifruje. Inbox Classic vás před jejím použitím upozorní.

U šifrovaného připojení Inbox Classic ověřuje totožnost serveru pomocí certifikátů, kterým důvěřuje operační systém. Ověřování nelze vypnout ani nastavit přijímání libovolného certifikátu.

Ve výchozím nastavení je heslo uloženo ve Správci pověření systému Windowsve vaší přihlašovací klíčenceve vaší klíčence, nikdy v úložišti pošty. U účtu přihlášeného přes prohlížeč se místo hesla ukládají přihlašovací tokeny, rovněž do systémového úložiště. V režimu pouze v paměti nebo při nedostupném úložišti však nemusí být možné údaje zachovat pro příští spuštění.
