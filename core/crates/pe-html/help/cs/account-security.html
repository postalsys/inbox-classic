Nastavení zabezpečení účtu

Nastavení zabezpečení serverů účtu a co jednotlivé volby znamenají.

Každý účet má pro server příchozí pošty a pro server odchozí pošty. Inbox Classic je vyplní, když najde nastavení vašeho poskytovatele. Chcete-li je změnit, otevřete vlastnosti účtu v nabídce > .

NastaveníVýznam
SSL/TLSSpojení je šifrované od samého začátku. Obvykle port 993 pro příchozí poštu a 465 pro odchozí poštu.
STARTTLSSpojení se zašifruje hned po navázání. Obvykle port 143 pro příchozí poštu a 587 pro odchozí poštu. Pokud server šifrování nenabídne, Inbox Classic se zastaví.
Vaše heslo i pošta putují sítí tak, že je může přečíst kdokoli.
Volbu používejte jen pro server na vlastním počítači nebo v místní síti. Inbox Classic vás před jejím použitím upozorní.

Inbox Classic u každého serveru ověřuje podle certifikátů, kterým váš systém důvěřuje, že je opravdu tím, za koho se vydává. Neexistuje žádný přepínač, který by přijal libovolný certifikát.
