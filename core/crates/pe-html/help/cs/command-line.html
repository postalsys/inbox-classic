Volby příkazového řádku

Volby pro spuštění Inbox Classic z terminálu, pro testování a pro agenty AI.

Spusťte program InboxClassic.exe"Inbox Classic.app/Contents/MacOS/Inbox Classic"inbox-classic s těmito volbami:

VolbaÚčinek
--store <soubor>Použije jiné úložiště pošty, například testovací
--memory-passwordsUchová hesla pouze v paměti do ukončení aplikace, bez uložení do systémového úložiště hesel
--pin-certificate <soubor>Přijme jen certifikát serveru z tohoto souboru (PEM nebo DER), pro testovací server s certifikátem podepsaným sebou samým
--sign-in-page-file <soubor>Místo otevření prohlížeče zapíše do tohoto souboru URL přihlašovací stránky
--language <kód>Použije daný jazyk při tomto spuštění, například cs
--backgroundSpustí se bez okna
--mcpPřipojí agenta AI k aplikaci Inbox Classic. Tuto volbu používá program agenta při automatickém spuštění
--versionVypíše verzi a skončí

Odkaz mailto: předaný jako argument otevře novou zprávu, stejně jako e-mailový odkaz.
