Volby příkazového řádku

Volby pro spuštění Inbox Classic z terminálu, pro testování a pro agenty AI.

Spusťte program InboxClassic.exe"Inbox Classic.app/Contents/MacOS/Inbox Classic"inbox-classic s těmito volbami:

VolbaÚčinek
--store <soubor>Použije jiné úložiště pošty, například testovací
--memory-passwordsUchová hesla jen pro toto spuštění, nikdy v úložišti hesel systému
--pin-certificate <soubor>Přijme jen certifikát serveru z tohoto souboru (PEM nebo DER), pro testovací server s certifikátem podepsaným sám sebou
--sign-in-page-file <soubor>Zapíše stránku přihlášení přes prohlížeč do tohoto souboru místo otevření prohlížeče
--language <kód>Zobrazí okna pro toto spuštění v daném jazyce, například cs
--backgroundSpustí se bez okna
--mcpPřipojí k Inbox Classic agenta AI. Spouští to program agenta, ne vy
--versionVypíše verzi a skončí

Odkaz mailto: předaný jako argument otevře novou zprávu, stejně jako e-mailový odkaz.
