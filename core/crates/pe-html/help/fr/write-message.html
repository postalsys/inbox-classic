Écrivez et envoyez un nouveau message, avec mise en forme, liens et images.

Mise en forme

La barre au-dessus du texte propose la police, le gras, l'italique, le souligné, la couleur, les listes, le retrait, l'alignement, les liens, une ligne de séparation et les images. Pour placer une image dans le texte, cliquez sur ou faites glisser un fichier image depuis l'Explorateur de fichiersle Finderle gestionnaire de fichiers dans le texte.

Un message sans mise en forme part en texte brut, que tous les programmes de messagerie affichent de la même façon. Un message mis en forme part en HTML, accompagné d'une copie en texte brut.

Liens

Pour créer un lien sur le texte sélectionné, cliquez sur et tapez l'adresse. Quand le curseur est dans un lien, la barre d'état indique où il mène. Faites Ctrl+Clic⌘+Clic sur un lien pour l'ouvrir dans votre navigateur. Cliquez dessus avec le bouton droit pour , et .

Les mots mal orthographiés sont soulignés. Cliquez sur l'un d'eux avec le bouton droit pour obtenir des suggestions.
