Écrire un message

Écrivez et envoyez un nouveau message, avec mise en forme, liens et images.

Pour écrire un message :

  1. Cliquez sur , ou appuyez sur . Un nouveau message s'ouvre dans une fenêtre à part.
  2. Saisissez les adresses dans le champ . Séparez-les par des virgules. Pendant la saisie, Inbox Classic propose des noms et des adresses correspondants. Appuyez sur EnterRetour ou Tab pour sélectionner une proposition.
  3. Renseignez le champ , puis rédigez votre message.
  4. Cliquez sur , ou appuyez sur Ctrl+Enter, ou appuyez sur ⌘Retour.

Pour ajouter Cc ou Cci, cliquez sur ou au bout de la ligne À. Les personnes en Cci reçoivent le message, mais les autres destinataires ne les voient pas.

Le champ indique le compte utilisé pour l’envoi. Si vous avez plusieurs comptes, vous pouvez en sélectionner un autre ici. Le message est envoyé depuis ce compte et une copie est enregistrée dans son dossier . Pour choisir un compte avant de rédiger, utilisez la flèche à côté du bouton .

Si vous mentionnez une pièce jointe dans l’objet ou le texte, par exemple « le plan ci-joint », sans avoir joint de fichier, Inbox Classic vous demande si vous souhaitez quand même envoyer le message.

Pour signer numériquement ou chiffrer le message, cliquez sur ou dans la barre d’outils. Pour en savoir plus, consultez .

Mise en forme

La barre au-dessus du texte propose la police, le gras, l'italique, le souligné, la couleur, les listes, le retrait, l'alignement, les liens, une ligne de séparation et les images. Pour placer une image dans le texte, cliquez sur ou faites glisser un fichier image depuis l'Explorateur de fichiersle Finderle gestionnaire de fichiers dans le texte.

Un message sans mise en forme est envoyé en texte brut, lisible par tous les logiciels de messagerie. Un message mis en forme est envoyé en HTML, avec une copie en texte brut.

Liens

Pour créer un lien sur le texte sélectionné, cliquez sur et tapez l'adresse. Quand le curseur est dans un lien, la barre d'état indique où il mène. Faites Ctrl+Clic⌘+Clic sur un lien pour l'ouvrir dans votre navigateur. Cliquez dessus avec le bouton droit pour choisir , ou .

Les mots mal orthographiés sont soulignés. Cliquez sur l'un d'eux avec le bouton droit pour obtenir des suggestions.
