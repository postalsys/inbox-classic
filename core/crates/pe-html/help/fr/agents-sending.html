Quand un agent envoie du courrier

Chaque message qu'un agent d'IA veut envoyer vous est d'abord montré, et attend dans la Boîte d'envoi avant de partir.

Un agent ne peut envoyer du courrier que si vous l'y avez autorisé, et chaque message seulement après votre accord.

Quand l'agent veut envoyer un message, Inbox Classic l'affiche avec chaque destinataire par son adresse. Les adresses auxquelles vous n'avez jamais écrit sont signalées par .

  1. Lisez les destinataires et le texte.
  2. Choisissez l'une des options :
    • autorise l’envoi et place le message dans la Boîte d’envoi. Le bouton s’active après un bref délai pour limiter les clics accidentels.
    • l'ouvre dans un nouveau message pour que vous le modifiiez.
    • , le choix par défaut, ne l'envoie pas.

Un programme ne peut avoir qu'un seul message en attente de votre confirmation à la fois. Si vous ne répondez pas tout de suite, l'agent est informé que votre réponse est toujours attendue. Il peut consulter votre décision plus tard. Le texte de signature de votre compte est ajouté par défaut au bas des messages et brouillons rédigés par un agent. Celui-ci peut toutefois l'omettre.

Un message d’agent dont vous autorisez l’envoi attend au moins 30 secondes dans la Boîte d'envoi. Tant qu'il n'est pas parti, vous pouvez l'y supprimer, ou cliquer sur dans > .

Réponses aux invitations

Un agent autorisé à envoyer du courrier peut accepter, accepter provisoirement ou refuser une invitation de calendrier pour vous, avec la même question. Au-dessus du texte, la question indique à quelle invitation le message répond et quand l'événement a lieu. Inbox Classic rédige la réponse à l'organisateur à partir de l'invitation elle-même, le message ne peut donc pas être ouvert pour être modifié avant. Votre réponse dans Inbox Classic change après l’envoi SMTP. Cela ne confirme pas que le calendrier de l’organisateur l’a enregistrée.

Brouillons rédigés par un agent

Lorsque vous ouvrez un brouillon rédigé par un agent, le nom de l'agent s'affiche au-dessus du texte du message. Vérifiez les destinataires et le texte avant de l'envoyer.

Un agent ne peut modifier ou supprimer que les brouillons qu'il a lui-même créés. Dès que vous enregistrez un de ces brouillons, l'agent ne peut plus le modifier ni le supprimer. C'est aussi le cas lorsqu'Inbox Classic enregistre automatiquement vos modifications. Le simple fait d'ouvrir le brouillon n'empêche pas l'agent de le modifier.

Un agent qui dispose aussi d'autres outils, par exemple pour naviguer sur le web ou lire vos fichiers, pourrait transmettre par ce biais ce qu'il lit. Inbox Classic ne peut pas voir ces outils. Ne laissez un agent envoyer du courrier que si vous en avez besoin.
