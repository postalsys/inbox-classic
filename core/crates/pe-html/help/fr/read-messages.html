Lire les messages

Lisez un message dans le volet de lecture ou dans une fenêtre à part, et parcourez votre courrier au clavier.

Sélectionnez un message dans la liste pour l'afficher dans le volet de lecture, sous son expéditeur, sa date, ses destinataires et son objet. Un message est marqué comme lu après avoir été affiché une seconde. La liste affiche la date de chaque message, mais jamais une date postérieure à son arrivée, afin qu'un message daté dans le futur ne reste pas en haut.

  • Pour le marquer vous-même, choisissez > () ou .
  • Pour marquer comme lus tous les messages d'un dossier, choisissez > (), ou cliquez sur le dossier avec le bouton droit.

Seulement les messages non lus

Pour n'afficher que les messages que vous n'avez pas lus, choisissez > , ou cliquez sur dans la barre d'outilsle bouton de filtre de la barre d'outilsle bouton de filtre de la barre d'en-tête. Cela vaut pour tous les dossiers et reste actif jusqu'à ce que vous le désactiviez. Un message que vous lisez reste dans la liste jusqu'à ce que vous passiez à un autre dossier.
