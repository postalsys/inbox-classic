Connecter un agent d'IA

Laissez un agent d'IA, comme Claude, lire et organiser votre courrier par l'intermédiaire d'Inbox Classic.

Vous pouvez laisser un agent d'IA travailler avec votre courrier. Il peut s'agir de Claude, de Cursor ou d'un autre programme compatible avec le Model Context Protocol (MCP). Inbox Classic ne contient aucune IA, et rien n'est envoyé à un service d'IA tant que vous ne laissez pas entrer un agent.

Pour connecter un agent :

  1. Choisissez > et cliquez sur . Inbox Classic affiche les lignes à ajouter aux paramètres de votre agent.
  2. Ajoutez-les aux serveurs MCP de votre agent. Dans Claude Desktop, c'est dans Settings > Developer > Edit Config.
  3. Démarrez l'agent. À sa première connexion, Inbox Classic vous demande ce qu'il a le droit de faire.

L'agent démarre Inbox Classic en arrière-plan s'il n'est pas déjà ouvert. Seuls les programmes exécutés sous votre compte sur cet ordinateur peuvent l'atteindre.

Pour désactiver tous les agents d'un coup, décochez dans > .
