Connecter un agent d'IA

Laissez un agent d'IA, comme Claude, lire et organiser votre courrier par l'intermédiaire d'Inbox Classic.

Vous pouvez laisser un agent d'IA travailler avec votre courrier. Il peut s'agir de Claude, de Cursor ou d'un autre programme compatible avec le Model Context Protocol (MCP). Inbox Classic ne contient aucune IA, et rien n'est envoyé à un service d'IA tant que vous ne laissez pas entrer un agent.

Pour connecter un agent :

  1. Choisissez > et cliquez sur . Inbox Classic affiche les lignes à ajouter aux paramètres de votre agent.
  2. Ajoutez-les aux serveurs MCP de votre agent. Dans Claude Desktop, c'est dans Settings > Developer > Edit Config.
  3. Démarrez l'agent. À sa première connexion, Inbox Classic vous demande ce qu'il a le droit de faire.

L'agent démarre Inbox Classic en arrière-plan s'il n'est pas déjà ouvert. Seuls les programmes exécutés sous votre compte sur cet ordinateur peuvent l'atteindre.

Inbox Classic identifie auprès du système le programme qui a lancé l’agent et lui associe les autorisations accordées. Si le nom annoncé par l’agent diffère, la demande d’autorisation le signale. Cette identification ne constitue pas une protection entre tous les programmes exécutés sous le même compte utilisateur.

Un agent peut suivre les changements dans votre Boîte de réception, un compte ou un dossier. Deux instructions prédéfinies sont aussi disponibles : « Triage my inbox » et « Summarize unread ». Ces fonctions respectent ses autorisations ; leurs lectures sont consignées dans son journal.

Quand Inbox Classic reconnaît le terminal de lancement, les agents qui en proviennent, comme Claude Code, partagent un même accès. L’autorisation est associée aux programmes lancés depuis Terminalprogrammes lancés depuis un terminal, et ceux-ci partagent ce que vous autorisez. Pour donner à un agent son propre accès, ajoutez --name et le nom de votre choix après --mcp dans ses paramètres, par exemple "args": ["--mcp", "--name", "Claude Code"]. Inbox Classic vous demande alors une autorisation distincte sous ce nom. Ce nom choisi librement ne prouve pas l’identité de l’agent.

Pour bloquer l’accès de tous les agents à la fois, désactivez l’option dans > .
