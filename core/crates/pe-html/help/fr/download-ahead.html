Télécharger les messages à l'avance

Les nouveaux messages sont téléchargés en arrière-plan dès leur arrivée pour que vous puissiez les ouvrir sans attendre.

Inbox Classic télécharge les nouveaux messages en arrière-plan dès leur arrivée. Vous pouvez ainsi les ouvrir immédiatement, même sans connexion Internet. Lorsque vous ouvrez un message, ceux qui le précèdent et le suivent sont également téléchargés pour vous permettre de passer plus rapidement au suivant.

Pour modifier les paramètres de téléchargement, ouvrez > Inbox Classic > > :

  • L’option télécharge les messages des 30 derniers jours dont la taille ne dépasse pas 1 Mo. L’option télécharge tous les messages dans la limite de stockage définie ci-dessous. Avec , un message n’est téléchargé que lorsque vous l’ouvrez.
  • Définit l’espace que les messages téléchargés de chaque compte peuvent occuper sur cet ordinateur. Lorsque cette limite est dépassée, les copies locales les plus anciennes sont supprimées. Les messages restent sur le serveur et sont téléchargés à nouveau lorsque vous les ouvrez.

Les messages des dossiers et , ainsi que ceux du dossier « Tous les messages » de Gmail, ne sont téléchargés qu’à l’ouverture.

Pour les messages de plus de 1 Mo, le texte s'affiche en premier. Le téléchargement des pièces jointes se poursuit en arrière-plan et la barre d'état indique sa progression. Une fois le téléchargement terminé, vous pouvez ouvrir les pièces jointes, enregistrer le message ou le transférer.
