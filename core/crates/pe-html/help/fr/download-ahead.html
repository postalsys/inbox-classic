Télécharger les messages à l'avance

Choisissez les messages à télécharger en arrière-plan pour les ouvrir plus rapidement, même hors connexion.

Inbox Classic télécharge les nouveaux messages en arrière-plan selon vos paramètres. Vous pouvez ainsi les ouvrir immédiatement, même sans connexion Internet. Lorsque vous ouvrez un message, les messages voisins dans l’ordre chronologique du dossier peuvent aussi être téléchargés pour vous permettre de passer plus rapidement au suivant.

Pour modifier les paramètres de téléchargement, ouvrez :

  •  : l’option télécharge les messages des 30 derniers jours dont la taille ne dépasse pas 1 Mo. L’option télécharge les messages dans la limite de stockage ci-dessous, avec les exceptions indiquées ensuite. Avec , le téléchargement anticipé est désactivé, y compris pour les messages voisins. Le contenu peut être téléchargé à l’ouverture.
  • limite l’espace des copies locales de contenu de chaque compte. Au-delà, les plus anciennes sont supprimées. Les brouillons et les messages ouverts depuis le lancement sont conservés, même si cela dépasse la limite. Celle-ci ne s’applique pas à toute la base de données. Les messages restent sur le serveur et sont téléchargés à nouveau lorsque vous les ouvrez.

Les messages des dossiers et , ainsi que ceux du dossier « Tous les messages » de Gmail, sont exclus du téléchargement anticipé général. Ils peuvent être téléchargés à l’ouverture.

Pour les messages de plus de 1 Mo, le texte peut s’afficher avant la fin du téléchargement si la structure du message et le serveur le permettent. Le téléchargement des pièces jointes se poursuit en arrière-plan et la barre d'état indique sa progression. Une fois le téléchargement terminé, vous pouvez ouvrir les pièces jointes, enregistrer le message ou le transférer.
