Gmail, Google Workspace, Outlook.com ou Microsoft 365

Pour ajouter le compte via votre navigateur :

  1. Cliquez sur ou . Votre navigateur web ouvre la page de connexion du fournisseur.
  2. Connectez-vous sur cette page, puis revenez dans Inbox Classic. Le compte est ajouté et son courrier commence à arriver.

Un bouton grisé est désactivé sur cet ordinateur. Cliquez sur en dessous pour en connaître la raison.

Tout autre compte

Pour ajouter le compte avec son mot de passe :

  1. Tapez votre nom, tel que les autres doivent le voir, dans .
  2. Tapez votre adresse dans .
  3. Cliquez sur . Inbox Classic recherche les paramètres de votre fournisseur, ce qui prend quelques secondes. interrompt la recherche.
  4. Tapez votre mot de passe dans .
  5. Vérifiez les paramètres des serveurs, puis cliquez sur . Inbox Classic se connecte et télécharge vos dossiers.

Si votre fournisseur demande un mot de passe d'application au lieu de votre mot de passe habituel, Inbox Classic vous le signale et propose d'ouvrir les instructions du fournisseur.

Quand aucun paramètre n'est trouvé, les noms des serveurs sont devinés : imap. et smtp. suivis de votre domaine. Comparez-les avec ce que vous indique votre fournisseur.
