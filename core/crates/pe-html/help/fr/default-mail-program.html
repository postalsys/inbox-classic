Faire d'Inbox Classic votre application de messagerie

Ouvrez dans Inbox Classic les liens de messagerie et les fichiers de messages des pages web et des autres programmes.

Les liens de messagerie (mailto:) ouvrent un nouveau message dans votre application de messagerie par défaut.

Pour qu'Inbox Classic devienne cette application, choisissez > . Windows ouvre ses paramètres Applications par défaut, où vous choisissez Inbox Classic pour les liens MAILTO. Seule une copie installée y figure. Inbox Classic devient aussitôt l'application de messagerie par défaut.

Quand vous cliquez ensuite sur un lien de messagerie, un nouveau message s'ouvre avec les adresses, l'objet et le texte du lien déjà remplis. Rien d'autre du lien n'est utilisé.

Si vous n'avez encore aucun compte, Inbox Classic vous demande d'en ajouter un d'abord. Cliquez de nouveau sur le lien une fois le compte ajouté.

Les fichiers de messages

Pour que les fichiers .eml s'ouvrent dans Inbox Classic quand vous double-cliquez dessus, cliquez sur dans > Inbox Classic > > . Windows ouvre ses paramètres Applications par défaut, où vous choisissez Inbox Classic pour les fichiers .eml. Inbox Classic devient aussitôt leur application.
