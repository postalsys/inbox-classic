Signer et chiffrer un message

Signez numériquement vos messages et chiffrez leur contenu pour que seuls vous et les destinataires puissiez le lire.

La signature numérique permet de vérifier que le contenu du message n’a pas été modifié depuis qu’il a été signé. L’identité du propriétaire de la clé se vérifie séparément. Seuls vous et les destinataires pouvez lire le contenu d’un message chiffré. À l’envoi, les messages chiffrés sont aussi signés. Vous devez disposer de votre propre clé pour signer ou chiffrer.

Pour signer ou chiffrer un message :

  1. Dans la fenêtre du message, cliquez sur ou , ou choisissez > ou . Vous pouvez aussi appuyer sur ou . Si aucune clé n’est configurée pour l’adresse d’expédition, Inbox Classic propose d’en créer une.
  2. Cliquez sur .

Lorsque est activé, chaque destinataire apparaît sous l’objet avec un symbole indiquant l’état de sa clé. Inbox Classic recherche les clés manquantes :

CouleurSignification
VertVous avez confirmé à qui appartient la clé.
BleuLa clé n’a pas été vérifiée, ou il s’agit de votre propre clé.
GrisInbox Classic recherche la clé du destinataire.
OrangeAucune clé utilisable n’est disponible pour le destinataire.

Si une clé manque ou est inutilisable

Pour envoyer un message chiffré, il faut une clé utilisable pour chaque destinataire. Si une clé manque ou est inutilisable, cliquez sur pour ouvrir la fenêtre . Choisissez pour relancer la recherche ou pour retirer le destinataire du message. L’option est disponible si le message ne contient plus de contenu provenant de messages chiffrés. Vous pouvez aussi demander sa clé publique au destinataire et l’importer.

Réponses au courrier chiffré

Lorsque vous répondez à un message chiffré ou le transférez, est activé automatiquement. Inbox Classic demande confirmation avant de le désactiver. Tant que le message contient du texte cité, des images ou des pièces jointes issus du message chiffré, il doit être envoyé chiffré.

Les brouillons de ces messages sont enregistrés chiffrés avec votre propre clé. La copie conservée dans reste également chiffrée.

Partager votre clé publique

Pour partager votre clé publique, choisissez > . La clé publique de l’adresse d’expédition sélectionnée est jointe au message sous forme de fichier. Les destinataires pourront l’utiliser pour vous envoyer des messages chiffrés.
