Options de la ligne de commande

Les options pour démarrer Inbox Classic depuis un terminal, pour les tests et pour les agents d'IA.

Démarrez le programme InboxClassic.exe"Inbox Classic.app/Contents/MacOS/Inbox Classic"inbox-classic avec ces options :

OptionEffet
--store <fichier>Utilise un autre stockage du courrier, par exemple pour des tests
--memory-passwordsNe garde les mots de passe que pendant cette session, jamais dans le stockage des mots de passe du système
--pin-certificate <fichier>N'accepte que le certificat de serveur de ce fichier (PEM ou DER), pour un serveur de test au certificat auto-signé
--sign-in-page-file <fichier>Écrit la page d'une connexion via le navigateur dans ce fichier au lieu d'ouvrir le navigateur
--language <code>Affiche les fenêtres dans cette langue pour cette session, par exemple de
--backgroundDémarre sans fenêtre
--mcpConnecte un agent d'IA à Inbox Classic. C'est le programme de l'agent qui lance cette option, pas vous
--versionAffiche la version et quitte

Un lien mailto: passé en argument ouvre un nouveau message, comme un lien de messagerie.
