Options de la ligne de commande

Les options pour démarrer Inbox Classic depuis un terminal, pour les tests et pour les agents d'IA.

Démarrez le programme InboxClassic.exe"Inbox Classic.app/Contents/MacOS/Inbox Classic"inbox-classic avec ces options :

OptionEffet
--store <fichier>Utilise la base de données de courrier indiquée au lieu de son emplacement par défaut, par exemple pour des tests
--memory-passwordsConserve les données de connexion, y compris celles obtenues via le navigateur, uniquement pendant cette exécution, sans utiliser le gestionnaire de secrets du système
--pin-certificate <fichier>Limite les certificats de serveur acceptés à ceux de ce fichier : plusieurs certificats PEM ou un certificat DER. Utile, par exemple, pour un serveur de test avec un certificat autosigné
--sign-in-page-file <fichier>Écrit dans ce fichier l’adresse de la page de connexion, au lieu d’ouvrir le navigateur
--language <code>Affiche les fenêtres dans cette langue pour cette session, par exemple de
--backgroundDémarre sans fenêtre
--mcpConnecte un agent d'IA à Inbox Classic. C'est le programme de l'agent qui lance cette option, pas vous
--versionAffiche la version et quitte

Un lien mailto: passé en argument ouvre un nouveau message si un compte est déjà configuré, comme un lien de messagerie.
