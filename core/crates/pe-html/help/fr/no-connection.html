Inbox Classic ne parvient pas à se connecter

Que faire quand le serveur de messagerie est inaccessible ou ne répond pas.

Vous pouvez voir l'un de ces messages dans la barre d'état ou le volet de lecture :

  • « connection error: … »
  • « the server did not answer in time »
  • « la connexion au serveur a échoué (…) »
  • « Le serveur de messagerie est inaccessible (…). »

Pour corriger le problème :

  1. Vérifiez votre connexion Internet.
  2. Ouvrez les propriétés du compte dans > et vérifiez les noms des serveurs et les ports.
  3. Si l'envoi échoue, utilisez le port 465 ou 587 pour le courrier sortant. Certains réseaux bloquent les ports de messagerie, en particulier le port 25.

Inbox Classic réessaie à la prochaine relève du courrier. Pour réessayer maintenant, cliquez sur .

Un message envoyé sans connexion attend dans la Boîte d'envoi et part dès que le serveur est joignable. Rien de ce que vous avez écrit n'est perdu.
