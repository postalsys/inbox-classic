Inbox Classic ne parvient pas à se connecter

Que faire quand le serveur de messagerie est inaccessible ou ne répond pas.

Vous pouvez voir l'un de ces messages dans la barre d'état ou le volet de lecture :

  • « connection error: … »
  • « the server did not answer in time »
  • « la connexion au serveur a échoué (…) »
  • « La connexion au serveur de messagerie a échoué ou a été interrompue (…). »

Pour corriger le problème :

  1. Vérifiez votre connexion Internet.
  2. Ouvrez les propriétés du compte dans > et vérifiez les noms des serveurs et les ports.
  3. Si l’envoi échoue, vérifiez le port et le mode de chiffrement indiqués par le fournisseur, généralement SSL/TLS sur le port 465 ou STARTTLS sur le port 587. Certains réseaux bloquent les ports de messagerie, en particulier le port 25.

Inbox Classic réessaie à la prochaine relève du courrier. Après deux échecs de connexion consécutifs, un avertissement apparaît à côté du compte dans la liste des dossiers et au-dessus de sa liste de messages. Pour réessayer maintenant, cliquez sur l’icône d’avertissement, sur dans la barre ou sur . L’avertissement disparaît quand le compte se reconnecte.

Un message envoyé sans connexion reste dans la Boîte d’envoi locale. Inbox Classic réessaie dès qu’il peut se connecter ; le serveur peut encore refuser le message.
