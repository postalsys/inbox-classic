Liens, scripts et pièces jointes

Comment Inbox Classic empêche un message d'exécuter du code ou d'ouvrir des pages de lui-même.

  • Les scripts des messages ne s'exécutent jamais. Inbox Classic nettoie chaque message avant de l'afficher, sans exécuter le code provenant du message.
  • Les liens vers des pages web s’ouvrent dans votre navigateur. Les liens de messagerie peuvent ouvrir un nouveau message dans Inbox Classic. Un message ne peut pas ouvrir une page ou une fenêtre de lui-même.
  • Les pièces jointes peuvent être enregistrées ou ouvertes, à votre demande, dans une application externe. Inbox Classic retire de leurs noms les caractères dangereux ou trompeurs avant l’enregistrement.
  • Le désabonnement vous demande d'abord confirmation, et indique ce qu'il va faire.
Avant de taper un mot de passe sur une page atteinte depuis un message, vérifiez l'adresse dans votre navigateur. Un message peut afficher une adresse et mener vers une autre.

Quand vous écrivez un message, la barre d'état indique où mène le lien sous le curseur, pour que vous puissiez le vérifier avant l'envoi.

Un code de connexion n'est proposé que si votre fournisseur de messagerie confirme une signature valide pour le domaine associé au code. Cela ne prouve ni l’identité d’une personne ni la fiabilité du contenu. Voir .

Inbox Classic traite les images des messages avant de les transmettre au composant d’affichage. Il n’utilise pas les polices jointes aux messages. Les fichiers que vous ouvrez dans une autre application sont ensuite traités par celle-ci.
