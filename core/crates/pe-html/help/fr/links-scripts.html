Liens, scripts et pièces jointes

Comment Inbox Classic empêche un message d'exécuter du code ou d'ouvrir des pages de lui-même.

  • Les scripts des messages ne s'exécutent jamais. Inbox Classic nettoie chaque message avant de l'afficher, et le volet de lecture ne peut pas exécuter de code.
  • Les liens s'ouvrent dans votre navigateur web, jamais dans Inbox Classic. Un message ne peut pas ouvrir une page ou une fenêtre de lui-même.
  • Les pièces jointes sont enregistrées, jamais ouvertes depuis Inbox Classic. Leurs noms sont rendus sûrs avant que vous les enregistriez.
  • Le désabonnement vous demande d'abord confirmation, et indique ce qu'il va faire.
Avant de taper un mot de passe sur une page atteinte depuis un message, vérifiez l'adresse dans votre navigateur. Un message peut afficher une adresse et mener vers une autre.

Quand vous écrivez un message, la barre d'état indique où mène le lien sous le curseur, pour que vous puissiez le vérifier avant l'envoi.
