Codes de connexion

Un message qui contient un code de connexion ou de vérification affiche ce code dans une carte d'où vous pouvez le copier.

Quand Inbox Classic détecte un code à usage unique dans un message pris en charge, par exemple pour se connecter, vérifier ou autoriser une action, une carte au-dessus du message affiche :

  • « Code de » suivi du domaine auquel le code est destiné
  • le code, en grands caractères
  • , qui place le code dans le presse-papiers
Ne saisissez un code que sur une page du domaine indiqué par la carte. Un message qui vous demande de taper un code ailleurs peut être une tentative de prise de contrôle de votre compte.

La carte n’apparaît que si votre fournisseur de messagerie confirme une signature valide pour le domaine du code ou son domaine parent. Cela confirme le domaine, mais pas l’identité d’une personne ni la fiabilité du contenu. Il n'y a pas de carte dans , ou , ni quand votre fournisseur ne signale pas les signatures.

Si la date du message remonte à plus d’une heure, la carte prévient que le code peut avoir expiré. Inbox Classic ne vérifie pas sa validité auprès du service qui l’a émis.

Codes dans les notifications

Pour inclure les codes détectés dans les notifications de nouveaux messages, activez dans . Les notifications de courrier doivent aussi être activées et autorisées. Le code n’apparaît que si le message est assez récent et petit pour être téléchargé et vérifié à temps. Les messages chiffrés affichent une notification générique, sans code. Cette option est désactivée par défaut, car les notifications peuvent être lues sur un écran verrouillé.
