Codes de connexion

Un message qui contient un code de connexion ou de vérification affiche ce code dans une carte d'où vous pouvez le copier.

Quand un message contient un code à usage unique, comme un code de connexion, de vérification ou d'approbation, une carte au-dessus du message affiche :

  • « Code de » suivi du domaine auquel le code est destiné
  • le code, en grands caractères
  • , qui place le code dans le presse-papiers
Ne saisissez un code que sur une page du domaine indiqué par la carte. Un message qui vous demande de taper un code ailleurs peut être une tentative de prise de contrôle de votre compte.

La carte n'apparaît que si votre fournisseur de messagerie confirme que le domaine a signé le message. Le code d'un message inventé par quelqu'un d'autre n'est pas proposé. Il n'y a pas de carte dans , ou , ni quand votre fournisseur ne signale pas les signatures.

Un code envoyé plus d'une heure avant que vous ouvriez le message a probablement expiré, et la carte le signale.

Codes dans les notifications

Pour voir le code dans la notification d'un nouveau message, activez dans > Inbox Classic > > . Ce réglage est désactivé au départ, car une notification peut se lire sur un écran verrouillé.
