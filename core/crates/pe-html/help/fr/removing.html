Désinstaller Inbox Classic

Retirez Inbox Classic de votre ordinateur, avec ou sans le courrier qu'il a téléchargé.

Désinstallez Inbox Classic depuis Paramètres > Applications > Applications installées. Il demande s'il faut aussi supprimer le courrier qu'il a téléchargé.

Quittez Inbox Classic et faites-le glisser du dossier Applications vers la Corbeille. Le courrier qu'il a téléchargé reste dans ~/Library/Application Support/Inbox Classic jusqu'à ce que vous supprimiez aussi ce dossier.

Supprimez le paquet avec sudo apt remove inbox-classic, ou avec sudo pacman -R inbox-classic sous Arch Linux et Omarchy. Le courrier qu'il a téléchargé reste dans ~/.local/share/inbox-classic jusqu'à ce que vous supprimiez aussi ce dossier.

Le courrier sur vos serveurs n'est jamais supprimé.
