Désinstaller Inbox Classic

Retirez Inbox Classic de votre ordinateur, en choisissant de conserver ou non ses données locales.

Désinstallez Inbox Classic depuis Paramètres > Applications > Applications installées. Le programme de désinstallation demande s’il faut aussi supprimer les données locales : courrier téléchargé, messages en attente d’envoi, comptes, paramètres, contacts, règles et clés de chiffrement.

Quittez Inbox Classic et faites-le glisser du dossier Applications vers la Corbeille. Les données locales, notamment le courrier téléchargé, les paramètres, les contacts et les clés de chiffrement, restent dans ~/Library/Application Support/Inbox Classic jusqu'à ce que vous supprimiez aussi ce dossier.

Supprimez le paquet avec sudo apt remove inbox-classic, ou avec sudo pacman -R inbox-classic sous Arch Linux et Omarchy. Les données locales, notamment le courrier téléchargé, les paramètres, les contacts et les clés de chiffrement, restent dans ~/.local/share/inbox-classic jusqu'à ce que vous supprimiez aussi ce dossier.

Le courrier sur vos serveurs n'est jamais supprimé.

La désinstallation et la suppression du dossier de données ne retirent pas les données de connexion du gestionnaire du système. Pour retirer celles d’un compte, supprimez d’abord ce compte dans > . Pour ne supprimer qu'un seul compte, voir .
