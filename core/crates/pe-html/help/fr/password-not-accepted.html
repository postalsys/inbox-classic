Le mot de passe n'est pas accepté

Que faire quand le serveur de messagerie refuse votre mot de passe ou votre connexion.

Vous pouvez voir l'un de ces messages :

  • Dans la barre d'état : « le serveur n'a pas accepté la connexion (…) »
  • Dans le volet de lecture : « Le serveur de messagerie a refusé la connexion (…). Vérifiez le mot de passe ou reconnectez-vous dans Fichier > Comptes. »
  • Une fenêtre qui vous demande de saisir de nouveau le mot de passe du compte

Pour corriger le problème :

  1. Tapez de nouveau le mot de passe quand Inbox Classic le demande, ou modifiez-le dans les propriétés du compte, dans > .
  2. Si votre fournisseur demande une deuxième étape quand vous vous connectez sur le web, il exige aussi un mot de passe d'application pour les programmes de messagerie. Créez-en un dans les paramètres de sécurité de votre compte et utilisez-le à la place de votre mot de passe habituel.
  3. Pour Gmail et Outlook.com, connectez-vous via le navigateur ou utilisez un mot de passe d'application. Voir .

Un compte qui se connecte via le navigateur

Quand le fournisseur met fin à la connexion, Inbox Classic affiche « La connexion au compte … a été refusée ou la session a expiré. » Il demande «  » Choisissez et connectez-vous de nouveau dans le navigateur.
