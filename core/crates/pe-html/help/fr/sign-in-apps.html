Applications de connexion

Enregistrez votre propre application de connexion auprès de Google, de Microsoft ou de tout fournisseur OpenID Connect, pour vous connecter via le navigateur.

La connexion via le navigateur utilise un client OAuth enregistré auprès du fournisseur. Inbox Classic a les siens pour Google et Microsoft. Le client Google intégré est configuré pour un accès limité, notamment aux utilisateurs de test : c'est pourquoi est désactivé au départ. Vous pouvez enregistrer votre propre client : dans votre projet Google Cloud, dans votre locataire Microsoft Entra ou auprès de tout fournisseur OpenID Connect. Les serveurs de courrier du fournisseur doivent aussi prendre en charge cette méthode de connexion.
