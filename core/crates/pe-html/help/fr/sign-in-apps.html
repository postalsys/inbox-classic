Applications de connexion

Enregistrez votre propre application de connexion auprès de Google, de Microsoft ou de tout fournisseur OpenID Connect, pour vous connecter via le navigateur.

La connexion via le navigateur utilise un client OAuth enregistré auprès du fournisseur. Inbox Classic a les siens pour Google et Microsoft. Google ne laisse que les utilisateurs de test utiliser le client d'Inbox Classic tant qu'il n'a pas vérifié l'application : c'est pourquoi est désactivé au départ. Vous pouvez enregistrer votre propre client : dans votre projet Google Cloud, dans votre locataire Microsoft Entra ou auprès de tout fournisseur OpenID Connect.
