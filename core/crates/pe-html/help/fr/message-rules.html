Trier le nouveau courrier avec des règles

Déplacez, marquez comme lus ou archivez automatiquement les messages entrants selon vos critères, ou ajoutez-leur un indicateur.

Une règle associe des critères de recherche à des actions à effectuer sur les messages qui y correspondent, dès leur arrivée dans la boîte de réception. Par exemple, une règle avec from:news@example.com peut déplacer les lettres d’information provenant de cette adresse dans un dossier à part et les marquer comme lues.

Pour créer une règle :

  1. Choisissez > , puis cliquez sur .
  2. Saisissez un nom et remplissez le champ avec les mêmes termes que dans la zone de recherche, par exemple from:, subject: ou list:. La ligne en dessous indique combien de messages de la boîte de réception correspondent actuellement à ces critères.
  3. Choisissez une ou plusieurs actions pour les messages correspondants : les déplacer dans un dossier, les marquer comme lus, leur ajouter un indicateur, les archiver, les déplacer dans le Courrier indésirable, les supprimer ou désactiver les notifications les concernant.
  4. Cliquez sur .

Vous pouvez aussi créer une règle à partir d’un message ou d’une recherche. Choisissez > pour préremplir les critères avec l’expéditeur ou la liste de diffusion du message sélectionné. Cliquez sur au-dessus des résultats de recherche pour reprendre les critères de la recherche en cours.

Comment fonctionnent les règles

Les règles traitent les nouveaux messages reçus tant qu’Inbox Classic est ouvert, y compris lorsqu’il est réduit dans la zone de notification. Elles ne s’appliquent aux messages déjà présents que si vous cochez . Les règles dont les critères sont remplis s’appliquent dans l’ordre de la liste. Dès qu’une règle déplace un message hors de la boîte de réception, les suivantes ne s’appliquent plus à ce message. Décochez la case d’une règle dans la liste pour la désactiver sans la supprimer.

Modifier les règles

Pour modifier une règle, sélectionnez-la dans la liste et cliquez sur , ou double-cliquez dessus. Utilisez et pour changer l’ordre, ou pour supprimer la règle. Dans l’éditeur de règle, cliquez sur pour afficher dans la fenêtre principale les messages qui correspondent actuellement aux critères.

Les règles s’appliquent aux nouveaux messages de la boîte de réception. Les filtres de dossier et de date ne sont donc pas pris en charge. Si vous utilisez in:, before:, after:, older_than: ou newer_than:, un message vous en explique la raison. Les règles ne peuvent ni envoyer de messages ni les supprimer définitivement : les déplace vers .

Les règles s’appliquent sur cet ordinateur. Pour trier le courrier quand il est éteint, utilisez les filtres de votre fournisseur de messagerie.
