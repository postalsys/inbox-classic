Pièces jointes

Ouvrez et enregistrez les pièces jointes reçues, et ajoutez des fichiers à vos propres messages.

Voir les images et les fichiers PDF dans le message

Les images et jusqu’à cinq pages de chaque fichier PDF s’affichent après le texte d’un message, avec leur nom et leur taille. Cliquez sur l’une d’elles pour ouvrir le fichier. Un lien permet d’ouvrir les PDF plus longs. L’affichage automatique est limité à 20 images et pages par message ; une ligne en dessous indique combien d’autres fichiers figurent dans la liste.

Inbox Classic génère ces aperçus sans exécuter le code contenu dans les fichiers ni charger leurs ressources externes. Un fichier dont l’aperçu ne peut pas être généré apparaît sous forme de vignette avec son nom, sa taille et la raison, par exemple une image HEIC ou un fichier PDF protégé par un mot de passe ; cliquez sur la vignette pour ouvrir le fichier. Tant qu’un message volumineux est en cours de téléchargement, ses fichiers apparaissent en vignettes jusqu’à leur arrivée. Dans un message signé ou chiffré, chaque partie affiche ses propres fichiers dans son propre cadre. Les aperçus des parties chiffrées restent en mémoire pendant l’affichage. En revanche, ouvrir un fichier dans une autre application ou l’enregistrer crée une copie non chiffrée sur le disque.

Pour afficher un fichier dans le message, ou l’en retirer, cliquez dessus avec le bouton droit dans la liste des fichiers et choisissez . Ce choix vaut tant que le message est affiché.

Pour ne voir que la liste, désactivez dans . Si Inbox Classic se ferme pendant la préparation d’un aperçu, les aperçus PDF sont désactivés au redémarrage. Cela ne prouve pas que le fichier a causé la fermeture ; activez pour les afficher à nouveau.

Quand vous imprimez un message, les aperçus d’images qui y sont affichés sont aussi imprimés. Les fichiers PDF ne le sont pas : une ligne nomme chacun d’eux, et vous l’imprimez depuis son propre programme. Dans un message signé ou chiffré, les images de chaque partie viennent juste après le texte de cette partie, chacune avec le nom de sa partie.

Ouvrir une pièce jointe

Les pièces jointes apparaissent sous l’en-tête du message, avec leur nom et leur taille. Double-cliquez sur un fichier pour l’ouvrir dans l’application associée. Au clavier, appuyez sur Tab pour atteindre les pièces jointes, sélectionnez-en une avec les flèches, puis appuyez sur Enter.

Faites un clic droit sur un fichier pour accéder à , et . L’icône du trombone, à droite de l’en-tête, affiche également la liste des pièces jointes.

Inbox Classic bloque l’ouverture directe des types de fichiers reconnus comme pouvant exécuter du code : scripts, programmes d’installation, raccourcis, images disque, pages web ou documents Office avec macros. La commande est désactivée pour ces fichiers. Ne les enregistrez pour les ouvrir vous-même que si vous faites confiance à leur provenance.

Pour ouvrir un fichier, Inbox Classic enregistre une copie dans un dossier temporaire de votre compte utilisateur. Au démarrage, l’application tente de supprimer les copies datant de plus d’un jour. Sous Windows et macOS, leur provenance d’Internet est signalée. Les pièces jointes des messages chiffrés y sont enregistrées sans chiffrement ; Inbox Classic vous en avertit à la première ouverture.

Enregistrer une pièce jointe

Faites un clic droit sur un fichier et choisissez . Pour enregistrer toutes les pièces jointes dans un dossier, choisissez . Inbox Classic retire du nom proposé les caractères qui pourraient masquer le véritable nom du fichier. Lors de l’enregistrement de toutes les pièces jointes, les fichiers existants sont conservés et les nouveaux reçoivent des noms distincts. Pour un seul fichier, le remplacement dépend du dialogue d’enregistrement du système.

N'ouvrez que les pièces jointes que vous attendez de la part de leur expéditeur. Un programme, ou un document qui vous demande d'« activer le contenu », peut prendre le contrôle de votre ordinateur. Les programmes comprennent les fichiers .exe, .msi, .js, .vbs, .bat et .scr..app, .pkg, .dmg et .command..sh, .deb, .AppImage et .desktop.

Joindre un fichier

Pour joindre des fichiers au message que vous écrivez :

  1. Cliquez sur .
  2. Choisissez les fichiers. Ils sont listés dans avec leur taille.

Vous pouvez aussi faire glisser des fichiers depuis l'Explorateur de fichiersle Finderle gestionnaire de fichiers sur les champs d'adresse. Un fichier qui n'est pas une image peut aussi être déposé sur le texte.

Pour retirer un fichier, sélectionnez-le et appuyez sur Delete, ou cliquez dessus avec le bouton droit et choisissez . Les fichiers sont lus au moment de l'envoi du message : laissez-les à leur place jusque-là.
