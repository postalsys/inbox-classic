Pièces jointes

Enregistrez les fichiers joints à un message, et joignez des fichiers aux messages que vous écrivez.

Enregistrer une pièce jointe

Pour enregistrer les fichiers d'un message :

  1. Cliquez sur le trombone à droite de l'en-tête du message. Il indique le nombre de fichiers.
  2. Choisissez un fichier pour l'enregistrer, ou choisissez pour les enregistrer tous dans un dossier.

Inbox Classic enregistre les fichiers, mais ne les ouvre jamais. Il propose un nom sûr, sans les caractères qui pourraient faire passer un nom pour autre chose. Un fichier du même nom déjà présent dans le dossier est conservé, et le nouveau reçoit un numéro.

N'ouvrez que les pièces jointes que vous attendez de la part de leur expéditeur. Un programme, ou un document qui vous demande d'« activer le contenu », peut prendre le contrôle de votre ordinateur. Les programmes comprennent les fichiers .exe, .msi, .js, .vbs, .bat et .scr..app, .pkg, .dmg et .command..sh, .deb, .AppImage et .desktop.

Joindre un fichier

Pour joindre des fichiers au message que vous écrivez :

  1. Cliquez sur .
  2. Choisissez les fichiers. Ils sont listés dans avec leur taille.

Vous pouvez aussi faire glisser des fichiers depuis l'Explorateur de fichiersle Finderle gestionnaire de fichiers sur les champs d'adresse. Un fichier qui n'est pas une image peut aussi être déposé sur le texte.

Pour retirer un fichier, sélectionnez-le et appuyez sur Delete, ou cliquez dessus avec le bouton droit et choisissez . Les fichiers sont lus au moment de l'envoi du message : laissez-les à leur place jusque-là.
