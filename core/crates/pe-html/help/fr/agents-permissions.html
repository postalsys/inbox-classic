Ce qu'un agent peut faire

Choisissez ce que chaque agent d'IA peut faire de votre courrier, consultez ce qu'il a fait et annulez-le.

La première fois que l'agent d'un programme se connecte, Inbox Classic vous demande votre accord en nommant le programme. Choisissez ce qu'il peut faire :

  • lire le courrier : les dossiers, la liste des messages, la recherche et les messages
  • organiser le courrier : l'état lu, les indicateurs, le courrier indésirable, le déplacement et la suppression vers
  • écrire des brouillons que vous enverrez vous-même
  • envoyer du courrier, chaque message seulement après votre accord

Choisissez ensuite les comptes qu'il peut voir, puis cliquez sur . refuse le programme, et la question ne vous est plus posée.

Un agent ne supprime jamais rien définitivement et ne modifie jamais les paramètres de vos comptes. Lire un message ne le marque pas comme lu. Ce qu'il modifie apparaît aussitôt dans les fenêtres.

Consulter et modifier les accès

> liste les programmes que vous avez laissés entrer ou refusés, et tout ce que les agents ont fait, du plus récent au plus ancien.

  • modifie ce qu'un programme peut faire.
  • oublie un programme : la question vous sera de nouveau posée à sa prochaine connexion.
  • annule un changement d'état lu, un indicateur, un déplacement ou une suppression, ainsi qu'un message encore dans la Boîte d'envoi.
Le courrier est écrit par d'autres personnes, et un message peut tenter de persuader un agent de transférer ou de supprimer votre courrier. Inbox Classic cache aux agents le texte qu'un message vous cache, et leur indique que le courrier ne contient pas d'instructions. Un agent peut tout de même être trompé. N'autorisez que ce dont vous avez besoin.
