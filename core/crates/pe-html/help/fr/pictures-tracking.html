Images et pistage

Pourquoi les images d'Internet sont bloquées, et comment les afficher pour un message ou un expéditeur de confiance.

Un message peut afficher des images que l'expéditeur conserve sur Internet. Télécharger une telle image indique à l'expéditeur que vous avez ouvert le message, quand et d'où. C'est pourquoi Inbox Classic ne les télécharge pas.

Les images envoyées dans le message lui-même sont affichées, car elles n'apprennent rien à l'expéditeur.

Quand un message contient des images d'Internet, une barre en travers indique que certaines images ont été bloquées. Pour les voir dans un message de confiance :

  • Ou choisissez > .

Seules les images de ce message s'affichent. Le message suivant est de nouveau bloqué.

Les expéditeurs de confiance

Ses images se chargent alors d'elles-mêmes, mais seulement quand votre fournisseur de messagerie confirme que le message vient bien de ce domaine. Un message qui se fait seulement passer pour lui demande toujours, et la barre indique que l'expéditeur n'a pas pu être confirmé. Dans , les images ne se chargent jamais d'elles-mêmes.

Le logo d'une marque à côté de l'en-tête n'est pas une image de pistage. Il est approuvé par votre serveur de messagerie, et il vient de la marque, pas des images de l'expéditeur.
