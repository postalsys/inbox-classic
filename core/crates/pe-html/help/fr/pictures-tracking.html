Images et pistage

Pourquoi les images externes sont bloquées et comment les afficher dans les messages auxquels vous faites confiance.

Un message peut contenir des images hébergées sur Internet. Leur téléchargement peut permettre à l'expéditeur de savoir quand et d'où vous avez ouvert le message. C'est pourquoi Inbox Classic ne télécharge pas les images externes par défaut.

Les images intégrées au message sont affichées, car leur ouverture ne transmet aucune information à l'expéditeur.

Lorsqu'un message contient des images externes, une barre située au-dessus du message indique que certaines images ont été bloquées. Pour les afficher dans un message auquel vous faites confiance :

  • Cliquez sur la barre.Cliquez sur dans la barre.
  • Ou choisissez > .

Seules les images de ce message sont alors affichées. Les images externes des autres messages restent bloquées.

Les expéditeurs de confiance

Pour télécharger automatiquement les images des messages d'un expéditeur, cliquez sur la flèche à droite de la barrecliquez sur la flèche à côté de dans la barrecliquez sur la flèche à côté de dans la barre. Choisissez de toujours télécharger les images de cet expéditeur, ou de tous ceux de son domaine.

Les images ne sont téléchargées automatiquement que si votre fournisseur de messagerie confirme que le message provient du domaine de l'expéditeur. Si cette origine ne peut pas être vérifiée, les images restent bloquées et la barre affiche un avertissement. Dans le dossier , les images externes ne sont jamais téléchargées automatiquement.

Pour retirer un expéditeur de la liste, utilisez dans > Inbox Classic > > .
