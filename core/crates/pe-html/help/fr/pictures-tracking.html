Images et pistage

Pourquoi les images externes sont bloquées et comment les afficher dans les messages auxquels vous faites confiance.

Un message peut contenir des images hébergées sur Internet. Leur téléchargement peut permettre à l'expéditeur de savoir quand et d'où vous avez ouvert le message. C'est pourquoi Inbox Classic ne télécharge pas les images externes par défaut.

Les images intégrées au message sont affichées, car leur ouverture ne transmet aucune information à l'expéditeur.

Inbox Classic traite les images intégrées au message, comme les images jointes, sans exécuter le code qu’elles pourraient contenir. Une image qu’il ne peut pas afficher (comme HEIC) apparaît comme un espace vide. Les images animées montrent leur première image. Les polices envoyées avec un message ne sont pas utilisées.

Lorsqu'un message contient des images externes, une barre située au-dessus du message indique que certaines images ont été bloquées. Pour les afficher dans un message auquel vous faites confiance :

  • Cliquez sur dans la barre.
  • Ou choisissez > .

Cela autorise les images de ce message. Pour les autres messages, vos réglages de chargement automatique et d’expéditeurs de confiance s’appliquent.

Les expéditeurs de confiance

Pour télécharger automatiquement les images des messages d'un expéditeur, cliquez sur la flèche à côté de dans la barre. Choisissez de toujours télécharger les images de cet expéditeur, ou de tous ceux de son domaine.

Les images ne sont téléchargées automatiquement que si votre fournisseur de messagerie confirme que le message provient du domaine de l'expéditeur. Cela confirme le domaine, pas l’identité d’une personne ni la fiabilité du contenu. Si cette origine ne peut pas être vérifiée, les images restent bloquées et la barre affiche un avertissement. Les images de tous les messages

Dans les parties chiffrées d’un message, vous devez autoriser le chargement des images externes à chaque ouverture, même pour un expéditeur de confiance. Cette option est désactivée par défaut, car le téléchargement des images peut permettre aux expéditeurs de savoir quand vous lisez leurs messages.

Le logo d'une marque à côté de l'en-tête est traité séparément des images du message et doit être approuvé par votre serveur de messagerie. Les logos téléchargés sont conservés et réutilisés. Lors d'un téléchargement, le serveur qui héberge le logo peut voir votre adresse IP et l'heure de la requête.
