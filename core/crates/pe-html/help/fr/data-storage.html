Où sont conservés votre courrier et vos mots de passe

Ce qu'Inbox Classic conserve sur votre ordinateur, et à quel endroit.

  • Le courrier téléchargé et les paramètres des comptes se trouvent par défaut dans %LOCALAPPDATA%\InboxClassic\store.db~/Library/Application Support/Inbox Classic/store.db~/.local/share/inbox-classic/store.db. Les messages conservés par le serveur y restent aussi. La copie locale sert à lire rapidement et hors connexion, ainsi qu'à la recherche. La base de données du courrier et l’index de recherche ne sont pas chiffrés dans leur ensemble.
  • Les mots de passe, les données de connexion obtenues via le navigateur et les secrets des applications de connexion se trouvent par défaut dans le Gestionnaire d'identification Windows, sous InboxClassic, chiffrés pour votre compte Windows.votre trousseau de session, sous InboxClassic, chiffrés pour votre compte Mac. Trousseaux d'accès les affiche.un gestionnaire compatible avec Secret Service, comme GNOME Keyring, sous InboxClassic, protégés par ce service. S’il est indisponible, ils ne sont conservés que pendant l’exécution en cours. Le mode de stockage en mémoire et les défaillances du gestionnaire peuvent limiter leur conservation à l’exécution en cours. Ils ne sont pas conservés dans la base de données du courrier, mais peuvent être inclus dans un fichier d’exportation protégé par une phrase secrète.
  • Les clés de chiffrement sont stockées dans la base de données locale du courrier. Les clés privées y sont chiffrées. La clé qui les protège est conservée séparément, avec vos identifiants de connexion. Le fichier de la base de données ne suffit donc pas à déchiffrer vos clés privées.

La recherche, l'explication des messages non remis, le regroupement en conversations et la détection des codes de connexion s'effectuent tous sur votre ordinateur. Rien de votre courrier n'est envoyé ailleurs pour cela.
