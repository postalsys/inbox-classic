Vider un dossier

Un message supprimé définitivement ne peut pas être récupéré, même avec Annuler.

Pour supprimer définitivement tous les messages du dossier ou du dossier  :

  1. Sélectionnez le dossier.
  2. Choisissez > > > , ou cliquez sur le dossier avec le bouton droit et choisissez . Inbox Classic indique combien de messages seront supprimés.
  3. Confirmez pour les supprimer.

Annuler

> () annule le dernier déplacement, la dernière suppression, le dernier archivage ou le dernier marquage comme indésirable, quel que soit le nombre de messages concernés. Ils retournent dans les dossiers d'où ils venaient, et y sont sélectionnés. Le menu indique ce qu'il annule, par exemple Annuler le déplacement, et la barre d'état indique ce qui a été fait.
