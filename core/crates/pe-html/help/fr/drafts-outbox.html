Les brouillons et la Boîte d'envoi

Enregistrez un message pour le terminer plus tard, et voyez ce qui attend d'être envoyé.

Enregistrer un brouillon

Cliquez sur , ou appuyez sur Ctrl+S⌘S. Le message est conservé dans le dossier du compte, sur le serveur. Enregistrer de nouveau remplace la copie précédente. La barre d'état du message indique quand il a été enregistré.

Inbox Classic enregistre aussi votre message automatiquement, quelques secondes après une pause dans la saisie, ou toutes les trente secondes si vous continuez à écrire. Si Inbox Classic ou votre ordinateur s’arrête de façon inattendue, vos messages en cours de rédaction se rouvrent au prochain démarrage d’Inbox Classic.

Quand vous fermez un message modifié, Inbox Classic demande s'il faut enregistrer les modifications :

  • l'enregistre dans .
  • abandonne les modifications. Si le brouillon n’a été enregistré qu’automatiquement, il est également supprimé du dossier .
  • revient au message.

Pour continuer à écrire, double-cliquez sur le brouillon dans . Il s'ouvre avec ses destinataires, son texte et ses fichiers. Une fois le message envoyé, le brouillon est supprimé.

Un message que vous écrivez est une fenêtre à part : vous pouvez lire votre courrier pendant qu'il reste ouvert. Quand vous fermez Inbox Classic, il ferme d'abord les messages en cours de rédaction, en demandant quoi faire de ceux qui ont des modifications.

La Boîte d'envoi

place le message dans la Boîte d’envoi. Par défaut, il est envoyé après quelques secondes. Pendant ce délai, vous pouvez annuler l’envoi (voir ci-dessous). La barre d'état de la fenêtre principale indique quand il est parti.

Quand un message ne peut pas partir, par exemple faute de connexion, il reste dans la Boîte d'envoi. Il part à la prochaine relève du courrier : rien de ce que vous avez écrit n'est perdu.

Pour voir ce qui attend, choisissez > . Chaque message y est listé avec la raison pour laquelle il n'est pas parti. réessaie aussitôt, et vous pouvez aussi y supprimer un message.

Annuler l’envoi d’un message

Par défaut, après un clic sur , le message attend quelques secondes avant d’être envoyé. La barre d’état affiche un compte à rebours. Pendant ce délai, cliquez sur à côté du compte à rebours, ou choisissez > pour annuler l’envoi. Le message se rouvre pour que vous puissiez le modifier ou l’abandonner. Cette option n’est disponible que tant que le message est en attente d’envoi.

Pour modifier le délai ou envoyer les messages immédiatement, choisissez > Inbox Classic > > et réglez . Si vous quittez Inbox Classic alors qu’un message est en attente, l’application tente de l’envoyer immédiatement.
