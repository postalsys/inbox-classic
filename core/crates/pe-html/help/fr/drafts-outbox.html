Les brouillons et la Boîte d'envoi

Enregistrez un message pour le terminer plus tard, et voyez ce qui attend d'être envoyé.

Enregistrer un brouillon

Cliquez sur , ou appuyez sur Ctrl+S⌘S. Le message est conservé dans le dossier du compte, sur le serveur. Enregistrer de nouveau remplace la copie précédente. La barre d'état du message indique quand il a été enregistré.

Inbox Classic enregistre aussi le message de lui-même quelques secondes après que vous avez cessé de taper, et toutes les trente secondes pendant que vous continuez. Si Inbox Classic ou votre ordinateur s'arrête de façon inattendue, les messages que vous écriviez s'ouvrent de nouveau au prochain démarrage.

Quand vous fermez un message modifié, Inbox Classic demande s'il faut enregistrer les modifications :

  • l'enregistre dans .
  • abandonne les modifications. Une copie enregistrée uniquement de façon automatique est aussi retirée de .
  • revient au message.

Pour continuer à écrire, double-cliquez sur le brouillon dans . Il s'ouvre avec ses destinataires, son texte et ses fichiers. Une fois le message envoyé, le brouillon est supprimé.

Un message que vous écrivez est une fenêtre à part : vous pouvez lire votre courrier pendant qu'il reste ouvert. Quand vous fermez Inbox Classic, il ferme d'abord les messages en cours de rédaction, en demandant quoi faire de ceux qui ont des modifications.

La Boîte d'envoi

place le message dans la Boîte d'envoi ; il part après quelques secondes, pendant lesquelles vous pouvez encore le reprendre (voir plus bas). La barre d'état de la fenêtre principale indique quand il est parti.

Quand un message ne peut pas partir, par exemple faute de connexion, il reste dans la Boîte d'envoi. Il part à la prochaine relève du courrier : rien de ce que vous avez écrit n'est perdu.

Pour voir ce qui attend, choisissez > . Chaque message y est listé avec la raison pour laquelle il n'est pas parti. réessaie aussitôt, et vous pouvez aussi y supprimer un message.

Reprendre un message envoyé

Après un clic sur , le message attend quelques secondes avant de partir, et la barre d’état affiche un compte à rebours. Pour le reprendre, cliquez sur à côté du compte à rebours, ou choisissez > . Le message s’ouvre de nouveau tel qu’il était, pour le modifier ou l’abandonner.

Pour choisir combien de temps un message attend, ou pour l’envoyer tout de suite, choisissez > Inbox Classic > > et réglez . Si vous quittez Inbox Classic pendant qu’un message attend, il part aussitôt.
