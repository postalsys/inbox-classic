Gmail et Outlook.com

Connectez-vous à Gmail, Outlook.com et leurs versions professionnelles via le navigateur. Certains comptes Google autorisent aussi les mots de passe d'application.

Ne saisissez pas votre mot de passe Google ou Microsoft habituel dans Inbox Classic. Les comptes Microsoft nécessitent une connexion via le navigateur. Pour Google, vous pouvez aussi utiliser un mot de passe d'application si votre compte le permet.

Se connecter via le navigateur

Cliquez sur ou dans la fenêtre . Vous tapez votre mot de passe sur la page même de Google ou de Microsoft : Inbox Classic ne le voit donc jamais. Un tel compte utilise toujours les serveurs de messagerie du fournisseur.

Une organisation Microsoft 365 devra peut-être d'abord autoriser Inbox Classic. Microsoft affiche alors Approbation de l'administrateur nécessaire, et Inbox Classic vous indique l'adresse où votre administrateur peut l'approuver.

Le bouton est désactivé par défaut. Le client intégré est configuré pour un accès limité, notamment aux utilisateurs de test. Utilisez votre propre application de connexion ou, si votre compte le permet, un mot de passe d'application (voir ).

Utiliser un mot de passe d'application Google

  1. Activez la Validation en deux étapes sur votre compte Google. Ouvrez ensuite Mots de passe des applications dans les paramètres du compte et créez un mot de passe. Cette option n'est pas disponible pour tous les comptes.
  2. Dans la fenêtre , tapez votre nom et votre adresse, puis cliquez sur .
  3. Si le bouton est proposé, cliquez sur . Sa présence dépend des applications de connexion activées ; sinon, passez directement au champ du mot de passe.
  4. Tapez le mot de passe d'application dans , puis cliquez sur .

Quand la connexion expire

Si Google ou Microsoft met fin à la connexion, Inbox Classic affiche « La connexion au compte … a été refusée ou la session a expiré. » Il vous demande s'il faut vous reconnecter dans le navigateur. Choisissez et connectez-vous de nouveau.
