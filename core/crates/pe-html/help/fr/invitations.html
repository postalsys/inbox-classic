Invitations de calendrier

Un message contenant une invitation de calendrier affiche l'événement au-dessus de son texte, prêt à être ouvert dans votre calendrier.

Quand un message contient un événement, une carte au-dessus du texte indique :

  • de quoi il s'agit : une invitation, une invitation mise à jour, une annulation ou une réponse
  • quand il a lieu, à votre heure locale
  • où il a lieu, qui l'organise et combien de personnes sont invitées
  • comment il se répète, le cas échéant

Pour accepter ou refuser, cliquez sur . L'événement s'ouvre dans votre application de calendrier, où vous y répondez.

Si aucune application de calendrier n'est configurée, Inbox Classic vous le signale. Configurez-en une, puis réessayez.
