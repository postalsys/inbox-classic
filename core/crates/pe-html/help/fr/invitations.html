Invitations de calendrier

Un message contenant une invitation de calendrier affiche l'événement au-dessus de son texte, prêt à être ouvert dans votre calendrier.

Quand Inbox Classic reconnaît un événement dans un message, une carte présente le premier événement avec les informations disponibles :

  • de quoi il s'agit : une invitation, une invitation mise à jour, une annulation ou une réponse
  • sa date et son heure, converties à votre heure locale si le fuseau est reconnu ; sinon, l’heure indiquée dans l’invitation est conservée
  • où il a lieu, qui l'organise et combien de personnes sont invitées
  • comment il se répète, le cas échéant

Pour accepter ou refuser, cliquez sur . L'événement s'ouvre dans votre application de calendrier, où vous pouvez répondre.

Si l’ouverture échoue, vérifiez qu’une application de calendrier est disponible et associée aux fichiers d’invitation, puis réessayez.

Un agent d'IA autorisé à envoyer du courrier peut aussi répondre à une invitation pour vous, mais seulement après que vous avez accepté le message qu'il veut envoyer.
