Courrier chiffré et signé

La barre au-dessus du message indique s’il est signé par son expéditeur et s’il a été chiffré pour vous.

Une signature valide confirme que le contenu n’a pas changé depuis sa signature. Pour confirmer l’identité du signataire, vous devez aussi vérifier à qui appartient la clé. Un message chiffré ne peut être lu qu’avec une clé privée adaptée.

La couleur de la barre résume l’état de protection du message :

CouleurSignification
VertSignature valide de l’expéditeur, avec une clé dont vous avez vérifié le propriétaire.
BleuSignature valide de l’expéditeur, avec une clé non vérifiée, ou message chiffré pour vous.
OrangeLa signature est invalide, quelqu’un d’autre que l’expéditeur a signé, ou une partie du message est illisible.
GrisAucune signature, ou une signature qui n’a pas pu être vérifiée, par exemple parce que la clé manque.

Si les parties du message sont protégées différemment, chacune apparaît dans un cadre avec son propre état de protection. La barre compte les parties selon leur état. Cliquez sur une indication d’état ou sur pour connaître le signataire, la clé et la date de signature de chaque partie.

Seules la barre et les indications au-dessus des cadres proviennent d’Inbox Classic. L’expéditeur peut imiter ces indications dans le contenu du message. Fiez-vous à la barre de l’application.

Les images provenant d’Internet dans une partie chiffrée ne sont chargées qu’avec votre accord, donné dans la barre des images. Vous devez renouveler cet accord à chaque ouverture. L’état de protection indique ensuite que des images ont été chargées.

Les images et les fichiers PDF joints à une partie s’affichent dans le cadre de cette partie, jamais dans celui d’une autre. Les aperçus des parties chiffrées restent en mémoire. Ouvrir une pièce jointe dans une autre application ou l’enregistrer crée toutefois une copie non chiffrée sur le disque.

Dans la liste des fichiers joints, un cadenas marque chaque fichier d’une partie chiffrée. Pointez un fichier pour voir de quelle partie il vient.

Lors d’une réponse ou d’un transfert, seul le contenu affiché est cité.

Dans la liste des messages, un cadenas signale les messages chiffrés et un sceau les messages signés. Si la recherche dans les messages chiffrés est activée et que la clé nécessaire est disponible, Inbox Classic peut les déchiffrer après leur téléchargement ou leur ouverture. Une fois le contenu déchiffré indexé, la liste peut afficher un aperçu et, s’il existe, l’objet protégé. Sans aperçu déchiffré, elle affiche . Les notifications de messages chiffrés utilisent toujours cette indication, même si leur contenu a déjà été déchiffré.

L’option dans permet aussi de rechercher dans le texte déchiffré. Ce texte et l’objet protégé sont conservés en clair dans l’index local ; désactiver l’option les retire de cet index. Les agents d’IA n’ont pas accès à ce contenu ni aux pièces jointes des messages chiffrés.
