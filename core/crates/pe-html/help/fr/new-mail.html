Recevoir le nouveau courrier

Comment Inbox Classic relève le courrier, vous prévient de son arrivée et continue de fonctionner quand sa fenêtre est fermée.

Inbox Classic relève chaque compte au démarrage, puis toutes les dix minutes. Il surveille aussi chaque Boîte de réception, afin de recevoir rapidement les nouveaux messages lorsque la connexion et le serveur le permettent.

Notifications

Si les notifications sont activées, si la fenêtre principale n’est pas au premier plan et si le système les autorise, une notification peut indiquer l’expéditeur et l’objet. Pour un message chiffré, elle affiche toujours « Message chiffré ». Cliquez dessus pour ouvrir le message. Pour désactiver ou activer les notifications, choisissez > . Vous pouvez aussi utiliser dans .

Les nouveaux messages des conversations surveillées sont aussi signalés lorsqu’ils arrivent dans vos dossiers ordinaires, mais pas dans les autres dossiers spéciaux. Les mêmes réglages de notification s’appliquent. Les messages des conversations ignorées ne sont pas signalés.
