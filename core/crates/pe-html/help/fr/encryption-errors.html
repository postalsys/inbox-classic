Erreurs de chiffrement

Que faire quand un serveur ne propose pas de chiffrement, ou l'exige alors qu'il est désactivé.

« the server does not offer STARTTLS »

Le compte est réglé sur STARTTLS, mais le serveur n'a pas proposé de chiffrement. Inbox Classic s'est arrêté, votre mot de passe n'a donc pas été envoyé.

  1. Ouvrez les propriétés du compte dans > .
  2. Réglez la sécurité sur SSL/TLS, avec le port 993 pour le courrier entrant ou 465 pour le courrier sortant.
  3. Cliquez sur .

Si rien d'autre ne fonctionne, le serveur ne peut pas être utilisé en toute sécurité.

« the server takes the password only over an encrypted connection »

Le serveur sortant est réglé sur . Votre mot de passe est correct. Réglez sur STARTTLS avec le port 587, ou sur SSL/TLS avec le port 465.

L'avertissement concernant une connexion sans chiffrement

Quand vous choisissez , Inbox Classic vous avertit que quiconque intercepte votre trafic réseau peut lire votre mot de passe et vos messages. Ne continuez que pour un serveur installé sur votre propre ordinateur ou votre réseau local.
