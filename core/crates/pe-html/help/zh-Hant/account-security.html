帳戶的安全性設定

帳戶伺服器的安全性設定，以及每一項的意義。

每個帳戶的內送伺服器有，外寄伺服器有。Inbox Classic 找到您服務提供者的設定時會自動填入。若要變更，請在 > 中開啟帳戶的內容。

設定意義
SSL/TLS連線從一開始就加密。內送郵件通常使用連接埠 993，外寄郵件通常使用 465。
STARTTLS連線一開始未加密，在傳送登入認證之前切換為 TLS。內送郵件通常使用連接埠 143，外寄郵件通常使用 587。伺服器若不提供加密，Inbox Classic 就會停止連線。
您的密碼和郵件以未加密的方式傳輸，攔截連線的人可以讀取。
只有伺服器位於您自己的電腦或區域網路上時，才使用。Inbox Classic 使用它之前會先警告您。

Inbox Classic 會依照您系統信任的憑證，檢查每部伺服器是否確實是它所宣稱的伺服器。沒有任何開關可以接受所有憑證。

根據預設，您的密碼保存在 Windows 認證管理員您的登入鑰匙圈您的金鑰圈中，絕不存放在郵件存放區。透過瀏覽器登入時，儲存在那裡的是權杖，而不是您的密碼。在僅限記憶體模式下，或系統存放區無法使用時，認證可能只在本次工作階段有效。
