撰寫郵件

撰寫並寄出新郵件，可使用格式設定、連結和圖片。

若要撰寫郵件：

  1. 按一下，或按 。新郵件會在獨立的視窗中開啟。
  2. 在中輸入地址。多個地址請以逗號分隔。輸入時，Inbox Classic 會建議相符的連絡人、地址和群組。按 Enter Return或 Tab 即可接受建議；選擇群組會加入它的成員。
  3. 輸入，然後撰寫郵件。
  4. 按一下，或按 Ctrl+Enter，或按 ⌘Return。

若要加入副本或密件副本，請按一下收件者行末端的或。密件副本中的人會收到郵件，但其他收件者看不到他們。

欄位顯示用來寄出郵件的帳戶。有多個帳戶時，您可以在那裡選擇其他帳戶。郵件就會以該帳戶寄出，並保存在它的中。若要從指定的帳戶開始撰寫，請使用旁的箭頭。

如果主旨或內文含有可辨識的附件字詞，例如「attached」，卻沒有附加任何檔案，Inbox Classic 會在寄出前詢問您。它能辨識英文、德文、愛沙尼亞文、西班牙文和法文中的特定字詞。

若要簽署或加密郵件，請按一下工具列上的或。請參閱。

格式設定

內文上方的列中有字型、粗體、斜體、底線、色彩、清單、縮排、對齊、連結、分隔線和圖片。若要在內文中放入圖片，請按一下，或從檔案總管 Finder 檔案管理員將圖片檔案拖曳到內文中。

沒有任何格式的郵件會以純文字寄出，郵件程式不需要 HTML 格式也能讀取。設定了格式的郵件會以 HTML 寄出，並附上一份純文字副本。

連結

若要將選取的文字設為連結，請按一下，然後輸入網址。狀態列會顯示指標下方連結的目的地，或文字游標所在的連結。以 Ctrl+按一下 ⌘+按一下網頁連結，即可在瀏覽器中開啟。電子郵件連結會開啟新郵件。以滑鼠右鍵按一下連結，可使用、和。

拼錯的字會加上底線。以滑鼠右鍵按一下該字即可查看建議。
