密碼不被接受

郵件伺服器拒絕您的密碼或登入時，該怎麼辦。

資料夾清單中的帳戶旁會出現警告。如果您只有一個帳戶，警告會出現在其收件匣旁。將指標移到警告上，即可查看詳細資訊。郵件清單上方的提示列會說明處理方式。狀態列和通知區域圖示Dock 圖示也會顯示這個問題。

Inbox Classic 會避免重複顯示相同的提示。自動重試的頻率會降低，以減少遭到拒絕的登入嘗試。若要立即再試，請按一下。

使用密碼的帳戶

  1. 按一下警告圖示或提示列中的，然後重新輸入密碼。您也可以在 > 中帳戶的內容裡變更密碼。
  2. 如果您的服務提供者要求應用程式密碼，請在其安全性設定中建立一組，並用它取代平常的密碼。
  3. Gmail 的應用程式密碼需要兩步驟驗證，而且您的帳戶不一定能使用。Outlook.com 和 Microsoft 365 在 Inbox Classic 中需要透過瀏覽器登入。請參閱。

透過瀏覽器登入的帳戶

當 Inbox Classic 詢問「」時，請選取並重新登入。如果選取，您可以稍後使用警告圖示或提示列中的登入。您也可以使用 > 或帳戶的內容。

您的服務提供者或組織可能會要求重新登入，例如在變更密碼之後。

  • 如果需要管理員核准，請選取並將連結傳送給管理員。重新登入無法取代這項核准。
  • 如果 IMAP 未啟用，請在信箱設定中啟用，或請管理員協助。
  • 如果您使用其他地址登入，請選取，並在服務提供者的頁面上選取正確的帳戶。
  • 服務提供者暫時中斷服務時，Inbox Classic 會等候並重試，不會要求您登入。

如果使用登入應用程式，也請檢查其權限範圍（scopes）是否允許存取郵件。請參閱。
