密碼不被接受

郵件伺服器拒絕您的密碼或登入時，該怎麼辦。

您可能會看到下列其中一項：

  • 在狀態列中：「伺服器不接受登入（...）」
  • 在讀取窗格中：「郵件伺服器不接受登入（...）。請檢查密碼，或在帳戶設定中重新登入。」
  • 要求您重新輸入帳戶密碼的視窗

若要解決這個問題：

  1. 在 Inbox Classic 詢問時重新輸入密碼，或在 > 中帳戶的內容裡變更密碼。
  2. 如果您的服務提供者要求郵件程式使用應用程式密碼，請在帳戶的安全性設定中建立一組，並用它取代您平常的密碼。
  3. Gmail 請透過瀏覽器登入；如果您的帳戶允許且已開啟兩步驟驗證，也可以使用應用程式密碼。Outlook.com 和 Microsoft 365 請透過瀏覽器登入：在 Inbox Classic 中，這些帳戶無法以應用程式密碼取代瀏覽器登入。請參閱。

透過瀏覽器登入的帳戶

服務提供者結束登入時，Inbox Classic 會顯示「登入...遭到拒絕，或工作階段已過期。」並詢問「」請選擇，然後在瀏覽器中再登入一次。

如果伺服器拒絕登入應用程式的權杖，請檢查該應用程式的範圍（scopes）是否提供郵件存取權。請參閱。
