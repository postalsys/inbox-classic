Inbox Classic 無法連線

無法連線到郵件伺服器，或伺服器沒有回應時，該怎麼辦。

您可能會在狀態列或讀取窗格中看到下列其中一項：

  • 「connection error: ...」
  • 「the server did not answer in time」
  • 「無法連線到伺服器（...）」
  • 「無法連線到郵件伺服器，或連線已中斷（...）。」

若要解決這個問題：

  1. 檢查您的網際網路連線。
  2. 在 > 中開啟帳戶的內容，並檢查伺服器名稱和連接埠。
  3. 如果無法寄信，請檢查外寄伺服器的安全性和連接埠：通常是連接埠 465 搭配 SSL/TLS，或連接埠 587 搭配 STARTTLS。有些網路會封鎖郵件連接埠，尤其是連接埠 25。

Inbox Classic 會在下次檢查郵件時再試一次。若要立即再試，請按一下。

沒有連線時寄出的郵件會留在本機寄件匣中。Inbox Classic 能連線時會重試；伺服器仍可能拒絕該郵件。
