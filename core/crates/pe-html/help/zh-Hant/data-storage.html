您的郵件和密碼存放在哪裡

Inbox Classic 在您的電腦上保存哪些資料，以及存放位置。

  • 下載的郵件和帳戶設定根據預設存放在 %LOCALAPPDATA%\InboxClassic\store.db ~/Library/Application Support/Inbox Classic/store.db ~/.local/share/inbox-classic/store.db。啟動選項或您的環境可能會變更這個位置。同步的郵件仍保留在伺服器上；寄件匣則只在本機。快取的副本只要仍然存放著，就能讓您離線閱讀。資料庫和搜尋索引並未整體加密。
  • 密碼、瀏覽器登入權杖和登入應用程式的密碼，通常存放在 Windows 認證管理員的 InboxClassic 之下，並針對您的 Windows 帳戶加密。您的登入鑰匙圈的 InboxClassic 之下，並針對您的 Mac 帳戶加密。「鑰匙圈存取」可以顯示它們。您的金鑰圈（GNOME Keyring）的 InboxClassic 之下，並針對您的登入加密。沒有金鑰圈時，它們只保留到 Inbox Classic 結束為止。這些認證不會存放在郵件資料庫中。在僅限記憶體模式下，它們只保留到應用程式結束為止。
  • 加密金鑰和您下載的郵件存放在一起。您的私密金鑰在那裡以另一把金鑰加密，該金鑰和您的密碼存放在一起，因此單憑郵件檔案無法開啟私密金鑰。

搜尋、退信說明、交談分組，以及尋找登入代碼，全都在您的電腦上執行。這些功能不會將您的郵件內容傳送到外部服務。

只有在您允許時，AI 代理程式才能看到您的郵件，而且只限您選擇的帳戶。請參閱。
