更新 Inbox Classic

取得最新版本的 Inbox Classic。

若要查看您使用的版本，請選擇 > Inbox Classic > 。

從 inboxclassic.com 下載最新的安裝程式並執行。它會直接更新已安裝的版本。您的帳戶和為它們下載的郵件都會保留。

當這個版本支援更新且已啟用自動檢查時，Inbox Classic 會檢查是否有新版本。請依照更新程式的提示安裝更新。若要立即檢查，請選擇 Inbox Classic > 。

如果您是從 apt 套件庫安裝 Inbox Classic，新版本會隨著系統本身的更新送達。如果您安裝的是 .deb 檔案，請從 inboxclassic.com 下載較新的檔案，並安裝在舊版本上。

在 Arch Linux 上，請以同樣方式使用 sudo pacman -U 安裝較新的套件。在 Omarchy 上，它自己的 Update 會帶來新版本。

更新後，您的帳戶、郵件和設定都會保留。
