郵件沒有顯示

郵件仍在下載、無法下載或無法顯示時，該怎麼辦。

「正在下載郵件...」

郵件會在您第一次開啟時下載。剛新增帳戶時，大部分郵件都還不在您的電腦上。寄件者和主旨可能會在內容下載完成前先出現。下載時間取決於連線和郵件大小。

「無法下載郵件」

窗格會說明原因，例如無法連線到郵件伺服器。下載失敗的已開啟郵件，會在帳戶同步後重試。若要立即再試，請按一下郵件上方資訊列中的。

如果登入遭拒，請參閱。如果無法建立安全連線，請參閱。

「無法顯示這封郵件」

Inbox Classic 無法讀取這封郵件，例如因為郵件已損毀，或使用了不支援的結構。其他郵件程式也許仍能讀取它。您的其他郵件不受影響。若要查看郵件的內容，請選擇 > 。

「」

Inbox Classic 使用 Microsoft Edge WebView2 執行階段來顯示郵件。如果缺少這個執行階段，請從 Microsoft 安裝它，然後重新啟動 Inbox Classic。即使已安裝 Edge 瀏覽器，也不一定表示這個執行階段可以使用。
