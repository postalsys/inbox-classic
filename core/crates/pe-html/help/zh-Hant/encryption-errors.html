加密錯誤

伺服器不提供加密，或在加密已關閉時要求加密，該怎麼辦。

「the server does not offer STARTTLS」

帳戶設定為 STARTTLS，但伺服器沒有提供加密。Inbox Classic 在傳送密碼之前就停止了這次連線嘗試。

  1. 在 > 中開啟帳戶的內容。
  2. 檢查您服務提供者的設定。如果支援，內送郵件請使用 SSL/TLS 搭配連接埠 993，外寄郵件請使用 465。
  3. 按一下。

如果其他方法都無效，就表示無法安全地使用這部伺服器。

「the server takes the password only over an encrypted connection」

外寄伺服器設定為。這個錯誤並不表示密碼正確。請依照您服務提供者的設定，將變更為 STARTTLS 搭配連接埠 587，或 SSL/TLS 搭配連接埠 465。

關於未加密連線的警告

當您選擇時，Inbox Classic 會警告您，任何攔截您網路流量的人都可以讀取您的密碼和郵件。區域網路本身並不會加密流量。只有在連線已透過其他方式受到保護時，才繼續進行。
