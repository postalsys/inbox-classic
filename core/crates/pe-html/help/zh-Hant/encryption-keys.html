加密金鑰

建立金鑰來簽署您的郵件並接收加密郵件，並保存您連絡人的金鑰。

Inbox Classic 使用 OpenPGP 金鑰簽署和加密郵件。您自己的金鑰分成兩半：交給別人的公開金鑰，以及留在您電腦上的私密金鑰。有了連絡人的金鑰，您就能檢查他們的簽章，並寄送加密郵件給他們。

若要建立您的金鑰：

  1. 選擇 > ，然後按一下。
  2. 選擇帳戶，然後按一下。這把金鑰會用於該帳戶的地址及其其他地址。
  3. 按一下，然後選擇一個密語。請將檔案和密語分別存放在不同的安全地方。
請保留私密金鑰的備份。如果這部電腦遺失或重設，沒有備份就無法還原金鑰，也可能無法解密舊郵件。

不用密語，金鑰也受到保護

您的私密金鑰受到一把存放在認證管理員鑰匙圈系統金鑰圈中的金鑰保護，因此您平常使用時不需要輸入密語。密語用於保護備份，匯入時也可能需要。如果金鑰已鎖定，請先檢查系統存放區是否可用且已解鎖。如果缺少它的保護金鑰，請按一下，然後選擇它的備份。

新增金鑰

按一下，即可從檔案新增金鑰，例如連絡人寄給您的金鑰，或您自己的備份。匯入受密語保護的私密金鑰時，會要求您輸入一次密語。接著 Inbox Classic 會詢問是否要將匯入的您自己的金鑰用於您的地址。

若要新增複製為文字的金鑰，請按一下。若要新增郵件附件中的公開金鑰，請開啟附件的功能表，然後選擇。只有公開金鑰能直接從郵件匯入。若要還原您自己的私密金鑰，請儲存附件，再於此處匯入該檔案。

從此之後，連絡人的金鑰就會用於他的地址。如果之後出現同一地址的另一把金鑰，目前的金鑰會繼續使用，直到您在連絡人的內容中選擇新的金鑰為止。

若要分享您的公開金鑰，請選取它，然後按一下。您也可以在帳戶內容的索引標籤中，選擇該帳戶的金鑰。

尋找金鑰

為沒有金鑰的收件者開啟加密時，Inbox Classic 會先查詢該地址的網域；若已啟用相關查詢，再查詢 keys.openpgp.org。若要自行尋找連絡人缺少或無法使用的金鑰，請在通訊錄中開啟該連絡人，然後按一下。通訊錄會標示有可用金鑰的連絡人，並以更醒目的標記表示金鑰擁有者已驗證。

郵件若以您沒有的金鑰簽署，會顯示金鑰不明。按一下該標籤旁的，即可到 keys.openpgp.org 尋找。這會傳送簽章中的金鑰指紋或金鑰識別碼，而不是電子郵件地址。找到金鑰後，Inbox Classic 會再次檢查簽章並更新標籤。找到金鑰並不代表已驗證它的擁有者。

若要停止在 keys.openpgp.org 尋找金鑰，請在中關閉。

發佈您的金鑰

若要讓其他人找到您的金鑰，請選取一把您自己的金鑰，然後按一下。Inbox Classic 會將公開金鑰的部分上傳到 keys.openpgp.org，並為尚未列出的地址要求確認連結。開啟各個連結後，就能透過相應的地址搜尋金鑰。已列出的地址不需要再次確認。

隨郵件寄送的金鑰

郵件也可以附帶公開金鑰。啟用 Autocrypt 時，從已選取金鑰的地址寄出的郵件會附帶其公開金鑰，其他能讀取它的應用程式可以用它來寄送加密郵件給您。當您開啟附帶寄件者金鑰的郵件時，Inbox Classic 會保存該金鑰，但標示為未驗證；如果某個地址已有金鑰，又出現另一把金鑰，會等您選擇。若要停止寄送您的金鑰，請在帳戶的索引標籤中關閉。

過期、撤銷和移除的金鑰

過期或已撤銷的金鑰會在清單中顯示相應狀態，且不再用於新的加密作業。金鑰後來過期，本身不會讓有效期間內產生的簽章失效。若要停止使用某把金鑰，請選取它，然後按一下。移除您自己的金鑰前，請保留備份，日後解密舊郵件時可能會需要。
