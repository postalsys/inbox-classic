Gmail 和 Outlook.com

Gmail、Outlook.com 和 Microsoft 365 請使用瀏覽器登入；符合條件的 Google 帳戶也可以使用應用程式密碼。

Google 和 Microsoft 不允許郵件程式使用您平常的密碼。在 Inbox Classic 中，Outlook.com 和 Microsoft 365 請使用瀏覽器登入。只有在您的帳戶允許時，才能選用 Google 應用程式密碼。

透過瀏覽器登入

在中按一下或。您是在 Google 或 Microsoft 自己的頁面上輸入密碼，因此 Inbox Classic 永遠不會看到它。這類帳戶一律使用服務提供者自己的郵件伺服器。

Microsoft 365 組織可能必須先允許 Inbox Classic。這時 Microsoft 會顯示需要系統管理員核准，Inbox Classic 則會告訴您系統管理員核准它的網址。

一開始是關閉的。在這個設定下，內建的 Google 登入應用程式只保留給測試使用者。請使用您自己的登入應用程式，或在帳戶允許時使用應用程式密碼（請參閱）。

使用應用程式密碼

Google 應用程式密碼需要兩步驟驗證，而且並非每個帳戶都能使用。例如，公司或學校的政策以及進階保護計畫都可能禁止使用。

  1. 在 Google 帳戶的安全性設定中開啟應用程式密碼，如果有這個選項，就建立一組密碼。
  2. 在中輸入您的名稱和地址，然後按一下。
  3. 按一下。
  4. 在中輸入應用程式密碼，然後按一下。

登入過期時

如果 Google 或 Microsoft 結束了登入，Inbox Classic 會顯示「登入...遭到拒絕，或工作階段已過期。」並詢問是否要在瀏覽器中重新登入。請選擇，然後再登入一次。
