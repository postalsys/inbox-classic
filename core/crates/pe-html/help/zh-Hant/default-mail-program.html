將 Inbox Classic 設為您的郵件應用程式

在 Inbox Classic 中開啟網頁和其他程式中的電子郵件連結與郵件檔案。

電子郵件連結（mailto:）會在您的預設郵件應用程式中開啟新郵件。

若要將 Inbox Classic 設為該應用程式，請選擇 > 。Windows 會開啟它的預設應用程式設定，請在那裡為 MAILTO 連結選擇 Inbox Classic。只有已安裝的版本會列在那裡。Inbox Classic 會要求系統將它設為預設郵件應用程式；變更能否生效取決於系統的權限和設定。

之後當您按一下電子郵件連結時，會開啟一封新郵件，並填入連結中的地址、主旨和內文。連結中的其他內容都不會使用。

如果您還沒有帳戶，Inbox Classic 會請您先新增一個。新增後，請再按一次連結。

郵件檔案

若要在按兩下 .eml 檔案時以 Inbox Classic 開啟，請在中按一下。Windows 會開啟它的預設應用程式設定，請在那裡為 .eml 檔案選擇 Inbox Classic。取消 Inbox Classic 的設定，並不會復原已在 Windows 中做的變更。Inbox Classic 會要求系統以它開啟這些檔案。
