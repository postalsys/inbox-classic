附件

開啟或儲存郵件附加的檔案，並在您撰寫的郵件中附加檔案。

在郵件中查看圖片和 PDF 檔案

圖片預覽和每個 PDF 最多五頁的內容，會連同名稱和大小顯示在郵件內文之後。按一下其中一個即可開啟檔案。較長的 PDF 檔案會有一個開啟它的連結。最多自動顯示 20 張圖片和頁面；下方有一行會計算其他檔案的數目。

這些是 Inbox Classic 自行繪製的副本：檔案中的任何內容都不會執行，也不會從網際網路載入任何東西。無法繪製的檔案會顯示為一個圖格，列出名稱、大小和原因，例如 HEIC 圖片或受密碼保護的 PDF 檔案；按一下圖格即可開啟檔案。大型郵件仍在下載時，其中的檔案在送達前會顯示為圖格。在已簽署或已加密的郵件中，每個部分會在自己的框架中顯示自己的檔案。加密部分的預覽會保留在記憶體中，而不是存成預覽檔案。另外開啟或儲存附件時，會寫出未加密的副本。

若要在郵件中顯示某個檔案，或將它移出，請在檔案清單中以滑鼠右鍵按一下它，然後選擇。這項設定在郵件顯示期間有效。

若只要看清單，請在中關閉。如果 Inbox Classic 在轉譯檔案預覽時停止運作，下次啟動時會停用 PDF 預覽並加以說明。這並不能證明是該檔案造成中斷；開啟即可再次顯示預覽。

列印郵件時，郵件中顯示的圖片預覽也會一併列印。PDF 檔案則不會：每個 PDF 會以一行列出名稱，請用它自己的程式列印。在已簽署或已加密的郵件中，每個部分的圖片緊接在該部分的文字之後，並標示所屬部分。

開啟附件

郵件的檔案列在郵件標頭下方，每個檔案都有名稱和大小。按兩下檔案，即可用您電腦上對應的程式開啟。使用鍵盤時，請按 Tab 直到選中檔案，用方向鍵挑選一個，然後按 Enter。

以滑鼠右鍵按一下檔案，可使用、和。標頭右側的迴紋針也會列出這些檔案。

Inbox Classic 會封鎖開啟可辨識的程式、指令碼、安裝程式、捷徑、磁碟映像、網頁，以及含有巨集的 Office 文件。這類檔案的無法使用；請儲存檔案，只有在您信任其來源時才自行開啟。

為了開啟檔案，Inbox Classic 會在您使用者帳戶的暫存資料夾中儲存一份副本。啟動時，應用程式會嘗試移除超過一天的暫存副本。在 Windows 和 macOS 上，檔案會標示為來自網際網路。加密郵件的附件會以未加密的方式存放在那裡；您第一次開啟這類附件時，Inbox Classic 會加以說明。

儲存附件

以滑鼠右鍵按一下檔案，然後選擇，或選擇將所有檔案儲存到一個資料夾。Inbox Classic 會建議一個安全的名稱，不含可能讓名稱看起來像別的東西的字元。儲存所有附件時，會保留現有的檔案，同名的新檔案會加上編號。儲存單一檔案時則依照系統的儲存對話方塊，它可能會提議取代檔案。

只開啟您預期會寄附件給您的人所寄來的附件。程式，或要求您「啟用內容」的文件，都可能接管您的電腦。程式包括 .exe、.msi、.js、.vbs、.bat 和 .scr 檔案。 .app、.pkg、.dmg 和 .command 檔案。 .sh、.deb、.AppImage 和 .desktop 檔案。

附加檔案

若要在您撰寫的郵件中附加檔案：

  1. 按一下。
  2. 選擇檔案。檔案會連同大小列在中。

您也可以從檔案總管 Finder 檔案管理員將檔案拖曳到地址欄位上。不是圖片的檔案也可以拖曳到內文上。

若要移除檔案，請選取它並按 Delete，或以滑鼠右鍵按一下它，然後選擇。檔案會在郵件寄出時才讀取，因此在那之前請將檔案留在原處。
