移除 Inbox Classic

從您的電腦移除 Inbox Classic，並選擇是否保留它的本機資料。

從「設定」>「應用程式」>「已安裝的應用程式」解除安裝 Inbox Classic。它會詢問是否也要移除所有本機應用程式資料，包括帳戶、郵件、連絡人、金鑰和設定。

結束 Inbox Classic，然後將它從「應用程式」移到垃圾桶。它下載的郵件會留在 ~/Library/Application Support/Inbox Classic 中，直到您也刪除該資料夾為止。

使用 sudo apt remove inbox-classic 移除套件；在 Arch Linux 和 Omarchy 上則使用 sudo pacman -R inbox-classic。它下載的郵件會留在 ~/.local/share/inbox-classic 中，直到您也刪除該資料夾為止。

這些預設的資料資料夾也包含連絡人、金鑰和設定；刪除它們會移除所有這些本機資料。如果您變更過位置，位置可能會不同。解除安裝不會移除伺服器上的郵件，也不一定會從系統的密碼存放區移除認證。

若要移除已儲存的帳戶登入認證，請先在 > 中移除每個帳戶。若只要移除一個帳戶，請參閱。
