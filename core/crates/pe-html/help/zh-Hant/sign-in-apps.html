登入應用程式

向 Google、Microsoft 或相容的 OpenID Connect 服務提供者註冊您自己的登入應用程式，以便透過瀏覽器登入。

透過瀏覽器登入時，會使用一個已向服務提供者註冊的 OAuth 用戶端。Inbox Classic 有自己的 Google 和 Microsoft 用戶端。在這個設定下，內建的 Google 用戶端只保留給測試使用者，因此一開始是關閉的。您可以註冊自己的用戶端：在您的 Google Cloud 專案中、在您的 Microsoft Entra 租用戶中，或向支援郵件存取的相容 OpenID Connect 服務提供者註冊。

若要新增登入應用程式：

  1. 選擇 > 。
  2. 按一下，然後按一下。
  3. 在旁，按一下 Google 或 Microsoft，即可填入簽發者、範圍和伺服器。若是其他服務提供者，請自行輸入。
  4. 依照底部方塊的說明，向服務提供者註冊用戶端。請註冊那裡顯示的。
  5. 輸入，如果服務提供者給了您，也請輸入。根據預設，用戶端密碼會保存在 Windows 認證管理員您的登入鑰匙圈您的金鑰圈中，而且不會再次顯示。
  6. 按一下，檢查簽發者探索及其服務位址。這不會驗證用戶端識別碼、用戶端密碼或郵件權限。然後按一下。
  7. 在的第一頁，使用新增帳戶。

在中，每個應用程式的核取方塊表示是否向新帳戶提供它，內建的應用程式也包括在內。已經在使用某個應用程式的帳戶會繼續運作。可變更應用程式，則可在沒有帳戶使用它時將其移除。

如果郵件伺服器拒絕應用程式的權杖，請檢查它的範圍是否提供郵件存取權。
