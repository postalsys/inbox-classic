取得新郵件

Inbox Classic 如何檢查郵件、通知您，以及在視窗關閉後繼續執行。

Inbox Classic 會在啟動時檢查每個帳戶，之後每十分鐘檢查一次。連線時，它也會監看每個收件匣的變動。新郵件出現的速度取決於伺服器和連線。

  • 若要立即檢查，請按一下，或按 。
  • 若要檢查單一帳戶，請使用旁的箭頭，或以滑鼠右鍵按一下帳戶，然後選擇。

通知

主視窗不在前景時，通知會告訴您寄件者和主旨。按一下通知即可開啟郵件。若要關閉或開啟通知，請選擇 > 。中的是同一個開關。

您監看的交談中有新郵件時，不只是收件匣，在您自己的資料夾中也會通知，但絕不會在、、、或其他特殊資料夾中通知。您忽略的交談中的新郵件會標示為已讀取，在任何資料夾中都不會通知。

關閉視窗時

Inbox Classic 會在通知區域中繼續執行，並繼續檢查郵件。那裡的圖示和它的工作列按鈕，會顯示收件匣中有多少封未讀取郵件。按一下圖示即可重新開啟視窗。以滑鼠右鍵按一下圖示，可使用和。

Inbox Classic 會在 Dock 中繼續執行，並繼續檢查郵件。Dock 圖示會顯示各收件匣中有多少封未讀取郵件。按一下圖示即可重新開啟視窗。

Inbox Classic 會在頂端列中繼續執行，並繼續檢查郵件。圖示的選單中有、和，支援的 Dock 會顯示收件匣中有多少封未讀取郵件。如果桌面沒有放置圖示的地方，關閉視窗就會結束 Inbox Classic。
