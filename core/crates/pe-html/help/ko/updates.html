Inbox Classic 업데이트

Inbox Classic의 최신 버전을 받습니다.

현재 버전을 확인하려면 > Inbox Classic > 를 선택합니다.

inboxclassic.com에서 최신 설치 프로그램을 다운로드하여 실행합니다. 설치된 프로그램이 그 자리에서 업데이트됩니다. 계정과 계정용으로 다운로드한 메일은 그대로 유지됩니다.

이 빌드가 업데이트를 지원하고 자동 확인이 켜져 있으면 Inbox Classic이 새 버전을 확인합니다. 업데이트를 설치하려면 업데이트 프로그램의 안내를 따릅니다. 지금 확인하려면 Inbox Classic > 을 선택합니다.

apt 저장소에서 Inbox Classic을 설치한 경우 새 버전은 시스템 업데이트와 함께 설치됩니다. .deb 파일로 설치한 경우 inboxclassic.com에서 새 파일을 다운로드하여 기존 버전 위에 설치합니다.

Arch Linux에서도 같은 방법으로 sudo pacman -U를 사용하여 새 패키지를 설치합니다. Omarchy에서는 Omarchy 자체의 업데이트로 새 버전이 설치됩니다.

업데이트해도 계정, 메일, 설정은 그대로 유지됩니다.
