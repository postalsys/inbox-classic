암호가 받아들여지지 않음

메일 서버가 암호나 로그인을 거부할 때 해결하는 방법입니다.

다음 중 하나가 표시될 수 있습니다.

  • 상태 표시줄: “서버가 로그인을 받아들이지 않았습니다(…)”
  • 읽기 창: “메일 서버가 로그인을 받아들이지 않았습니다(…). 계정 설정에서 암호를 확인하거나 다시 로그인하십시오.”
  • 계정의 암호를 다시 입력하라는 창

문제를 해결하려면 다음과 같이 합니다.

  1. Inbox Classic이 요청하면 암호를 다시 입력하거나, > 명령으로 계정 속성을 열어 암호를 바꿉니다.
  2. 공급자가 메일 프로그램에 앱 암호를 요구하는 경우 계정의 보안 설정에서 앱 암호를 만들어 평소 암호 대신 사용합니다.
  3. Gmail은 브라우저를 통해 로그인하거나, 계정에서 허용하고 2단계 인증이 켜져 있으면 앱 암호를 사용합니다. Outlook.com과 Microsoft 365는 브라우저를 통해 로그인해야 합니다. Inbox Classic에서 이러한 계정은 앱 암호로 브라우저 로그인을 대신할 수 없습니다. 항목을 참조하십시오.

브라우저를 통해 로그인하는 계정

공급자가 로그인을 종료하면 Inbox Classic에 “… 로그인이 거부되었거나 세션이 만료되었습니다.”라는 메시지가 표시됩니다. 그런 다음 “”라고 묻습니다. 단추를 클릭하고 브라우저에서 다시 로그인합니다.

서버가 로그인 앱의 토큰을 거부하면 앱의 범위에 메일 액세스 권한이 포함되어 있는지 확인합니다. 항목을 참조하십시오.
