암호가 받아들여지지 않음

메일 서버가 암호나 로그인을 거부할 때 해결하는 방법입니다.

폴더 목록의 계정 옆에 경고가 표시됩니다. 계정이 하나뿐이면 해당 계정의 받은 편지함 옆에 표시됩니다. 경고에 포인터를 올리면 자세한 내용을 볼 수 있습니다. 메시지 목록 위의 막대에서 해결 방법을 안내합니다. 상태 표시줄과 알림 영역 아이콘Dock 아이콘에도 문제가 표시됩니다.

Inbox Classic은 같은 질문을 반복하지 않도록 합니다. 거부되는 로그인 시도를 줄이기 위해 자동 재시도 간격이 길어집니다. 지금 시도하려면 단추를 클릭하십시오.

암호를 사용하는 계정

  1. 경고 아이콘이나 막대의 단추를 클릭한 다음 암호를 다시 입력하십시오. > 에서 계정 속성을 열어 암호를 바꿀 수도 있습니다.
  2. 공급자가 앱 암호를 요구하면 공급자의 보안 설정에서 앱 암호를 만들고 평소 암호 대신 사용하십시오.
  3. Gmail 앱 암호에는 2단계 인증이 필요하며, 계정에 따라 사용할 수 없을 수도 있습니다. Inbox Classic에서 Outlook.com과 Microsoft 365를 사용하려면 브라우저를 통해 로그인해야 합니다. 항목을 참조하십시오.

브라우저를 통해 로그인하는 계정

Inbox Classic이 “”라고 물으면 단추를 선택하고 다시 로그인하십시오. 단추를 선택해도 나중에 경고 아이콘이나 막대의 단추로 로그인할 수 있습니다. > 명령이나 계정 속성을 사용할 수도 있습니다.

공급자나 조직에서 암호 변경 등의 이유로 다시 로그인하도록 요구할 수 있습니다.

  • 관리자의 승인이 필요하면 단추를 선택하고 관리자에게 링크를 보내십시오. 다시 로그인하는 것으로 이 승인을 대신할 수는 없습니다.
  • IMAP이 비활성화되어 있으면 사서함 설정에서 켜거나 관리자에게 요청하십시오.
  • 다른 주소로 로그인했다면 단추를 선택하고 공급자의 페이지에서 올바른 계정을 선택하십시오.
  • 공급자의 일시적인 서비스 중단 중에는 Inbox Classic이 로그인을 요구하지 않고 기다렸다가 다시 시도합니다.

로그인 앱을 사용하는 경우 앱의 범위에 메일 액세스 권한이 포함되어 있는지도 확인하십시오. 항목을 참조하십시오.
