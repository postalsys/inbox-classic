링크, 스크립트 및 첨부 파일

메시지가 스스로 코드를 실행하거나 페이지를 열지 못하도록 Inbox Classic이 차단하는 방법입니다.

  • 메시지의 스크립트는 실행되지 않습니다. Inbox Classic은 메시지를 표시하기 전에 메시지의 스크립트와 활성 마크업을 제거합니다. 앱 자체의 표시 컨트롤에서는 스크립트를 사용합니다.
  • 웹 링크는 사용자가 선택할 때 브라우저에서 열립니다. 전자 메일 링크를 선택하면 새 메시지가 열릴 수 있습니다. 메시지 내용이 스스로 페이지나 창을 열 수는 없습니다.
  • 첨부 파일은 사용자가 요청할 때만 외부 프로그램에서 열립니다. Inbox Classic은 먼저 임시 복사본을 저장하고, 인식된 실행 파일 형식은 차단합니다. 제안된 파일 이름은 저장하기 전에 정리됩니다.
  • 구독 취소는 먼저 사용자에게 묻고 어떤 작업을 할지 알려 줍니다.
메시지를 통해 들어간 페이지에서 암호를 입력하기 전에 브라우저의 주소를 확인하십시오. 메시지에는 한 주소를 표시하고 다른 주소로 연결할 수 있습니다.

메시지를 작성할 때 상태 표시줄에는 마우스 포인터 아래나 텍스트 커서 위치에 있는 링크의 대상이 표시되므로 보내기 전에 확인할 수 있습니다.

로그인 코드는 메일 공급자가 코드의 도메인이나 상위 도메인의 서명을 확인한 경우에만 제공됩니다. 이는 개별 보낸 사람을 확인하는 것이 아닙니다. 항목을 참조하십시오.

포함된 그림은 표시되기 전에 정적 이미지로 변환되며, 메시지가 제공하는 글꼴은 사용되지 않습니다. 사용자가 허용한 원격 그림은 웹 보기에서 표시됩니다.
