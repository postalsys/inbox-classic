바로 가기 키

모든 명령의 바로 가기 키와 목록, 편집기, 주소록에서 사용하는 키입니다.

처음 나오는 표에는 바로 가기 키가 있는 명령이 메뉴별로 정리되어 있습니다. 그다음 표에는 특정 위치에서만 사용하는 키가 나와 있습니다.

메시지 목록에서

키동작
↑ ↓위 또는 아래 메시지 선택
Shift+↑ Shift+↓선택 영역을 메시지 하나만큼 늘리거나 줄이기
Ctrl+Click⌘+Click메시지를 선택 영역에 추가하거나 선택 영역에서 빼기
Shift+Click선택한 메시지부터 클릭한 메시지까지 모두 선택
EnterReturn메시지를 별도의 창에서 열거나 초안 편집
→ ←대화의 다른 메시지 표시 또는 숨기기
N읽지 않은 다음 메시지로 이동
A메시지 보관
W대화 지켜보기
K대화 무시
Tab포커스를 받을 수 있는 다음 컨트롤로 이동
Menu선택한 메시지의 바로 가기 메뉴 열기
Esc검색을 끝내고 폴더를 다시 표시

메시지를 작성할 때

키동작
Ctrl+B⌘B굵게
Ctrl+I⌘I기울임꼴
Ctrl+U⌘U밑줄
Ctrl+K⌘K링크 추가 또는 커서 위치의 링크 변경
Ctrl+Click⌘+Click브라우저에서 링크 열기
Ctrl+A⌘A모두 선택. 접혀 있는 인용 메시지도 펼칩니다
Ctrl+S⌘S메시지를 임시 보관함에 저장
Ctrl+Enter⌘Return메시지 보내기
Alt+C, Alt+B참조 또는 숨은 참조 줄 표시

입력할 때 표시되는 주소 목록에서

키동작
↑ ↓주소 또는 그룹 선택
EnterReturn 또는 Tab선택한 주소 또는 그룹 삽입
Esc목록 닫기
Shift+Delete자동으로 기억해 둔 주소를 선택해 추천 목록에서 숨기기. 저장된 연락처와 그룹은 삭제되지 않습니다

키동작
Delete확인 후 선택한 연락처, 그룹 또는 직접 입력한 그룹 주소 제거
Esc연락처나 그룹을 저장하지 않고 닫기
