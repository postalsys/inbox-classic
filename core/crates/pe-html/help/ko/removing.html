Inbox Classic 제거

컴퓨터에서 Inbox Classic을 제거하고, 로컬 데이터를 유지할지 선택합니다.

설정 > 앱 > 설치된 앱에서 Inbox Classic을 제거합니다. 이때 계정, 메일, 연락처, 키, 설정을 포함한 모든 로컬 앱 데이터도 제거할지 묻습니다.

Inbox Classic을 종료하고 응용 프로그램 폴더에서 휴지통으로 옮깁니다. 다운로드한 메일은 ~/Library/Application Support/Inbox Classic 폴더도 삭제할 때까지 그곳에 남아 있습니다.

sudo apt remove inbox-classic 명령으로 패키지를 제거합니다. Fedora에서는 sudo dnf remove inbox-classic 명령을, Arch Linux와 Omarchy에서는 sudo pacman -R inbox-classic 명령을 사용합니다. 다운로드한 메일은 ~/.local/share/inbox-classic 폴더도 삭제할 때까지 그곳에 남아 있습니다.

이러한 기본 데이터 폴더에는 연락처, 키, 설정도 들어 있으므로 폴더를 삭제하면 이 로컬 데이터가 모두 제거됩니다. 위치를 바꾼 경우에는 위치가 다를 수 있습니다. 제거해도 서버의 메일은 삭제되지 않으며, 시스템 암호 저장소의 자격 증명이 반드시 제거되는 것도 아닙니다.

저장된 계정 로그인 자격 증명을 제거하려면 먼저 > 명령으로 각 계정을 제거합니다. 계정 하나만 제거하려면 항목을 참조하십시오.
