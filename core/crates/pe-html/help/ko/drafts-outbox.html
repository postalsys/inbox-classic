임시 보관함 및 보낼 편지함

나중에 마저 쓸 메시지를 저장하고, 보내기를 기다리는 메시지를 확인합니다.

임시 보관 메시지 저장

단추를 클릭하거나 Ctrl+S⌘S 키를 누릅니다. 메시지가 서버에 있는 계정의 폴더에 보관됩니다. 다시 저장하면 이전 사본이 바뀝니다. 메시지의 상태 표시줄에 저장된 시간이 표시됩니다.

Inbox Classic은 입력을 멈추고 몇 초가 지나면, 또는 계속 입력하는 동안에는 30초마다 메시지를 자동으로 저장합니다. Inbox Classic이나 컴퓨터가 예기치 않게 종료되면 다음에 Inbox Classic을 시작할 때 작성 중이던 메시지가 다시 열립니다.

변경 내용이 있는 메시지를 닫으면 저장할지 묻습니다.

  • : 메시지를 폴더에 저장합니다.
  • : 변경 내용을 버립니다. 임시 보관 메시지가 자동으로만 저장되었다면 폴더에서도 제거됩니다.
  • : 메시지로 돌아갑니다.

계속 작성하려면 폴더에서 임시 보관 메시지를 두 번 클릭합니다. 받는 사람, 본문, 파일이 그대로 열립니다. 임시 보관 메시지는 메시지가 보낼 편지함의 대기열에 안전하게 들어가면, 보내기가 끝나기 전에 제거됩니다.

작성하는 메시지는 별도의 창이므로 열어 둔 채로 메일을 읽을 수 있습니다. Inbox Classic을 닫으면 먼저 작성 중인 메시지가 닫히며, 변경 내용이 있는 메시지는 저장할지 묻습니다.

보낼 편지함

단추를 클릭하면 메시지가 보낼 편지함에 들어갑니다. 기본적으로 몇 초 후에 보내지며, 그동안 보내기를 취소할 수 있습니다(아래 참조). 기본 창의 상태 표시줄에 메시지를 보낸 때가 표시됩니다.

연결이 없는 경우처럼 메시지를 보낼 수 없으면 메시지는 보낼 편지함에 남습니다. Inbox Classic은 다음에 메일을 확인할 때 다시 보내려고 시도합니다.

보내기를 기다리는 메시지를 보려면 > 을 선택합니다. 각 메시지와 아직 보내지 않은 이유가 나열됩니다. 단추를 클릭하면 즉시 다시 시도하며, 여기서 메시지를 삭제할 수도 있습니다.

메시지 보내기 취소

기본적으로 단추를 클릭하면 메시지는 몇 초 동안 기다린 후에 보내집니다. 상태 표시줄에 남은 시간이 표시됩니다. 그동안 보내기를 취소하려면 남은 시간 옆의 단추를 클릭하거나 > 를 선택합니다. 메시지가 다시 열리므로 편집하거나 버릴 수 있습니다. 이 기능은 메시지가 보낼 편지함에 남아 있더라도 남은 시간이 끝날 때까지만 사용할 수 있습니다. 이미 보낸 메시지는 회수할 수 없습니다.

대기 시간을 바꾸거나 메시지를 바로 보내려면 페이지를 열고 설정을 조정합니다. 메시지가 대기 중일 때 Inbox Classic을 끝내면 앱은 메시지를 즉시 보내려고 시도합니다.
