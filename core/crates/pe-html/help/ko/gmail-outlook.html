Gmail 및 Outlook.com

Gmail, Outlook.com 및 Microsoft 365에는 브라우저 로그인을 사용합니다. 조건을 충족하는 Google 계정은 앱 암호도 사용할 수 있습니다.

Google과 Microsoft는 메일 프로그램이 평소 암호를 사용하는 것을 허용하지 않습니다. Inbox Classic에서 Outlook.com과 Microsoft 365에는 브라우저 로그인을 사용하십시오. Google 앱 암호는 계정에서 허용하는 경우에만 사용할 수 있습니다.

브라우저를 통해 로그인

창에서 또는 단추를 클릭합니다. 암호는 Google이나 Microsoft의 자체 페이지에 입력하므로 Inbox Classic은 암호를 알 수 없습니다. 이렇게 추가한 계정은 항상 공급자의 자체 메일 서버를 사용합니다.

Microsoft 365 조직에서는 먼저 Inbox Classic을 허용해야 할 수 있습니다. 이 경우 Microsoft에 관리자 승인 필요가 표시되고, Inbox Classic이 관리자가 승인할 수 있는 주소를 알려 줍니다.

단추는 처음에 사용할 수 없도록 설정되어 있습니다. 현재 구성에서 기본 제공 Google 로그인 앱은 테스트 사용자 전용입니다. 직접 등록한 로그인 앱을 사용하거나, 계정에서 허용하는 경우 앱 암호를 사용하십시오( 참조).

앱 암호 사용

Google 앱 암호를 사용하려면 2단계 인증이 필요하며, 모든 계정에서 사용할 수 있는 것은 아닙니다. 예를 들어 직장이나 학교의 정책 또는 고급 보호 프로그램 때문에 사용하지 못할 수 있습니다.

  1. Google 계정의 보안 설정에서 앱 비밀번호를 열고, 해당 옵션이 있으면 암호를 만듭니다.
  2. 창에서 이름과 주소를 입력하고 단추를 클릭합니다.
  3. 단추를 클릭합니다.
  4. 상자에 앱 암호를 입력한 다음 단추를 클릭합니다.

로그인이 만료된 경우

Google이나 Microsoft가 로그인을 종료하면 Inbox Classic에 “… 로그인이 거부되었거나 세션이 만료되었습니다.”라는 메시지가 표시됩니다. 그런 다음 브라우저에서 다시 로그인할지 묻습니다. 단추를 클릭하고 다시 로그인합니다.
