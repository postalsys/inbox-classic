로그인 앱

Google, Microsoft 또는 호환되는 OpenID Connect 공급자에 직접 로그인 앱을 등록하여 브라우저를 통해 로그인합니다.

브라우저를 통한 로그인에는 공급자에 등록된 OAuth 클라이언트가 사용됩니다. Inbox Classic에는 Google과 Microsoft용 자체 클라이언트가 있습니다. 현재 구성에서 기본 제공 Google 클라이언트는 테스트 사용자 전용이므로 단추는 처음에 사용할 수 없도록 설정되어 있습니다. Google Cloud 프로젝트, Microsoft Entra 테넌트 또는 메일 액세스를 지원하는 호환 OpenID Connect 공급자에 직접 클라이언트를 등록할 수 있습니다.

로그인 앱을 추가하려면 다음과 같이 합니다.

  1. > 을 선택합니다.
  2. 단추를 클릭한 다음 단추를 클릭합니다.
  3. 옆의 Google 또는 Microsoft를 클릭하면 발급자, 범위, 서버가 채워집니다. 다른 공급자의 경우 직접 입력합니다.
  4. 아래쪽 상자의 설명에 따라 공급자에 클라이언트를 등록합니다. 그곳에 표시된 값을 등록합니다.
  5. 상자에 값을 입력하고, 공급자가 클라이언트 암호를 제공한 경우 상자에도 입력합니다. 기본적으로 클라이언트 암호는 Windows 자격 증명 관리자에로그인 키체인에키링에 저장되며 다시 표시되지 않습니다.
  6. 단추를 클릭하여 발급자 검색과 서비스 주소를 확인합니다. 이 확인은 클라이언트 ID, 클라이언트 암호 또는 메일 권한의 유효성을 검사하지 않습니다. 그런 다음 단추를 클릭합니다.
  7. 창의 첫 페이지에서 단추로 계정을 추가합니다.

창에서 각 앱의 확인란은 스위치는 기본 제공 앱을 포함하여 해당 앱을 새 계정에 제공할지 나타냅니다. 이미 앱을 사용하는 계정은 계속 작동합니다. 단추는 앱을 변경하고, 단추는 앱을 사용하는 계정이 없을 때 앱을 제거합니다.

메일 서버가 앱의 토큰을 거부하면 앱의 범위에 메일 액세스 권한이 포함되어 있는지 확인합니다.
