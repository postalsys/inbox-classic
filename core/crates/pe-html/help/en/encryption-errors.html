Encryption errors

What to do when a server does not offer encryption, or wants it where it is off.

“the server does not offer STARTTLS”

The account is set to STARTTLS, but the server did not offer encryption. Inbox Classic stopped this connection attempt before sending the password.

  1. Open the account’s properties in > .
  2. Check your provider’s settings. If supported, use SSL/TLS with port 993 for incoming mail or 465 for outgoing mail.
  3. Click .

If nothing else works, the server cannot be used safely.

“the server takes the password only over an encrypted connection”

The outgoing server is set to . This error does not confirm that the password is correct. Following your provider’s settings, change to STARTTLS with port 587, or SSL/TLS with port 465.

The warning about a connection without encryption

When you choose , Inbox Classic warns that anyone who intercepts your network traffic can read your password and messages. A local network does not itself encrypt traffic. Continue only if you accept this risk for a server on your own computer or local network.
