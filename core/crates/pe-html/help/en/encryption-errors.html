Encryption errors

What to do when a server does not offer encryption, or wants it where it is off.

“the server does not offer STARTTLS”

The account is set to STARTTLS, but the server did not offer encryption. Inbox Classic stopped, so your password was not sent.

  1. Open the account’s properties in > .
  2. Set the security to SSL/TLS, with port 993 for incoming mail or 465 for outgoing mail.
  3. Click .

If nothing else works, the server cannot be used safely.

“the server takes the password only over an encrypted connection”

The outgoing server is set to . Your password is fine. Change to STARTTLS with port 587, or SSL/TLS with port 465.
