Save, print and import messages

Save messages as files, open and bring in message files, print a message and see its headers and source.

Save messages as files

Choose > () to save the message shown as an .eml file, which other mail programs open. With several messages selected, it asks for a folder and saves each one there, named after its subject. When saving several messages, existing files are kept and new files receive unused names. For a single message, replacement depends on the system’s save dialog.

You can also drag messages from the list to the desktop or to a folder in File Explorerthe Finderthe file manager.

Import message files

Select a folder and choose > , or drag .eml files onto a folder in the folder list. The messages are queued for import into that server folder and appear when the operation finishes. A file that is not a message is not imported.

Print

  1. Choose > (). The system’s print dialog opens. Preview and printing options vary by platform.
  2. Choose the printer, the copies and the pages, or save as PDF.
  3. Click the print button. The message prints with its sender, date, recipients and subject.

Headers and source

> () shows the message’s Internet headers: who sent it, through which servers, and when. At most the first 256 KiB of headers are shown. > () shows the message source as text, up to the first 4 MiB. A notice indicates when the display is truncated. in that window saves it as an .eml file.
