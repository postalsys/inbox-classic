Save, print and import messages

Save messages as files, bring message files in, print a message and see its headers and source.

Save messages as files

Choose > () to save the message shown as an .eml file, which other mail programs open. With several messages selected, it asks for a folder and saves each one there, named after its subject. A file already there is never replaced.

You can also drag messages from the list to the desktop or to a folder in File Explorerthe Finderthe file manager.

Import message files

Select a folder and choose > , or drag .eml files onto a folder in the folder list. The messages are put in that folder, on the server too. A file that is not a message is not imported.

Print

  1. Choose > (). A print preview opens.
  2. Choose the printer, the copies and the pages, or save as PDF.
  3. Click the print button. The message prints with its sender, date, recipients and subject.

Headers and source

> () shows the message’s Internet headers: who sent it, through which servers, and when. > () shows the whole message as text. in that window saves it as an .eml file.
