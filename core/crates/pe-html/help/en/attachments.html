Attachments

Save the files a message brings, and attach files to the messages you write.

Save an attachment

To save the files of a message:

  1. Click the paper clip at the right of the message header. It shows how many files there are.
  2. Choose a file to save it, or choose to save them all into a folder.

Inbox Classic saves files, but never opens them. It suggests a safe name, without characters that could make a name look like something else. A file of the same name already in the folder is kept, and the new one gets a number.

Open attachments only from people you expect them from. A program, or a document that asks you to “enable content”, can take over your computer. Programs include .exe, .msi, .js, .vbs, .bat and .scr files..app, .pkg, .dmg and .command files..sh, .deb, .AppImage and .desktop files.

Attach a file

To attach files to the message you write:

You can also drag files from File Explorerthe Finderthe file manager onto the address fields. A file that is not a picture can also go onto the text.

To take a file off, select it and press Delete, or right-click it and choose . The files are read when the message is sent, so keep them where they are until then.
