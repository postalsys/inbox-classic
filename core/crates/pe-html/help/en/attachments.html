Attachments

Open or save the files a message brings, and attach files to the messages you write.

See pictures and PDF files in the message

Pictures and the first pages of PDF files are shown after the text of a message, with their names and sizes. Click one to open the file. A longer PDF file has a link that opens it. A message shows up to 20 pictures and pages; a line under them says how many more files are in the list.

These are copies that Inbox Classic draws itself: nothing in a file runs, and nothing is loaded from the internet. A file it cannot draw shows as a tile with its name, its size and the reason, for example a HEIC picture or a PDF file protected by a password; click the tile to open the file. While a large message is still downloading, its files show as tiles until they arrive. In a signed or encrypted message, each part shows its own files inside its own frame. Those of an encrypted part are kept in memory only, never on disk, and are gone when you show another message.

To show a file in the message, or to take it out, right-click it in the list of files and choose . This lasts while the message is shown.

To see only the list, turn off in . If Inbox Classic ever closes while it is showing a file in a message, PDF files are no longer shown and the message says so; turn on to show them again.

When you print a message, its pictures are printed with it. PDF files are not: a line names each one, and you print it from its own program. In a signed or encrypted message, each part’s pictures come right after that part’s text, each named with its part.

Open an attachment

The files of a message are listed under its header, each with its name and size. Double-click a file to open it with the program your computer uses for it. With the keyboard, press Tab until the files are chosen, pick one with the arrow keys and press Enter.

Right-click a file for , and . The paper clip at the right of the header lists the files too.

Inbox Classic never opens a file that can run programs: programs, scripts, installers, shortcuts, disk images, web pages and Office documents with macros. Their is off; save such a file, and open it yourself only if you trust where it comes from.

To open a file, Inbox Classic saves a copy in a temporary folder for your user account. Copies older than a day are removed when the app starts. On Windows and macOS, files are marked as coming from the internet. Attachments from encrypted messages are stored there without encryption; Inbox Classic explains this the first time you open one.

Save an attachment

Right-click a file and choose , or choose to save them all into a folder. Inbox Classic suggests a safe name, without characters that could make a name look like something else. A file of the same name already in the folder is kept, and the new one gets a number.

Open attachments only from people you expect them from. A program, or a document that asks you to “enable content”, can take over your computer. Programs include .exe, .msi, .js, .vbs, .bat and .scr files..app, .pkg, .dmg and .command files..sh, .deb, .AppImage and .desktop files.

To take a file off, select it and press Delete, or right-click it and choose . The files are read when the message is sent, so keep them where they are until then.
