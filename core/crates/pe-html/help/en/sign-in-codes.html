Sign-in codes

A message with a sign-in or verification code shows the code in a card you can copy from.

When a message has a one-time code, such as a sign-in, verification or approval code, a card above it shows:

  • “Code from” and the domain the code is for
  • the code, in large type
  • , which puts the code on the clipboard
Enter a code only on a page of the domain the card names. A message that asks you to type a code somewhere else may be an attempt to take over your account.

The card appears only when your mail provider confirms that the domain signed the message. A code in a message someone else made up is not offered. There is no card in , or , or when your provider does not report signatures.

A code sent more than an hour before you opened it has probably expired, and the card says so.
