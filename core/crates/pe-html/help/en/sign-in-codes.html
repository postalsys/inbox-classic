Sign-in codes

A message with a sign-in or verification code shows the code in a card you can copy from.

When Inbox Classic recognizes an eligible sign-in, verification or approval code, a card above the message shows:

  • “Code from” and the domain the code is for
  • the code, in large type
  • , which puts the code on the clipboard
Enter a code only on a page of the domain the card names. A message that asks you to type a code somewhere else may be an attempt to take over your account.

The card requires your provider to confirm a signature from the relevant domain or its parent. This does not verify the individual sender or every claim in the message. There is no card in , or , or when your provider does not report signatures.

If the message’s date is more than an hour old, the card warns that the code may have expired. Inbox Classic does not check expiry with the service.

Codes in notifications

To see the code in the notification of a new message, turn on in . It is off by default because notifications may be visible on a locked screen. A code appears only when notifications are allowed and the fresh message can be downloaded and checked in time.
