A message is not shown

What to do when a message is still downloading, cannot be downloaded, or cannot be shown.

“Downloading the message…”

A message is downloaded the first time you open it. Right after you add an account, most messages are not on your computer yet. The sender and subject can appear before the contents finish downloading. Download time depends on the connection and message size.

“The message could not be downloaded”

The pane says why, for example that the mail server could not be reached. An open message with a failed download is retried after the account synchronizes. To try at once, click on the bar over the message.

“This message cannot be shown”

Inbox Classic could not read the message, for example because it is damaged or uses an unsupported structure. Another mail program may still be able to read it. The rest of your mail is not affected. To see what the message holds, choose > .

Inbox Classic uses the Microsoft Edge WebView2 Runtime to display messages. If the runtime is missing, install it from Microsoft and restart Inbox Classic. Having the Edge browser installed does not by itself confirm that the runtime is available.
