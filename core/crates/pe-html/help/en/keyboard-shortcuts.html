Keyboard shortcuts

The keys of every command, and the keys that work in lists, the editor and the Address Book.

The first table lists every command that has a key, by menu. The tables after it list the keys that work in one place only.

In the message list

KeysDoes
↑ ↓Select the message above or below
Shift+↑ Shift+↓Add the message above or below to the selection
Ctrl+Click⌘+ClickAdd a message to the selection, or take it out
Shift+ClickSelect every message from the selected one to this one
EnterReturnOpen the message in a window of its own
→ ←Show or hide the other messages of a conversation
NGo to the next unread message
AArchive the message
WWatch the conversation
KIgnore the conversation
TabMove between the folder list, the message list and the reading pane
MenuOpen the right-click menu of the selected message
EscEnd a search and show the folder again

While you write

KeysDoes
Ctrl+B⌘BBold
Ctrl+I⌘IItalic
Ctrl+U⌘UUnderline
Ctrl+K⌘KAdd a link, or change the link at the cursor
Ctrl+Click⌘+ClickOpen a link in your browser
Ctrl+A⌘ASelect all, the folded original message of a reply included
Ctrl+S⌘SSave the message in Drafts
Ctrl+Enter⌘ReturnSend the message
Alt+C, Alt+BShow the Cc or Bcc line

In the list of addresses as you type

KeysDoes
↑ ↓Choose a person
EnterReturn or TabTake the chosen person
EscClose the list
Shift+DeleteTake the chosen person out of the list for good

In the Address Book

KeysDoes
DeleteDelete the selected contacts, or the selected group, after asking
EscClose a contact or group without saving
