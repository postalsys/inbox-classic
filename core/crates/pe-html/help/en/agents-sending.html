When an agent sends mail

Every message an AI agent wants to send is shown to you first, and waits in the Outbox before it goes.

An agent can send mail only if you allowed it to, and each message only after you say yes.

When the agent wants to send, Inbox Classic shows the message with every recipient by address. Addresses you have never written to are marked .

  1. Read the recipients and the text.
  2. Choose one:
    • sends it. It comes on after a moment, so you cannot press it by accident.
    • opens it in a new message for you to change.
    • , the default, does not send it.

A message you send waits 30 seconds in the Outbox. Until it goes, you can delete it there, or click in > .

An agent that also has other tools, such as browsing the web or reading your files, could pass on what it reads through them. Inbox Classic cannot see those. Let an agent send only if you need it to.
