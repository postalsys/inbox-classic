When an agent sends mail

Every message an AI agent wants to send is shown to you first, and waits in the Outbox before it goes.

An agent can send mail only if you allowed it to, and each message only after you say yes.

When the agent wants to send, Inbox Classic shows the message with every recipient by address. Addresses you have never written to are marked .

  1. Read the recipients and the text.
  2. Choose one:
    • sends it. It comes on after a moment, so you cannot press it by accident.
    • opens it in a new message for you to change.
    • , the default, does not send it.

An agent asks about one message at a time. If you take a while to answer, the agent is told that the message waits for you, and it can ask later what you decided. By default, the messages and drafts it writes end with your signature, as yours do, but the agent can leave it out.

A message you send waits 30 seconds in the Outbox. Until it goes, you can delete it there, or click in > .

Answers to invitations

An agent that may send mail can accept, tentatively accept or decline a calendar invitation for you, through the same question. Above the text, the question says which invitation the message answers and when the event is. Inbox Classic writes the answer to the organizer from the invitation itself, so the message cannot be opened to change first. Your answer to the invitation changes only once the message has been sent.

Drafts an agent writes

When you open a draft an agent wrote, a line above the message names the agent. Check the recipients and the text before you send it.

The agent can change or remove its draft until you save it yourself. From then on, the draft is yours.

An agent that also has other tools, such as browsing the web or reading your files, could pass on what it reads through them. Inbox Classic cannot see those. Let an agent send only if you need it to.
