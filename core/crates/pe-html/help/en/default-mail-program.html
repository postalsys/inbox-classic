Make Inbox Classic your mail app

Open e-mail links and message files from web pages and other programs in Inbox Classic.

E-mail links (mailto:) open a new message in your default mail app.

To make Inbox Classic that app, choose > . Windows opens its Default apps settings, where you choose Inbox Classic for MAILTO links. Only an installed copy is listed there. Inbox Classic asks the system to make it the default mail app; the change depends on system permissions and settings.

When you then click an e-mail link, a new message opens with the link’s addresses, subject and text filled in. Nothing else of the link is used.

If you have no account yet, Inbox Classic asks you to add one first. Click the link again once it is added.

Message files

To open .eml files in Inbox Classic when you double-click them, click in . Windows opens its Default apps settings, where you choose Inbox Classic for .eml files. Canceling Inbox Classic’s settings does not undo changes already made in Windows. Inbox Classic asks the system to use it for these files.
