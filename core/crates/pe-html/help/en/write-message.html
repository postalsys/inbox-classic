Formatting

The bar above the text has the font, bold, italic, underline, color, lists, indent, alignment, links, a dividing line and pictures. To put a picture in the text, click or drag a picture file from File Explorerthe Finderthe file manager into the text.

A message with no formatting goes as plain text, which every mail program shows the same way. A formatted one goes as HTML with a plain text copy.
