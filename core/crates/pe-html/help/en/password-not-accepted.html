The password is not accepted

What to do when the mail server refuses your password or sign-in.

You may see one of these:

  • In the status bar: “the server did not accept the sign-in (…)”
  • In the reading pane: “The mail server did not accept the sign-in (…). Check the password or sign in again in File > Accounts.”
  • A window that asks you to enter the password of the account again

To fix it:

  1. Type the password again when Inbox Classic asks, or change it in the account’s properties in > .
  2. If your provider asks for a second step when you sign in on the web, it needs an app password for mail programs too. Create one in your account’s security settings and use it instead of your usual password.
  3. For Gmail and Outlook.com, sign in through the browser or use an app password. See .
