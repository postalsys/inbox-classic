Links, scripts and attachments

How Inbox Classic keeps a message from running code or opening pages on its own.

  • Scripts in messages never run. Inbox Classic cleans every message before it shows it, and the reading pane cannot run code.
  • Links open in your web browser, never inside Inbox Classic. A message cannot open a page or a window by itself.
  • Attachments are saved, never opened from Inbox Classic. Their names are made safe before you save them.
  • Unsubscribe asks you first, and says what it will do.
Before you type a password on a page you reached from a message, check the address in your browser. A message can show one address and link to another.

When you write a message, the status bar shows where the link at the cursor goes, so you can check it before you send.
