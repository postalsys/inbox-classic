Links, scripts and attachments

How Inbox Classic keeps a message from running code or opening pages on its own.

  • Scripts in messages never run. Inbox Classic removes message scripts and active markup before displaying it. The app’s own display controls still use scripts.
  • Web links open in your browser when you choose them. E-mail links can open a new message. Message content cannot open a page or window on its own.
  • Attachments open in an external program only when you ask. Inbox Classic first saves a temporary copy and blocks recognized executable formats. Suggested file names are cleaned before saving.
  • Unsubscribe asks you first, and says what it will do.
Before you type a password on a page you reached from a message, check the address in your browser. A message can show one address and link to another.

When you write a message, the status bar shows the destination of the link under the pointer or at the text cursor, so you can check it before you send.

A sign-in code is offered only when your mail provider confirms a signature from the relevant domain or its parent. This does not verify an individual sender. See .

Embedded pictures are converted to static images before display, and fonts supplied by the message are not used. Remote pictures that you allow are displayed by the web view.
