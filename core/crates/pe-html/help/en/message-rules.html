Sort new mail with rules

Automatically move, mark as read, flag or archive incoming messages that meet your criteria.

A rule combines search criteria with actions to apply to matching messages as they arrive in your Inbox. For example, a rule with from:news@example.com can move newsletters from that address to a separate folder and mark them as read.

To make a rule:

  1. Choose > , then click .
  2. Enter a name and fill in using the same terms as in the search box, such as from:, subject: or list:. The line below shows how many existing Inbox messages match these criteria.
  3. Choose one or more actions for matching messages: move them to a folder, mark them as read, flag them, archive them, move them to Junk E-mail, delete them or suppress notifications.
  4. Click .

You can also create a rule from a message or a search. Choose > to fill in the selected message’s sender or mailing list. Click above the search results to use your current search criteria.

How rules work

Rules process new Inbox messages while Inbox Classic is running, including when it is minimized to the notification area. Existing messages are only affected if you check . Matching rules run in the order shown in the list. Once a rule moves a message out of the Inbox, no further rules apply to that message. Clear a rule’s check box in the list to disable it without deleting it.

Changing rules

To edit a rule, select it in the list and click , or double-click it. Use and to change the order, or to delete the rule. In the rule editor, click to see the messages that currently match in the main window.

Rules apply to new Inbox messages, so folder and date filters are not supported. If you use in:, before:, after:, older_than: or newer_than:, a message explains why these filters cannot be used. Rules cannot send messages or delete them permanently: moves them to .

Rules run on this computer. To sort mail while it is off, use the filters of your mail provider.
