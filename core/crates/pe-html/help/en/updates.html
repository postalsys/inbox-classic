Update Inbox Classic

Get the newest version of Inbox Classic.

To see which version you have, choose > .

Download the newest installer from inboxclassic.com and run it. It updates the installed copy in place. Your accounts and the mail downloaded for them are kept.

Inbox Classic updates itself. It checks for a new version by itself, and asks before it installs one. To check now, choose Inbox Classic > .

If you installed Inbox Classic from its apt repository, new versions come with your system’s own updates. If you installed a .deb file, download the newer one from inboxclassic.com and install it over the old one.

On Arch Linux, install the newer package with sudo pacman -U the same way. On Omarchy, its own Update brings the new version.

Your accounts, mail and settings are kept across updates.
