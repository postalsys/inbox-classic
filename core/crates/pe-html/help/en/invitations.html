Calendar invitations

A message with a calendar invitation shows the event above its text, ready to open in your calendar.

When a message carries an event, a card above the text shows:

  • what it is: an invitation, an updated invitation, a cancellation or a response
  • when it is, in your own time
  • where it is, who organizes it, and how many are invited
  • how it repeats, if it does

To accept or decline, click . The event opens in your calendar app, where you answer it.

If no calendar app is set up, Inbox Classic says so. Set one up, then try again.
