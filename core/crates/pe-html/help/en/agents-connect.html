Connect an AI agent

Let an AI agent, such as Claude, read and organize your mail through Inbox Classic.

You can let an AI agent work with your mail. It can be Claude, Cursor or another program that supports the Model Context Protocol (MCP). There is no AI in Inbox Classic, and nothing is sent to an AI service unless you let an agent in.

To connect an agent:

  1. Choose > and click . Inbox Classic shows the lines to add to your agent’s settings.
  2. Add them to the MCP servers of your agent. In Claude Desktop, that is Settings > Developer > Edit Config.
  3. Start the agent. The first time it connects, Inbox Classic asks you what it may do.

The agent starts Inbox Classic in the background if it is not running. Only programs running as you on this computer can reach it.

Inbox Classic asks the system which program started the agent, rather than taking the agent’s word for it, so an agent cannot get the access you gave another program just by saying it is that program. If an agent says it is a different program, the question tells you. This keeps your agents apart; it does not protect you from a harmful program running as you, which could read your mail anyway.

An agent can also keep your Inbox, an account or a folder in view and be told when its mail changes, and it can offer two ready-made requests, “Triage my inbox” and “Summarize unread”. Both follow what you allow the agent, and what it reads this way shows in its log like everything else it reads.

Agents such as Claude Code share access when started from the same recognized terminal program. It asks once for programs started from Terminalprograms started from a terminal, and they share what you allow. To give an agent its own access, add --name and a name of your choice after --mcp in its settings, for example "args": ["--mcp", "--name", "Claude Code"]. Inbox Classic then asks about it by that name. The chosen name does not verify the agent’s identity.

To turn all agents off at once, turn off in > .
