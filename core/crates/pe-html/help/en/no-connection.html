Inbox Classic cannot connect

What to do when the mail server cannot be reached or does not answer.

You may see one of these in the status bar or the reading pane:

  • “connection error: …”
  • “the server did not answer in time”
  • “the connection to the server failed (…)”
  • “The mail server could not be reached (…).”

To fix it:

  1. Check your internet connection.
  2. Open the account’s properties in > and check the server names and ports.
  3. If sending fails, use port 465 or 587 for outgoing mail. Some networks block the mail ports, port 25 in particular.

A message you send while there is no connection waits in the Outbox and goes once the server can be reached. Nothing you wrote is lost.
