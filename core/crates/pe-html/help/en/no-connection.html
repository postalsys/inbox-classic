Inbox Classic cannot connect

What to do when the mail server cannot be reached or does not answer.

You may see one of these in the status bar or the reading pane:

  • “connection error: …”
  • “the server did not answer in time”
  • “the connection to the server failed (…)”
  • “The connection to the mail server could not be made or was interrupted (…).”

To fix it:

  1. Check your internet connection.
  2. Open the account’s properties in > and check the server names and ports.
  3. If sending fails, check the outgoing server’s security and port: typically SSL/TLS on port 465 or STARTTLS on port 587. Some networks block the mail ports, port 25 in particular.

Inbox Classic tries again at the next check for mail. When an account cannot connect twice in a row, a gray mark appears on it in the folder list and a bar over its list says so. To try now, click the mark, in the bar, or . The mark goes by itself once the server answers.

A message you send without a connection stays in the local Outbox. Inbox Classic retries when it can connect; the server may still reject the message.
