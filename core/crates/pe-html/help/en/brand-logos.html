Brand logos

Mail from a brand that publishes a logo shows that logo beside the message header.

Some companies publish a logo for their mail. Inbox Classic shows it beside the header of their messages. It does so only when your mail server confirmed that the message comes from the brand’s domain and approved the logo.

A logo is a sign that the sender is who it says it is. A message without one is not necessarily fake, as most senders publish no logo.

The logo comes with the message or, if not, from the brand’s own secure web address, once each time Inbox Classic runs. Inbox Classic checks the picture before it shows it, and loads nothing else for it.
