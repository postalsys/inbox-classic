Command-line options

Options for starting Inbox Classic from a terminal, for testing and for AI agents.

Start the program InboxClassic.exe"Inbox Classic.app/Contents/MacOS/Inbox Classic"inbox-classic with these options:

OptionDoes
--store <file>Uses another mail store, such as one for testing
--memory-passwordsKeeps passwords for this run only, never in the system’s password store
--pin-certificate <file>Accepts only the server certificate in this file (PEM or DER), for a test server with a self-signed certificate
--sign-in-page-file <file>Writes the page of a browser sign-in to this file instead of opening the browser
--language <code>Shows the windows in this language for this run, such as de
--backgroundStarts without its window
--mcpConnects an AI agent to Inbox Classic. The agent’s program starts this, not you
--versionPrints the version and ends

A mailto: link given as the argument opens a new message, as an e-mail link does.
