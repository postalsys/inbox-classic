Command-line options

Options for starting Inbox Classic from a terminal, for testing and for AI agents.

Start the program InboxClassic.exe"Inbox Classic.app/Contents/MacOS/Inbox Classic"inbox-classic with these options:

OptionDoes
--store <file>Uses another mail store, such as one for testing
--memory-passwordsKeeps sign-in credentials for this run only, instead of saving them in the system’s credential store
--pin-certificate <file>Accepts only certificates in this file for a test server: one DER certificate, or one or more PEM certificates
--sign-in-page-file <file>Writes the browser sign-in URL to this file instead of opening the browser
--language <code>Shows the windows in this language for this run, such as de
--backgroundStarts without its window
--mcpConnects an AI agent to Inbox Classic. The agent’s program starts this, not you
--versionPrints the version and ends

A mailto: link given as the argument opens a new message when an account is configured, as an e-mail link does.
