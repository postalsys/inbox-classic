Tehisintellekti agendi ühendamine

Laske tehisintellekti agendil, näiteks Claude'il, Inbox Classicu kaudu teie posti lugeda ja korraldada.

Saate lasta tehisintellekti agendil oma postiga töötada. See võib olla Claude, Cursor või mõni muu programm, mis toetab Model Context Protocoli (MCP). Inbox Classicus endas pole tehisintellekti ja tehisintellekti teenusele ei saadeta midagi, kui te agenti sisse ei lase.

Agendi ühendamiseks tehke järgmist.

  1. Valige > ja klõpsake nuppu . Inbox Classic näitab ridu, mis tuleb lisada agendi sätetesse.
  2. Lisage need oma agendi MCP-serverite hulka. Claude Desktopis on see Settings > Developer > Edit Config.
  3. Käivitage agent. Esimesel ühendumisel küsib Inbox Classic teilt, mida see teha tohib.

Kui Inbox Classic ei tööta, käivitab agent selle taustal. Sellele pääsevad ligi ainult programmid, mis töötavad selles arvutis teie nime all.

Inbox Classic küsib süsteemilt, milline programm agendi käivitas, selle asemel et agendi sõna uskuda, nii et üks programm ei saa kasutada juurdepääsu, mille andsite teisele. Kui agent väidab end olevat mõni teine programm, ütleb küsimus teile seda.

Agent saab ka jälgida teie Sisendkausta, kontot või kausta ja saada teate, kui nende kirjad muutuvad, ning pakkuda kahte valmis päringut, „Triage my inbox“ ja „Summarize unread“. Mõlemad järgivad seda, mida agendil lubate, ja see, mida agent nii loeb, kuvatakse tema logis nagu kõik muu, mida ta loeb.

Terminalist käivitatud agendid, näiteks Claude Code, on Inbox Classicu jaoks üks programm. See küsib luba ühe korra rakendusest Terminal käivitatud programmideleterminalist käivitatud programmidele ja need jagavad teie antud õigusi. Kui soovite anda agendile eraldi juurdepääsu, lisage selle sätetes argumendi --mcp järele --name ja enda valitud nimi, näiteks "args": ["--mcp", "--name", "Claude Code"]. Seejärel kasutab Inbox Classic küsimisel seda nime.

Kõigi agentide juurdepääsu keelamiseks lülitage menüüs > valik välja.
