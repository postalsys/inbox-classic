Krüptimisvead

Mida teha, kui server ei paku krüptimist või nõuab seda seal, kus see on välja lülitatud.

„the server does not offer STARTTLS“

Konto on seatud kasutama STARTTLS-i, kuid server ei pakkunud krüptimist. Inbox Classic peatus, seega teie parooli ei saadetud.

  1. Avage konto atribuudid menüüst > .
  2. Seadke turbeks SSL/TLS, sissetuleva posti jaoks pordiga 993 või väljuva posti jaoks pordiga 465.
  3. Klõpsake nuppu .

Kui miski muu ei tööta, ei saa serverit turvaliselt kasutada.

„the server takes the password only over an encrypted connection“

Väljuva posti server on seatud valikule . Teie parool on korras. Muutke sätte väärtuseks STARTTLS pordiga 587 või SSL/TLS pordiga 465.

Hoiatus krüptimata ühenduse kohta

Kui valite valiku , hoiatab Inbox Classic, et igaüks, kes teie võrguliiklust pealt kuulab, saab lugeda teie parooli ja kirju. Jätkake ainult oma arvutis või kohtvõrgus oleva serveri puhul.
