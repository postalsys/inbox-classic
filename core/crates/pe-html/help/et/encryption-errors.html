Krüptimisvead

Mida teha, kui server ei paku krüptimist või nõuab seda seal, kus see on välja lülitatud.

„the server does not offer STARTTLS“

Konto on seatud kasutama STARTTLS-i, kuid server ei pakkunud krüptimist. See ühendus katkestati enne sisselogimisandmete saatmist.

  1. Avage konto atribuudid menüüst > .
  2. Kui teenusepakkuja seda toetab, valige SSL/TLS ja tema määratud port. Tavaliselt on see sissetuleval postil 993 ja väljuval postil 465.
  3. Klõpsake nuppu .

Kui miski muu ei tööta, ei saa serverit turvaliselt kasutada.

„the server takes the password only over an encrypted connection“

Väljuva posti server on seatud valikule . See teade ei kinnita parooli õigsust. Vastavalt teenusepakkuja juhistele muutke sätte väärtuseks STARTTLS pordiga 587 või SSL/TLS pordiga 465.

Hoiatus krüptimata ühenduse kohta

Kui valite valiku , hoiatab Inbox Classic, et igaüks, kes teie võrguliiklust pealt kuulab, saab lugeda teie parooli ja kirju. Ka kohtvõrk ei krüpteeri ühendust. Kasutage seda valikut ainult teadlikult oma arvutis või kontrollitud kohtvõrgus oleva serveriga.
