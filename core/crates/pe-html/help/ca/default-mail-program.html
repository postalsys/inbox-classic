Fer d’Inbox Classic l’aplicació de correu

Obriu amb Inbox Classic els enllaços de correu electrònic i els fitxers de missatge de les pàgines web i d’altres programes.

Els enllaços de correu electrònic (mailto:) obren un missatge nou a l’aplicació de correu per defecte.

Per fer que Inbox Classic sigui aquesta aplicació, trieu > . Windows obre la configuració d’Aplicacions per defecte, on podeu triar Inbox Classic per als enllaços MAILTO. Només hi apareix una còpia instal·lada. Inbox Classic passa a ser de seguida l’aplicació de correu per defecte.

Aleshores, quan feu clic en un enllaç de correu electrònic, s’obre un missatge nou amb les adreces, l’assumpte i el text de l’enllaç ja omplerts. No es fa servir res més de l’enllaç.

Si encara no teniu cap compte, Inbox Classic us demana que n’afegiu un primer. Un cop afegit, torneu a fer clic a l’enllaç.

Fitxers de missatge

Per obrir els fitxers .eml amb Inbox Classic quan hi feu doble clic, feu clic a a . Windows obre la configuració d’Aplicacions per defecte, on podeu triar Inbox Classic per als fitxers .eml. Inbox Classic passa a ser de seguida la seva aplicació.
