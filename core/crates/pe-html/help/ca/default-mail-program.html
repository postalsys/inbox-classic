Definir Inbox Classic com a aplicació de correu predeterminada

Feu servir Inbox Classic per obrir enllaços de correu electrònic i fitxers de missatge des de pàgines web i altres programes.

Els enllaços de correu electrònic (mailto:) obren un missatge nou a l’aplicació de correu predeterminada.

Per definir Inbox Classic com a aplicació predeterminada, trieu > . Windows obre la configuració d’Aplicacions predeterminades, on podeu triar Inbox Classic per als enllaços MAILTO. Només hi apareix una còpia instal·lada. Inbox Classic es defineix immediatament com a aplicació de correu predeterminada.

Aleshores, quan feu clic en un enllaç de correu electrònic, s’obre un missatge nou amb les adreces, l’assumpte i el text de l’enllaç ja omplerts. Els altres paràmetres de l’enllaç s’ignoren.

Si encara no teniu cap compte, Inbox Classic us demana que n’afegiu un primer. Un cop afegit, torneu a fer clic a l’enllaç.

Fitxers de missatge

Per obrir els fitxers .eml amb Inbox Classic quan hi feu doble clic, feu clic a a . Windows obre la configuració d’Aplicacions predeterminades, on podeu triar Inbox Classic per als fitxers .eml. Inbox Classic es defineix immediatament com a aplicació predeterminada per a aquests fitxers.
