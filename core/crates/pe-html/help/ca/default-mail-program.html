Definir Inbox Classic com a aplicació de correu predeterminada

Feu servir Inbox Classic per obrir enllaços de correu electrònic i fitxers de missatge des de pàgines web i altres programes.

Els enllaços de correu electrònic (mailto:) obren un missatge nou a l’aplicació de correu predeterminada.

Per definir Inbox Classic com a aplicació predeterminada, trieu > . Si encara cal canviar l’associació, Windows obre la configuració d’Aplicacions predeterminades, on podeu triar Inbox Classic per als enllaços MAILTO. Inbox Classic només apareix a la llista si està instal·lat. Inbox Classic demana al sistema que el defineixi com a aplicació de correu predeterminada. Si el canvi falla, comproveu la configuració del sistema.

Aleshores, quan feu clic en un enllaç de correu electrònic, s’obre un missatge nou amb les adreces, l’assumpte i el text de l’enllaç ja omplerts. Els altres paràmetres de l’enllaç s’ignoren.

Si encara no teniu cap compte, Inbox Classic us demana que n’afegiu un primer. Un cop afegit, torneu a fer clic a l’enllaç.

Fitxers de missatge

Per obrir els fitxers .eml amb Inbox Classic quan hi feu doble clic, feu clic a a . Si encara cal canviar l’associació, Windows obre la configuració d’Aplicacions predeterminades, on podeu triar Inbox Classic per als fitxers .eml. Inbox Classic demana al sistema que el defineixi com a aplicació predeterminada per a aquests fitxers. Si el canvi no s’aplica, comproveu-ne l’associació al sistema.
