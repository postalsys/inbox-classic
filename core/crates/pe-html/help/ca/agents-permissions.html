Què pot fer un agent

Trieu què pot fer cada agent d’IA amb el vostre correu, consulteu-ne l’activitat i desfeu-ne els canvis.

La primera vegada que es connecta l’agent d’un programa, Inbox Classic demana autorització i mostra el nom del programa. Trieu què pot fer:

  • llegir el correu: consultar carpetes, missatges i converses, cercar missatges, consultar regles de missatges i cercar contactes
  • organitzar el correu: canviar l’estat de lectura i les banderes, gestionar el correu brossa, moure i arxivar missatges, crear carpetes, suprimir missatges (movent-los a la carpeta ) i cancel·lar subscripcions a llistes de correu amb la vostra autorització
  • escriure esborranys perquè els envieu vós i modificar o descartar els esborranys creats pel mateix agent, mentre no els deseu
  • enviar correu, amb la vostra aprovació per a cada missatge

Després trieu els comptes que pot veure i feu clic a . rebutja el programa, i no se us tornarà a demanar autorització per a aquest programa.

Un agent només pot suprimir definitivament els esborranys que ha creat i que encara no heu desat. No canvia la configuració dels vostres comptes. Pot consultar les regles de missatges i veure a quins missatges s’aplicarien, sense modificar aquests missatges. No pot crear, modificar ni suprimir regles. Llegir un missatge no el marca com a llegit. Els canvis que fa l’agent es veuen immediatament a l’aplicació.

Cancel·lar subscripcions a llistes de correu

Un agent autoritzat a organitzar el correu pot proposar-vos de cancel·lar subscripcions a llistes de correu. Inbox Classic mostra les adreces dels remitents i demana una sola confirmació per a totes les llistes seleccionades:

  • demana a les llistes seleccionades que deixin d’enviar-vos missatges.
  • és l’opció predeterminada i no envia cap sol·licitud de cancel·lació.

Un agent no pot fer servir missatges de la carpeta per cancel·lar subscripcions. Per a cada programa, el límit és de 30 sol·licituds de cancel·lació autoritzades per vós durant les últimes 24 hores. Les sol·licituds que fallen també compten per a aquest límit.

Veure i canviar l’accés

> mostra els programes als quals heu permès o denegat l’accés, i tot el que han fet els agents, del més nou al més antic.

  • canvia què pot fer un programa.
  • elimina un programa i els seus permisos. La propera vegada que es connecti, caldrà tornar-ne a autoritzar l’accés.
  • desfà els canvis en l’estat de lectura, les banderes i la classificació com a correu brossa, així com els trasllats, els arxivaments i les supressions de missatges. També permet cancel·lar l’enviament de missatges que encara són a la Safata de sortida.
El correu l’escriuen altres persones, i un missatge pot intentar convèncer un agent perquè reenviï o suprimeixi el vostre correu. Inbox Classic oculta als agents el text que no veieu al missatge i els indica que el contingut del correu no s’ha de tractar com a instruccions. Tot i així, un agent es pot deixar enganyar. Permeteu només el que necessiteu.
