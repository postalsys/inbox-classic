Inbox Classic no es pot connectar

Què cal fer quan no es pot contactar amb el servidor de correu o no respon.

Podeu veure un d’aquests missatges a la barra d’estat o a la subfinestra de lectura:

  • «connection error: …»
  • «the server did not answer in time»
  • «la connexió amb el servidor ha fallat (…)»
  • «No s’ha pogut establir la connexió amb el servidor de correu o s’ha interromput (…).»

Per solucionar-ho:

  1. Comproveu la connexió a internet.
  2. Obriu les propietats del compte a > i comproveu els noms i els ports dels servidors.
  3. Si l’enviament falla, comproveu les opcions de sortida: normalment, SSL/TLS fa servir el port 465 i STARTTLS el 587. Algunes xarxes bloquegen els ports de correu, sobretot el port 25.

Inbox Classic ho torna a provar a la comprovació de correu següent. Després de dos errors de connexió consecutius, apareix un avís al costat del compte a la llista de carpetes i sobre la seva llista de missatges. Per provar-ho ara, feu clic a la icona d’avís, a a la barra o a . L’avís desapareix quan el compte es torna a connectar.

Un missatge que envieu sense connexió es queda a la Safata de sortida local. Inbox Classic ho torna a provar quan es pot connectar; el servidor encara pot rebutjar el missatge.
