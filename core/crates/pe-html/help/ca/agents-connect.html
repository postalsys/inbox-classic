Connectar un agent d’IA

Deixeu que un agent d’IA, com ara Claude, llegeixi i organitzi el vostre correu a través d’Inbox Classic.

Podeu deixar que un agent d’IA treballi amb el vostre correu. Pot ser Claude, Cursor o un altre programa compatible amb el Model Context Protocol (MCP). Inbox Classic no conté cap IA, i no s’envia res a cap servei d’IA tret que hi deixeu entrar un agent.

Per connectar un agent:

  1. Trieu > i feu clic a . Inbox Classic mostra les línies que cal afegir a la configuració de l’agent.
  2. Afegiu-les als servidors MCP de l’agent. A Claude Desktop, és Settings > Developer > Edit Config.
  3. Inicieu l’agent. La primera vegada que es connecta, Inbox Classic us pregunta què pot fer.

L’agent inicia Inbox Classic en segon pla si no s’està executant. Només hi poden accedir els programes que s’executen amb el vostre usuari en aquest ordinador.

Per desactivar tots els agents alhora, desmarqueu a > .
