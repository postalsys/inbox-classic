Connectar un agent d’IA

Connecteu un agent d’IA, com ara Claude, per llegir i organitzar el vostre correu a través d’Inbox Classic.

Podeu autoritzar un agent d’IA a treballar amb el vostre correu. Pot ser Claude, Cursor o un altre programa compatible amb el Model Context Protocol (MCP). Inbox Classic no inclou cap servei d’IA i només permet l’accés dels agents amb la vostra autorització.

Per connectar un agent:

  1. Trieu > i feu clic a . Inbox Classic mostra el fragment que cal afegir a la configuració dels servidors MCP de l’agent.
  2. Afegiu aquest fragment a la configuració dels servidors MCP de l’agent. A Claude Desktop, és Settings > Developer > Edit Config.
  3. Inicieu l’agent. La primera vegada que es connecta, Inbox Classic us pregunta què pot fer.

L’agent inicia Inbox Classic en segon pla si no s’està executant. Només hi poden accedir els programes que s’executen amb el vostre compte d’usuari en aquest ordinador.

Inbox Classic pregunta al sistema quin programa ha iniciat l’agent, en lloc de confiar només en el nom que declara. Això separa els permisos dels programes identificats, però no protegeix el correu d’un programa maliciós que s’executi amb el mateix usuari del sistema. Si el nom declarat no coincideix amb el programa identificat, la pregunta us ho indica.

Un agent també pot tenir a la vista la vostra Safata d’entrada, un compte o una carpeta i rebre un avís quan hi canvia el correu, i pot oferir dues peticions ja preparades, «Triage my inbox» i «Summarize unread». Tant aquestes vistes com les peticions preparades respecten els permisos i els comptes autoritzats. Les lectures apareixen al registre de l’agent.

Els agents iniciats des del mateix programa de terminal reconegut, com ara Claude Code, comparteixen l’accés. Inbox Classic agrupa els programes iniciats des del Terminalprogrames iniciats des d’un terminal segons la ruta del programa de terminal, no com un sol grup per a tots els terminals. Per donar a un agent el seu propi accés, afegiu --name i un nom que trieu després de --mcp a la seva configuració, per exemple "args": ["--mcp", "--name", "Claude Code"]. Aleshores Inbox Classic demana un permís separat amb aquest nom; el nom triat no és una identitat verificada.

Per bloquejar l’accés de tots els agents, desactiveu l’opció a > .
