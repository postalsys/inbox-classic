Quan un agent envia correu

Cada missatge que un agent d’IA vol enviar se us mostra primer, i espera a la Safata de sortida abans de l’enviament.

Un agent només pot enviar correu amb la vostra autorització, que cal donar per a cada missatge.

Quan un agent sol·licita un enviament, Inbox Classic mostra el missatge amb l’adreça de cada destinatari. Les adreces a les quals no heu escrit mai es marquen com a .

  1. Comproveu els destinataris i llegiu el text.
  2. Trieu una opció:
    • posa el missatge a la Safata de sortida. El botó s’activa després d’un breu interval per evitar que el premeu per accident.
    • obre una finestra de redacció perquè editeu el missatge.
    • , l’opció predeterminada, no l’envia.

Cada programa només pot tenir un missatge pendent de la vostra confirmació. Si no responeu de seguida, Inbox Classic informa l’agent que encara espera una resposta. L’agent pot consultar la vostra decisió més endavant. Per defecte, els missatges i els esborranys de l’agent inclouen el text de la signatura del vostre compte. L’agent pot optar per ometre’l.

Un missatge del qual aproveu l’enviament espera 30 segons a la Safata de sortida. Abans que s’enviï, el podeu suprimir allà o fer clic a a > .

Respostes a invitacions

Un agent autoritzat a enviar correu pot acceptar, acceptar provisionalment o rebutjar una invitació de calendari en nom vostre, amb la mateixa pregunta. Damunt del text, la pregunta indica a quina invitació respon el missatge i quan és l’esdeveniment. Inbox Classic escriu la resposta a l’organitzador a partir de la mateixa invitació, de manera que el missatge no es pot obrir abans per canviar-lo. La vostra resposta a la invitació només canvia quan el missatge s’ha enviat.

Esborranys que escriu un agent

Quan obriu un esborrany escrit per un agent, el nom de l’agent apareix damunt del text del missatge. Comproveu els destinataris i el text abans d’enviar-lo.

Un agent només pot modificar o descartar els esborranys que ha creat. Quan en deseu un, l’agent ja no el pot modificar ni descartar. Això també s’aplica quan Inbox Classic desa automàticament els vostres canvis. El fet d’obrir l’esborrany no impedeix que l’agent el continuï modificant.

Un agent que també té altres eines, com ara navegar per internet o llegir els vostres fitxers, podria transmetre a través d’elles el que llegeix. Inbox Classic no controla aquestes altres eines. Autoritzeu l’enviament de correu només quan sigui necessari.
