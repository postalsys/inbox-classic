Quan un agent envia correu

Cada missatge que un agent d’IA vol enviar se us mostra primer, i espera a la Safata de sortida abans de sortir.

Un agent només pot enviar correu si li ho heu permès, i cada missatge només després que digueu que sí.

Quan l’agent vol enviar, Inbox Classic mostra el missatge amb l’adreça de cada destinatari. Les adreces a les quals no heu escrit mai es marquen com a .

  1. Llegiu els destinataris i el text.
  2. Trieu una opció:
    • l’envia. S’activa al cap d’un moment, perquè no el pugueu prémer per accident.
    • l’obre en un missatge nou perquè el canvieu.
    • , l’opció per defecte, no l’envia.

Un agent pregunta per un sol missatge alhora. Els missatges i esborranys que escriu acaben amb la vostra signatura, com els vostres.

Un missatge que envieu espera 30 segons a la Safata de sortida. Fins que surt, el podeu suprimir allà o fer clic a a > .

Un agent que també té altres eines, com ara navegar per internet o llegir els vostres fitxers, podria transmetre a través d’elles el que llegeix. Inbox Classic no les pot veure. Deixeu que un agent enviï correu només si cal.
