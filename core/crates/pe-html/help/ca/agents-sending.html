Quan un agent envia correu

Cada missatge que un agent d’IA vol enviar se us mostra primer, i espera a la Safata de sortida abans de l’enviament.

Un agent només pot enviar correu amb la vostra autorització, que cal donar per a cada missatge.

Quan un agent sol·licita un enviament, Inbox Classic mostra el missatge amb l’adreça de cada destinatari. Les adreces a les quals no heu escrit mai es marquen com a .

  1. Comproveu els destinataris i llegiu el text.
  2. Trieu una opció:
    • posa el missatge a la Safata de sortida. El botó s’activa després d’un breu interval per evitar que el premeu per accident.
    • obre una finestra de redacció perquè editeu el missatge.
    • , l’opció predeterminada, no l’envia.

Un agent pregunta per un sol missatge alhora. Els missatges i esborranys que escriu acaben amb la vostra signatura, com els vostres.

Un missatge del qual aproveu l’enviament espera 30 segons a la Safata de sortida. Abans que s’enviï, el podeu suprimir allà o fer clic a a > .

Un agent que també té altres eines, com ara navegar per internet o llegir els vostres fitxers, podria transmetre a través d’elles el que llegeix. Inbox Classic no controla aquestes altres eines. Autoritzeu l’enviament de correu només quan sigui necessari.
