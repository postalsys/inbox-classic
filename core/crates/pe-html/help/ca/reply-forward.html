  • () reenvia el missatge. Podeu triar a quins destinataris el voleu enviar.

Les respostes i els reenviaments fan servir el compte que va rebre el missatge original. Si es va enviar a una de les altres adreces d’enviament del compte, aquesta adreça es fa servir com a remitent.

El missatge original

En una resposta, el missatge original queda plegat sota un botó ••• sota el vostre text, de manera que només veieu el que escriviu. Encara que estigui plegat, s’inclou a la resposta enviada. Per escurçar-lo, feu clic al botó, o seleccioneu-ho tot amb Ctrl+A⌘A: el text original queda visible i el podeu editar.

En un reenviament, l’original és al text des del principi, perquè és el que envieu.

Una resposta segueix el format de l’original. Una resposta a un missatge de text sense format és text sense format, amb l’original citat amb >, tret que apliqueu format a la resposta.
