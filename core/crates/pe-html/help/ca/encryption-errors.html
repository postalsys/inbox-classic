Errors de xifratge

Què heu de fer quan un servidor no ofereix xifratge, o l’exigeix quan el compte el té desactivat.

«the server does not offer STARTTLS»

El compte està configurat amb STARTTLS, però el servidor no ha ofert xifratge. Inbox Classic ha interromput la connexió abans d’enviar la contrasenya.

  1. Obriu les propietats del compte a > .
  2. Si el proveïdor ho admet, configureu la seguretat com a SSL/TLS, amb el port 993 per al correu entrant o el 465 per al correu sortint.
  3. Feu clic a .

Si la connexió continua fallant, confirmeu amb el proveïdor quins ports i opcions de xifratge heu de fer servir.

«the server takes the password only over an encrypted connection»

El servidor de sortida està configurat com a . El servidor exigeix xifratge abans d’acceptar la contrasenya; aquesta resposta no confirma si la contrasenya és correcta. Segons les instruccions del proveïdor, canvieu a STARTTLS amb el port 587, o a SSL/TLS amb el port 465.

L’avís sobre una connexió sense xifratge

Quan trieu , Inbox Classic avisa que qualsevol que intercepti el vostre trànsit de xarxa pot llegir la contrasenya i els missatges. Continueu només si la connexió està protegida d’una altra manera. Una xarxa local no garanteix el xifratge.
