Errors de xifratge

Què heu de fer quan un servidor no ofereix xifratge, o el demana on està desactivat.

«the server does not offer STARTTLS»

El compte està configurat amb STARTTLS, però el servidor no ha ofert xifratge. Inbox Classic s’ha aturat, de manera que no s’ha enviat la vostra contrasenya.

  1. Obriu les propietats del compte a > .
  2. Configureu la seguretat com a SSL/TLS, amb el port 993 per al correu entrant o el 465 per al correu sortint.
  3. Feu clic a .

Si no funciona res més, el servidor no es pot fer servir amb seguretat.

«the server takes the password only over an encrypted connection»

El servidor de sortida està configurat com a . La vostra contrasenya és correcta. Canvieu a STARTTLS amb el port 587, o a SSL/TLS amb el port 465.

L’avís sobre una connexió sense xifratge

Quan trieu , Inbox Classic avisa que qualsevol que intercepti el vostre trànsit de xarxa pot llegir la contrasenya i els missatges. Continueu només amb un servidor del vostre propi ordinador o de la vostra xarxa local.
