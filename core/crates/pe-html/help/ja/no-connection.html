Inbox Classicが接続できない

メール サーバーに接続できないとき、またはサーバーが応答しないときの対処方法。

ステータス バーまたは閲覧ウィンドウに、次のいずれかが表示されることがあります。

  • 「connection error: …」
  • 「the server did not answer in time」
  • 「サーバーへの接続に失敗しました（…）」
  • 「メール サーバーに接続できなかったか、接続が中断されました（…）。」

解決するには、次のようにします。

  1. インターネット接続を確認します。
  2. > でアカウントのプロパティを開き、サーバー名とポートを確認します。
  3. 送信に失敗する場合は、送信サーバーのセキュリティとポートを確認します。一般的には、ポート465のSSL/TLSか、ポート587のSTARTTLSです。ネットワークによってはメール用のポート、特にポート25がブロックされています。

Inbox Classicは、次回のメールの確認時に再試行します。接続に2回続けて失敗すると、フォルダー一覧のアカウントの横とメッセージ一覧の上に接続の警告が表示されます。今すぐ試すには、警告アイコン、バーの、またはをクリックします。アカウントが再接続すると警告は消えます。

接続がないときに送信したメッセージは、ローカルの送信トレイに残ります。Inbox Classicは接続できるようになると再試行しますが、サーバーがメッセージを拒否することもあります。
