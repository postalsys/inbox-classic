メッセージを作成する

書式、リンク、画像を使って新しいメッセージを作成し、送信します。

メッセージを作成するには、次のようにします。

  1. をクリックするか、を押します。新しいメッセージが専用のウィンドウで開きます。
  2. にアドレスを入力します。複数の場合はコンマで区切ります。入力中に、一致する連絡先、アドレス、グループが候補として表示されます。EnterReturnキーかTabキーで候補を確定します。グループを選ぶと、そのメンバーが追加されます。
  3. を入力し、本文を書きます。
  4. をクリックするか、Ctrl+Enterキーを押しますか、⌘Returnキーを押します。

CCやBCCを追加するには、宛先の行の末尾にあるまたはをクリックします。BCCの受信者にもメッセージは届きますが、ほかの受信者にはBCCの受信者が見えません。

欄には、メッセージの送信に使うアカウントが表示されます。アカウントが複数ある場合は、ここで別のアカウントを選択できます。その場合、メッセージはそのアカウントから送信され、そのアカウントのに保存されます。特定のアカウントから書き始めるには、の横の矢印を使います。

件名や本文に「attached」など添付ファイルを示す語句があるのにファイルが添付されていない場合は、Inbox Classicが送信前に確認します。認識されるのは、英語、ドイツ語、エストニア語、スペイン語、フランス語の特定の語句です。

メッセージにデジタル署名したり暗号化したりするには、ツールバーのまたはをクリックします。を参照してください。

書式

本文の上のバーには、フォント、太字、斜体、下線、色、箇条書き、インデント、配置、リンク、区切り線、画像があります。本文に画像を入れるには、をクリックするか、エクスプローラーFinderファイル マネージャーから画像ファイルを本文にドラッグします。

書式のないメッセージはプレーン テキストで送信され、HTMLの書式がなくてもメール プログラムで読めます。書式付きのメッセージは、プレーン テキストのコピーを付けてHTMLで送信されます。

リンク

選択した文字列にリンクを付けるには、をクリックしてアドレスを入力します。ステータス バーには、ポインターの下にあるリンク、または文字カーソルの位置にあるリンクのリンク先が表示されます。WebリンクをCtrl+クリック⌘+クリックすると、ブラウザーで開きます。メールのリンクでは新しいメッセージが開きます。リンクを右クリックすると、、、が表示されます。

スペルの誤りがある語には下線が引かれます。右クリックすると候補が表示されます。
