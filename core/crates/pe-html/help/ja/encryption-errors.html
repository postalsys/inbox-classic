暗号化のエラー

サーバーが暗号化を提供しないとき、または暗号化がオフなのにサーバーが暗号化を求めるときの対処方法。

「the server does not offer STARTTLS」

アカウントはSTARTTLSに設定されていますが、サーバーが暗号化を提供しませんでした。Inbox Classicは、パスワードを送信する前にこの接続の試みを中止しました。

  1. > でアカウントのプロパティを開きます。
  2. プロバイダーの設定を確認します。対応していれば、受信メールにはポート993、送信メールにはポート465でSSL/TLSを使います。
  3. をクリックします。

どの方法でもうまくいかない場合、そのサーバーは安全に使えません。

「the server takes the password only over an encrypted connection」

送信サーバーがに設定されています。このエラーは、パスワードが正しいことを示すものではありません。プロバイダーの設定に従って、をポート587のSTARTTLS、またはポート465のSSL/TLSに変更してください。

暗号化なしの接続についての警告

を選択すると、ネットワークの通信を傍受した人にパスワードやメッセージを読まれるおそれがあるとInbox Classicが警告します。ローカル ネットワークであっても、通信そのものは暗号化されません。接続が別の方法で保護されている場合にのみ続行してください。
