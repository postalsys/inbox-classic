Inbox Classic nevar izveidot savienojumu

Kā rīkoties, ja pasta serveris nav sasniedzams vai neatbild.

Statusa joslā vai lasīšanas rūtī var būt redzams kāds no šiem paziņojumiem:

  • „connection error: …”
  • „the server did not answer in time”
  • „savienojums ar serveri neizdevās (…)”
  • „Neizdevās sazināties ar pasta serveri (…).”

Lai to novērstu:

  1. Pārbaudiet interneta savienojumu.
  2. Atveriet konta rekvizītus sadaļā > un pārbaudiet serveru nosaukumus un portus.
  3. Ja sūtīšana neizdodas, pārbaudiet pakalpojuma sniedzēja ieteikto portu un šifrēšanas veidu. Bieži izmanto portu 465 ar SSL/TLS vai 587 ar STARTTLS. Daži tīkli bloķē pasta portus, it īpaši portu 25.

Inbox Classic mēģina vēlreiz nākamajā pasta pārbaudē. Lai mēģinātu tūlīt, noklikšķiniet uz .

Ja sūtīšanas brīdī nav savienojuma, ziņojums paliek izsūtnē. Inbox Classic vēlāk mēģina to nosūtīt atkārtoti; iespējams, būs jānovērš arī pierakstīšanās vai cita servera kļūda.
