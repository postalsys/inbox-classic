Definir o Inbox Classic como aplicativo de e-mail padrão

Use o Inbox Classic para abrir links de e-mail e arquivos de mensagens a partir de páginas da Web e outros programas.

Os links de e-mail (mailto:) abrem uma mensagem nova no seu aplicativo de e-mail padrão.

Para definir o Inbox Classic como padrão, escolha > . O Windows abre as configurações de Aplicativos padrão, onde você escolhe o Inbox Classic para os links MAILTO. O Inbox Classic só aparece nessa lista se estiver instalado. O Inbox Classic solicita ao sistema que o defina como aplicativo de e-mail padrão. O resultado depende das configurações e permissões do sistema.

Quando você clicar em um link de e-mail depois disso, uma mensagem nova será aberta com os endereços, o assunto e o texto do link já preenchidos. Outros parâmetros do link são ignorados.

Se você ainda não tiver nenhuma conta, o Inbox Classic pede que você adicione uma primeiro. Depois de adicioná-la, clique no link de novo.

Arquivos de mensagens

Para abrir os arquivos .eml no Inbox Classic quando você clica duas vezes neles, clique em em . O Windows abre as configurações de Aplicativos padrão, onde você escolhe o Inbox Classic para os arquivos .eml. Cancelar a janela de configurações do Inbox Classic não desfaz alterações já feitas no Windows. O Inbox Classic solicita ao sistema que o defina como aplicativo padrão para esses arquivos.
