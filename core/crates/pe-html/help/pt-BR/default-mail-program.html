Tornar o Inbox Classic seu aplicativo de e-mail

Abra no Inbox Classic os links de e-mail e os arquivos de mensagens de páginas da Web e de outros programas.

Os links de e-mail (mailto:) abrem uma mensagem nova no seu aplicativo de e-mail padrão.

Para tornar o Inbox Classic esse aplicativo, escolha > . O Windows abre as configurações de Aplicativos padrão, onde você escolhe o Inbox Classic para os links MAILTO. Só uma cópia instalada aparece ali. O Inbox Classic passa a ser na hora o aplicativo de e-mail padrão.

Quando você clicar em um link de e-mail depois disso, uma mensagem nova será aberta com os endereços, o assunto e o texto do link já preenchidos. Nada mais do link é usado.

Se você ainda não tiver nenhuma conta, o Inbox Classic pede que você adicione uma primeiro. Depois de adicioná-la, clique no link de novo.

Arquivos de mensagens

Para abrir os arquivos .eml no Inbox Classic quando você clica duas vezes neles, clique em em > Inbox Classic > > . O Windows abre as configurações de Aplicativos padrão, onde você escolhe o Inbox Classic para os arquivos .eml. O Inbox Classic passa a ser na hora o aplicativo desses arquivos.
