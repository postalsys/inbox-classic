Atualizar o Inbox Classic

Obtenha a versão mais recente do Inbox Classic.

Para ver qual versão você tem, escolha > Inbox Classic > .

Baixe o instalador mais recente em inboxclassic.com e execute-o. Ele atualiza a instalação existente. Suas contas e os e-mails baixados para elas são mantidos.

Se esta versão oferecer suporte a atualizações e a verificação automática estiver ativada, o Inbox Classic procura novas versões. Siga as instruções do atualizador para instalá-las. Para procurar agora, escolha Inbox Classic > .

Se você instalou o Inbox Classic pelo repositório apt dele, as novas versões chegam com as atualizações do próprio sistema. Se instalou um arquivo .deb, baixe o mais recente em inboxclassic.com e instale-o para atualizar a versão existente.

No Fedora, o pacote adiciona o repositório do Inbox Classic ao ser instalado, então as novas versões chegam com sudo dnf upgrade e com as atualizações do próprio sistema.

No Arch Linux, instale o pacote mais recente com sudo pacman -U da mesma forma. No Omarchy, use a função Update para obter a nova versão.

Suas contas, seus e-mails e suas configurações são mantidos entre atualizações.
