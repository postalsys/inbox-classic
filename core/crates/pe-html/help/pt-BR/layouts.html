Layouts

Escolha o layout clássico, com a lista de mensagens acima do painel de leitura, ou o layout em colunas para uma tela larga.

O Inbox Classic tem dois layouts:

  • : a lista de pastas à esquerda, a lista de mensagens no alto à direita e o painel de leitura abaixo dela.
  • : a lista de pastas, a lista de mensagens e o painel de leitura lado a lado. Cada mensagem ocupa três linhas: remetente e data, assunto e uma prévia do texto, sem as mensagens anteriores citadas na resposta.

Com , o layout acompanha a largura da janela: uma janela larga mostra o layout em colunas, e uma mais estreita, o layout clássico. Por padrão, o layout é automático.

Ordenar as mensagens

Escolha > e o critério de ordenação. Depois, escolha a ordem crescente ou decrescente. No layout em colunas, o botão acima das mensagens indica por qual critério elas estão ordenadas; clique nele para acessar as mesmas opções. No layout clássico, você também pode clicar no cabeçalho de uma coluna.

A prévia aparece quando o texto da mensagem já foi baixado. O Inbox Classic baixa o texto dos e-mails antigos em segundo plano.
