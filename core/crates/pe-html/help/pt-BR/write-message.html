Formatação

A barra acima do texto permite escolher a fonte e aplicar negrito, itálico, sublinhado, cores, listas, recuos e alinhamento, além de inserir links, linhas divisórias e imagens. Para colocar uma imagem no texto, clique em ou arraste um arquivo de imagem do Explorador de Arquivosdo Finderdo gerenciador de arquivos para o texto.

Uma mensagem sem formatação é enviada como texto simples, compatível com todos os programas de e-mail. Uma mensagem formatada é enviada como HTML com uma cópia em texto simples.
