Links, scripts e anexos

Como o Inbox Classic impede que uma mensagem execute código ou abra páginas sozinha.

  • Os scripts e outros conteúdos ativos das mensagens são removidos antes da exibição. Isso se refere ao código enviado pelo remetente; a interface usa código próprio para exibir e operar o painel de leitura.
  • Os links de páginas da Web abrem no navegador. Links de e-mail abrem uma janela de composição no aplicativo de e-mail configurado. Uma mensagem não pode abrir uma página ou uma janela sozinha.
  • Os anexos são salvos em uma pasta temporária antes de serem abertos no aplicativo padrão do sistema. O Inbox Classic bloqueia a abertura direta de tipos de arquivo conhecidos por poderem executar programas. Isso não garante que todos os outros arquivos sejam seguros. Os nomes dos arquivos são ajustados para remover caracteres perigosos ou enganosos.
  • Cancelar inscrição pede confirmação e explica a ação que será realizada.
Antes de digitar uma senha em uma página que você abriu a partir de uma mensagem, verifique o endereço no navegador. Uma mensagem pode mostrar um endereço e levar a outro.

Quando você escreve uma mensagem, a barra de status mostra o endereço do link em que está o cursor, para você poder verificá-lo antes de enviar.

Um código de login só é oferecido quando seu provedor de e-mail confirma a autenticação do domínio do remetente. Consulte .

O Inbox Classic processa as imagens antes de exibi-las e não usa fontes fornecidas pela mensagem. As imagens resultantes ainda são exibidas pelo componente de visualização do sistema.
