Links, scripts e anexos

Como o Inbox Classic impede que uma mensagem execute código ou abra páginas sozinha.

  • Os scripts das mensagens nunca são executados. O Inbox Classic limpa cada mensagem antes de mostrá-la, e o painel de leitura não pode executar código.
  • Os links abrem no seu navegador, nunca dentro do Inbox Classic. Uma mensagem não pode abrir uma página ou uma janela sozinha.
  • Os anexos são salvos em uma pasta temporária antes de serem abertos no aplicativo padrão do sistema. Tipos de arquivo capazes de executar programas não podem ser abertos diretamente pelo Inbox Classic. Os nomes dos arquivos são ajustados para remover caracteres perigosos ou enganosos.
  • Cancelar inscrição pede confirmação e explica a ação que será realizada.
Antes de digitar uma senha em uma página que você abriu a partir de uma mensagem, verifique o endereço no navegador. Uma mensagem pode mostrar um endereço e levar a outro.

Quando você escreve uma mensagem, a barra de status mostra o endereço do link em que está o cursor, para você poder verificá-lo antes de enviar.

As imagens e as fontes de uma mensagem nunca chegam aos decodificadores do sistema.
