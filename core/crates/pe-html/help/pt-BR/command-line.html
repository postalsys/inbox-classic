Opções da linha de comando

Opções para iniciar o Inbox Classic a partir de um terminal, para testes e para agentes de IA.

Inicie o programa InboxClassic.exe"Inbox Classic.app/Contents/MacOS/Inbox Classic"inbox-classic com estas opções:

OpçãoFunção
--store <file>Usa outro armazenamento de e-mails, como um para testes
--memory-passwordsMantém as senhas apenas durante esta execução, nunca no armazenamento de senhas do sistema
--pin-certificate <file>Aceita apenas o certificado de servidor deste arquivo (PEM ou DER), para um servidor de teste com um certificado autoassinado
--sign-in-page-file <file>Grava a página de um login no navegador neste arquivo em vez de abrir o navegador
--language <code>Mostra as janelas neste idioma durante esta execução, como de
--backgroundInicia sem a janela
--mcpConecta um agente de IA ao Inbox Classic. Quem inicia isso é o programa do agente, não você
--versionMostra a versão e sai

Um link mailto: passado como argumento abre uma nova mensagem, assim como um link de e-mail.
