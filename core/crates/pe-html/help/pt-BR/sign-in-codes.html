Códigos de login

Uma mensagem com um código de login ou de verificação mostra o código em um cartão com a opção de copiá-lo.

Quando o Inbox Classic reconhece um código compatível de login, verificação ou aprovação, um cartão acima da mensagem mostra:

  • “Código de” e o domínio para o qual o código foi emitido
  • o código, em tamanho de texto maior
  • , que coloca o código na área de transferência
Digite um código apenas em uma página do domínio indicado no cartão. Uma mensagem que pede para você digitar um código em outro lugar pode ser uma tentativa de roubar sua conta.

O cartão só aparece quando seu provedor de e-mail confirma uma assinatura digital válida para o domínio do código ou seu domínio pai. Mensagens sem essa autenticação não oferecem o código no cartão. A autenticação do domínio não garante a identidade de uma pessoa nem a segurança de todo o conteúdo. Não há cartão em , ou , nem quando o provedor não informa o resultado dessa autenticação.

Se a data da mensagem for de mais de uma hora atrás, o cartão avisa que o código pode ter expirado. O Inbox Classic não consulta a validade com o serviço que emitiu o código.

Códigos nas notificações

Para ver o código na notificação de uma mensagem nova, ative em . A opção vem desativada, porque uma notificação pode ser lida com a tela bloqueada. Ela só vale para mensagens pequenas e recentes, com conteúdo baixado a tempo e um código reconhecido, quando as condições normais de notificação são atendidas.
