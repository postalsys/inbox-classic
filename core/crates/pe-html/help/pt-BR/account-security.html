Configurações de segurança da conta

As configurações de segurança dos servidores de uma conta, e o que cada uma significa.

Cada conta tem para o servidor de recepção e para o de envio. O Inbox Classic as preenche quando encontra as configurações do seu provedor. Para alterá-las, abra as propriedades da conta em > .

ConfiguraçãoSignificado
SSL/TLSA conexão é criptografada desde o início. Normalmente a porta 993 para os e-mails recebidos e 465 para os enviados.
STARTTLSA conexão é criptografada logo depois de ser aberta. Normalmente a porta 143 para os e-mails recebidos e 587 para os enviados. O Inbox Classic para se o servidor não oferecer criptografia.
Sua senha e seus e-mails circulam de forma legível para qualquer pessoa na rede.
Use apenas para um servidor no seu próprio computador ou na sua rede local. O Inbox Classic avisa você antes de usá-la.

O Inbox Classic verifica se cada servidor é quem diz ser, com base nos certificados em que o seu sistema confia. Não existe nenhuma opção para aceitar qualquer certificado.
