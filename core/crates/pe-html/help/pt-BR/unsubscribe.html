Sair de uma lista de e-mails

Pare de receber as mensagens de uma lista de e-mails com o botão Cancelar inscrição.

Se uma mensagem inclui instruções para sair da lista de e-mails, ela mostra o botão à direita do cabeçalho.

Para sair da lista:

  1. Clique em . O Inbox Classic explica o que será feito e pede confirmação.
  2. Confirme. Dependendo da lista, acontece uma de três coisas:
    • O Inbox Classic envia uma solicitação direta de cancelamento. Nenhuma página é aberta e nenhum e-mail é enviado.
    • O Inbox Classic prepara o e-mail exigido pela lista para cancelar a inscrição. Clique em para enviá-la.
    • A página da lista abre no seu navegador, onde você conclui o cancelamento.

A barra de status indica quando a lista aceitou o pedido.

O Inbox Classic só envia a solicitação direta de cancelamento quando a lista assinou a mensagem com DKIM. Isso ajuda a impedir que mensagens falsificadas usem esse recurso para enviar solicitações indevidas.
