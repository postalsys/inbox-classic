Sair de uma lista de e-mails

Pare de receber as mensagens de uma lista de e-mails com o botão Cancelar inscrição.

Uma mensagem de uma lista de e-mails que indica como sair dela tem à direita do cabeçalho.

Para sair da lista:

  1. Clique em . O Inbox Classic diz o que vai acontecer e pergunta primeiro.
  2. Confirme. Dependendo da lista, acontece uma de três coisas:
    • O Inbox Classic pede à lista que pare. Nenhuma página abre e nenhuma mensagem é enviada.
    • O Inbox Classic escreve a mensagem que a lista pede. Clique em para enviá-la.
    • A página da lista abre no seu navegador, onde você termina o processo.

A barra de status indica quando a lista aceitou o pedido.

O Inbox Classic só pede à lista que pare por conta própria quando o servidor da lista assinou a mensagem. Uma mensagem falsa não pode usar isso para atingir outra pessoa.
