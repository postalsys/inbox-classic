Chyby šifrovania

Čo robiť, keď server neponúka šifrovanie alebo ho vyžaduje tam, kde je vypnuté.

„the server does not offer STARTTLS“

Konto je nastavené na STARTTLS, ale server šifrovanie neponúkol. Inbox Classic sa zastavil, takže vaše heslo nebolo odoslané.

  1. Otvorte vlastnosti konta v ponuke > .
  2. Nastavte zabezpečenie na SSL/TLS s portom 993 pre prichádzajúcu poštu alebo 465 pre odchádzajúcu poštu.
  3. Kliknite na .

Ak nič iné nepomôže, server nemožno bezpečne používať.

„the server takes the password only over an encrypted connection“

Server odchádzajúcej pošty je nastavený na . Vaše heslo je v poriadku. Zmeňte na STARTTLS s portom 587 alebo na SSL/TLS s portom 465.

Upozornenie na pripojenie bez šifrovania

Keď vyberiete , Inbox Classic upozorní, že ktokoľvek, kto zachytí vašu sieťovú komunikáciu, môže prečítať vaše heslo a správy. Pokračujte iba pri serveri vo vlastnom počítači alebo v lokálnej sieti.
