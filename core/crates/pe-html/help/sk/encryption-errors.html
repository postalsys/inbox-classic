Chyby zabezpečeného pripojenia

Čo robiť, keď server neponúka šifrovanie alebo ho vyžaduje tam, kde je vypnuté.

„the server does not offer STARTTLS“

Konto je nastavené na STARTTLS, ale server šifrovanie neponúkol. Inbox Classic ukončil tento pokus o pripojenie pred prihlásením, takže pri ňom heslo neodoslal.

  1. Otvorte vlastnosti konta v ponuke > .
  2. Podľa pokynov poskytovateľa nastavte podporovaný spôsob zabezpečenia a port. SSL/TLS bežne používa port 993 pre prichádzajúcu a 465 pre odchádzajúcu poštu.
  3. Kliknite na .

Ak server šifrované pripojenie nepodporuje, obráťte sa na poskytovateľa; samotné vypnutie šifrovania problém so zabezpečením nevyrieši.

„the server takes the password only over an encrypted connection“

Server odchádzajúcej pošty je nastavený na . Toto hlásenie nepotvrdzuje správnosť hesla. Podľa pokynov poskytovateľa zmeňte na STARTTLS s portom 587 alebo na SSL/TLS s portom 465.

Upozornenie na pripojenie bez šifrovania

Keď vyberiete , Inbox Classic upozorní, že ktokoľvek, kto zachytí vašu sieťovú komunikáciu, môže prečítať vaše heslo a správy. Pokračujte len vtedy, ak je ochrana spojenia zabezpečená inak. Samotná lokálna sieť šifrovanie nezaručuje.
