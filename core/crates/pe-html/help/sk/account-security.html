Nastavenia zabezpečenia konta

Nastavenia zabezpečenia serverov konta a čo každé z nich znamená.

Každé konto má pre server prichádzajúcej pošty a pre server odchádzajúcej pošty. Inbox Classic ich vyplní, keď nájde nastavenia vášho poskytovateľa. Ak ich chcete zmeniť, otvorte vlastnosti konta v ponuke > .

NastavenieVýznam
SSL/TLSPripojenie je šifrované od začiatku. Zvyčajne port 993 pre prichádzajúcu poštu a 465 pre odchádzajúcu poštu.
STARTTLSPripojenie sa zašifruje hneď po otvorení. Zvyčajne port 143 pre prichádzajúcu poštu a 587 pre odchádzajúcu poštu. Ak server šifrovanie neponúkne, Inbox Classic sa zastaví.
Vaše heslo a pošta putujú sieťou tak, že ich môže prečítať ktokoľvek.
Možnosť používajte iba pre server vo vlastnom počítači alebo v lokálnej sieti. Inbox Classic vás pred jej použitím upozorní.

Inbox Classic overuje, či je každý server tým, za ktorý sa vydáva, podľa certifikátov, ktorým váš systém dôveruje. Neexistuje prepínač, ktorý by prijal akýkoľvek certifikát.

Vaše heslo sa uchováva v Správcovi poverení systému Windowsvašej prihlasovacej kľúčenkevašej kľúčenke, nikdy nie v úložisku pošty. Konto, ktoré sa prihlasuje cez prehliadač, nemá uložené vôbec žiadne heslo.
