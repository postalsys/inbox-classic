Łączenie agenta AI

Pozwól agentowi AI, takiemu jak Claude, czytać i porządkować Twoją pocztę przez Inbox Classic.

Możesz pozwolić agentowi AI pracować z Twoją pocztą. Może to być Claude, Cursor lub inny program obsługujący Model Context Protocol (MCP). Inbox Classic nie ma wbudowanej AI. Nic nie jest wysyłane do usługi AI, dopóki nie udzielisz agentowi dostępu.

Aby połączyć agenta:

  1. Wybierz > i kliknij . Inbox Classic pokaże konfigurację, którą trzeba dodać do ustawień agenta.
  2. Dodaj ją do ustawień serwerów MCP agenta. W Claude Desktop jest to Settings > Developer > Edit Config.
  3. Uruchom agenta. Przy pierwszym połączeniu Inbox Classic zapyta Cię, co agent może robić.

Agent uruchamia Inbox Classic w tle, jeśli program nie działa. Dostęp do niego mają tylko programy uruchomione na tym komputerze z Twojego konta.

Inbox Classic sprawdza w systemie, który program uruchomił agenta. Agent nie uzyska dostępu przyznanego innemu programowi, podając jedynie jego nazwę. Jeśli podana nazwa się nie zgadza, zobaczysz to w pytaniu o zgodę. Pozwala to rozdzielić uprawnienia agentów, ale nie chroni przed złośliwym programem uruchomionym z Twojego konta, który i tak mógłby odczytać pocztę.

Agent może też obserwować Skrzynkę odbiorczą, konto lub folder i otrzymywać powiadomienia o zmianach w poczcie, a także zaproponować dwa gotowe polecenia, „Triage my inbox” i „Summarize unread”. Oba działają w granicach przyznanych uprawnień. Odczytane w ten sposób wiadomości są odnotowywane w dzienniku, tak jak pozostałe odczyty agenta.

Agenci uruchamiani przez ten sam rozpoznany program terminala, na przykład Claude Code, domyślnie współdzielą jego uprawnienia. Inbox Classic pyta raz o programy uruchomione z aplikacji Terminalprogramy uruchomione z terminala, a programy uruchomione przez ten sam terminal korzystają ze wspólnych uprawnień. Inny program terminala może mieć osobny zestaw uprawnień. Aby dać agentowi osobny dostęp, dodaj --name i wybraną przez siebie nazwę po --mcp w jego ustawieniach, na przykład "args": ["--mcp", "--name", "Claude Code"]. Inbox Classic zapyta wtedy o niego pod tą nazwą. Nazwa służy do rozdzielenia dostępu, a nie do potwierdzenia tożsamości programu.

Aby zablokować dostęp wszystkim agentom, wyłącz opcję w oknie > .
