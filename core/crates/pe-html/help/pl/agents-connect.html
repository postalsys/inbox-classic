Łączenie agenta AI

Pozwól agentowi AI, takiemu jak Claude, czytać i porządkować Twoją pocztę przez Inbox Classic.

Możesz pozwolić agentowi AI pracować z Twoją pocztą. Może to być Claude, Cursor lub inny program obsługujący Model Context Protocol (MCP). W Inbox Classic nie ma AI i nic nie jest wysyłane do usługi AI, dopóki nie wpuścisz agenta.

Aby połączyć agenta:

  1. Wybierz > i kliknij . Inbox Classic pokaże wiersze, które trzeba dodać do ustawień agenta.
  2. Dodaj je do serwerów MCP agenta. W Claude Desktop jest to Settings > Developer > Edit Config.
  3. Uruchom agenta. Przy pierwszym połączeniu Inbox Classic zapyta Cię, co agent może robić.

Agent uruchamia Inbox Classic w tle, jeśli program nie działa. Dostęp do niego mają tylko programy uruchomione na tym komputerze z Twojego konta.

Inbox Classic pyta system, który program uruchomił agenta, zamiast wierzyć agentowi na słowo, dzięki czemu jeden program nie może korzystać z dostępu przyznanego innemu. Jeśli agent podaje się za inny program, pytanie o zgodę to pokaże.

Agent może też obserwować Skrzynkę odbiorczą, konto lub folder i dostawać powiadomienie, gdy zmieni się w nich poczta, a także zaproponować dwa gotowe polecenia, „Triage my inbox” i „Summarize unread”. Oba przestrzegają tego, na co zezwolisz agentowi, a to, co agent w ten sposób odczyta, widać w jego dzienniku tak jak wszystko inne, co odczytuje.

Agenci uruchamiani z terminala, na przykład Claude Code, są dla Inbox Classic jednym programem. Inbox Classic pyta raz o programy uruchomione z aplikacji Terminalprogramy uruchomione z terminala, a wszystkie one współdzielą to, na co zezwolisz. Aby dać agentowi osobny dostęp, dodaj --name i wybraną przez siebie nazwę po --mcp w jego ustawieniach, na przykład "args": ["--mcp", "--name", "Claude Code"]. Inbox Classic zapyta wtedy o niego pod tą nazwą.

Aby zablokować dostęp wszystkim agentom, wyłącz opcję w oknie > .
