Łączenie agenta AI

Pozwól agentowi AI, takiemu jak Claude, czytać i porządkować Twoją pocztę przez Inbox Classic.

Możesz pozwolić agentowi AI pracować z Twoją pocztą. Może to być Claude, Cursor lub inny program obsługujący Model Context Protocol (MCP). W Inbox Classic nie ma AI i nic nie jest wysyłane do usługi AI, dopóki nie wpuścisz agenta.

Aby połączyć agenta:

  1. Wybierz > i kliknij . Inbox Classic pokaże wiersze, które trzeba dodać do ustawień agenta.
  2. Dodaj je do serwerów MCP agenta. W Claude Desktop jest to Settings > Developer > Edit Config.
  3. Uruchom agenta. Przy pierwszym połączeniu Inbox Classic zapyta Cię, co agent może robić.

Agent uruchamia Inbox Classic w tle, jeśli program nie działa. Dostęp do niego mają tylko programy uruchomione na tym komputerze z Twojego konta.

Aby zablokować dostęp wszystkim agentom, wyłącz opcję w oknie > .
