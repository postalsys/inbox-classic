Co może robić agent

Wybierz, co każdy agent AI może robić z Twoją pocztą, oraz przeglądaj i cofaj jego działania.

Gdy agent programu łączy się po raz pierwszy, Inbox Classic pyta Cię o zgodę, podając nazwę programu. Wybierz, co agent może robić:

  • czytanie poczty: foldery, lista wiadomości, wyszukiwanie i wiadomości
  • porządkowanie poczty: stan przeczytania, flagi, śmieci, przenoszenie i usuwanie do folderu
  • pisanie wersji roboczych do wysłania przez Ciebie
  • wysyłanie poczty, każdej wiadomości dopiero po Twojej zgodzie

Potem wybierz konta, które agent może widzieć, i kliknij . odrzuca program i Inbox Classic nie pyta już o niego.

Agent nigdy niczego nie usuwa trwale i nigdy nie zmienia ustawień kont. Przeczytanie wiadomości przez agenta nie oznacza jej jako przeczytanej. To, co zmieni, od razu widać w oknach.

Przeglądanie i zmiana dostępu

> wymienia programy, które wpuszczono lub odrzucono, oraz wszystko, co zrobili agenci, od najnowszych działań.

  • zmienia, co program może robić.
  • zapomina program, więc przy następnym połączeniu Inbox Classic znów zapyta o zgodę.
  • cofa zmianę stanu przeczytania, flagę, przeniesienie lub usunięcie oraz wiadomość, która jest jeszcze w Skrzynce nadawczej.
Pocztę piszą inni ludzie, a wiadomość może próbować namówić agenta do przesłania dalej lub usunięcia Twojej poczty. Inbox Classic ukrywa przed agentami tekst, który wiadomość ukrywa przed Tobą, i mówi im, że poczta nie jest poleceniami. Agenta wciąż można oszukać. Zezwalaj tylko na to, czego potrzebujesz.
