Inbox Classic jako domyślny program pocztowy

Otwieraj w Inbox Classic linki e-mail i pliki wiadomości ze stron internetowych i innych programów.

Linki e-mail (mailto:) otwierają nową wiadomość w domyślnym programie pocztowym.

Aby był nim Inbox Classic, wybierz > . System Windows otworzy ustawienia Aplikacje domyślne, w których wybierzesz Inbox Classic dla linków MAILTO. Program pojawi się na tej liście tylko po zainstalowaniu. Inbox Classic próbuje ustawić się jako domyślny program pocztowy i informuje, jeśli się to nie uda.

Gdy potem klikniesz link e-mail, otworzy się nowa wiadomość z wypełnionymi adresami, tematem i tekstem z linku. Nic więcej z linku nie jest używane.

Jeśli nie masz jeszcze konta, Inbox Classic poprosi o dodanie go. Po dodaniu konta kliknij link ponownie.

Pliki wiadomości

Aby pliki .eml otwierały się w Inbox Classic po dwukrotnym kliknięciu, kliknij w . System Windows otworzy ustawienia Aplikacje domyślne, w których wybierzesz Inbox Classic dla plików .eml. Inbox Classic próbuje ustawić się jako domyślna aplikacja do otwierania tych plików i informuje, jeśli się to nie uda.
