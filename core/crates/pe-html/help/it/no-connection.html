Inbox Classic non riesce a connettersi

Cosa fare quando il server di posta non è raggiungibile o non risponde.

Nella barra di stato o nel riquadro di lettura può comparire uno di questi messaggi:

  • “connection error: …”
  • “the server did not answer in time”
  • “la connessione al server non è riuscita (…)”
  • “Impossibile collegarsi al server di posta, oppure la connessione è stata interrotta (…).”

Per risolvere:

  1. Controlla la connessione a internet.
  2. Apri le proprietà dell’account in > e controlla i nomi dei server e le porte.
  3. Se l’invio non riesce, controlla le impostazioni consigliate dal provider per la posta in uscita: in genere la porta 465 con SSL/TLS o la 587 con STARTTLS. Alcune reti bloccano le porte della posta, in particolare la porta 25.

Inbox Classic riprova al successivo controllo della posta. Dopo due errori di connessione consecutivi, compare un avviso accanto all’account nell’elenco delle cartelle e sopra il suo elenco dei messaggi. Per riprovare subito, fai clic sull’icona di avviso, su nella barra o su . L’avviso scompare quando l’account si riconnette.

Un messaggio che invii senza connessione resta nella cartella locale Posta in uscita. Inbox Classic riprova quando riesce a connettersi; il server può comunque rifiutare il messaggio.
