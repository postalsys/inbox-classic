Impostare Inbox Classic come app di posta predefinita

Apri con Inbox Classic i collegamenti di posta delle pagine web e degli altri programmi, oltre ai file di messaggio.

I collegamenti di posta elettronica (mailto:) aprono un nuovo messaggio nell’app di posta predefinita.

Per impostare Inbox Classic come app di posta predefinita, scegli > . Windows apre le impostazioni App predefinite, dove puoi associare Inbox Classic ai collegamenti MAILTO. L’app compare nell’elenco solo se è stata installata. Inbox Classic diventa subito l’app di posta predefinita.

Quando fai clic su un collegamento di posta elettronica, si apre un nuovo messaggio con gli indirizzi, l’oggetto e il testo indicati nel collegamento. Gli altri parametri vengono ignorati.

Se non hai ancora un account, Inbox Classic ti chiede prima di aggiungerne uno. Dopo averlo aggiunto, fai di nuovo clic sul collegamento.

File di messaggio

Per aprire i file .eml in Inbox Classic con un doppio clic, fai clic su in . Windows apre le impostazioni App predefinite, dove scegli Inbox Classic per i file .eml. Inbox Classic viene impostata come app predefinita per i file .eml.
