Rendere Inbox Classic l’app di posta

Apri in Inbox Classic i link di posta elettronica e i file di messaggio delle pagine web e degli altri programmi.

I link di posta elettronica (mailto:) aprono un nuovo messaggio nell’app di posta predefinita.

Per rendere Inbox Classic quell’app, scegli > . Windows apre le impostazioni App predefinite, dove scegli Inbox Classic per i link MAILTO. Lì compare solo una copia installata. Inbox Classic diventa subito l’app di posta predefinita.

Quando poi fai clic su un link di posta elettronica, si apre un nuovo messaggio con gli indirizzi, l’oggetto e il testo del link già compilati. Nient’altro del link viene usato.

Se non hai ancora un account, Inbox Classic ti chiede prima di aggiungerne uno. Dopo averlo aggiunto, fai di nuovo clic sul link.

File di messaggio

Per aprire i file .eml in Inbox Classic con un doppio clic, fai clic su in . Windows apre le impostazioni App predefinite, dove scegli Inbox Classic per i file .eml. Inbox Classic diventa subito la loro app.
