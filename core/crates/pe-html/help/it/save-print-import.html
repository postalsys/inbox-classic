Salvare, stampare e importare messaggi

Salva i messaggi come file, apri e importa file di messaggi, stampa un messaggio e consulta le intestazioni e l’origine.

Salvare i messaggi come file

Scegli > () per salvare il messaggio mostrato come file .eml, leggibile anche dagli altri programmi di posta. Se selezioni più messaggi, Inbox Classic chiede una cartella di destinazione e salva ogni messaggio in un file con l’oggetto come nome. Nel salvataggio di più messaggi vengono scelti nomi liberi, senza sostituire file esistenti. Per un singolo messaggio, la conferma di sovrascrittura dipende dalla finestra di salvataggio del sistema.

Puoi anche trascinare i messaggi dall’elenco sul desktop o in una cartella aperta in Esplora filenel Findernel gestore di file.

Importare file di messaggi

Seleziona una cartella e scegli > , oppure trascina file .eml su una cartella dell’elenco delle cartelle. I messaggi vengono aggiunti alla coda di importazione per la cartella selezionata e successivamente caricati sul server. Un file che non è un messaggio non viene importato.

Aprire file di messaggi

Fai doppio clic su un file .eml in Esplora filenel Findernel gestore di file, oppure fai clic con il pulsante destro e aprilo con Inbox Classic. Il messaggio si apre in una finestra separata con i comandi , , , e . Se lo apre un’altra app, vedi .

Stampare

  1. Scegli > (). Si apre l’interfaccia di stampa prevista dal sistema.
  2. Scegli tra le opzioni disponibili per stampante, copie e pagine; il salvataggio in PDF dipende dal sistema.
  3. Fai clic sul pulsante di stampa. Il messaggio viene stampato con mittente, data, destinatari e oggetto.

Intestazioni e origine

> () mostra le intestazioni Internet del messaggio: chi l’ha inviato, attraverso quali server e quando. > () mostra il messaggio come testo, fino a 4 MiB; il testo oltre questo limite viene omesso. Le intestazioni mostrate nelle proprietà sono limitate a 256 KiB. in quella finestra lo salva come file .eml.
