Salvare, stampare e importare messaggi

Salva i messaggi come file, apri e importa file di messaggi, stampa un messaggio e consulta le intestazioni e l’origine.

Salvare i messaggi come file

Scegli > () per salvare il messaggio mostrato come file .eml, leggibile anche dagli altri programmi di posta. Se selezioni più messaggi, Inbox Classic chiede una cartella di destinazione e salva ogni messaggio in un file con l’oggetto come nome. Un file già presente non viene mai sostituito.

Puoi anche trascinare i messaggi dall’elenco sul desktop o in una cartella aperta in Esplora filenel Findernel gestore di file.

Importare file di messaggi

Seleziona una cartella e scegli > , oppure trascina file .eml su una cartella dell’elenco delle cartelle. I messaggi vengono importati nella cartella selezionata, anche sul server. Un file che non è un messaggio non viene importato.

Aprire file di messaggi

Fai doppio clic su un file .eml in Esplora filenel Findernel gestore di file, oppure fai clic con il pulsante destro e aprilo con Inbox Classic. Il messaggio si apre in una finestra separata con i comandi , , , e . Se lo apre un’altra app, vedi .

Stampare

  1. Scegli > (). Si apre un’anteprima di stampa.
  2. Scegli la stampante, il numero di copie e le pagine, oppure salva come PDF.
  3. Fai clic sul pulsante di stampa. Il messaggio viene stampato con mittente, data, destinatari e oggetto.

Intestazioni e origine

> () mostra le intestazioni Internet del messaggio: chi l’ha inviato, attraverso quali server e quando. > () mostra l’intero messaggio come testo. in quella finestra lo salva come file .eml.
