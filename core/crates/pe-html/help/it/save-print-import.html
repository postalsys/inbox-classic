Salvare, stampare e importare messaggi

Salva i messaggi come file, apri e importa file di messaggi, stampa un messaggio e vedi le intestazioni e l’origine.

Salvare i messaggi come file

Scegli > () per salvare il messaggio mostrato come file .eml, che gli altri programmi di posta sanno aprire. Con più messaggi selezionati, chiede una cartella e vi salva ciascuno con il nome del suo oggetto. Un file già presente non viene mai sostituito.

Puoi anche trascinare i messaggi dall’elenco alla scrivania o a una cartella in Esplora fileFindergestore dei file.

Importare file di messaggi

Seleziona una cartella e scegli > , oppure trascina file .eml su una cartella dell’elenco delle cartelle. I messaggi vengono messi in quella cartella, anche sul server. Un file che non è un messaggio non viene importato.

Aprire file di messaggi

Fai doppio clic su un file .eml in Esplora fileFindergestore dei file, oppure fai clic con il pulsante destro e aprilo con Inbox Classic. Si apre in una finestra del messaggio con , , , e . Se lo apre un’altra app, vedi .

Stampare

  1. Scegli > (). Si apre un’anteprima di stampa.
  2. Scegli la stampante, le copie e le pagine, oppure salva come PDF.
  3. Fai clic sul pulsante di stampa. Il messaggio viene stampato con mittente, data, destinatari e oggetto.

Intestazioni e origine

> () mostra le intestazioni Internet del messaggio: chi l’ha inviato, attraverso quali server e quando. > () mostra l’intero messaggio come testo. in quella finestra lo salva come file .eml.
