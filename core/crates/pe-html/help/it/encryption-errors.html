Errori di crittografia

Cosa fare quando un server non offre la crittografia, o la richiede dove è disattivata.

“the server does not offer STARTTLS”

L’account è impostato su STARTTLS, ma il server non ha offerto la crittografia. Inbox Classic si è fermato, quindi la password non è stata inviata.

  1. Apri le proprietà dell’account in > .
  2. Imposta la sicurezza su SSL/TLS, con la porta 993 per la posta in arrivo o 465 per la posta in uscita.
  3. Fai clic su .

Se non funziona nient’altro, il server non si può usare in modo sicuro.

“the server takes the password only over an encrypted connection”

Il server della posta in uscita è impostato su . La password è corretta. Cambia in STARTTLS con la porta 587, oppure in SSL/TLS con la porta 465.

L’avviso su una connessione senza crittografia

Quando scegli , Inbox Classic avverte che chiunque intercetti il traffico della tua rete può leggere la password e i messaggi. Continua solo per un server sul tuo computer o sulla tua rete locale.
