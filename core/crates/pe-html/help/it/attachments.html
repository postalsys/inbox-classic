Allegati

Apri o salva i file che arrivano con un messaggio e allega file ai messaggi che scrivi.

Aprire un allegato

I file di un messaggio sono elencati sotto la sua intestazione, ognuno con nome e dimensione. Fai doppio clic su un file per aprirlo con il programma che il computer usa per quel tipo di file. Con la tastiera, premi Tab finché non sono selezionati i file, scegline uno con i tasti freccia e premi Enter.

Fai clic destro su un file per , e . Anche la graffetta a destra dell’intestazione elenca i file.

Inbox Classic non apre mai un file che può eseguire programmi: programmi, script, programmi di installazione, collegamenti, immagini disco, pagine web e documenti di Office con macro. Per questi file è disattivato; salva il file e aprilo tu stesso solo se ti fidi della sua provenienza.

Un file viene aperto da una tua cartella che Inbox Classic svuota dopo un giorno, ed è contrassegnato come proveniente da Internet. Il file di un messaggio crittografato vi resta decrittografato finché è aperto; la prima volta, Inbox Classic te lo dice.

Salvare un allegato

Fai clic destro su un file e scegli , oppure scegli per salvarli tutti in una cartella. Inbox Classic propone un nome sicuro, senza caratteri che potrebbero far sembrare un nome qualcos’altro. Un file con lo stesso nome già presente nella cartella viene conservato, e quello nuovo riceve un numero.

Apri gli allegati solo di persone da cui te li aspetti. Un programma, o un documento che ti chiede di “abilitare il contenuto”, può prendere il controllo del computer. Tra i programmi ci sono i file .exe, .msi, .js, .vbs, .bat e .scr..app, .pkg, .dmg e .command..sh, .deb, .AppImage e .desktop.

Allegare un file

Per allegare file al messaggio che scrivi:

  1. Fai clic su .
  2. Scegli i file. Vengono elencati in con le loro dimensioni.

Puoi anche trascinare i file da Esplora fileFinderil gestore di file sui campi degli indirizzi. Un file che non è un’immagine si può trascinare anche sul testo.

Per togliere un file, selezionalo e premi Delete, oppure fai clic destro su di esso e scegli . I file vengono letti quando il messaggio viene inviato, quindi lasciali dove sono fino ad allora.
