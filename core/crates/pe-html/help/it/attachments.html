Allegati

Salva i file che arrivano con un messaggio e allega file ai messaggi che scrivi.

Salvare un allegato

Per salvare i file di un messaggio:

  1. Fai clic sulla graffetta a destra dell’intestazione del messaggio. Indica quanti file ci sono.
  2. Scegli un file per salvarlo, oppure scegli per salvarli tutti in una cartella.

Inbox Classic salva i file, ma non li apre mai. Propone un nome sicuro, senza caratteri che potrebbero far sembrare un nome qualcos’altro. Un file con lo stesso nome già presente nella cartella viene conservato, e quello nuovo riceve un numero.

Apri gli allegati solo di persone da cui te li aspetti. Un programma, o un documento che ti chiede di “abilitare il contenuto”, può prendere il controllo del computer. Tra i programmi ci sono i file .exe, .msi, .js, .vbs, .bat e .scr..app, .pkg, .dmg e .command..sh, .deb, .AppImage e .desktop.

Allegare un file

Per allegare file al messaggio che scrivi:

  1. Fai clic su .
  2. Scegli i file. Vengono elencati in con le loro dimensioni.

Puoi anche trascinare i file da Esplora fileFinderil gestore di file sui campi degli indirizzi. Un file che non è un’immagine si può trascinare anche sul testo.

Per togliere un file, selezionalo e premi Delete, oppure fai clic destro su di esso e scegli . I file vengono letti quando il messaggio viene inviato, quindi lasciali dove sono fino ad allora.
