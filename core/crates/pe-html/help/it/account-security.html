Impostazioni di sicurezza dell’account

Le impostazioni di sicurezza dei server di un account e il significato di ciascuna.

Ogni account ha per il server della posta in arrivo e per quello della posta in uscita. Inbox Classic le compila quando trova le impostazioni del tuo provider. Per cambiarle, apri le proprietà dell’account in > .

ImpostazioneSignificato
SSL/TLSLa connessione è crittografata fin dall’inizio. Di solito si usa la porta 993 per la posta in arrivo e la 465 per quella in uscita.
STARTTLSLa connessione viene crittografata subito dopo l’apertura. Di solito si usa la porta 143 per la posta in arrivo e la 587 per quella in uscita. Inbox Classic interrompe la connessione se il server non offre la crittografia.
La password e la posta viaggiano in chiaro, e possono essere lette da chi intercetta il traffico di rete.
Usa solo per un server sul tuo computer o sulla tua rete locale. Inbox Classic ti avvisa prima di usare una connessione non crittografata.

Inbox Classic verifica che ogni server sia davvero quello che dice di essere, in base ai certificati considerati attendibili dal sistema. Non c’è alcuna opzione per accettare qualsiasi certificato.

La password è conservata in Gestione credenziali di Windowsnel portachiavi di loginnel tuo portachiavi, mai nell’archivio della posta. Per un account che accede tramite il browser, Inbox Classic conserva le credenziali di accesso ricevute dal provider, non la tua password.
