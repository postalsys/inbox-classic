Opzioni della riga di comando

Opzioni per avviare Inbox Classic da un terminale, per i test e per gli agenti IA.

Avvia il programma InboxClassic.exe"Inbox Classic.app/Contents/MacOS/Inbox Classic"inbox-classic con queste opzioni:

OpzioneEffetto
--store <file>Usa un altro archivio della posta, per esempio uno per i test
--memory-passwordsConserva le password solo per questa esecuzione, mai nell’archivio delle password del sistema
--pin-certificate <file>Accetta solo il certificato del server contenuto in questo file (PEM o DER), per un server di prova con un certificato autofirmato
--sign-in-page-file <file>Scrive in questo file la pagina di un accesso tramite browser invece di aprire il browser
--language <code>Mostra le finestre in questa lingua per questa esecuzione, per esempio de
--backgroundSi avvia senza la finestra
--mcpCollega un agente IA a Inbox Classic. Lo avvia il programma dell’agente, non tu
--versionMostra la versione ed esce

Un link mailto: passato come argomento apre un nuovo messaggio, come fa un link di posta elettronica.
