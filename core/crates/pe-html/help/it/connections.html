Le connessioni di Inbox Classic

A quali servizi si connette Inbox Classic e perché: i dettagli tecnici.

  • I tuoi server di posta, tramite IMAP per leggere la posta e SMTP per inviarla. Le connessioni sono crittografate con TLS, e il certificato di ogni server viene verificato con quelli considerati attendibili dal sistema. Inbox Classic rifiuta un server senza crittografia, a meno che tu non scelga e confermi.
  • Quando aggiungi un account, per cercarne i server. Inbox Classic legge i record DNS del tuo dominio tramite DNS over HTTPS (Cloudflare, poi Google), mai con il DNS in chiaro. Prova anche il file autoconfig del provider e l’elenco dei provider di Thunderbird (ISPDB). Per Exchange interroga Microsoft Autodiscover, che riceve la password solo quando la chiede tramite HTTPS. Un server senza crittografia non viene mai scelto.
  • Accesso tramite browser, con OAuth 2.0 e PKCE, verso Google, Microsoft o il provider della tua app di accesso. Il browser completa l’accesso tramite un indirizzo di ritorno locale a questo computer.
  • Loghi dei marchi (BIMI), dall’indirizzo HTTPS del marchio quando il messaggio non contiene il logo e non è possibile riutilizzare una copia salvata. I loghi scaricati vengono salvati e riutilizzati, anche dopo il riavvio dell’app. Il logo viene caricato solo se il server di posta conferma che il messaggio ha superato il controllo DMARC e approva il logo.
  • Immagini da internet, quando ne autorizzi il caricamento, per il singolo messaggio o tramite le impostazioni delle immagini.
  • Annullamento dell’iscrizione, solo quando fai clic. Una richiesta diretta di annullamento (RFC 8058) viene inviata solo se la lista ha firmato il messaggio con DKIM.
  • Le chiavi di crittografia vengono cercate quando manca la chiave di un destinatario per cifrare un messaggio o quando avvii una ricerca. Se cerchi per indirizzo e-mail, Inbox Classic consulta prima il dominio di quell’indirizzo (Web Key Directory). Se necessario, invia l’indirizzo a keys.openpgp.org, purché questa ricerca sia abilitata. Una ricerca per impronta digitale o ID della chiave invia invece quel dato a keys.openpgp.org, anziché l’indirizzo e-mail.
  • Aggiornamenti, da inboxclassic.com, per sapere se è uscita una nuova versione.

I codici di accesso vengono proposti solo quando l’intestazione Authentication-Results del provider dice che il dominio ha firmato il messaggio (DKIM). Questa verifica non richiede connessioni aggiuntive.
