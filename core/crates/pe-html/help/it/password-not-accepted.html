La password non viene accettata

Cosa fare quando il server di posta rifiuta la password o l’accesso.

Può comparire uno di questi avvisi:

  • Nella barra di stato: “il server non ha accettato l’accesso (…)”
  • Nel riquadro di lettura: “Il server di posta non ha accettato l’accesso (…). Controlla la password o accedi di nuovo nelle impostazioni dell’account.”
  • Una finestra che chiede di inserire di nuovo la password dell’account

Per risolvere:

  1. Digita di nuovo la password quando Inbox Classic la chiede, oppure cambiala nelle proprietà dell’account in > .
  2. Se il provider usa l’autenticazione a due fattori, potrebbe richiedere una password per le app nei programmi di posta. Se il provider la supporta, creane una nelle impostazioni di sicurezza dell’account e usala al posto della password abituale.
  3. Per Outlook.com, accedi tramite il browser. Per Gmail puoi usare anche il browser, oppure una password per le app se il tuo account la supporta e hai attivato la verifica in due passaggi. Vedi .

Un account che accede tramite il browser
