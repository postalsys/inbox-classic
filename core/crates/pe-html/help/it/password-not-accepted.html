La password non viene accettata

Cosa fare quando il server di posta rifiuta la password o l’accesso.

Può comparire uno di questi:

  • Nella barra di stato: “il server non ha accettato l’accesso (…)”
  • Nel riquadro di lettura: “Il server di posta non ha accettato l’accesso (…). Controlla la password o accedi di nuovo in File > Account.”
  • Una finestra che chiede di inserire di nuovo la password dell’account

Per risolvere:

  1. Digita di nuovo la password quando Inbox Classic la chiede, oppure cambiala nelle proprietà dell’account in > .
  2. Se il tuo provider chiede un secondo passaggio quando accedi dal web, anche i programmi di posta hanno bisogno di una password per le app. Creane una nelle impostazioni di sicurezza del tuo account e usala al posto della password abituale.
  3. Per Gmail e Outlook.com, accedi tramite il browser o usa una password per le app. Vedi .
