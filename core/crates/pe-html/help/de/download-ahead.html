Nachrichten vorab herunterladen

Neue Nachrichten werden beim Eintreffen im Hintergrund heruntergeladen, damit Sie sie ohne Wartezeit öffnen können.

Inbox Classic lädt neue Nachrichten im Hintergrund herunter, sobald sie eintreffen. So können Sie sie sofort öffnen, auch ohne Internetverbindung. Beim Öffnen einer Nachricht werden außerdem die Nachrichten darüber und darunter heruntergeladen, damit Sie schneller zur nächsten Nachricht wechseln können.

Die Einstellungen für das Herunterladen finden Sie unter > Inbox Classic > > :

  • Mit werden Nachrichten der letzten 30 Tage mit jeweils höchstens 1 MB heruntergeladen. Mit werden alle Nachrichten bis zum unten festgelegten Speicherlimit heruntergeladen. Mit wird eine Nachricht erst beim Öffnen heruntergeladen.
  • Legt fest, wie viel Speicherplatz die heruntergeladenen Nachrichten jedes Kontos auf diesem Computer belegen dürfen. Wird das Limit überschritten, werden die ältesten lokalen Kopien entfernt. Die Nachrichten bleiben auf dem Server und werden beim Öffnen erneut heruntergeladen.

Nachrichten in den Ordnern und sowie im Gmail-Ordner „Alle Nachrichten“ werden erst beim Öffnen heruntergeladen.

Bei Nachrichten über 1 MB wird zunächst der Text angezeigt. Die Anlagen werden im Hintergrund weiter heruntergeladen; den Fortschritt sehen Sie in der Statusleiste. Sobald der Download abgeschlossen ist, können Sie die Anlagen öffnen und die Nachricht speichern oder weiterleiten.
