  • Die Option fasst die Nachrichten einer Unterhaltung in einer Zeile zusammen. Diese Option ist standardmäßig aktiviert.

In verschlüsselten Nachrichtenteilen müssen Sie das Laden externer Bilder weiterhin jedes Mal erlauben. Diese Option ist standardmäßig deaktiviert, da Absender so erfahren können, wann Sie ihre Nachrichten lesen. Siehe .
  • Die Schaltfläche öffnet die Liste der Absender, deren Bilder bei bestätigter Absenderdomäne automatisch heruntergeladen werden. Dort können Sie Absender aus der Liste entfernen. Für Junk-E-Mails und verschlüsselte Nachrichtenteile ist weiterhin eine gesonderte Erlaubnis nötig.
  • Die Option ist standardmäßig aktiviert. Mit verfügbaren Schlüsseln versucht Inbox Classic, heruntergeladene Nachrichten im Hintergrund zu entschlüsseln. Dadurch wird ihr Text durchsuchbar, und die Liste kann eine Vorschau und den geschützten Betreff anzeigen. Der entschlüsselte Inhalt wird unverschlüsselt im lokalen Suchindex gespeichert. Wenn Sie die Option deaktivieren, werden die abgeleiteten Inhalte aus dem Index entfernt und wieder die äußeren Betreffe angezeigt. KI-Agenten können diesen Inhalt nicht durchsuchen.
