Neue Nachrichten mit Regeln sortieren

Lassen Sie eingehende Nachrichten nach Ihren Kriterien automatisch verschieben, als gelesen markieren, kennzeichnen oder archivieren.

Eine Regel besteht aus Suchkriterien und Aktionen, die auf passende Nachrichten beim Eintreffen im Posteingang angewendet werden. Eine Regel mit from:news@example.com kann zum Beispiel Newsletter von dieser Adresse in einen eigenen Ordner verschieben und als gelesen markieren.

So erstellen Sie eine Regel:

  1. Wählen Sie > und klicken Sie auf .
  2. Geben Sie einen Namen ein und tragen Sie unter dieselben Suchbegriffe wie im Suchfeld ein, etwa mit from:, subject: oder list:. Die Zeile darunter zeigt, wie viele vorhandene Nachrichten im Posteingang diesen Kriterien entsprechen.
  3. Wählen Sie eine oder mehrere Aktionen für passende Nachrichten: in einen Ordner verschieben, als gelesen markieren, kennzeichnen, archivieren, in Junk-E-Mail verschieben, löschen oder Benachrichtigungen unterdrücken.
  4. Klicken Sie auf .

Sie können eine Regel auch aus einer Nachricht oder einer Suche erstellen. Mit > wird der Absender oder die Mailingliste der ausgewählten Nachricht übernommen. Mit über den Suchergebnissen übernehmen Sie die aktuellen Suchkriterien.

So funktionieren Regeln

Regeln verarbeiten neue Nachrichten im Posteingang, solange Inbox Classic läuft, auch wenn es in den Infobereich minimiert ist. Vorhandene Nachrichten werden nur einbezogen, wenn Sie aktivieren. Passende Regeln werden in der Reihenfolge der Liste angewendet. Sobald eine Regel eine Nachricht aus dem Posteingang verschiebt, werden für diese Nachricht keine weiteren Regeln ausgeführt. Deaktivieren Sie das Kontrollkästchen einer Regel in der Liste, um sie auszuschalten, ohne sie zu löschen.

Regeln ändern

Um eine Regel zu bearbeiten, wählen Sie sie in der Liste aus und klicken Sie auf , oder doppelklicken Sie darauf. Mit und ändern Sie die Reihenfolge. Mit löschen Sie die Regel. Im Regeleditor zeigt die Nachrichten, die derzeit den Kriterien entsprechen, im Hauptfenster an.

Regeln gelten für neu eingehende Nachrichten im Posteingang. Filter nach Ordner oder Datum werden daher nicht unterstützt. Regeln werden auf diesem Computer ausgeführt. Um Nachrichten auch bei ausgeschaltetem Computer zu sortieren, verwenden Sie die Filter Ihres E-Mail-Anbieters.
