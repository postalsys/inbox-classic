Sicherheitseinstellungen eines Kontos

Die Sicherheitseinstellungen der Server eines Kontos, und was jede bedeutet.

Jedes Konto hat für den Posteingangsserver und für den Postausgangsserver. Inbox Classic trägt sie ein, wenn es die Einstellungen Ihres Anbieters findet. Um sie zu ändern, öffnen Sie die Eigenschaften des Kontos unter > .

EinstellungBedeutung
SSL/TLSDie Verbindung ist von Anfang an verschlüsselt. Meist Port 993 für eingehende und 465 für ausgehende E-Mails.
STARTTLSDie Verbindung wird gleich nach dem Öffnen verschlüsselt. Meist Port 143 für eingehende und 587 für ausgehende E-Mails. Inbox Classic bricht ab, wenn der Server keine Verschlüsselung anbietet.
Ihr Passwort und Ihre E-Mails sind für jeden im Netzwerk lesbar.
Verwenden Sie nur für einen Server auf Ihrem eigenen Computer oder in Ihrem lokalen Netzwerk. Inbox Classic warnt Sie, bevor es diese Einstellung verwendet.

Inbox Classic prüft anhand der Zertifikate, denen Ihr System vertraut, dass jeder Server der ist, der er zu sein vorgibt. Es gibt keinen Schalter, um jedes beliebige Zertifikat zu akzeptieren.

Ihr Passwort wird in der Windows-Anmeldeinformationsverwaltungin Ihrem Schlüsselbund „Anmeldung“in Ihrem Schlüsselbund aufbewahrt, nie im E-Mail-Speicher. Ein Konto, das sich über den Browser anmeldet, speichert überhaupt kein Passwort.
