Verschlüsselungsfehler

Was Sie tun können, wenn ein Server keine Verschlüsselung anbietet oder sie verlangt, wo sie ausgeschaltet ist.

„the server does not offer STARTTLS“

Das Konto ist auf STARTTLS eingestellt, aber der Server hat keine Verschlüsselung angeboten. Inbox Classic hat den Verbindungsversuch vor der Anmeldung abgebrochen und kein Passwort gesendet.

  1. Öffnen Sie die Eigenschaften des Kontos unter > .
  2. Prüfen Sie die Vorgaben Ihres Anbieters. Falls unterstützt, verwenden Sie SSL/TLS mit Port 993 für eingehende oder 465 für ausgehende E-Mails.
  3. Klicken Sie auf .

Wenn nichts anderes funktioniert, lässt sich der Server nicht sicher verwenden.

„the server takes the password only over an encrypted connection“

Der Postausgangsserver ist auf eingestellt. Der Server verlangt eine verschlüsselte Anmeldung; daraus lässt sich nicht schließen, ob das Passwort richtig ist. Ändern Sie entsprechend den Vorgaben Ihres Anbieters auf STARTTLS mit Port 587 oder SSL/TLS mit Port 465.

Die Warnung vor einer Verbindung ohne Verschlüsselung

Wenn Sie wählen, warnt Inbox Classic, dass jeder, der Ihren Netzwerkverkehr abfängt, Ihr Passwort und Ihre Nachrichten lesen kann. Ein lokales Netzwerk allein schützt nicht davor. Fahren Sie nur fort, wenn der Verbindungsweg anderweitig abgesichert ist.
