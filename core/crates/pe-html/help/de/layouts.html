Layouts

Wählen Sie das klassische Layout mit der Nachrichtenliste über der gelesenen Nachricht oder das Spaltenlayout für einen breiten Bildschirm.

Inbox Classic hat zwei Layouts:

  • : die Ordnerliste links, die Nachrichtenliste oben rechts und der Lesebereich darunter.
  • : Ordnerliste, Nachrichtenliste und Lesebereich nebeneinander. Jede Nachricht hat drei Zeilen: wer sie wann gesendet hat, den Betreff und die ersten Worte der Nachricht, ohne die zitierten früheren Nachrichten.

Mit richtet sich das Layout nach der Breite des Fensters: Ein breites Fenster zeigt das Spaltenlayout, ein schmaleres das klassische Layout. Ab Werk ist das Layout automatisch.

So wählen Sie ein Layout:

  1. Wählen Sie > .
  2. Wählen Sie , oder .

Dieselbe Auswahl finden Sie unter > Inbox Classic > > .

Nachrichten sortieren

Wählen Sie > und wonach sortiert werden soll, dann ob aufsteigend oder absteigend. Im Spaltenlayout zeigt die Schaltfläche über den Nachrichten, wonach sie sortiert sind; ein Klick darauf bietet dieselbe Auswahl. Im klassischen Layout können Sie auch auf eine Spaltenüberschrift klicken.

Die ersten Worte einer Nachricht erscheinen, sobald Inbox Classic ihren Text hat. Für bereits vorhandene E-Mail lädt es den Text im Hintergrund herunter.
