Wenn ein Agent E-Mails sendet

Jede Nachricht, die ein KI-Agent senden möchte, wird Ihnen zuerst gezeigt und wartet im Postausgang, bevor sie gesendet wird.

Ein Agent kann nur E-Mails senden, wenn Sie es ihm erlaubt haben, und jede Nachricht erst nach Ihrer Zustimmung.

Wenn der Agent senden möchte, zeigt Inbox Classic die Nachricht mit jedem Empfänger samt Adresse. Adressen, an die Sie noch nie geschrieben haben, sind mit markiert.

  1. Lesen Sie die Empfänger und den Text.
  2. Wählen Sie eine Möglichkeit:
    • reiht die Nachricht zum Senden ein. Die Schaltfläche wird erst nach einem Moment aktiv, um versehentliche Bestätigungen zu verringern.
    • öffnet sie als neue Nachricht, die Sie ändern können.
    • , die Voreinstellung, sendet sie nicht.

Pro Programm kann jeweils nur eine Nachricht auf Ihre Bestätigung warten. Wenn Sie nicht gleich antworten, erfährt der Agent, dass Ihre Entscheidung noch aussteht. Er kann sie später abfragen. Nachrichten und Entwürfe eines Agenten enthalten standardmäßig die Textsignatur Ihres Kontos. Der Agent kann sie jedoch weglassen.

Eine Nachricht, die Sie senden, wartet 30 Sekunden im Postausgang. Solange sie noch im Postausgang liegt, können Sie sie dort löschen oder unter > auf klicken.

Antworten auf Einladungen

Ein Agent mit Sendeberechtigung kann eine Einladung annehmen, unter Vorbehalt annehmen oder ablehnen. Jede Antwort braucht Ihre Zustimmung. Die Abfrage nennt Einladung und Termin. Inbox Classic erstellt die Antwort aus den Kalenderdaten und richtet sie an den Organisator; eine vorherige Bearbeitung ist hier nicht möglich. Die Antwort enthält keine Textsignatur. Der angezeigte Antwortstatus ändert sich erst nach erfolgreichem Senden. Ob der Kalender des Organisators die Antwort übernommen hat, wird damit nicht bestätigt.

Entwürfe eines Agenten

Wenn Sie einen Entwurf eines Agenten öffnen, sehen Sie über dem Nachrichtentext, welcher Agent ihn verfasst hat. Prüfen Sie die Empfänger und den Text, bevor Sie ihn senden.

Ein Agent kann nur seine eigenen Entwürfe ändern oder verwerfen. Sobald Sie einen solchen Entwurf speichern, können nur noch Sie ihn bearbeiten. Das gilt auch, wenn Inbox Classic Ihre Änderungen automatisch speichert. Das Öffnen allein verhindert weitere Änderungen durch den Agenten nicht.

Ein Agent, der noch andere Werkzeuge hat, etwa zum Surfen im Web oder zum Lesen Ihrer Dateien, könnte darüber weitergeben, was er liest. Inbox Classic kann diese nicht sehen. Lassen Sie einen Agenten nur senden, wenn Sie das brauchen.
