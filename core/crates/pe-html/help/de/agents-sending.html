Wenn ein Agent E-Mails sendet

Jede Nachricht, die ein KI-Agent senden möchte, wird Ihnen zuerst gezeigt und wartet im Postausgang, bevor sie gesendet wird.

Ein Agent kann nur E-Mails senden, wenn Sie es ihm erlaubt haben, und jede Nachricht erst nach Ihrer Zustimmung.

Wenn der Agent senden möchte, zeigt Inbox Classic die Nachricht mit jedem Empfänger samt Adresse. Adressen, an die Sie noch nie geschrieben haben, sind mit markiert.

  1. Lesen Sie die Empfänger und den Text.
  2. Wählen Sie eine Möglichkeit:
    • sendet die Nachricht. Die Schaltfläche wird erst nach einem Moment aktiv, sodass Sie sie nicht versehentlich drücken.
    • öffnet sie als neue Nachricht, die Sie ändern können.
    • , die Voreinstellung, sendet sie nicht.

Eine Nachricht, die Sie senden, wartet 30 Sekunden im Postausgang. Bis sie gesendet ist, können Sie sie dort löschen oder unter > auf klicken.

Ein Agent, der noch andere Werkzeuge hat, etwa zum Surfen im Web oder zum Lesen Ihrer Dateien, könnte darüber weitergeben, was er liest. Inbox Classic kann diese nicht sehen. Lassen Sie einen Agenten nur senden, wenn Sie das brauchen.
