Entwürfe und der Postausgang

Speichern Sie eine Nachricht, um sie später fertigzustellen, und sehen Sie, was auf das Senden wartet.

Einen Entwurf speichern

Klicken Sie auf oder drücken Sie Ctrl+S⌘S. Die Nachricht wird im Ordner des Kontos auf dem Server abgelegt. Erneutes Speichern ersetzt die frühere Kopie. Die Statusleiste der Nachricht zeigt, wann sie gespeichert wurde.

Wenn Sie eine Nachricht mit Änderungen schließen, werden Sie gefragt, ob sie gespeichert werden sollen:

  • speichert sie im Ordner .
  • verwirft die Änderungen.
  • kehrt zur Nachricht zurück.

Um weiterzuschreiben, doppelklicken Sie im Ordner auf den Entwurf. Er öffnet sich mit seinen Empfängern, seinem Text und seinen Dateien. Sobald er gesendet ist, wird der Entwurf entfernt.

Eine Nachricht, die Sie schreiben, ist ein eigenes Fenster, sodass Sie E-Mails lesen können, während es geöffnet bleibt. Wenn Sie Inbox Classic beenden, werden zuerst die Nachrichten geschlossen, die Sie gerade schreiben, und bei denen mit Änderungen wird nachgefragt.

Der Postausgang

legt die Nachricht in den Postausgang und sendet sie sofort. Die Statusleiste des Hauptfensters meldet, wann sie gesendet ist.

Kann eine Nachricht nicht gesendet werden, etwa ohne Verbindung, bleibt sie im Postausgang. Sie wird beim nächsten Abrufen von E-Mails gesendet, sodass nichts verloren geht, was Sie geschrieben haben.

Um zu sehen, was wartet, wählen Sie > . Dort steht jede Nachricht mit dem Grund, warum sie nicht gesendet wurde. versucht es sofort erneut, und Sie können dort auch eine Nachricht löschen.
