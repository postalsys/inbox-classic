Nachrichten kennzeichnen, archivieren und verschieben

Kennzeichnen Sie Nachrichten, markieren Sie sie als Junk, archivieren Sie sie oder verschieben Sie sie in einen anderen Ordner, einzeln oder mehrere auf einmal.

Mehrere Nachrichten auswählen

Mit Ctrl+Klick⌘+Klick fügen Sie eine Nachricht zur Auswahl hinzu, oder Sie klicken auf die erste und mit Shift+Klick auf die letzte. > () wählt alle Nachrichten der Liste aus. Die folgenden Befehle wirken dann auf alle.

Kennzeichnen

Wählen Sie > (), um eine Nachricht zu kennzeichnen oder die Kennzeichnung zu entfernen. Um sie mit einer Farbe zu kennzeichnen, wählen Sie > und eine Farbe. Apple Mail zeigt dieselben Farben. entfernt die Kennzeichnung.

Junk

Klicken Sie auf oder drücken Sie , um eine Nachricht in den Ordner zu verschieben und Ihrem Mailserver mitzuteilen, dass sie Junk ist. Im Ordner verschiebt sie zurück in den Posteingang.

Archivieren

Klicken Sie auf oder drücken Sie A in der Nachrichtenliste, um eine Nachricht aus dem Posteingang in den Ordner zu verschieben. Hat das Konto keinen solchen Ordner, legt Inbox Classic ihn an. Bei Gmail entfernt das Archivieren die Labels der Nachricht, sodass sie nur noch in „Alle Nachrichten“ liegt.

Sie können Nachrichten auch auf einen Ordner in der Ordnerliste ziehen. Halten Sie beim Loslassen Ctrl⌥ gedrückt, um sie stattdessen zu kopieren. Eine in ein anderes Konto verschobene Nachricht wird erst von ihrem eigenen Server entfernt, wenn die Kopie angekommen ist.

All das geschieht auch auf dem Server, sodass Ihre anderen E-Mail-Programme es ebenfalls sehen.
