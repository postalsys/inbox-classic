Befehlszeilenoptionen

Optionen zum Starten von Inbox Classic aus einem Terminal, für Tests und für KI-Agenten.

Starten Sie das Programm InboxClassic.exe"Inbox Classic.app/Contents/MacOS/Inbox Classic"inbox-classic mit diesen Optionen:

OptionWirkung
--store <datei>Verwendet einen anderen E-Mail-Speicher, etwa einen zum Testen
--memory-passwordsBehält Passwörter nur für diesen Lauf, nie im Passwortspeicher des Systems
--pin-certificate <datei>Akzeptiert nur das Serverzertifikat in dieser Datei (PEM oder DER), für einen Testserver mit selbstsigniertem Zertifikat
--sign-in-page-file <datei>Schreibt die Seite einer Browser-Anmeldung in diese Datei, statt den Browser zu öffnen
--language <code>Zeigt die Fenster für diesen Lauf in dieser Sprache, etwa de
--backgroundStartet ohne Fenster
--mcpVerbindet einen KI-Agenten mit Inbox Classic. Das Programm des Agenten startet dies, nicht Sie
--versionGibt die Version aus und beendet sich

Ein als Argument übergebener mailto:-Link öffnet eine neue Nachricht, wie es ein E-Mail-Link tut.
