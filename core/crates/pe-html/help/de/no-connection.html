Inbox Classic kann keine Verbindung herstellen

Was Sie tun können, wenn der Mailserver nicht erreichbar ist oder nicht antwortet.

Sie sehen vielleicht eine dieser Meldungen in der Statusleiste oder im Lesebereich:

  • „connection error: …“
  • „the server did not answer in time“
  • „die Verbindung zum Server ist fehlgeschlagen (…)“
  • „Der Mailserver war nicht erreichbar (…).“

So beheben Sie das:

  1. Prüfen Sie Ihre Internetverbindung.
  2. Öffnen Sie die Eigenschaften des Kontos unter > und prüfen Sie die Servernamen und Ports.
  3. Schlägt das Senden fehl, verwenden Sie für ausgehende E-Mails Port 465 oder 587. Manche Netzwerke sperren die Mail-Ports, besonders Port 25.

Inbox Classic versucht es beim nächsten Abrufen erneut. Um es jetzt zu versuchen, klicken Sie auf .

Eine Nachricht, die Sie ohne Verbindung senden, wartet im Postausgang und wird gesendet, sobald der Server erreichbar ist. Nichts, was Sie geschrieben haben, geht verloren.
