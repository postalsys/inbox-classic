Formatierung

Die Leiste über dem Text enthält Schriftart, Fett, Kursiv, Unterstrichen, Farbe, Listen, Einzug, Ausrichtung, Links, eine Trennlinie und Bilder. Um ein Bild in den Text einzufügen, klicken Sie auf oder ziehen eine Bilddatei aus dem Explorerdem Finderdem Dateimanager in den Text.

Eine Nachricht ohne Formatierung wird als reiner Text gesendet, den jedes E-Mail-Programm gleich anzeigt. Eine formatierte Nachricht wird als HTML mit einer Kopie als reiner Text gesendet.

Links

Um den markierten Text mit einem Link zu versehen, klicken Sie auf und geben die Adresse ein. Steht der Cursor in einem Link, zeigt die Statusleiste, wohin er führt.
