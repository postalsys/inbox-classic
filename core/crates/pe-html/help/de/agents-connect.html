Einen KI-Agenten verbinden

Lassen Sie einen KI-Agenten wie Claude Ihre E-Mails über Inbox Classic lesen und ordnen.

Sie können einen KI-Agenten mit Ihren E-Mails arbeiten lassen. Das kann Claude, Cursor oder ein anderes Programm sein, das das Model Context Protocol (MCP) unterstützt. Inbox Classic enthält selbst keine KI, und nichts wird an einen KI-Dienst gesendet, solange Sie keinen Agenten zulassen.

So verbinden Sie einen Agenten:

  1. Wählen Sie > und klicken Sie auf . Inbox Classic zeigt die Zeilen, die Sie in die Einstellungen Ihres Agenten einfügen.
  2. Fügen Sie sie zu den MCP-Servern Ihres Agenten hinzu. In Claude Desktop finden Sie diese unter Einstellungen > Entwickler > Konfiguration bearbeiten.
  3. Starten Sie den Agenten. Wenn er sich zum ersten Mal verbindet, fragt Inbox Classic Sie, was er tun darf.

Der Agent startet Inbox Classic im Hintergrund, falls es nicht läuft. Nur Programme, die unter Ihrem Benutzer auf diesem Computer laufen, können es erreichen.

Um alle Agenten auf einmal auszuschalten, deaktivieren Sie unter > .
