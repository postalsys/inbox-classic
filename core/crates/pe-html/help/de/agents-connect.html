Einen KI-Agenten verbinden

Lassen Sie einen KI-Agenten wie Claude Ihre E-Mails über Inbox Classic lesen und ordnen.

Sie können einen KI-Agenten mit Ihren E-Mails arbeiten lassen. Das kann Claude, Cursor oder ein anderes Programm sein, das das Model Context Protocol (MCP) unterstützt. Inbox Classic enthält selbst keine KI, und nichts wird an einen KI-Dienst gesendet, solange Sie keinen Agenten zulassen.

So verbinden Sie einen Agenten:

  1. Wählen Sie > und klicken Sie auf . Inbox Classic zeigt die Zeilen, die Sie in die Einstellungen Ihres Agenten einfügen.
  2. Fügen Sie sie zu den MCP-Servern Ihres Agenten hinzu. In Claude Desktop finden Sie diese unter Einstellungen > Entwickler > Konfiguration bearbeiten.
  3. Starten Sie den Agenten. Wenn er sich zum ersten Mal verbindet, fragt Inbox Classic Sie, was er tun darf.

Der Agent startet Inbox Classic im Hintergrund, falls es nicht läuft. Nur Programme, die unter Ihrem Benutzer auf diesem Computer laufen, können es erreichen.

Inbox Classic ermittelt über das Betriebssystem, welches Programm den Agenten gestartet hat. Eine bloße Namensangabe verschafft ihm nicht die Berechtigungen eines anderen Programms. Weicht die Angabe von der erkannten Herkunft ab, zeigt die Abfrage das an. Diese Zuordnung schützt Ihre E-Mails jedoch nicht vor einem bösartigen Programm, das unter demselben Benutzerkonto läuft.

Ein Agent kann Änderungen in einem freigegebenen Posteingang, Konto oder Ordner abonnieren. Die vorbereiteten Anfragen „Triage my inbox“ und „Summarize unread“ helfen beim Ordnen des Posteingangs und beim Zusammenfassen ungelesener Nachrichten. Auch dabei gelten die erteilten Berechtigungen; Lesezugriffe werden wie andere Zugriffe protokolliert.

Agenten aus demselben erkannten Terminalprogramm, etwa Claude Code, teilen sich einen Zugriffseintrag. Inbox Classic fragt nach Programmen aus diesem TerminalprogrammProgrammen aus diesem Terminalprogramm. Für einen separaten Eintrag ergänzen Sie in den Agenteneinstellungen nach --mcp die Option --name und einen Namen, zum Beispiel "args": ["--mcp", "--name", "Claude Code"]. Inbox Classic fragt dann unter diesem Namen nach Berechtigungen. Der gewählte Name ist kein Identitätsnachweis.

Um den Zugriff aller Agenten auf Inbox Classic auszuschalten, deaktivieren Sie unter > .
