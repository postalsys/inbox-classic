Einen KI-Agenten verbinden

Lassen Sie einen KI-Agenten wie Claude Ihre E-Mails über Inbox Classic lesen und ordnen.

Sie können einen KI-Agenten mit Ihren E-Mails arbeiten lassen. Das kann Claude, Cursor oder ein anderes Programm sein, das das Model Context Protocol (MCP) unterstützt. Inbox Classic enthält selbst keine KI, und nichts wird an einen KI-Dienst gesendet, solange Sie keinen Agenten zulassen.

So verbinden Sie einen Agenten:

  1. Wählen Sie > und klicken Sie auf . Inbox Classic zeigt die Zeilen, die Sie in die Einstellungen Ihres Agenten einfügen.
  2. Fügen Sie sie zu den MCP-Servern Ihres Agenten hinzu. In Claude Desktop finden Sie diese unter Einstellungen > Entwickler > Konfiguration bearbeiten.
  3. Starten Sie den Agenten. Wenn er sich zum ersten Mal verbindet, fragt Inbox Classic Sie, was er tun darf.

Der Agent startet Inbox Classic im Hintergrund, falls es nicht läuft. Nur Programme, die unter Ihrem Benutzer auf diesem Computer laufen, können es erreichen.

Inbox Classic fragt das System, welches Programm den Agenten gestartet hat, statt sich auf die Angaben des Agenten zu verlassen. So kann ein Programm nicht den Zugriff nutzen, den Sie einem anderen gegeben haben. Gibt sich ein Agent als ein anderes Programm aus, sagt Ihnen das die Abfrage.

Ein Agent kann außerdem Ihren Posteingang, ein Konto oder einen Ordner im Blick behalten und erfährt, wenn sich die E-Mails darin ändern. Er kann zwei fertige Anfragen anbieten, „Triage my inbox“ und „Summarize unread“. Beide halten sich an das, was Sie dem Agenten erlauben, und was er so liest, erscheint wie alles andere, was er liest, in seinem Protokoll.

Agenten, die Sie aus einem Terminal starten, etwa Claude Code, sind für Inbox Classic ein einziges Programm. Es fragt einmal nach aus Terminal gestarteten Programmenaus einem Terminal gestarteten Programmen, und diese teilen sich, was Sie erlauben. Um einem Agenten eigenen Zugriff zu geben, fügen Sie in seinen Einstellungen nach --mcp --name und einen Namen Ihrer Wahl hinzu, zum Beispiel "args": ["--mcp", "--name", "Claude Code"]. Inbox Classic fragt dann unter diesem Namen nach ihm.

Um alle Agenten auf einmal auszuschalten, deaktivieren Sie unter > .
