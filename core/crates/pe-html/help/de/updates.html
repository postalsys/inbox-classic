Inbox Classic aktualisieren

Holen Sie sich die neueste Version von Inbox Classic.

Um zu sehen, welche Version Sie haben, wählen Sie > Inbox Classic > .

Laden Sie das neueste Installationsprogramm von inboxclassic.com herunter und führen Sie es aus. Es aktualisiert die installierte Kopie an Ort und Stelle. Ihre Konten und die dafür heruntergeladenen E-Mails bleiben erhalten.

Inbox Classic aktualisiert sich selbst. Es sucht von selbst nach einer neuen Version und fragt, bevor es sie installiert. Um jetzt zu suchen, wählen Sie Inbox Classic > .

Haben Sie Inbox Classic aus seinem apt-Repository installiert, kommen neue Versionen mit den Updates Ihres Systems. Haben Sie eine .deb-Datei installiert, laden Sie die neuere von inboxclassic.com herunter und installieren Sie sie über die alte.

Unter Arch Linux installieren Sie das neuere Paket auf dieselbe Weise mit sudo pacman -U. Unter Omarchy bringt dessen eigenes Update die neue Version.

Ihre Konten, E-Mails und Einstellungen bleiben bei Updates erhalten.
