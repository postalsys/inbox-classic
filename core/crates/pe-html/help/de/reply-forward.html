Antworten und weiterleiten

Antworten Sie dem Absender oder allen, oder leiten Sie eine Nachricht an jemand anderen weiter.

  • () antwortet dem Absender.
  • () antwortet allen, an die die Nachricht ging.
  • () leitet die Nachricht weiter. Sie geben die Empfänger ein.

Eine Antwort oder Weiterleitung wird von dem Konto gesendet, in dem die ursprüngliche Nachricht liegt.

Die ursprüngliche Nachricht

In einer Antwort ist die ursprüngliche Nachricht hinter einer Schaltfläche ••• unter Ihrem Text eingeklappt, sodass Sie nur sehen, was Sie schreiben. Sie wird in jedem Fall mit Ihrer Antwort gesendet. Um sie zu kürzen, klicken Sie auf die Schaltfläche oder wählen mit Ctrl+A⌘A alles aus: Die ursprüngliche Nachricht wird dann Teil Ihres Textes.

Bei einer Weiterleitung steht die ursprüngliche Nachricht von Anfang an im Text, denn sie ist es, was Sie senden.

Eine Antwort übernimmt das Format der ursprünglichen Nachricht. Eine Antwort auf eine Nachricht in reinem Text ist reiner Text, mit der ursprünglichen Nachricht mit > zitiert, sofern Sie nichts formatieren.

Wählen Sie mehrere Nachrichten aus und klicken Sie auf . Es entsteht eine neue Nachricht, an die alle als .eml-Dateien angehängt sind. Ihr Betreff ist der der ersten Nachricht.
