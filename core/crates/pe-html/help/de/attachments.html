Anlagen

Speichern Sie die Dateien, die eine Nachricht mitbringt, und hängen Sie Dateien an Ihre eigenen Nachrichten an.

Eine Anlage speichern

So speichern Sie die Dateien einer Nachricht:

  1. Klicken Sie auf die Büroklammer rechts im Nachrichtenkopf. Sie zeigt, wie viele Dateien es sind.
  2. Wählen Sie eine Datei, um sie zu speichern, oder wählen Sie , um alle in einem Ordner zu speichern.

Inbox Classic speichert Dateien, öffnet sie aber nie. Es schlägt einen sicheren Namen vor, ohne Zeichen, mit denen ein Name wie etwas anderes aussehen könnte. Eine gleichnamige Datei, die schon im Ordner liegt, bleibt erhalten, und die neue erhält eine Nummer.

Öffnen Sie Anlagen nur von Personen, von denen Sie sie erwarten. Ein Programm oder ein Dokument, das Sie auffordert, „Inhalte zu aktivieren“, kann Ihren Computer übernehmen. Programme sind etwa .exe-, .msi-, .js-, .vbs-, .bat- und .scr-Dateien..app-, .pkg-, .dmg- und .command-Dateien..sh-, .deb-, .AppImage- und .desktop-Dateien.

Eine Datei anhängen

So hängen Sie Dateien an die Nachricht an, die Sie schreiben:

  1. Klicken Sie auf .
  2. Wählen Sie die Dateien. Sie werden unter mit ihrer Größe aufgelistet.

Sie können Dateien auch aus dem Explorerdem Finderdem Dateimanager auf die Adressfelder ziehen. Eine Datei, die kein Bild ist, können Sie auch auf den Text ziehen.

Um eine Datei wieder zu entfernen, wählen Sie sie aus und drücken Delete, oder klicken Sie mit der rechten Maustaste darauf und wählen . Die Dateien werden erst beim Senden gelesen, lassen Sie sie also bis dahin, wo sie sind.
