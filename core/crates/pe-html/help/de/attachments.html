Anlagen

Öffnen oder speichern Sie die Dateien, die eine Nachricht mitbringt, und hängen Sie Dateien an Ihre eigenen Nachrichten an.

Eine Anlage öffnen

Die Dateien einer Nachricht stehen unter ihrem Kopf, jede mit Name und Größe. Doppelklicken Sie auf eine Datei, um sie mit dem Programm zu öffnen, das Ihr Computer dafür verwendet. Mit der Tastatur drücken Sie Tab, bis die Dateien ausgewählt sind, wählen eine mit den Pfeiltasten und drücken Enter.

Ein Rechtsklick auf eine Datei bietet , und . Auch die Büroklammer rechts im Kopf listet die Dateien.

Inbox Classic öffnet nie eine Datei, die Programme ausführen kann: Programme, Skripte, Installationsprogramme, Verknüpfungen, Datenträgerabbilder, Webseiten und Office-Dokumente mit Makros. Bei ihnen ist aus; speichern Sie eine solche Datei und öffnen Sie sie nur selbst, wenn Sie ihrer Herkunft vertrauen.

Eine Datei wird aus einem eigenen Ordner von Ihnen geöffnet, den Inbox Classic nach einem Tag leert, und ist als aus dem Internet stammend markiert. Eine Datei einer verschlüsselten Nachricht liegt dort entschlüsselt, solange sie offen ist; beim ersten Mal sagt Inbox Classic das.

Eine Anlage speichern

Klicken Sie mit der rechten Maustaste auf eine Datei und wählen Sie , oder wählen Sie , um alle in einem Ordner zu speichern. Inbox Classic schlägt einen sicheren Namen vor, ohne Zeichen, mit denen ein Name wie etwas anderes aussehen könnte. Eine gleichnamige Datei, die schon im Ordner liegt, bleibt erhalten, und die neue erhält eine Nummer.

Öffnen Sie Anlagen nur von Personen, von denen Sie sie erwarten. Ein Programm oder ein Dokument, das Sie auffordert, „Inhalte zu aktivieren“, kann Ihren Computer übernehmen. Programme sind etwa .exe-, .msi-, .js-, .vbs-, .bat- und .scr-Dateien..app-, .pkg-, .dmg- und .command-Dateien..sh-, .deb-, .AppImage- und .desktop-Dateien.

Eine Datei anhängen

So hängen Sie Dateien an die Nachricht an, die Sie schreiben:

  1. Klicken Sie auf .
  2. Wählen Sie die Dateien. Sie werden unter mit ihrer Größe aufgelistet.

Sie können Dateien auch aus dem Explorerdem Finderdem Dateimanager auf die Adressfelder ziehen. Eine Datei, die kein Bild ist, können Sie auch auf den Text ziehen.

Um eine Datei wieder zu entfernen, wählen Sie sie aus und drücken Delete, oder klicken Sie mit der rechten Maustaste darauf und wählen . Die Dateien werden erst beim Senden gelesen, lassen Sie sie also bis dahin, wo sie sind.
