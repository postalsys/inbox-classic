Anlagen

Öffnen und speichern Sie empfangene Anlagen und fügen Sie Ihren eigenen Nachrichten Dateien hinzu.

Eine Anlage öffnen

Unter den Kopfzeilen einer Nachricht finden Sie die Anlagen mit Name und Größe. Ein Doppelklick öffnet die Datei im zugehörigen Programm. Mit der Tastatur gelangen Sie über Tab zu den Anlagen. Wählen Sie die gewünschte Datei mit den Pfeiltasten und drücken Sie Enter.

Mit einem Rechtsklick auf eine Datei erreichen Sie , und . Auch das Büroklammersymbol rechts neben den Kopfzeilen öffnet die Liste der Anlagen.

Dateitypen, die Programme ausführen können, öffnet Inbox Classic nicht. Dazu gehören Programme, Skripte, Installationsdateien, Verknüpfungen, Datenträgerabbilder, Webseiten und Office-Dokumente mit Makros. Bei diesen Dateien ist deaktiviert. Speichern und öffnen Sie solche Dateien nur selbst, wenn Sie der Quelle vertrauen.

Zum Öffnen legt Inbox Classic eine Kopie in einem temporären Ordner Ihres Benutzerkontos ab. Kopien, die älter als einen Tag sind, werden beim Start der App gelöscht. Unter Windows und macOS wird die Herkunft aus dem Internet vermerkt. Anlagen aus verschlüsselten Nachrichten liegen dort unverschlüsselt; darauf weist Inbox Classic beim ersten Öffnen hin.

Eine Anlage speichern

Klicken Sie mit der rechten Maustaste auf die Datei und wählen Sie . Mit speichern Sie alle Anlagen in einem Ordner. Inbox Classic entfernt aus den vorgeschlagenen Dateinamen Zeichen, die den tatsächlichen Namen verschleiern könnten. Existiert bereits eine gleichnamige Datei, bleibt sie erhalten; die neue Datei erhält eine Nummer.

Öffnen Sie Anlagen nur von Personen, von denen Sie sie erwarten. Ein Programm oder ein Dokument, das Sie auffordert, „Inhalte zu aktivieren“, kann Ihren Computer übernehmen. Programme sind etwa .exe-, .msi-, .js-, .vbs-, .bat- und .scr-Dateien..app-, .pkg-, .dmg- und .command-Dateien..sh-, .deb-, .AppImage- und .desktop-Dateien.

Eine Datei anhängen

So hängen Sie Dateien an die Nachricht an, die Sie schreiben:

  1. Klicken Sie auf .
  2. Wählen Sie die Dateien. Sie werden unter mit ihrer Größe aufgelistet.

Sie können Dateien auch aus dem Explorerdem Finderdem Dateimanager auf die Adressfelder ziehen. Eine Datei, die kein Bild ist, können Sie auch auf den Text ziehen.

Um eine Datei wieder zu entfernen, wählen Sie sie aus und drücken Delete, oder klicken Sie mit der rechten Maustaste darauf und wählen . Die Dateien werden erst beim Senden gelesen, lassen Sie sie also bis dahin, wo sie sind.
