Ein Konto entfernen

Wenn Sie ein Konto entfernen, werden die dafür heruntergeladenen E-Mails und sein gespeichertes Passwort von diesem Computer gelöscht. Die E-Mails auf dem Server bleiben erhalten.

So entfernen Sie ein Konto:

  1. Wählen Sie > .
  2. Wählen Sie das Konto aus und klicken Sie auf , oder drücken Sie Delete.
  3. Bestätigen Sie. Das Konto verschwindet aus der Ordnerliste.
