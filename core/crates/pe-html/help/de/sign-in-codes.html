Anmeldecodes

Eine Nachricht mit einem Anmelde- oder Bestätigungscode zeigt den Code in einer Karte, aus der Sie ihn kopieren können.

Wenn Inbox Classic einen passenden Anmelde-, Bestätigungs- oder Freigabecode erkennt, zeigt eine Karte über der Nachricht:

  • „Code von“ und die Domäne, für die der Code gilt
  • den Code in großer Schrift
  • , womit der Code in die Zwischenablage kommt
Geben Sie einen Code nur auf einer Seite der Domäne ein, die die Karte nennt. Eine Nachricht, die Sie auffordert, einen Code anderswo einzugeben, kann ein Versuch sein, Ihr Konto zu übernehmen.

Die Karte erscheint nur, wenn Ihr E-Mail-Anbieter eine gültige Signatur für die Domäne des Codes oder deren übergeordnete Domäne bestätigt. Das bestätigt die Domain, aber nicht die Identität einer Person oder die Vertrauenswürdigkeit des Inhalts. In den Ordnern , und gibt es keine Karte, ebenso wenig, wenn Ihr Anbieter keine Signaturen meldet.

Liegt das Datum der Nachricht mehr als eine Stunde zurück, warnt die Karte, dass der Code abgelaufen sein könnte. Inbox Classic prüft die Gültigkeit nicht beim ausstellenden Dienst.

Codes in Benachrichtigungen

Um den Code in der Benachrichtigung über eine neue Nachricht zu sehen, schalten Sie unter ein. Ein Code erscheint dort nur, wenn Benachrichtigungen erlaubt sind und die passende Nachricht rechtzeitig heruntergeladen und erkannt wurde. Die Einstellung ist standardmäßig deaktiviert, da Benachrichtigungen auch auf einem gesperrten Bildschirm lesbar sein können.
