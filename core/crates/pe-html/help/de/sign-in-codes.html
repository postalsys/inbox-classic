Anmeldecodes

Eine Nachricht mit einem Anmelde- oder Bestätigungscode zeigt den Code in einer Karte, aus der Sie ihn kopieren können.

Enthält eine Nachricht einen Einmalcode, etwa einen Anmelde-, Bestätigungs- oder Freigabecode, zeigt eine Karte darüber:

  • „Code von“ und die Domäne, für die der Code gilt
  • den Code in großer Schrift
  • , womit der Code in die Zwischenablage kommt
Geben Sie einen Code nur auf einer Seite der Domäne ein, die die Karte nennt. Eine Nachricht, die Sie auffordert, einen Code anderswo einzugeben, kann ein Versuch sein, Ihr Konto zu übernehmen.

Die Karte erscheint nur, wenn Ihr E-Mail-Anbieter bestätigt, dass die Domäne die Nachricht signiert hat. Ein Code in einer von jemand anderem gefälschten Nachricht wird nicht angeboten. In den Ordnern , und gibt es keine Karte, ebenso wenig, wenn Ihr Anbieter keine Signaturen meldet.

Ein Code, der mehr als eine Stunde vor dem Öffnen gesendet wurde, ist wahrscheinlich abgelaufen, und die Karte sagt das.

Codes in Benachrichtigungen

Um den Code in der Benachrichtigung über eine neue Nachricht zu sehen, schalten Sie unter > Inbox Classic > > ein. Die Einstellung ist anfangs aus, da eine Benachrichtigung auf einem gesperrten Bildschirm lesbar sein kann.
