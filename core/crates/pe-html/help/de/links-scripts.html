Links, Skripte und Anlagen

Wie Inbox Classic verhindert, dass eine Nachricht von sich aus Code ausführt oder Seiten öffnet.

  • Skripte in Nachrichten werden nie ausgeführt. Inbox Classic bereinigt jede Nachricht, bevor es sie anzeigt, und der Lesebereich kann keinen Code ausführen.
  • Links öffnen sich in Ihrem Webbrowser, nie in Inbox Classic. Eine Nachricht kann keine Seite und kein Fenster von sich aus öffnen.
  • Anlagen werden gespeichert, nie aus Inbox Classic heraus geöffnet. Ihre Namen werden vor dem Speichern unbedenklich gemacht.
  • Abbestellen fragt Sie zuerst und sagt, was es tun wird.
Bevor Sie auf einer Seite, zu der Sie über eine Nachricht gelangt sind, ein Passwort eingeben, prüfen Sie die Adresse in Ihrem Browser. Eine Nachricht kann eine Adresse anzeigen und auf eine andere verlinken.

Wenn Sie eine Nachricht schreiben, zeigt die Statusleiste, wohin der Link am Cursor führt, sodass Sie ihn vor dem Senden prüfen können.
