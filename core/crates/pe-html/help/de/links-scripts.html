Links, Skripte und Anlagen

Wie Inbox Classic verhindert, dass eine Nachricht von sich aus Code ausführt oder Seiten öffnet.

  • Skripte in Nachrichten werden nie ausgeführt. Inbox Classic bereinigt jede Nachricht, bevor es sie anzeigt, und entfernt dabei Skripte und aktive Inhalte aus dem Nachrichtentext.
  • Weblinks öffnen sich in Ihrem Webbrowser. E-Mail-Links können ein neues Nachrichtenfenster öffnen. Eine Nachricht kann keine Seite und kein Fenster von sich aus öffnen.
  • Anlagen können Sie speichern oder auf eigenen Wunsch im zugehörigen externen Programm öffnen. Erkannte ausführbare Dateitypen lassen sich nur speichern. Problematische Zeichen werden aus vorgeschlagenen Dateinamen entfernt.
  • Abbestellen fragt Sie zuerst und sagt, was es tun wird.
Bevor Sie auf einer Seite, zu der Sie über eine Nachricht gelangt sind, ein Passwort eingeben, prüfen Sie die Adresse in Ihrem Browser. Eine Nachricht kann eine Adresse anzeigen und auf eine andere verlinken.

Wenn Sie eine Nachricht schreiben, zeigt die Statusleiste, wohin der Link unter dem Mauszeiger oder am Textcursor führt, sodass Sie ihn vor dem Senden prüfen können.

Ein Anmeldecode wird nur angeboten, wenn Ihr E-Mail-Anbieter eine gültige Signatur für die relevante Domain oder deren übergeordnete Domain bestätigt. Das bestätigt nicht die Identität einer Person. Siehe .

Eingebettete Bilder werden für die Vorschau neu als Bilder aufbereitet, ohne Skripte aus den Dateien auszuführen. Freigegebene externe Bilder werden separat geladen. Mitgesendete Schriftarten werden nicht verwendet.
