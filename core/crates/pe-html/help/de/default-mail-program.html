Inbox Classic als E-Mail-Programm festlegen

Öffnen Sie E-Mail-Links aus Webseiten und anderen Programmen in Inbox Classic.

E-Mail-Links (mailto:) öffnen eine neue Nachricht in Ihrem Standard-E-Mail-Programm.

Um Inbox Classic zu diesem Programm zu machen, wählen Sie > . Windows öffnet seine Einstellungen für Standard-Apps, wo Sie Inbox Classic für MAILTO-Links wählen. Dort ist nur eine installierte Kopie aufgeführt. Inbox Classic wird sofort zum Standard-E-Mail-Programm.

Wenn Sie dann auf einen E-Mail-Link klicken, öffnet sich eine neue Nachricht mit den Adressen, dem Betreff und dem Text des Links. Sonst wird nichts aus dem Link übernommen.

Haben Sie noch kein Konto, bittet Inbox Classic Sie, zuerst eines hinzuzufügen. Klicken Sie danach erneut auf den Link.
