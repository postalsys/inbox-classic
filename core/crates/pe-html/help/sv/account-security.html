Säkerhetsinställningar för konton

Säkerhetsinställningarna för ett kontos servrar, och vad var och en betyder.

Varje konto har för den inkommande servern och för den utgående. Inbox Classic fyller i dem när det hittar leverantörens inställningar. Om du vill ändra dem öppnar du kontots egenskaper i > .

InställningBetydelse
SSL/TLSAnslutningen är krypterad från början. Oftast port 993 för inkommande e-post och 465 för utgående e-post.
STARTTLSAnslutningen krypteras direkt efter att den öppnats. Oftast port 143 för inkommande e-post och 587 för utgående e-post. Inbox Classic avbryter om servern inte erbjuder kryptering.
Ditt lösenord och din e-post skickas läsbara för alla i nätverket.
Använd bara för en server på din egen dator eller ditt lokala nätverk. Inbox Classic varnar dig innan det används.

Inbox Classic kontrollerar att varje server är den den utger sig för att vara, mot de certifikat som systemet litar på. Det finns ingen inställning för att godta vilket certifikat som helst.

Ditt lösenord sparas i Windows Autentiseringshanterarendin inloggningsnyckelringdin nyckelring, aldrig i e-postlagret. Ett konto som loggar in via webbläsaren sparar inget lösenord alls.
