Kommandoradsalternativ

Alternativ för att starta Inbox Classic från en terminal, för tester och för AI-agenter.

Starta programmet InboxClassic.exe"Inbox Classic.app/Contents/MacOS/Inbox Classic"inbox-classic med de här alternativen:

AlternativGör
--store <fil>Använder ett annat e-postlager, till exempel ett för tester
--memory-passwordsBehåller kontonas inloggningsuppgifter bara medan programmet körs, utan att spara dem i systemets lösenordslager
--pin-certificate <fil>Godtar bara servercertifikatet i den här filen (PEM eller DER), för en testserver med ett självsignerat certifikat
--sign-in-page-file <fil>Skriver webbadressen för webbläsarinloggningen till filen i stället för att öppna webbläsaren
--language <kod>Använder det här språket medan programmet körs, till exempel de
--backgroundStartar utan fönster
--mcpAnsluter en AI-agent till Inbox Classic. Det här alternativet används av agentens program för att starta anslutningen
--versionSkriver ut versionen och avslutar

En mailto:-länk som anges som argument öppnar ett nytt meddelande, precis som en e-postlänk gör.
