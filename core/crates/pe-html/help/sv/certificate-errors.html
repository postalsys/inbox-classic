Certifikatfel

Vad du kan göra när Inbox Classic inte kan bekräfta att det är den riktiga e-postservern som svarar.

Du kan se något av följande:

  • I statusfältet: ”TLS-fel: …”
  • I läsfönstret: ”Anslutningen till e-postservern kunde inte göras säker (…).”

Ett TLS-fel innebär att den säkra anslutningen inte kunde upprättas. Om certifikatkontrollen misslyckas avbryts anslutningen innan lösenordet skickas. Felet kan också ha andra orsaker än ett ogiltigt certifikat.

Så här åtgärdar du det:

  1. Öppna kontots egenskaper i > .
  2. Kontrollera servernamnen. De måste vara de namn som serverns certifikat är utfärdat för. Det är ofta leverantörens namn, till exempel imap.provider.com, inte din egen domän.
  3. Kontrollera att datorns datum och tid stämmer.

Om nätverket granskar krypterad trafik, som vissa kontors- och skolnätverk gör, kontaktar du nätverkets administratör.

Det finns ingen inställning för att godta vilket certifikat som helst. Om ett falskt certifikat godtogs skulle någon på nätverket kunna läsa ditt lösenord och din e-post.
