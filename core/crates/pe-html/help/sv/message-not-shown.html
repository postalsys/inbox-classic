Ett meddelande visas inte

Vad du kan göra när ett meddelande fortfarande hämtas, inte kan hämtas eller inte kan visas.

”Hämtar meddelandet…”

Om meddelandet inte redan har hämtats i förväg hämtas det när du öppnar det. Direkt efter att du har lagt till ett konto finns de flesta meddelanden inte på datorn än. Avsändaren och ämnet visas genast, och innehållet visas när det har hämtats.

”Det gick inte att hämta meddelandet”

Läsfönstret visar varför, till exempel att e-postservern inte gick att nå. Efter att kontot har synkroniserats försöker Inbox Classic hämta meddelandet igen om det fortfarande är öppet. Om du vill försöka direkt klickar du på i fältet ovanför meddelandet.

”Det här meddelandet kan inte visas”

Vissa meddelanden är skadade eller uppbyggda på ett sätt som Inbox Classic inte kan visa. Inbox Classic visar då den här texten i stället för meddelandet. Resten av din e-post påverkas inte. Om du vill se vad meddelandet innehåller väljer du > .
