Gör Inbox Classic till ditt e-postprogram

Öppna e-postlänkar och meddelandefiler från webbsidor och andra program i Inbox Classic.

E-postlänkar (mailto:) öppnar ett nytt meddelande i ditt standardprogram för e-post.

Om du vill göra Inbox Classic till det programmet väljer du > . Windows öppnar inställningarna för standardappar, där du väljer Inbox Classic för MAILTO-länkar. Bara en installerad kopia visas där. Inbox Classic blir standardprogram för e-post direkt.

När du sedan klickar på en e-postlänk öppnas ett nytt meddelande med länkens adresser, ämne och text ifyllda. Inget annat från länken används.

Om du inte har något konto än ber Inbox Classic dig att lägga till ett först. Klicka på länken igen när kontot har lagts till.

Meddelandefiler

Om du vill att .eml-filer ska öppnas i Inbox Classic när du dubbelklickar på dem klickar du på i . Windows öppnar inställningarna för standardappar, där du väljer Inbox Classic för .eml-filer. Inbox Classic blir deras program direkt.
