Ta bort Inbox Classic

Ta bort Inbox Classic från datorn, med eller utan den e-post som hämtats.

Avinstallera Inbox Classic i Inställningar > Appar > Installerade appar. Du får frågan om den hämtade e-posten också ska tas bort.

Avsluta Inbox Classic och flytta programmet från Program till papperskorgen. Den hämtade e-posten finns kvar i ~/Library/Application Support/Inbox Classic tills du också tar bort den mappen.

Ta bort paketet med sudo apt remove inbox-classic, eller med sudo pacman -R inbox-classic på Arch Linux och Omarchy. Den hämtade e-posten finns kvar i ~/.local/share/inbox-classic tills du också tar bort den mappen.

E-posten på dina servrar tas aldrig bort.
