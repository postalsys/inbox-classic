Krypteringsfel

Vad du gör när en server inte erbjuder kryptering, eller kräver den där den är avstängd.

”the server does not offer STARTTLS”

Kontot är inställt på STARTTLS, men servern erbjöd ingen kryptering. Inbox Classic avbröt anslutningen före inloggning, så ditt lösenord skickades inte.

  1. Öppna kontots egenskaper i > .
  2. Om leverantören stöder SSL/TLS från anslutningens början väljer du det. Vanliga portar är 993 för inkommande och 465 för utgående e-post; kontrollera leverantörens anvisningar.
  3. Klicka på .

Om inget annat fungerar kan servern inte användas säkert.

”the server takes the password only over an encrypted connection”

Servern för utgående e-post är inställd på . Det här felet bekräftar inte att lösenordet är rätt. Ändra enligt leverantörens anvisningar till STARTTLS med port 587, eller SSL/TLS med port 465.

Varningen om en anslutning utan kryptering

När du väljer varnar Inbox Classic för att den som avlyssnar din nätverkstrafik kan läsa ditt lösenord och dina meddelanden. Fortsätt bara om anslutningen skyddas på annat sätt. Ett lokalt nätverk garanterar inte kryptering.
