Krypteringsfel

Vad du gör när en server inte erbjuder kryptering, eller kräver den där den är avstängd.

”the server does not offer STARTTLS”

Kontot är inställt på STARTTLS, men servern erbjöd ingen kryptering. Inbox Classic avbröt, så ditt lösenord skickades inte.

  1. Öppna kontots egenskaper i > .
  2. Ställ in säkerheten på SSL/TLS, med port 993 för inkommande e-post eller 465 för utgående e-post.
  3. Klicka på .

Om inget annat fungerar kan servern inte användas säkert.

”the server takes the password only over an encrypted connection”

Servern för utgående e-post är inställd på . Ditt lösenord är rätt. Ändra till STARTTLS med port 587, eller SSL/TLS med port 465.

Varningen om en anslutning utan kryptering

När du väljer varnar Inbox Classic för att den som avlyssnar din nätverkstrafik kan läsa ditt lösenord och dina meddelanden. Fortsätt bara för en server på din egen dator eller ditt lokala nätverk.
