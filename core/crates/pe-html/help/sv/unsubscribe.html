Lämna en e-postlista

Stoppa meddelandena från en e-postlista med knappen för att avsluta prenumerationen.

Ett meddelande från en e-postlista som talar om hur du lämnar den har till höger i huvudet.

Så här lämnar du listan:

  1. Klicka på . Inbox Classic talar om vad som kommer att hända och frågar först.
  2. Bekräfta. Beroende på listan händer en av tre saker:
    • Inbox Classic ber listan att sluta. Ingen sida öppnas och inget meddelande skickas.
    • Inbox Classic skriver det meddelande som listan vill ha. Klicka på för att skicka det.
    • Listans sida öppnas i webbläsaren, där du gör klart.

Statusfältet visar när listan har tagit emot begäran.

Inbox Classic ber listan att sluta av sig självt bara när listans server har signerat meddelandet. Ett påhittat meddelande kan inte använda det för att nå någon annan.
