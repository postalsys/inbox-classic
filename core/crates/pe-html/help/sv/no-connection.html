Inbox Classic kan inte ansluta

Vad du kan göra när e-postservern inte går att nå eller inte svarar.

Du kan se något av följande i statusfältet eller läsfönstret:

  • ”anslutningsfel: …”
  • ”servern svarade inte i tid”
  • ”anslutningen till servern misslyckades (…)”
  • ”Det gick inte att nå e-postservern (…).”

Så här åtgärdar du det:

  1. Kontrollera din internetanslutning.
  2. Öppna kontots egenskaper i > och kontrollera servernamnen och portarna.
  3. Om det inte går att skicka kontrollerar du leverantörens inställningar för utgående e-post. Kontrollera även säkerhetstypen: vanliga kombinationer är SSL/TLS med port 465 eller STARTTLS med port 587. Vissa nätverk blockerar e-postportarna, särskilt port 25.

Inbox Classic försöker igen nästa gång e-posten kontrolleras. Om du vill försöka nu klickar du på .

Ett meddelande som du skickar när det inte finns någon anslutning väntar i Utkorgen medan Inbox Classic försöker igen. Om sändningen misslyckas visas ett fel; kontrollera Utkorgen för att se om meddelandet fortfarande väntar.
