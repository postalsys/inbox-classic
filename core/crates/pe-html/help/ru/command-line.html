Параметры командной строки

Параметры для запуска Inbox Classic из терминала, для тестирования и для ИИ-агентов.

Запустите программу InboxClassic.exe"Inbox Classic.app/Contents/MacOS/Inbox Classic"inbox-classic с этими параметрами:

ПараметрДействие
--store <file>Использует другое хранилище почты, например тестовое
--memory-passwordsХранит пароли только на время этого запуска, никогда в системном хранилище паролей
--pin-certificate <file>Принимает только сертификат сервера из этого файла (PEM или DER), для тестового сервера с самоподписанным сертификатом
--sign-in-page-file <file>Записывает страницу входа через браузер в этот файл вместо открытия браузера
--language <code>Показывает окна на этом языке на время этого запуска, например de
--backgroundЗапускает программу без окна
--mcpПодключает ИИ-агента к Inbox Classic. Этот параметр использует программа агента, а не вы
--versionВыводит версию и завершает работу

Ссылка mailto:, переданная как аргумент, открывает новое сообщение, как ссылка на адрес электронной почты.
