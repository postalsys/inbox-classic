Параметры командной строки

Параметры для запуска Inbox Classic из терминала, для тестирования и для ИИ-агентов.

Запустите программу InboxClassic.exe"Inbox Classic.app/Contents/MacOS/Inbox Classic"inbox-classic с этими параметрами:

ПараметрДействие
--store <file>Использует указанный файл базы почты, например отдельную тестовую базу
--memory-passwordsХранит пароли и другие секретные данные только в памяти до выхода, без сохранения в системное хранилище
--pin-certificate <file>Принимает только сертификаты сервера из указанного файла: один или несколько в PEM либо один в DER. Подходит для тестового сервера с самоподписанным сертификатом
--sign-in-page-file <file>Записывает адрес страницы входа в указанный файл вместо открытия браузера
--language <code>Показывает окна на этом языке на время этого запуска, например de
--backgroundЗапускает программу без главного окна
--mcpПодключает ИИ-агента к Inbox Classic. Этот параметр использует программа агента, а не вы
--versionВыводит версию и завершает работу

Ссылка mailto:, переданная как аргумент, открывает новое сообщение, если уже настроена учетная запись.
