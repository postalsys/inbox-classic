Настройка, порядок и удаление учетных записей

Переименуйте учетную запись, измените ее параметры или пароль, расположите учетные записи в удобном порядке или удалите одну из них.

Изменение учетной записи

  1. Выберите > . В окне перечислены ваши учетные записи.
  2. Выделите одну и нажмите или дважды щелкните ее.
  3. Измените нужные параметры и нажмите .

  • : имя отправителя, которое видят получатели ваших сообщений.
  • Чтобы сохранить пароль, оставьте поле пустым.
  • В свойствах учетной записи со входом через браузер указано используемое приложение для входа.
  • В поле перечислите через запятую дополнительные адреса, с которых вы отправляете почту из этой учетной записи. Можно указать имя и адрес: Sales <sales@example.com> или просто адрес. После этого в поле под учетной записью можно будет выбрать любой из этих адресов.
  • Поле содержит серверы, результатам проверки отправителя которых доверяет учетная запись. Почтовый сервер записывает эти результаты в заголовки каждого сообщения. Inbox Classic использует доверенные результаты для проверки доменов отправителей. На их основе программа решает, показывать ли логотипы, одноразовые коды и варианты отписки и загружать ли изображения от доверенных отправителей. Значения по умолчанию берутся из настроек известных провайдеров или из доменов сервера входящей почты и вашего адреса электронной почты. Если провайдер записывает результаты под другим именем, например mx.example.net, укажите его здесь. Разделяйте несколько имен запятыми. Оставьте поле пустым, чтобы восстановить значения по умолчанию. После изменения сохраненная почта проверяется снова в фоновом режиме после синхронизации учетной записи.

Кнопка в том же окне добавляет еще одну учетную запись.

Удаление учетной записи

При удалении учетной записи с этого компьютера удаляются ее локальные данные, включая сообщения в очереди отправки, и сохраненные данные для входа. Почта на сервере остается; сообщения, которые есть только на этом компьютере, будут потеряны.

Чтобы удалить учетную запись:

  1. Выберите > .
  2. Выделите учетную запись и нажмите или, в Windows, клавишу Delete.
  3. Подтвердите удаление. Учетная запись исчезнет из списка папок.
