Inbox Classic как почтовая программа по умолчанию

Открывайте ссылки на адреса электронной почты и файлы сообщений из веб-страниц и других программ в Inbox Classic.

Ссылки на адреса электронной почты (mailto:) открывают новое сообщение в почтовой программе по умолчанию.

Чтобы сделать такой программой Inbox Classic, выберите > . Windows откроет параметры приложений по умолчанию, где нужно выбрать Inbox Classic для ссылок MAILTO. Там показывается только установленная копия. Inbox Classic запрашивает у системы назначение почтовой программой по умолчанию. Если это не удастся, появится сообщение об ошибке.

Когда вы затем щелкаете ссылку на адрес электронной почты, открывается новое сообщение с адресами, темой и текстом из ссылки. Другие параметры, включая вложения, из ссылки не используются.

Если у вас еще нет учетной записи, Inbox Classic попросит сначала добавить ее. После этого щелкните ссылку снова.

Файлы сообщений

Чтобы файлы .eml открывались в Inbox Classic двойным щелчком, нажмите в разделе . Windows откроет параметры приложений по умолчанию, где нужно выбрать Inbox Classic для файлов .eml. Inbox Classic запрашивает у системы назначение программой для этих файлов. Если это не удастся, появится сообщение об ошибке.
