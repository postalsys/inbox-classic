Удаление Inbox Classic

Удалите Inbox Classic с компьютера вместе с загруженной почтой или без нее.

Удалите Inbox Classic в разделе Параметры > Приложения > Установленные приложения. Программа предложит удалить также локальные данные: загруженную почту, настройки, контакты, ключи и очередь отправки.

Завершите работу Inbox Classic и переместите ее из папки «Программы» в Корзину. Загруженная почта остается в ~/Library/Application Support/Inbox Classic, пока вы не удалите и эту папку.

Удалите пакет командой sudo apt remove inbox-classic, в Fedora командой sudo dnf remove inbox-classic или, в Arch Linux и Omarchy, sudo pacman -R inbox-classic. Загруженная почта остается в ~/.local/share/inbox-classic, пока вы не удалите и эту папку.

Удаление программы или ее папки данных не удаляет почту на серверах. При удалении папки данных теряются также локальные настройки, контакты, ключи и сообщения, которые есть только на этом компьютере.

Чтобы удалить сохраненные данные для входа в учетные записи, сначала удалите каждую учетную запись в меню > . Другие записи в системном хранилище паролей, например секреты приложений для входа, могут сохраниться после удаления программы. Чтобы удалить только одну учетную запись, см. раздел .
