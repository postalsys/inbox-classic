Настройки

Выберите язык Inbox Classic, настройте отображение почты, уведомления и предварительную загрузку.

Выберите . Настройки разделены на три страницы: , и . Нажмите , чтобы сохранить изменения, или , чтобы применить их сразу. При смене языка может появиться предложение перезапустить Inbox Classic. Кнопка отменяет еще не сохраненные изменения, включая удаление надежных отправителей из списка. Назначение программы для почтовых ссылок и файлов .eml в системных настройках Windows при этом сохраняется. Изменения вступают в силу сразу, кроме языка: он меняется после перезапуска Inbox Classic.

  • Параметр определяет язык окон и справки: язык вашей системы или один из языков списка. Inbox Classic ищет поддерживаемый язык среди предпочитаемых языков системы. Если ни один не подходит, используется английский.
  • Параметр включает уведомления о новой почте. Они не показываются, пока главное окно на переднем плане, и могут быть заблокированы системой. По умолчанию это включено.
  • Параметр добавляет распознанный код для входа в уведомление, если проверка домена и условия показа кода выполнены. По умолчанию это выключено, так как уведомление можно прочитать на заблокированном экране. Пока уведомления выключены, этот параметр недоступен.
  • Параметр задерживает сообщение перед отправкой в папке «Исходящие» на несколько секунд, чтобы отправку еще можно было отменить. По умолчанию это 10 секунд.
  • Команда позволяет назначить Inbox Classic для почтовых ссылок, а для файлов сообщений. См. раздел .
  • Параметр время от времени проверяет, нет ли новой версии Inbox Classic. См. раздел .

Для смены языка нужен перезапуск Inbox Classic. Нажмите или , чтобы язык сменился при следующем запуске.

  • Параметр определяет макет: автоматический по ширине окна, классический или со столбцами. См. раздел .
  • Параметр объединяет исходное сообщение и ответы на него в беседу. По умолчанию это включено.
  • Параметр показывает логотипы брендов, изображения контактов и инициалы в макете со столбцами. По умолчанию это включено.
  • Параметр показывает сообщения, которые вы читаете и пишете, на темном фоне, когда в системе включен темный режим. По умолчанию это включено.
  • Параметр показывает изображения и первые страницы файлов PDF после текста сообщения. По умолчанию включено. Отключите , чтобы оставить только изображения. См. раздел .
  • Параметр включает автоматическую загрузку изображений, кроме сообщений в нежелательной почте. Для зашифрованных частей каждый раз требуется явное разрешение. По умолчанию параметр отключен: загрузка изображений может сообщить отправителю о прочтении. См. раздел .
  • Кнопка открывает список отправителей, для которых разрешена автоматическая загрузка изображений при подтвержденном домене. Здесь можно удалить их из списка. Исключения для нежелательной и зашифрованной почты сохраняются.
  • Параметр включает поиск по расшифрованным сообщениям. После загрузки Inbox Classic пытается расшифровать сообщения на этом компьютере с помощью доступных закрытых ключей. Если это удается, их текст и защищенные темы становятся доступны для поиска и списка сообщений. По умолчанию это включено. Расшифрованный текст и защищенные темы хранятся в локальном поисковом индексе без шифрования. Отключение параметра удаляет эти данные и возвращает внешние темы в список. ИИ-агенты не могут искать по расшифрованному содержимому.
  • Параметр разрешает поиск ключей на keys.openpgp.org. При поиске ключа получателя сначала проверяется его домен; серверу ключей передается адрес. При поиске ключа подписи передается отпечаток или идентификатор ключа. Поиск запускается при шифровании или по вашему запросу. По умолчанию это включено.

  • Параметр определяет, какие сообщения загружаются до открытия: по умолчанию это недавние сообщения размером до 1 МБ каждое. См. раздел .
  • Параметр задает целевой объем кеша содержимого для каждой учетной записи. По умолчанию это 1 ГБ. Черновики и сообщения, открытые после запуска, не удаляются, поэтому лимит может быть превышен.

Установщик спрашивает язык при первой установке и сохраняет его как язык, выбранный здесь.

Язык только для Inbox Classic можно также выбрать в разделе Системные настройки > Основные > Язык и регион.
