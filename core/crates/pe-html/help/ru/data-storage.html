Где хранятся почта и пароли

Что Inbox Classic хранит на вашем компьютере и где.

  • Загруженная почта и параметры учетных записей по умолчанию хранятся в %LOCALAPPDATA%\InboxClassic\store.db~/Library/Application Support/Inbox Classic/store.db~/.local/share/inbox-classic/store.db. Эти пути можно изменить параметрами запуска. База почты сама по себе не зашифрована. Сообщения, которые уже есть на сервере, остаются и там. Локальная копия нужна для быстрого чтения, работы без сети и поиска.
  • Пароли, токены входа через браузер и секреты приложений для входа по умолчанию сохраняются в диспетчере учетных данных Windows под именем InboxClassic, с шифрованием для вашей учетной записи Windows.связке ключей пользователя под именем InboxClassic, с шифрованием для вашей учетной записи Mac. Их можно просмотреть в приложении «Связка ключей».системном хранилище ключей с поддержкой Secret Service, например GNOME Keyring под именем InboxClassic, с шифрованием для вашей учетной записи пользователя. Если хранилище ключей недоступно, они хранятся только до выхода из Inbox Classic. При недоступном системном хранилище или режиме хранения только в памяти сохранение между запусками не гарантируется. В базе почты этих данных нет.
  • Ключи шифрования хранятся вместе с загруженной почтой. Ваши закрытые ключи зашифрованы там ключом, который хранится рядом с вашими паролями, поэтому одного файла хранилища почты недостаточно, чтобы их расшифровать.

Поиск, определение причин недоставки сообщений, группировка в беседы и поиск кодов для входа выполняются на вашем компьютере. Для этого ничего из вашей почты никуда не отправляется.
