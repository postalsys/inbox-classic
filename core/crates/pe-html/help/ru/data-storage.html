Где хранятся почта и пароли

Что Inbox Classic хранит на вашем компьютере и где.

  • Загруженная почта и параметры учетных записей хранятся в %LOCALAPPDATA%\InboxClassic\store.db~/Library/Application Support/Inbox Classic/store.db~/.local/share/inbox-classic/store.db. Ваша почта остается и на сервере. Копия здесь нужна для быстрого чтения, работы без сети и поиска.
  • Пароли, данные входа через браузер и секреты приложений для входа хранятся в диспетчере учетных данных Windows под именем InboxClassic, в зашифрованном для вашей учетной записи Windows виде.вашей связке ключей входа под именем InboxClassic, в зашифрованном для вашей учетной записи Mac виде. Их показывает приложение «Связка ключей».вашей связке ключей (GNOME Keyring) под именем InboxClassic, в зашифрованном для вашего входа виде. Без связки ключей они хранятся только до выхода из Inbox Classic. В хранилище почты их никогда нет.

Поиск, объяснение недоставленных сообщений, группировка в беседы и поиск кодов для входа выполняются на вашем компьютере. Для этого ничего из вашей почты никуда не отправляется.
