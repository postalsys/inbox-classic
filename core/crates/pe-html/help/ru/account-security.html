Параметры безопасности учетной записи

Как защищены подключения к почтовым серверам и чем отличаются доступные варианты.

У каждой учетной записи есть параметр для сервера входящей почты и для сервера исходящей. Inbox Classic выбирает подходящие значения, когда находит параметры вашего провайдера. Чтобы изменить их, откройте свойства учетной записи в меню > .

ПараметрЗначение
SSL/TLSСоединение шифруется с самого начала. Обычно порт 993 для входящей почты и 465 для исходящей.
STARTTLSСоединение шифруется сразу после открытия. Обычно порт 143 для входящей почты и 587 для исходящей. Inbox Classic прерывает подключение, если сервер не предлагает шифрование.
Ваш пароль и почта передаются в открытом виде, и их может прочитать любой в сети.
Используйте вариант только для сервера на своем компьютере или в доверенной локальной сети. Сама по себе локальная сеть не защищает передаваемые данные. Перед таким подключением Inbox Classic покажет предупреждение.

При защищенном подключении Inbox Classic по умолчанию проверяет сертификат сервера по доверенным сертификатам системы. Принимать любые сертификаты без проверки нельзя.

По умолчанию пароль сохраняется в диспетчере учетных данных Windowsсвязке ключей пользователясистемном хранилище ключей, а не в хранилище почты. При входе через браузер Inbox Classic сохраняет токен для продления доступа, а не пароль учетной записи. Если системное хранилище недоступно или выбран режим хранения только в памяти, данные могут не сохраниться после выхода.
