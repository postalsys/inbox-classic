Параметры безопасности учетной записи

Параметры безопасности серверов учетной записи и значение каждого из них.

У каждой учетной записи есть параметр для сервера входящей почты и для сервера исходящей. Inbox Classic заполняет их, когда находит параметры вашего провайдера. Чтобы изменить их, откройте свойства учетной записи в меню > .

ПараметрЗначение
SSL/TLSСоединение шифруется с самого начала. Обычно порт 993 для входящей почты и 465 для исходящей.
STARTTLSСоединение шифруется сразу после открытия. Обычно порт 143 для входящей почты и 587 для исходящей. Inbox Classic прерывает подключение, если сервер не предлагает шифрование.
Ваш пароль и почта передаются в открытом виде, и их может прочитать любой в сети.
Используйте вариант только для сервера на вашем компьютере или в локальной сети. Inbox Classic предупреждает вас, прежде чем его использовать.

Inbox Classic проверяет, что каждый сервер действительно тот, за кого себя выдает, по сертификатам, которым доверяет ваша система. Переключателя, позволяющего принимать любой сертификат, нет.

Ваш пароль хранится в диспетчере учетных данных Windowsвашей связке ключей входавашей связке ключей, а не в хранилище почты. Учетная запись, которая входит через браузер, вообще не хранит пароль.
