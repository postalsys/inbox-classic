Ключи шифрования

Создайте ключ, чтобы подписывать сообщения и получать зашифрованную почту, и храните ключи своих контактов.

Inbox Classic подписывает и шифрует почту ключами OpenPGP. Ваш ключ состоит из открытой и закрытой частей. Открытый ключ можно передавать другим, а закрытый остается на вашем компьютере. Ключи ваших контактов позволяют проверять их подписи и шифровать для них почту.

Чтобы создать ключ:

  1. Выберите > и нажмите .
  2. Выберите учетную запись и нажмите . Ключ используется для адреса учетной записи и ее других адресов.
  3. Нажмите и придумайте парольную фразу. Храните файл и парольную фразу в разных надежных местах.
Храните резервную копию своего закрытого ключа. Если компьютер будет утерян или сброшен, без резервной копии вы не сможете восстановить ключ и можете лишиться возможности расшифровать старую почту.

Ключи защищены без парольных фраз

Ваши закрытые ключи защищены ключом, который хранится в диспетчере учетных данных Windowsсвязке ключей пользователясистемном хранилище ключей, поэтому для их использования не нужно вводить парольную фразу. Парольная фраза выбирается только для резервной копии. Если ключ отмечен как недоступный, сначала проверьте, доступно ли системное хранилище ключей и разблокировано ли оно. Если защитный ключ утерян, нажмите и выберите резервную копию закрытого ключа.

Добавление ключей

Нажмите , чтобы добавить ключ из файла, присланного контактом, или восстановить собственный ключ из резервной копии. Если закрытый ключ защищен парольной фразой, ее нужно ввести один раз. Затем Inbox Classic спросит, использовать ли импортированный собственный ключ для ваших адресов.

Чтобы добавить ключ, скопированный как текст, нажмите . Чтобы добавить открытый ключ, вложенный в сообщение, откройте меню вложения и выберите . Непосредственно из почты можно импортировать только открытые ключи. Чтобы восстановить свой закрытый ключ, сохраните вложение и импортируйте его файл здесь.

С этого момента ключ контакта используется для его адреса. Если позже появится другой ключ для того же адреса, продолжает использоваться текущий, пока вы не выберете новый в свойствах контакта.

Чтобы поделиться открытым ключом, выделите его и нажмите . Ключ учетной записи можно также выбрать в ее свойствах, на вкладке .

Поиск ключей

Когда вы включаете шифрование для получателя, у которого нет ключа, Inbox Classic сначала ищет его через домен адреса, затем на keys.openpgp.org, если этот поиск включен. Чтобы самостоятельно найти отсутствующий или непригодный для использования ключ контакта, откройте контакт в адресной книге и нажмите . Адресная книга отмечает контакты с подходящими для шифрования ключами, а более заметный значок указывает на ключи с подтвержденным владельцем.

В сообщении, подписанном ключом, которого у вас нет, указано, что ключ неизвестен. Нажмите рядом с этой пометкой, чтобы найти его на keys.openpgp.org. Отправляется отпечаток или идентификатор ключа из подписи, а не адрес электронной почты. Если ключ найден, Inbox Classic снова проверяет подпись и обновляет пометку. Обнаружение ключа не подтверждает его владельца.

Чтобы отключить поиск ключей на keys.openpgp.org, отключите параметр в разделе .

Публикация своего ключа

Чтобы другие могли найти ваш ключ, выделите один из своих ключей и нажмите . Inbox Classic отправляет его открытую часть на keys.openpgp.org и запрашивает ссылки для подтверждения адресов, которых еще нет в каталоге. Откройте каждую ссылку, чтобы ключ можно было найти по соответствующему адресу. Адреса, уже внесенные в каталог, не требуют повторного подтверждения.

Ключи, передаваемые с почтой

Ключи передаются и вместе с почтой. Если Autocrypt включен и для адреса отправителя выбран ключ, сообщения содержат его открытую часть. Другие почтовые программы могут использовать ее, чтобы шифровать сообщения для вас. При открытии сообщения с ключом отправителя Inbox Classic сохраняет этот ключ без подтверждения его владельца. Если для адреса уже используется другой ключ, новый ожидает вашего решения. Чтобы больше не отправлять свой ключ, отключите на вкладке учетной записи.

Просроченные, отозванные и удаленные ключи

Просроченный или отозванный ключ отмечается в списке и больше не используется для нового шифрования. Последующее истечение срока действия ключа само по себе не делает недействительными подписи, созданные, пока ключ был действителен. Чтобы прекратить использование ключа, выделите его и нажмите . Перед удалением своего ключа сохраните резервную копию: она может понадобиться для расшифровки старой почты.
