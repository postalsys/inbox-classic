Sair de uma lista de correio

Pare as mensagens de uma lista de correio com o botão Cancelar subscrição.

Uma mensagem de uma lista de correio que indica como sair dela tem à direita do cabeçalho.

Para sair da lista:

  1. Clique em . O Inbox Classic diz o que vai acontecer e pergunta primeiro.
  2. Confirme. Consoante a lista, acontece uma de três coisas:
    • O Inbox Classic pede à lista que pare. Não abre nenhuma página nem é enviada nenhuma mensagem.
    • O Inbox Classic escreve a mensagem que a lista pede. Clique em para a enviar.
    • A página da lista abre no seu browser, onde termina o processo.

A barra de estado indica quando a lista aceitou o pedido.

O Inbox Classic só pede à lista que pare por si quando o servidor da lista assinou a mensagem. Uma mensagem falsa não o pode usar para contactar outra pessoa.
