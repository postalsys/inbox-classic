Definições de segurança da conta

As definições de segurança dos servidores de uma conta, e o que cada uma significa.

Nas propriedades de cada conta, encontra para o servidor de receção e para o de envio. O Inbox Classic preenche estas opções quando encontra as definições do seu fornecedor. Para as alterar, abra as propriedades da conta em > .

DefiniçãoSignificado
SSL/TLSA ligação é encriptada desde o início. Normalmente a porta 993 para o correio recebido e 465 para o correio enviado.
STARTTLSA ligação é encriptada logo depois de ser aberta. Normalmente a porta 143 para o correio recebido e 587 para o correio enviado. O Inbox Classic interrompe a ligação se o servidor não oferecer encriptação.
A sua palavra-passe e o seu correio são transmitidos sem encriptação e podem ser lidos por quem intercete o tráfego.
Use apenas quando compreender e aceitar esse risco. Uma rede local, por si só, não protege a ligação. O Inbox Classic mostra um aviso antes de usar esta opção.

Nas ligações encriptadas, o Inbox Classic verifica a identidade do servidor com base nos certificados em que o sistema confia. Não existe uma opção para aceitar qualquer certificado. Pela linha de comandos, é possível fixar o certificado esperado de um servidor.

Por predefinição, as credenciais ficam guardadas no Gestor de Credenciais do Windowsno seu porta-chaves de início de sessãono seu porta-chaves, quando esse armazenamento está disponível. Não ficam na base de dados do correio. O modo apenas em memória não as conserva após fechar a aplicação. O início de sessão pelo browser guarda uma credencial de renovação, em vez da palavra-passe da conta.
