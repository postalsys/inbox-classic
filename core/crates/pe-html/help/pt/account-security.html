Definições de segurança da conta

As definições de segurança dos servidores de uma conta, e o que cada uma significa.

Cada conta tem para o servidor de receção e para o de envio. O Inbox Classic preenche-as quando encontra as definições do seu fornecedor. Para as alterar, abra as propriedades da conta em > .

DefiniçãoSignificado
SSL/TLSA ligação é encriptada desde o início. Normalmente a porta 993 para o correio recebido e 465 para o correio enviado.
STARTTLSA ligação é encriptada logo depois de ser aberta. Normalmente a porta 143 para o correio recebido e 587 para o correio enviado. O Inbox Classic para se o servidor não oferecer encriptação.
A sua palavra-passe e o seu correio circulam de forma legível para qualquer pessoa na rede.
Use apenas para um servidor no seu próprio computador ou na sua rede local. O Inbox Classic avisa-o antes de a usar.

O Inbox Classic verifica se cada servidor é quem diz ser, com base nos certificados em que o seu sistema confia. Não existe nenhuma opção para aceitar qualquer certificado.
