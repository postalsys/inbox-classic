Opções da linha de comandos

Opções para iniciar o Inbox Classic a partir de um terminal, para testes e para agentes de IA.

Inicie o programa InboxClassic.exe"Inbox Classic.app/Contents/MacOS/Inbox Classic"inbox-classic com estas opções:

OpçãoFunção
--store <file>Usa outra base de dados de correio, por exemplo para testes
--memory-passwordsMantém as credenciais apenas durante esta execução, sem as guardar no armazenamento do sistema; as novas chaves privadas precisam de uma cópia de segurança para serem usadas após reiniciar
--pin-certificate <file>Aceita os certificados indicados no ficheiro PEM, ou o certificado único de um ficheiro DER; confirme previamente a origem dos certificados
--sign-in-page-file <file>Guarda neste ficheiro o URL da página de início de sessão, em vez de abrir o browser
--language <code>Mostra as janelas neste idioma durante esta execução, como de
--backgroundInicia em segundo plano, sem mostrar a janela principal
--mcpLiga um agente de IA ao Inbox Classic. Esta opção é usada pelo programa do agente para estabelecer a ligação
--versionMostra a versão e termina

Uma ligação mailto: indicada como argumento abre uma nova mensagem, tal como uma ligação de e-mail.
