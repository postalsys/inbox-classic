Opções da linha de comandos

Opções para iniciar o Inbox Classic a partir de um terminal, para testes e para agentes de IA.

Inicie o programa InboxClassic.exe"Inbox Classic.app/Contents/MacOS/Inbox Classic"inbox-classic com estas opções:

OpçãoFunção
--store <file>Usa outro armazenamento de correio, como um para testes
--memory-passwordsGuarda as palavras-passe apenas durante esta execução, nunca no armazenamento de palavras-passe do sistema
--pin-certificate <file>Aceita apenas o certificado de servidor deste ficheiro (PEM ou DER), para um servidor de teste com um certificado autoassinado
--sign-in-page-file <file>Escreve a página de um início de sessão no browser neste ficheiro em vez de abrir o browser
--language <code>Mostra as janelas neste idioma durante esta execução, como de
--backgroundInicia sem a janela
--mcpLiga um agente de IA ao Inbox Classic. É o programa do agente que o inicia, não o utilizador
--versionMostra a versão e termina

Uma ligação mailto: indicada como argumento abre uma nova mensagem, tal como uma ligação de e-mail.
