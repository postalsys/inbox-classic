Atualizar o Inbox Classic

Obtenha a versão mais recente do Inbox Classic.

Para ver que versão tem, escolha > Inbox Classic > .

Transfira o instalador mais recente de inboxclassic.com e execute-o. O instalador atualiza a aplicação existente. As suas contas e o correio transferido para elas são mantidos.

O Inbox Classic procura atualizações automaticamente se essa opção estiver ativada. Siga as instruções do atualizador para as instalar. Para verificar se há atualizações agora, escolha Inbox Classic > .

Se instalou o Inbox Classic a partir do respetivo repositório apt, as novas versões chegam com as atualizações do sistema. Se instalou um ficheiro .deb, transfira o mais recente de inboxclassic.com e instale-o para atualizar a versão existente.

No Fedora, o pacote adiciona o repositório do Inbox Classic ao ser instalado, pelo que as novas versões chegam com sudo dnf upgrade e com as atualizações do sistema.

No Arch Linux, instale o pacote mais recente com sudo pacman -U da mesma forma. No Omarchy, use a função Update se a sua instalação estiver integrada nesse mecanismo; caso contrário, atualize pelo método usado para instalar.

As suas contas, o correio e as definições são mantidos entre atualizações.
