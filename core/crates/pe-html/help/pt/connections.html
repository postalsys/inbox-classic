As ligações que o Inbox Classic estabelece

Onde o Inbox Classic se liga, e porquê, para os mais curiosos em termos técnicos.

  • Os seus servidores de correio, por IMAP para ler o correio e por SMTP para o enviar. As ligações são encriptadas com TLS, e o certificado de cada servidor é verificado com base nos certificados em que o seu sistema confia. O Inbox Classic recusa um servidor sem encriptação, a não ser que escolha e confirme.
  • Quando adiciona uma conta, para procurar os respetivos servidores. O Inbox Classic lê os registos DNS do seu domínio através de DNS over HTTPS (Cloudflare e depois Google), nunca por DNS simples. Também experimenta o ficheiro autoconfig do seu fornecedor e a lista de fornecedores do Thunderbird (ISPDB). Para o Exchange, pergunta à Deteção Automática da Microsoft, que só recebe a sua palavra-passe quando a pede por HTTPS. Nunca é escolhido um servidor sem encriptação.
  • Início de sessão no browser, com OAuth 2.0 e PKCE, na Google, na Microsoft ou no fornecedor da sua aplicação de início de sessão. O browser regressa ao Inbox Classic apenas neste computador.
  • Logótipos de marcas (BIMI), a partir do endereço HTTPS da marca quando a mensagem não traz o logótipo, uma vez por cada execução do Inbox Classic. Isto só acontece quando o seu servidor de correio aprovou a verificação DMARC da mensagem e o logótipo.
  • Imagens da Internet, só quando as pede.
  • Cancelar subscrição, só quando clica nesse botão. Um pedido com um clique (RFC 8058) só é enviado quando a lista assinou a mensagem com DKIM.
  • Chaves de encriptação, só quando encripta para alguém cuja chave não tem: o domínio do endereço dessa pessoa (Web Key Directory) e depois keys.openpgp.org, a menos que o tenha desativado. Só o endereço é enviado.
  • Atualizações, a partir de inboxclassic.com, para ver se saiu uma nova versão.

Os códigos de início de sessão só são oferecidos quando o cabeçalho Authentication-Results do seu fornecedor indica que o domínio assinou a mensagem (DKIM). Isto não precisa de nenhuma ligação própria.
