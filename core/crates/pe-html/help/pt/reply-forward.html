Responder e reencaminhar

Responda ao remetente ou a todos, ou reencaminhe uma mensagem para outra pessoa.

  • () responde ao endereço Reply-To, se existir, ou ao remetente.
  • () responde ao remetente e aos destinatários de Para e Cc, excluindo os seus próprios endereços.
  • () reencaminha a mensagem para os destinatários que indicar.

As respostas e os reencaminhamentos são enviados a partir da conta que contém a mensagem original. Se esta foi recebida num dos outros endereços configurados na conta, esse endereço é usado como remetente.

A mensagem original

Numa resposta, a mensagem original fica recolhida atrás de um botão ••• por baixo do seu texto, para ver apenas o que escreve. É incluída no envio mesmo que continue recolhida. Para editar ou encurtar o texto citado, clique no botão, ou selecione tudo com Ctrl+A⌘A: a mensagem original passa então a fazer parte do seu texto.

Num reencaminhamento, a mensagem original está no texto desde o início, para que a possa editar antes do envio.

Uma resposta segue o formato da mensagem original. Uma resposta a uma mensagem de texto simples é texto simples, com a mensagem original citada com >, a menos que acrescente formatação.
