Códigos de início de sessão

Uma mensagem com um código de início de sessão ou de verificação apresenta o código num painel, com um botão para o copiar.

Quando uma mensagem tem um código de utilização única, como um código de início de sessão, de verificação ou de aprovação, um painel acima da mensagem mostra:

  • «Código de» e o domínio a que o código se destina
  • o código, em letra grande
  • , que coloca o código na área de transferência
Introduza um código apenas numa página do domínio indicado no painel. Uma mensagem que lhe peça para escrever um código noutro sítio pode ser uma tentativa de se apoderarem da sua conta.

O painel só aparece quando o seu fornecedor de correio confirma que o domínio assinou a mensagem. Se o domínio não puder ser confirmado, o código não é apresentado. O painel também não aparece em , ou , nem quando o seu fornecedor não fornece os resultados dessa verificação.

Um código enviado mais de uma hora antes de o abrir provavelmente já expirou, e o painel avisa dessa possibilidade.
