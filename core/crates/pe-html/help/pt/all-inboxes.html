A Caixa de Entrada de cada conta

Por baixo de , a Caixa de Entrada de cada conta tem uma linha própria, com o nome da conta e o número de mensagens não lidas. Selecione uma linha para ver só essa Caixa de Entrada. É aqui que fica a Caixa de Entrada de cada conta: a própria conta, mais abaixo, mostra as outras pastas.

As linhas seguem a ordem das suas contas. Para mudar a ordem, arraste uma linha para cima ou para baixo de outra. Consulte .
