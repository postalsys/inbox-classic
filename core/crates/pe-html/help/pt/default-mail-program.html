Definir o Inbox Classic como aplicação de correio predefinida

Abra no Inbox Classic as ligações de e-mail e os ficheiros de mensagens de páginas web e de outros programas.

As ligações de e-mail (mailto:) abrem uma nova mensagem na sua aplicação de correio predefinida.

Para definir o Inbox Classic como aplicação de correio predefinida, escolha > . O Windows abre as definições de Aplicações predefinidas, onde escolhe o Inbox Classic para as ligações MAILTO. O Inbox Classic só aparece nessa lista se tiver sido instalado. O Inbox Classic passa a ser de imediato a aplicação de correio predefinida.

A partir daí, ao clicar numa ligação de e-mail, abre-se uma nova mensagem com os endereços, o assunto e o texto da ligação já preenchidos. Os restantes dados da ligação são ignorados.

Se ainda não tiver nenhuma conta, o Inbox Classic pede-lhe que adicione uma primeiro. Depois de a adicionar, clique novamente na ligação.

Ficheiros de mensagens

Para abrir os ficheiros .eml no Inbox Classic quando faz duplo clique neles, clique em em > Inbox Classic > > . O Windows abre as definições de Aplicações predefinidas, onde escolhe o Inbox Classic para os ficheiros .eml. O Inbox Classic passa a ser de imediato a aplicação predefinida para abrir esses ficheiros.
