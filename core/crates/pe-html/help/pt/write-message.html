Escreva e envie uma nova mensagem, com formatação, ligações e imagens.

Se o assunto ou o texto contiver uma palavra reconhecida como referência a um anexo, como a palavra inglesa «attached», mas não houver nenhum ficheiro anexado, o Inbox Classic pede confirmação antes de enviar a mensagem. O aviso só reconhece determinadas palavras em inglês, alemão, estónio, espanhol e francês.

Formatação

A barra por cima do texto tem o tipo de letra, negrito, itálico, sublinhado, cor, listas, avanço, alinhamento, ligações, uma linha divisória e imagens. Para colocar uma imagem no texto, clique em ou arraste um ficheiro de imagem do Explorador de Ficheirosdo Finderdo gestor de ficheiros para o texto.

Uma mensagem sem formatação é enviada como texto simples, que todos os programas de correio conseguem apresentar. Uma mensagem formatada é enviada como HTML com uma cópia em texto simples.
