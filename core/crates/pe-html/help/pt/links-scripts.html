Ligações, scripts e anexos

Como o Inbox Classic impede que uma mensagem execute código ou abra páginas por si.

  • Os scripts das mensagens nunca são executados. O Inbox Classic limpa cada mensagem antes de a mostrar, e o painel de leitura não pode executar código.
  • As ligações abrem no seu browser, nunca dentro do Inbox Classic. Uma mensagem não pode abrir uma página ou uma janela por si.
  • Os anexos são guardados, nunca abertos a partir do Inbox Classic. Os nomes são tornados seguros antes de os guardar.
  • Cancelar subscrição pergunta-lhe primeiro e diz o que vai fazer.
Antes de escrever uma palavra-passe numa página a que chegou a partir de uma mensagem, verifique o endereço no browser. Uma mensagem pode mostrar um endereço e apontar para outro.

Quando escreve uma mensagem, a barra de estado mostra para onde aponta a ligação no cursor, para que a possa verificar antes de enviar.
