Ligações, scripts e anexos

Como o Inbox Classic impede que uma mensagem execute código ou abra páginas automaticamente.

  • Os scripts das mensagens nunca são executados. O Inbox Classic remove conteúdo potencialmente perigoso antes de apresentar cada mensagem, incluindo scripts e elementos ativos da mensagem. Os scripts próprios da aplicação continuam a funcionar.
  • As ligações web abrem no seu browser, nunca dentro do Inbox Classic. Uma mensagem não pode abrir uma página ou uma janela automaticamente.
  • Os anexos são guardados antes de serem abertos numa aplicação externa. Os tipos reconhecidos de programas, scripts e outros ficheiros ativos têm a abertura direta bloqueada; isso não garante que qualquer outro ficheiro seja seguro. Os nomes são tratados para remover carateres que os possam disfarçar.
  • Cancelar subscrição pede confirmação e explica a ação antes de a executar.
Antes de escrever uma palavra-passe numa página a que chegou a partir de uma mensagem, verifique o endereço no browser. Uma mensagem pode mostrar um endereço e apontar para outro.

Quando escreve uma mensagem, a barra de estado mostra a ligação sob o ponteiro do rato ou, na ausência dela, junto ao cursor de texto, para que a possa verificar antes de enviar.

Um código de início de sessão só é apresentado quando o seu fornecedor de correio confirma uma assinatura do domínio do código ou de um domínio superior; isso não confirma a identidade da pessoa. Consulte .

O Inbox Classic converte as imagens incorporadas para as apresentar e remove tipos de letra fornecidos pela mensagem. As imagens externas autorizadas seguem outro percurso; esta proteção não significa que nenhum dado de imagem chegue ao visualizador do sistema.
