Ligações, scripts e anexos

Como o Inbox Classic impede que uma mensagem execute código ou abra páginas automaticamente.

  • Os scripts das mensagens nunca são executados. O Inbox Classic remove conteúdo potencialmente perigoso antes de apresentar cada mensagem, e o painel de leitura não pode executar código.
  • As ligações abrem no seu browser, nunca dentro do Inbox Classic. Uma mensagem não pode abrir uma página ou uma janela automaticamente.
  • Os anexos são guardados antes de serem abertos numa aplicação externa. Tipos de ficheiros que podem executar código não podem ser abertos diretamente pelo Inbox Classic. Os nomes são tratados para remover carateres que os possam disfarçar.
  • Cancelar subscrição pede confirmação e explica a ação antes de a executar.
Antes de escrever uma palavra-passe numa página a que chegou a partir de uma mensagem, verifique o endereço no browser. Uma mensagem pode mostrar um endereço e apontar para outro.

Quando escreve uma mensagem, a barra de estado mostra para onde aponta a ligação onde se encontra o cursor, para que a possa verificar antes de enviar.

Um código de início de sessão só é apresentado quando o seu fornecedor de correio confirma o domínio do remetente. Consulte .

As imagens e os tipos de letra de uma mensagem nunca chegam aos descodificadores do sistema.
