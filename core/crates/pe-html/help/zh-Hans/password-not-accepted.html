密码未被接受

邮件服务器拒绝您的密码或登录时该怎么办。

文件夹列表中的帐户旁会出现警告。如果您只有一个帐户，警告会出现在其收件箱旁。将指针指向警告可查看详细信息。邮件列表上方的提示栏会说明如何处理。状态栏和系统托盘图标Dock 图标也会显示此问题。

Inbox Classic 会避免重复显示相同的提示，并降低自动重试的频率，以减少被拒绝的登录尝试。要立即重试，请单击。

使用密码的帐户

  1. 单击警告图标或提示栏中的，然后重新输入密码。您也可以在 > 中的帐户属性里更改密码。
  2. 如果您的提供商要求使用应用密码，请在其安全设置中创建一个，并用它代替平时的密码。
  3. Gmail 的应用密码需要两步验证，而且您的帐户可能无法使用。Outlook.com 和 Microsoft 365 在 Inbox Classic 中需要通过浏览器登录。请参阅。

通过浏览器登录的帐户

Inbox Classic 询问“”时，请选择并重新登录。如果选择，您可以稍后通过警告图标或提示栏中的登录。您也可以使用 > 或帐户属性。

您的提供商或组织可能会要求重新登录，例如在密码更改后。

  • 如果需要管理员批准，请选择并将链接发送给管理员。重新登录不能代替此批准。
  • 如果 IMAP 已关闭，请在邮箱设置中将其打开，或向管理员求助。
  • 如果您使用了另一个地址登录，请选择，然后在提供商的页面上选择正确的帐户。
  • 提供商的服务暂时中断时，Inbox Classic 会等待并重试，不会要求您登录。

如果使用登录应用，还应检查其范围是否允许访问邮件。请参阅。
