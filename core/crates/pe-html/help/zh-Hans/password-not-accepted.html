密码未被接受

邮件服务器拒绝您的密码或登录时该怎么办。

您可能会看到以下提示之一：

  • 状态栏中：“服务器未接受登录（…）”
  • 阅读窗格中：“邮件服务器未接受登录（…）。请检查密码，或在帐户设置中重新登录。”
  • 一个要求您重新输入帐户密码的窗口

要解决此问题，请：

  1. 在 Inbox Classic 询问时重新键入密码，或在 > 中的帐户属性里更改密码。
  2. 如果您的提供商要求邮件程序使用应用密码，请在帐户的安全设置中创建一个，并用它代替平时的密码。
  3. 对于 Gmail，请通过浏览器登录；如果您的帐户允许且已打开两步验证，也可以使用应用密码。对于 Outlook.com 和 Microsoft 365，请通过浏览器登录：在 Inbox Classic 中，这些帐户无法用应用密码代替浏览器登录。请参阅。

通过浏览器登录的帐户

提供商终止登录时，Inbox Classic 会提示“…的登录被拒绝，或会话已过期。”并询问“”。选择，然后在浏览器中重新登录一次。

如果服务器拒绝登录应用的令牌，请检查该应用的范围是否包含邮件访问。请参阅。
