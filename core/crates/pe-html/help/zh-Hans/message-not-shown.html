邮件未显示

邮件仍在下载、无法下载或无法显示时该怎么办。

“正在下载邮件…”

邮件在您第一次打开时下载。刚添加帐户时，大多数邮件还不在您的计算机上。发件人和主题可能在内容下载完成之前就已显示。下载时间取决于网络连接和邮件大小。

“无法下载邮件”

窗格中会说明原因，例如无法连接到邮件服务器。下载失败的已打开邮件会在帐户同步后重试。要立即重试，请单击邮件上方栏中的。

如果登录被拒绝，请参阅。如果无法建立安全连接，请参阅。

“无法显示此邮件”

Inbox Classic 无法读取该邮件，例如邮件已损坏或使用了不受支持的结构。其他邮件程序也许仍能读取它。您的其他邮件不受影响。要查看邮件包含的内容，请选择 > 。

“”

Inbox Classic 使用 Microsoft Edge WebView2 Runtime 显示邮件。如果缺少该运行时，请从 Microsoft 安装它，然后重新启动 Inbox Classic。安装了 Edge 浏览器并不一定表示该运行时可用。
