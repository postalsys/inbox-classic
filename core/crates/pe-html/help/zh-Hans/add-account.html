添加邮件帐户

通过浏览器登录，或使用地址和密码，添加您的第一个帐户或其他帐户。

Inbox Classic 第一次启动时会打开。以后要添加其他帐户，请选择 > 。

Gmail、Google Workspace、Outlook.com 或 Microsoft 365

要通过浏览器添加帐户，请：

  1. 单击或。Web 浏览器会打开该提供商的登录页面。
  2. 在那里登录，然后回到 Inbox Classic。帐户即被添加，邮件开始到达。

呈灰色的按钮在这台计算机上已关闭。单击其下方的可查看原因。

其他 IMAP 和 SMTP 帐户

要使用密码添加帐户，请：

  1. 在中键入希望别人看到的姓名。
  2. 在中键入您的地址。
  3. 单击。Inbox Classic 会查找提供商的设置，这可能需要几秒钟。会停止查找。在 Windows 和 Linux 上，设置将以手动设置继续；在 Mac 上，则取消添加帐户。
  4. 在中键入您的密码。
  5. 检查服务器设置，然后单击。Inbox Classic 会登录并下载您的文件夹。

如果提供商要求使用应用密码而非常用密码，Inbox Classic 会告诉您，并提出打开提供商的说明。

未找到设置时，服务器名称是猜测的：imap. 和 smtp. 后接您的域名。请将其与提供商提供的信息进行核对。
