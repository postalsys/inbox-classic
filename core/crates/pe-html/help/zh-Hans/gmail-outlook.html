Gmail 和 Outlook.com

对 Gmail、Outlook.com 和 Microsoft 365 使用浏览器登录；符合条件的 Google 帐户也可以使用应用密码。

Google 和 Microsoft 不允许邮件程序使用您平常的密码。在 Inbox Classic 中，请对 Outlook.com 和 Microsoft 365 使用浏览器登录。只有在您的帐户允许时，才能使用 Google 应用密码。

通过浏览器登录

在中单击或。您在 Google 或 Microsoft 自己的页面上键入密码，因此 Inbox Classic 永远看不到它。这样的帐户始终使用提供商自己的邮件服务器。

Microsoft 365 组织可能需要先允许 Inbox Classic。此时 Microsoft 会显示 Need admin approval（需要管理员批准），Inbox Classic 会告诉您管理员进行批准的地址。

默认处于关闭状态。在此配置中，内置的 Google 登录应用仅供测试用户使用。请使用您自己的登录应用，或者在帐户允许时使用应用密码（请参阅）。

使用应用密码

Google 应用密码要求启用两步验证，并且并非所有帐户都能使用。例如，工作或学校的策略以及高级保护功能可能会阻止使用它。

  1. 在 Google 帐户的安全设置中打开应用专用密码，如果有此选项，请创建一个密码。
  2. 在中键入您的姓名和地址，然后单击。
  3. 单击。
  4. 在中键入应用密码，然后单击。

登录过期时

如果 Google 或 Microsoft 结束了登录，Inbox Classic 会提示“…的登录被拒绝，或会话已过期。”并询问是否在浏览器中重新登录。请选择并再次登录。
