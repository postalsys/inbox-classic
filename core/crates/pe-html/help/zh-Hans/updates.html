更新 Inbox Classic

获取最新版本的 Inbox Classic。

要查看您使用的版本，请选择 > Inbox Classic > 。

从 inboxclassic.com 下载最新的安装程序并运行。它会就地更新已安装的程序。您的帐户及为其下载的邮件都会保留。

如果此版本支持更新并已启用自动检查，Inbox Classic 会检查新版本。按照更新程序的提示安装更新。要立即检查，请选择 Inbox Classic > 。

如果您是从 apt 软件源安装的 Inbox Classic，新版本会随系统自身的更新一起提供。如果您安装的是 .deb 文件，请从 inboxclassic.com 下载较新的文件，并覆盖安装旧版本。

在 Arch Linux 上，用 sudo pacman -U 以同样方式安装较新的软件包。在 Omarchy 上，其自带的“更新”会带来新版本。

更新后，您的帐户、邮件和设置都会保留。
