Inbox Classic 无法连接

无法连接到邮件服务器或服务器没有响应时该怎么办。

您可能会在状态栏或阅读窗格中看到以下内容之一：

  • “connection error: …”
  • “the server did not answer in time”
  • “与服务器的连接失败（…）”
  • “无法连接到邮件服务器，或连接已中断（…）。”

要解决此问题，请：

  1. 检查您的 Internet 连接。
  2. 在 > 中打开帐户属性，检查服务器名称和端口。
  3. 如果发送失败，请检查发送服务器的安全设置和端口：通常是端口 465 上的 SSL/TLS，或端口 587 上的 STARTTLS。有些网络会阻止邮件端口，尤其是端口 25。

Inbox Classic 会在下次检查邮件时重试。连续两次连接失败后，文件夹列表中的帐户旁和邮件列表上方会显示连接警告。要立即重试，请单击警告图标、提示栏中的或。帐户重新连接后，警告就会消失。

在没有连接时发送的邮件会留在本地发件箱中。Inbox Classic 能够连接时会重试；服务器仍可能拒绝该邮件。
