撰写邮件

撰写并发送新邮件，可以设置格式、添加链接和图片。

要撰写邮件，请：

  1. 单击，或按。新邮件会在单独的窗口中打开。
  2. 在中键入地址，多个地址之间用逗号分隔。键入时，Inbox Classic 会建议匹配的联系人、地址和组。按EnterReturn或Tab接受建议；选择组会添加组中的所有成员。
  3. 输入，然后撰写邮件。
  4. 单击，或按Ctrl+Enter，或按⌘Return。

要添加抄送或密件抄送，请单击“收件人”行末尾的或。密件抄送中的人会收到邮件，但其他收件人看不到他们。

字段显示用于发送邮件的帐户。如果有多个帐户，您可以在这里选择其他帐户。邮件随后将通过该帐户发送，并保存在该帐户的中。要从指定的帐户开始撰写，请使用旁边的箭头。

如果主题或正文中有可识别的附件用词（例如“attached”），却没有附加文件，Inbox Classic 会在发送前询问您。它能识别英语、德语、爱沙尼亚语、西班牙语和法语中的部分用词。

要对邮件签名或加密，请单击工具栏上的或。请参阅。

格式

正文上方的格式栏提供字体、加粗、倾斜、下划线、颜色、列表、缩进、对齐、链接、分隔线和图片。要在正文中插入图片，请单击，或将图片文件从文件资源管理器访达文件管理器拖到正文中。

没有任何格式的邮件以纯文本形式发送，邮件程序无需 HTML 格式即可阅读。带格式的邮件以 HTML 形式发送，并附带一份纯文本副本。

链接
