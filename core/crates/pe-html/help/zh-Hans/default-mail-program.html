将 Inbox Classic 设为邮件应用

在 Inbox Classic 中打开网页和其他程序中的电子邮件链接和邮件文件。

电子邮件链接（mailto:）会在默认邮件应用中打开一封新邮件。

要将 Inbox Classic 设为该应用，请选择 > 。Windows 会打开“默认应用”设置，您可以在其中为 MAILTO 链接选择 Inbox Classic。那里只列出已安装的副本。Inbox Classic 会请求系统将其设为默认邮件应用；能否更改取决于系统的权限和设置。

之后单击电子邮件链接时，会打开一封新邮件，并填入链接中的地址、主题和正文。链接的其他内容不会被使用。

如果您还没有帐户，Inbox Classic 会要求您先添加一个。添加后请再次单击该链接。

邮件文件

要在双击 .eml 文件时用 Inbox Classic 打开它们，请在中单击。Windows 会打开“默认应用”设置，您可以在其中为 .eml 文件选择 Inbox Classic。取消 Inbox Classic 的设置不会撤消已在 Windows 中做出的更改。Inbox Classic 会请求系统用它打开这些文件。
