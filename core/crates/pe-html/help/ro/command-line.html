Opțiuni din linia de comandă

Opțiuni pentru pornirea Inbox Classic dintr-un terminal, pentru testare și pentru agenții IA.

Porniți programul InboxClassic.exe"Inbox Classic.app/Contents/MacOS/Inbox Classic"inbox-classic cu aceste opțiuni:

OpțiuneEfect
--store <fișier>Folosește o altă bază de date pentru mesaje, de exemplu una pentru testare
--memory-passwordsPăstrează parolele doar pentru această rulare, niciodată în depozitul de parole al sistemului
--pin-certificate <fișier>Acceptă certificatele de server indicate în acest fișier: unul sau mai multe în format PEM ori unul în format DER, de exemplu pentru un server de test cu certificat autosemnat
--sign-in-page-file <fișier>Salvează adresa paginii de conectare în acest fișier în loc să deschidă browserul
--language <cod>Afișează ferestrele în această limbă pentru această rulare, de exemplu ro
--backgroundPornește fără fereastra principală
--mcpConectează un agent IA la Inbox Classic. Programul agentului lansează Inbox Classic cu această opțiune; nu trebuie să o folosiți manual.
--versionAfișează versiunea și se încheie

Un link mailto: dat ca argument deschide un mesaj nou, dacă există deja un cont, la fel ca un link de e-mail.
