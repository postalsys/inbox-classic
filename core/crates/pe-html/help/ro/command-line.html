Opțiuni din linia de comandă

Opțiuni pentru pornirea Inbox Classic dintr-un terminal, pentru testare și pentru agenții IA.

Porniți programul InboxClassic.exe"Inbox Classic.app/Contents/MacOS/Inbox Classic"inbox-classic cu aceste opțiuni:

OpțiuneEfect
--store <fișier>Folosește altă stocare de e-mail, de exemplu una pentru testare
--memory-passwordsPăstrează parolele doar pentru această rulare, niciodată în depozitul de parole al sistemului
--pin-certificate <fișier>Acceptă doar certificatul de server din acest fișier (PEM sau DER), pentru un server de test cu certificat autosemnat
--sign-in-page-file <fișier>Scrie pagina unei conectări prin browser în acest fișier în loc să deschidă browserul
--language <cod>Afișează ferestrele în această limbă pentru această rulare, de exemplu ro
--backgroundPornește fără fereastră
--mcpConectează un agent IA la Inbox Classic. Programul agentului pornește această opțiune, nu dvs.
--versionAfișează versiunea și se încheie

Un link mailto: dat ca argument deschide un mesaj nou, la fel ca un link de e-mail.
