Un mesaj nu este afișat

Ce faceți când un mesaj încă se descarcă, nu poate fi descărcat sau nu poate fi afișat.

„Se descarcă mesajul…”

Un mesaj este descărcat prima dată când îl deschideți. Imediat după ce adăugați un cont, majoritatea mesajelor nu sunt încă pe computer. Expeditorul și subiectul apar imediat, iar mesajul urmează într-o clipă.

„Mesajul nu a putut fi descărcat”
