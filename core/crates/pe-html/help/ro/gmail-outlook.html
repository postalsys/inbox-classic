Gmail și Outlook.com

Pentru Gmail, folosiți conectarea prin browser sau, dacă setările contului permit, o parolă de aplicație. Outlook.com și Microsoft 365 acceptă doar conectarea prin browser.

Google și Microsoft nu permit programelor de e-mail să folosească parola obișnuită. Pentru Gmail, parola de aplicație este o alternativă numai dacă este disponibilă în setările contului; pentru Outlook.com și Microsoft 365, conectarea se face doar prin browser.

Conectarea prin browser

Faceți clic pe sau în . Introduceți parola pe pagina Google sau Microsoft, așa că Inbox Classic nu o vede niciodată. Un astfel de cont folosește întotdeauna serverele de e-mail ale furnizorului.

Într-o organizație Microsoft 365, poate fi necesar ca administratorul să aprobe mai întâi utilizarea Inbox Classic. Microsoft afișează atunci Need admin approval, iar Inbox Classic afișează adresa paginii unde administratorul poate aproba aplicația.

Când conectarea expiră

Dacă Google sau Microsoft închide sesiunea, Inbox Classic afișează „Conectarea la contul «…» a fost refuzată sau sesiunea a expirat.” Vă întreabă dacă vă conectați din nou în browser. Alegeți și conectați-vă încă o dată.
