Conectarea unui agent IA

Permiteți unui agent IA, cum ar fi Claude, să vă citească și să vă organizeze e-mailul prin Inbox Classic.

Puteți permite unui agent IA să lucreze cu e-mailul dvs. Poate fi Claude, Cursor sau alt program care acceptă Model Context Protocol (MCP). În Inbox Classic nu există IA și nimic nu este trimis unui serviciu IA decât dacă permiteți accesul unui agent.

Pentru a conecta un agent:

  1. Alegeți > și faceți clic pe . Inbox Classic afișează rândurile de adăugat în setările agentului.
  2. Adăugați-le la serverele MCP ale agentului. În Claude Desktop, acestea sunt în Settings > Developer > Edit Config.
  3. Porniți agentul. Prima dată când se conectează, Inbox Classic vă întreabă ce poate face.

Agentul pornește Inbox Classic în fundal dacă nu rulează. Doar programele care rulează sub utilizatorul dvs. pe acest computer pot ajunge la el.

Inbox Classic întreabă sistemul ce program a pornit agentul, în loc să se bazeze pe ce spune agentul, astfel încât un program să nu poată folosi accesul pe care l-ați dat altuia. Dacă un agent spune că este alt program, întrebarea vă arată acest lucru.

Un agent poate, de asemenea, să urmărească folderul Mesaje primite, un cont sau un folder și să fie anunțat când se schimbă mesajele din ele, și poate oferi două solicitări gata pregătite, „Triage my inbox” și „Summarize unread”. Ambele respectă ce îi permiteți agentului, iar ce citește astfel apare în jurnalul său ca tot restul a ceea ce citește.

Agenții pe care îi porniți dintr-un terminal, cum ar fi Claude Code, sunt un singur program pentru Inbox Classic. Aplicația întreabă o singură dată pentru programele pornite din Terminalprogramele pornite dintr-un terminal, iar acestea au în comun ce permiteți. Pentru ca un agent să aibă propriul acces, adăugați --name și un nume ales de dvs. după --mcp în setările sale, de exemplu "args": ["--mcp", "--name", "Claude Code"]. Inbox Classic vă întreabă apoi despre el sub acest nume.

Pentru a bloca accesul tuturor agenților, dezactivați opțiunea din > .
