Conectarea unui agent IA

Permiteți unui agent IA, cum ar fi Claude, să vă citească și să vă organizeze e-mailul prin Inbox Classic.

Puteți permite unui agent IA să lucreze cu e-mailul dvs. Poate fi Claude, Cursor sau alt program care acceptă Model Context Protocol (MCP). În Inbox Classic nu există IA și nimic nu este trimis unui serviciu IA decât dacă permiteți accesul unui agent.

Pentru a conecta un agent:

  1. Alegeți > și faceți clic pe . Inbox Classic afișează rândurile de adăugat în setările agentului.
  2. Adăugați-le la serverele MCP ale agentului. În Claude Desktop, acestea sunt în Settings > Developer > Edit Config.
  3. Porniți agentul. Prima dată când se conectează, Inbox Classic vă întreabă ce poate face.

Agentul pornește Inbox Classic în fundal dacă nu rulează. Doar programele care rulează sub utilizatorul dvs. pe acest computer pot ajunge la el.

Pentru a dezactiva toți agenții deodată, debifați în > .
