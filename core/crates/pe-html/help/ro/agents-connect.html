Conectarea unui agent IA

Permiteți unui agent IA, cum ar fi Claude, să vă citească și să vă organizeze mesajele prin Inbox Classic.

Puteți permite unui agent IA să lucreze cu mesajele dvs. Poate fi Claude, Cursor sau alt program care acceptă Model Context Protocol (MCP). În Inbox Classic nu există IA și nimic nu este trimis unui serviciu IA decât dacă permiteți accesul unui agent.

Pentru a conecta un agent:

  1. Alegeți > și faceți clic pe . Inbox Classic afișează configurația pe care trebuie să o adăugați în setările agentului.
  2. Adăugați această configurație la lista serverelor MCP ale agentului. În Claude Desktop, acestea sunt în Settings > Developer > Edit Config.
  3. Porniți agentul. Prima dată când se conectează, Inbox Classic vă întreabă ce poate face.

Agentul pornește Inbox Classic în fundal dacă nu rulează. Doar programele care rulează în contul dvs. de utilizator pe acest computer se pot conecta la Inbox Classic.

Inbox Classic verifică prin sistemul de operare ce program a pornit agentul, fără să se bazeze pe numele declarat de agent. Simplul fapt că se prezintă sub alt nume nu îi permite agentului să folosească permisiunile altui program. Dacă declară un alt program, dialogul de confirmare vă arată acest lucru. Acest mecanism separă permisiunile agenților. Nu vă protejează de un program rău intenționat care rulează în contul dvs. de utilizator și ar putea citi oricum mesajele.

Un agent poate urmări folderul Mesaje primite, un cont sau un folder și poate fi anunțat când se schimbă mesajele. Poate oferi și două cereri predefinite: „Triage my inbox” și „Summarize unread”. Ambele respectă permisiunile acordate agentului. Mesajele citite astfel sunt înregistrate în jurnal, la fel ca toate celelalte citiri.

Agenții porniți fără un nume distinct din același terminal recunoscut, cum ar fi Claude Code, pot folosi aceleași permisiuni. Aplicația cere acordul pentru programele pornite din Terminalprogramele pornite dintr-un terminal, grupate după calea programului recunoscut. Terminalele diferite nu sunt neapărat grupate împreună. Pentru ca un agent să aibă propriul acces, adăugați --name și un nume ales de dvs. după --mcp în setările sale, de exemplu "args": ["--mcp", "--name", "Claude Code"]. Inbox Classic vă cere apoi un acord separat pentru acel nume. Numele ales separă accesul salvat; nu este o dovadă verificată a identității agentului.

Pentru a bloca accesul tuturor agenților, dezactivați opțiunea din > .
