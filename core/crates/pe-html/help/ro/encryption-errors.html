Erori de criptare

Ce faceți când un server nu oferă criptare sau o cere acolo unde este dezactivată.

„the server does not offer STARTTLS”

Contul este setat la STARTTLS, dar serverul nu a oferit criptare. Inbox Classic s-a oprit, așa că parola nu a fost trimisă.

  1. Deschideți proprietățile contului din > .
  2. Setați securitatea la SSL/TLS, cu portul 993 pentru e-mailul primit sau 465 pentru cel trimis.
  3. Faceți clic pe .

Dacă nimic altceva nu funcționează, serverul nu poate fi folosit în siguranță.

„the server takes the password only over an encrypted connection”

Serverul de ieșire este setat la . Parola este în regulă. Schimbați în STARTTLS cu portul 587 sau SSL/TLS cu portul 465.

Avertismentul despre o conexiune fără criptare

Când alegeți , Inbox Classic vă avertizează că oricine interceptează traficul de rețea vă poate citi parola și mesajele. Continuați doar pentru un server de pe propriul computer sau din rețeaua locală.
