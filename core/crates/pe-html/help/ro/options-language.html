Fiecare modificare se aplică imediat.

  • alege limba ferestrelor și a acestui ajutor: limba sistemului sau una dintre limbile din listă. Când Inbox Classic nu are limba sistemului, folosește engleza.
  • afișează o notificare când sosesc e-mailuri noi. Implicit este activată.
  • afișează codul unui mesaj de conectare în notificarea lui. Implicit este dezactivată, deoarece o notificare poate fi citită pe un ecran blocat. Nu este disponibilă cât timp notificările sunt dezactivate.
  • păstrează câteva secunde în Mesaje de trimis un mesaj pe care îl trimiteți, ca să îl mai puteți anula cu Anulare. Implicit este de 10 secunde.

  • afișează siglele mărcilor, imaginile contactelor și inițialele în aspectul pe coloane. Implicit este activată.
  • afișează mesajele pe care le citiți și le scrieți pe un fundal întunecat cât timp sistemul este în modul întunecat. Implicit este activată.
  • afișează imaginile și primele pagini ale fișierelor PDF după textul unui mesaj. La început este activată. lasă deoparte doar fișierele PDF. Consultați .
