Setările de securitate ale contului

Setările de securitate ale serverelor unui cont și ce înseamnă fiecare.

Fiecare cont are pentru serverul de intrare și pentru cel de ieșire. Inbox Classic le completează când găsește setările furnizorului dvs. Pentru a le schimba, deschideți proprietățile contului din > .

SetareSemnificație
SSL/TLSConexiunea este criptată de la început. De obicei portul 993 pentru e-mailul primit și 465 pentru cel trimis.
STARTTLSConexiunea este criptată imediat după deschidere. De obicei portul 143 pentru e-mailul primit și 587 pentru cel trimis. Inbox Classic se oprește dacă serverul nu oferă criptare.
Parola și e-mailurile circulă în clar, oricine din rețea le poate citi.
Folosiți doar pentru un server de pe propriul computer sau din rețeaua locală. Inbox Classic vă avertizează înainte să o folosească.

Inbox Classic verifică dacă fiecare server este cel care pretinde că este, pe baza certificatelor în care are încredere sistemul. Nu există nicio opțiune care să accepte orice certificat.

Parola este păstrată în Managerul de acreditări Windowsportcheiul de autentificareportcheiul dvs., niciodată în stocarea de e-mail. Un cont care se conectează prin browser nu păstrează deloc parolă.
