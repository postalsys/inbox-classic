Inbox Classic ca aplicație de e-mail

Deschideți în Inbox Classic linkurile de e-mail și fișierele de mesaje din pagini web și alte programe.

Linkurile de e-mail (mailto:) deschid un mesaj nou în aplicația de e-mail implicită.

Pentru a seta Inbox Classic ca aplicație implicită, alegeți > . Windows deschide setările Aplicații implicite, unde alegeți Inbox Classic pentru linkurile MAILTO. Acolo apare doar o copie instalată. Inbox Classic cere sistemului să îl folosească drept aplicație de e-mail implicită. Dacă asocierea nu se schimbă, verificați setările sistemului.

Când faceți apoi clic pe un link de e-mail, se deschide un mesaj nou cu adresele, subiectul și textul din link completate. Nimic altceva din link nu este folosit.

Dacă nu aveți încă un cont, Inbox Classic vă cere să adăugați mai întâi unul. După ce l-ați adăugat, faceți din nou clic pe link.

Fișiere de mesaje

Pentru a deschide fișierele .eml în Inbox Classic cu dublu clic, faceți clic pe în . Windows deschide setările Aplicații implicite, unde alegeți Inbox Classic pentru fișierele .eml. Inbox Classic cere sistemului asocierea acestor fișiere cu aplicația. Dacă asocierea nu se schimbă, verificați setările sistemului.
