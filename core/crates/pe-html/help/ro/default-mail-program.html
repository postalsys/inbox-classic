Inbox Classic ca aplicație de e-mail

Deschideți în Inbox Classic linkurile de e-mail și fișierele de mesaje din pagini web și alte programe.

Linkurile de e-mail (mailto:) deschid un mesaj nou în aplicația de e-mail implicită.

Pentru ca Inbox Classic să fie acea aplicație, alegeți > . Windows deschide setările Aplicații implicite, unde alegeți Inbox Classic pentru linkurile MAILTO. Acolo apare doar o copie instalată. Inbox Classic devine imediat aplicația de e-mail implicită.

Când faceți apoi clic pe un link de e-mail, se deschide un mesaj nou cu adresele, subiectul și textul din link completate. Nimic altceva din link nu este folosit.

Dacă nu aveți încă un cont, Inbox Classic vă cere să adăugați mai întâi unul. După ce l-ați adăugat, faceți din nou clic pe link.

Fișiere de mesaje

Pentru a deschide fișierele .eml în Inbox Classic cu dublu clic, faceți clic pe în > Inbox Classic > > . Windows deschide setările Aplicații implicite, unde alegeți Inbox Classic pentru fișierele .eml. Inbox Classic devine imediat aplicația lor.
