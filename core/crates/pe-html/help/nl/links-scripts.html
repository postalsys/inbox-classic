Links, scripts en bijlagen

Hoe Inbox Classic voorkomt dat een bericht zelf code uitvoert of pagina’s opent.

  • Scripts in berichten worden nooit uitgevoerd. Inbox Classic schoont elk bericht op voordat het wordt getoond, en het leesvenster kan geen code uitvoeren.
  • Links gaan open in je webbrowser, nooit in Inbox Classic. Een bericht kan niet zelf een pagina of venster openen.
  • Bijlagen worden opgeslagen, nooit vanuit Inbox Classic geopend. Hun namen worden veilig gemaakt voordat je ze opslaat.
  • Afmelden vraagt het je eerst, en zegt wat er gaat gebeuren.
Controleer het adres in je browser voordat je een wachtwoord typt op een pagina die je via een bericht hebt bereikt. Een bericht kan het ene adres tonen en naar een ander verwijzen.

Als je een bericht schrijft, toont de statusbalk waar de link bij de cursor naartoe gaat, zodat je die kunt controleren voordat je verzendt.
