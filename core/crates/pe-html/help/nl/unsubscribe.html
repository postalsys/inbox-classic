Afmelden voor een mailinglijst

Meld je af voor een mailinglijst via de afmeldknop in het bericht.

Als een mailinglijst afmeldgegevens meestuurt, verschijnt de knop rechts in de koptekst.

Zo meld je je af:

  1. Klik op . Inbox Classic legt uit wat er gaat gebeuren en vraagt om bevestiging.
  2. Bevestig. Afhankelijk van de lijst gebeurt een van deze drie dingen:
    • Inbox Classic stuurt een afmeldverzoek naar de mailinglijst. Er wordt geen webpagina geopend en geen e-mail verzonden.
    • Inbox Classic stelt een afmeldbericht op. Klik op om het te verzenden.
    • De afmeldpagina van de mailinglijst wordt geopend in je browser. Rond het afmelden daar af.

De statusbalk meldt wanneer de server het verzoek heeft geaccepteerd. Dit garandeert niet dat de mailinglijst al is gestopt met verzenden.

Inbox Classic kan alleen rechtstreeks een afmeldverzoek versturen als de server van de mailinglijst het bericht heeft ondertekend. Zo voorkomt de app dat vervalste afmeldgegevens een verzoek naar een andere server sturen.
