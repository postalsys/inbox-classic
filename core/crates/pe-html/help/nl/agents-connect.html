Een AI-agent verbinden

Laat een AI-agent, zoals Claude, je mail lezen en ordenen via Inbox Classic.

Je kunt een AI-agent met je mail laten werken. Dat kan Claude zijn, Cursor of een ander programma dat het Model Context Protocol (MCP) ondersteunt. Inbox Classic bevat zelf geen AI, en er gaat niets naar een AI-dienst tenzij je een agent toegang geeft.

Zo verbind je een agent:

  1. Kies > en klik op . Inbox Classic toont de regels die je aan de instellingen van je agent toevoegt.
  2. Voeg ze toe aan de MCP-servers van je agent. In Claude Desktop is dat Settings > Developer > Edit Config.
  3. Start de agent. De eerste keer dat hij verbinding maakt, vraagt Inbox Classic je wat hij mag doen.

De agent start Inbox Classic op de achtergrond als het niet al draait. Alleen programma’s die onder jouw gebruiker op deze computer draaien, kunnen het bereiken.

Wil je alle agents in één keer uitschakelen, schakel dan uit in > .
