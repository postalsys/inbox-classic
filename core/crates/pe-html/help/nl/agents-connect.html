Een AI-agent verbinden

Laat een AI-agent, zoals Claude, je mail lezen en ordenen via Inbox Classic.

Je kunt een AI-agent met je mail laten werken. Dat kan Claude zijn, Cursor of een ander programma dat het Model Context Protocol (MCP) ondersteunt. Inbox Classic bevat zelf geen AI. Je e-mail wordt pas toegankelijk voor een AI-dienst wanneer je een agent toegang geeft.

Zo verbind je een agent:

  1. Kies > en klik op . Inbox Classic toont de configuratie die je aan de instellingen van je agent toevoegt.
  2. Voeg deze configuratie toe aan de MCP-servers van je agent. In Claude Desktop is dat Settings > Developer > Edit Config.
  3. Start de agent. De eerste keer dat hij verbinding maakt, vraagt Inbox Classic je wat hij mag doen.

De agent start Inbox Classic op de achtergrond als het niet al draait. Alleen programma’s die onder jouw gebruikersaccount op deze computer draaien, kunnen verbinding maken.

Inbox Classic vraagt het systeem welk programma de agent heeft gestart, in plaats van de agent op zijn woord te geloven, en gebruikt dat als basis voor de machtigingen. Dit beschermt niet tegen een kwaadwillend programma dat onder hetzelfde gebruikersaccount draait. Als de opgegeven naam afwijkt, zie je dat in het toestemmingsvenster.

Een agent kan ook je Postvak IN, een account of een map in de gaten houden en een melding krijgen als de e-mail daarin verandert, en hij kan twee kant-en-klare verzoeken aanbieden, “Triage my inbox” en “Summarize unread”. Beide volgen wat je de agent toestaat, en wat hij zo leest, verschijnt in zijn logboek net als alles wat hij verder leest.

Agents die je vanuit een terminal start, zoals Claude Code, kunnen voor Inbox Classic bij hetzelfde programma horen. Het vraagt één keer toestemming voor programma’s gestart vanuit Terminalprogramma’s gestart vanuit een terminal, en die delen wat je toestaat. Wil je een agent eigen toegang geven, voeg dan in de instellingen van de agent --name en een naam naar keuze toe na --mcp, bijvoorbeeld "args": ["--mcp", "--name", "Claude Code"]. Inbox Classic vraagt dan onder die naam om toestemming. Deze naam maakt een aparte vermelding, maar bewijst niet de identiteit van het programma.

Wil je alle agents in één keer uitschakelen, schakel dan uit in > .
