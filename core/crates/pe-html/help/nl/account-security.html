Beveiligingsinstellingen van een account

Kies hoe de verbindingen met de mailservers worden beveiligd.

Elk account heeft voor de server voor inkomende mail en voor de server voor uitgaande mail. Inbox Classic vult ze in wanneer het de instellingen van je provider vindt. Wil je ze wijzigen, open dan de eigenschappen van het account in > .

InstellingBetekenis
SSL/TLSDe verbinding is vanaf het begin versleuteld. Meestal poort 993 voor inkomende mail en 465 voor uitgaande mail.
STARTTLSDe verbinding wordt versleuteld voordat aanmeldgegevens worden verstuurd. Meestal poort 143 voor inkomende mail en 587 voor uitgaande mail. Inbox Classic stopt als de server geen versleuteling aanbiedt.
Je wachtwoord en e-mail worden onversleuteld verstuurd. Wie het netwerkverkeer onderschept, kan ze lezen.
Gebruik alleen als de verbinding op een andere manier is beveiligd. Een lokaal netwerk maakt een verbinding niet vanzelf versleuteld. Inbox Classic waarschuwt je voordat het deze instelling gebruikt.

Bij versleutelde verbindingen controleert Inbox Classic de identiteit van elke server aan de hand van certificaten die je systeem vertrouwt. Je kunt deze controle niet uitschakelen.

Je wachtwoord wordt standaard bewaard in Windows Referentiebeheerje inlogsleutelhangerje sleutelbos, nooit in de lokale mailopslag. Een account dat zich via de browser aanmeldt, bewaart aanmeldgegevens in plaats van je wachtwoord. In de geheugenmodus blijven deze gegevens alleen bewaard totdat je de app sluit.
