Aanmeldcodes

Een bericht met een aanmeld- of verificatiecode toont de code op een kaart waarvan je hem kunt kopiëren.

Als een bericht een eenmalige code bevat, zoals een aanmeld-, verificatie- of goedkeuringscode, toont een kaart erboven:

  • “Code van” en het domein waarvoor de code is
  • de code, in grote letters
  • , dat de code op het klembord zet
Voer een code alleen in op een pagina van het domein dat de kaart noemt. Een bericht dat je vraagt een code ergens anders in te typen, kan een poging zijn om je account over te nemen.

De kaart verschijnt alleen als je mailprovider bevestigt dat het domein het bericht heeft ondertekend. Een code in een bericht dat iemand anders heeft verzonnen, wordt niet aangeboden. Er is geen kaart in , of , of als je provider geen handtekeningen meldt.

Een code die meer dan een uur voordat je het bericht opende is verzonden, is waarschijnlijk verlopen, en dat staat dan op de kaart.

Codes in meldingen
