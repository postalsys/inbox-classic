Aanmeldcodes

Aanmeld- en verificatiecodes verschijnen op een kaart boven het bericht, zodat je ze eenvoudig kunt kopiëren.

Als een bericht een eenmalige code bevat, zoals een aanmeld-, verificatie- of goedkeuringscode, toont een kaart erboven:

  • “Code van” en het bijbehorende domein
  • de code, in grote letters
  • , dat de code op het klembord zet
Voer een code alleen in op een pagina van het domein dat de kaart noemt. Een bericht dat je vraagt een code ergens anders in te typen, kan een poging zijn om je account over te nemen.

De kaart verschijnt alleen als je mailprovider een geldige digitale handtekening bevestigt voor het domein van de code. Dit bevestigt de herkomst van het bericht, maar garandeert niet dat de inhoud betrouwbaar is. Er is geen kaart in , of , of als je provider geen informatie over de digitale handtekening doorgeeft.

Als de datum van het bericht meer dan een uur oud is, meldt de kaart dat de code verlopen kan zijn. Inbox Classic kan niet controleren of de code nog geldig is.

Codes in meldingen

Om de code te zien in de melding van een nieuw bericht, zet je aan in . Deze instelling staat standaard uit, omdat meldingen ook op een vergrendeld scherm zichtbaar kunnen zijn. De code verschijnt alleen bij een recent bericht dat klein genoeg is en op tijd wordt gedownload. Ook de gewone voorwaarden voor meldingen blijven gelden.
