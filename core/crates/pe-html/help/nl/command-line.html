Opdrachtregelopties

Opties om Inbox Classic vanuit een terminal te starten, voor tests en voor AI-agents.

Start het programma InboxClassic.exe"Inbox Classic.app/Contents/MacOS/Inbox Classic"inbox-classic met deze opties:

OptieDoet
--store <file>Gebruikt een andere mailopslag, bijvoorbeeld een om te testen
--memory-passwordsBewaart wachtwoorden alleen voor deze keer, nooit in de wachtwoordopslag van het systeem
--pin-certificate <file>Accepteert alleen het servercertificaat in dit bestand (PEM of DER), voor een testserver met een zelfondertekend certificaat
--sign-in-page-file <file>Schrijft de pagina van een aanmelding via de browser naar dit bestand in plaats van de browser te openen
--language <code>Toont de vensters deze keer in deze taal, bijvoorbeeld de
--backgroundStart zonder venster
--mcpVerbindt een AI-agent met Inbox Classic. Het programma van de agent start dit, niet jij
--versionToont de versie en stopt

Een mailto:-link als argument opent een nieuw bericht, net als een e-maillink.
