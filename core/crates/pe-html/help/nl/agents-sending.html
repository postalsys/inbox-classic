Als een agent e-mail verzendt

Controleer elk bericht van een AI-agent voordat je toestemming geeft; daarna wacht het nog even in Postvak UIT.

Een agent heeft toestemming nodig om e-mail te verzenden. Daarnaast moet je elk afzonderlijk bericht goedkeuren.

Als de agent wil verzenden, toont Inbox Classic het bericht en het e-mailadres van elke ontvanger. Adressen waarnaar je nog nooit hebt geschreven, zijn gemarkeerd met .

  1. Controleer de ontvangers en de berichttekst.
  2. Kies een van de volgende opties:
    • zet het bericht klaar voor verzending. De knop wordt pas na een korte pauze actief om onbedoeld verzenden te voorkomen.
    • opent het bericht in het opstelvenster, zodat je het kunt bewerken.
    • , de standaardkeuze, verzendt het niet.

Per programma kan er maar één bericht tegelijk op je bevestiging wachten. Als je niet meteen antwoordt, meldt Inbox Classic aan de agent dat je antwoord nog uitstaat. De agent kan je keuze later opvragen. De handtekeningtekst van je account wordt standaard toegevoegd aan berichten en concepten van een agent. De agent kan die ook weglaten.

Na je toestemming wacht het bericht 30 seconden in Postvak UIT. Zolang het nog niet is verzonden, kun je het daar verwijderen, of op klikken in > .

Antwoorden op uitnodigingen

Een agent die e-mail mag verzenden, kan via een eigen toestemmingsvenster namens jou een agenda-uitnodiging accepteren, voorlopig accepteren of afwijzen. Boven de tekst staat in de vraag op welke uitnodiging het bericht antwoordt en wanneer de afspraak is. Inbox Classic schrijft het antwoord aan de organisator op basis van de uitnodiging zelf, dus “Eerst bewerken” is niet beschikbaar en de handtekeningtekst van je account wordt niet toegevoegd. Inbox Classic werkt je antwoord bij zodra de mailserver het bericht heeft geaccepteerd voor verzending. Dat bevestigt niet dat de agenda van de organisator het al heeft verwerkt.

Concepten die een agent schrijft

Als je een concept van een agent opent, zie je boven de berichttekst welke agent het heeft geschreven. Controleer de ontvangers en de tekst voordat je het verzendt.

Een agent kan alleen concepten wijzigen of verwijderen die hij zelf heeft gemaakt. Zodra je zo’n concept opslaat of verzendt, kan de agent het niet meer wijzigen of verwijderen. Het verwijderen van een eigen, nog niet door jou opgeslagen concept is definitief. Dat geldt ook als Inbox Classic je wijzigingen automatisch opslaat. Als je het concept alleen opent, kan de agent het nog steeds wijzigen.

Een agent die ook andere hulpmiddelen kan gebruiken, zoals een browser of toegang tot je bestanden, kan gelezen informatie langs die weg doorgeven. Inbox Classic heeft daar geen zicht op. Geef alleen toestemming om te verzenden als dat nodig is.
