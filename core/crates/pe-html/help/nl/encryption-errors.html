Problemen met verbindingsbeveiliging

Los problemen op wanneer de mailserver geen versleuteling aanbiedt of een beveiligde verbinding vereist.

“de server biedt geen STARTTLS aan”

Het account is ingesteld op STARTTLS, maar de server bood geen versleuteling aan. Inbox Classic heeft de verbinding afgebroken zonder je wachtwoord te versturen.

  1. Open de eigenschappen van het account via > .
  2. Stel de beveiliging in op SSL/TLS, met poort 993 voor inkomende e-mail of 465 voor uitgaande e-mail.
  3. Klik op .

Biedt de server geen werkende versleutelde verbinding aan, dan kun je hem niet veilig gebruiken.

“de server accepteert het wachtwoord alleen via een versleutelde verbinding”

De server voor uitgaande e-mail staat op . De server vereist een versleutelde verbinding voordat je je kunt aanmelden. Zet op STARTTLS met poort 587, of op SSL/TLS met poort 465.

De waarschuwing over een verbinding zonder versleuteling

Kies je , dan waarschuwt Inbox Classic dat iedereen die je netwerkverkeer onderschept je wachtwoord en berichten kan lezen. Ga alleen verder voor een server op je eigen computer of je lokale netwerk.
