Problemen met verbindingsbeveiliging

Los problemen op wanneer de mailserver geen versleuteling aanbiedt of een beveiligde verbinding vereist.

“the server does not offer STARTTLS”

Het account is ingesteld op STARTTLS, maar de server bood geen versleuteling aan. Inbox Classic heeft de verbinding afgebroken zonder je wachtwoord te versturen.

  1. Open de eigenschappen van het account via > .
  2. Als je provider dit ondersteunt, stel je de beveiliging in op SSL/TLS met de opgegeven poort; meestal 993 voor inkomende e-mail of 465 voor uitgaande e-mail.
  3. Klik op .

Biedt de server geen werkende versleutelde verbinding aan, dan kun je hem niet veilig gebruiken.

“the server takes the password only over an encrypted connection”

De server voor uitgaande e-mail staat op . De server vereist een versleutelde verbinding voordat je je kunt aanmelden. Dit zegt niet of het wachtwoord klopt. Zet op STARTTLS met poort 587, of op SSL/TLS met poort 465.

De waarschuwing over een verbinding zonder versleuteling

Kies je , dan waarschuwt Inbox Classic dat iedereen die je netwerkverkeer onderschept je wachtwoord en berichten kan lezen. Ga alleen verder als de verbinding op een andere manier is beveiligd. Een lokaal netwerk maakt de verbinding niet vanzelf versleuteld.
