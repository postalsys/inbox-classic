Inbox Classic oletussähköpostiohjelmaksi

Avaa verkkosivujen ja muiden ohjelmien sähköpostilinkit ja viestitiedostot Inbox Classicissa.

Sähköpostilinkit (mailto:) avaavat uuden viestin oletussähköpostiohjelmassasi.

Aseta Inbox Classic oletussähköpostiohjelmaksi valitsemalla > . Windows avaa oletussovellusten asetukset. Valitse siellä Inbox Classic MAILTO-linkkien avaamiseen. Ohjelma näkyy luettelossa vain, jos se on asennettu. Inbox Classicista tulee heti oletussähköpostiohjelma.

Kun napsautat sähköpostilinkkiä, uusi viesti avautuu ja linkin sisältämät vastaanottajat, aihe ja teksti täytetään valmiiksi. Linkin muita tietoja ei käytetä.

Jos sinulla ei vielä ole tiliä, Inbox Classic pyytää lisäämään sellaisen ensin. Napsauta linkkiä uudelleen, kun tili on lisätty.

Viestitiedostot

Jos haluat .eml-tiedostojen avautuvan Inbox Classicissa kaksoisnapsautuksella, napsauta kohdassa > Inbox Classic > > . Windows avaa oletussovellusten asetukset. Valitse siellä Inbox Classic .eml-tiedostojen avaamiseen. Inbox Classic asetetaan heti .eml-tiedostojen oletussovellukseksi.
