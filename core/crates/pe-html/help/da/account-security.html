Sikkerhedsindstillinger for konti

Vælg, hvordan forbindelserne til kontoens mailservere skal krypteres.

Hver konto har for den indgående server og for den udgående. Inbox Classic udfylder dem, når det finder din udbyders indstillinger. Hvis du vil ændre dem, skal du åbne kontoens egenskaber under > .

IndstillingBetydning
SSL/TLSForbindelsen er krypteret fra starten. Som regel port 993 til indgående mail og 465 til udgående mail.
STARTTLSForbindelsen krypteres lige efter, at den er åbnet. Som regel port 143 til indgående mail og 587 til udgående mail. Inbox Classic stopper, hvis serveren ikke tilbyder kryptering.
Adgangskoden og din mail sendes ukrypteret og kan læses af andre, som opsnapper netværkstrafikken.
Brug kun til en server på din egen computer eller dit lokale netværk. Inbox Classic advarer dig, før den bruges.

Inbox Classic kontrollerer, at hver server er den, den giver sig ud for at være, ud fra de certifikater, dit system stoler på. Certifikatkontrollen kan ikke slås fra, og programmet kan ikke indstilles til at acceptere vilkårlige certifikater.

Din adgangskode gemmes i Windows Legitimationsstyringdin login-nøgleringdin nøglering, aldrig i mailarkivet. Ved login via browseren gemmes logintokens i stedet for adgangskoden, også i systemets beskyttede lager.
