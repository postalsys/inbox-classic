Krypteringsfejl

Hvad du gør, når en server ikke tilbyder kryptering, eller kræver den, hvor den er slået fra.

»the server does not offer STARTTLS«

Kontoen er indstillet til STARTTLS, men serveren tilbød ikke kryptering. Inbox Classic stoppede, så din adgangskode blev ikke sendt.

  1. Åbn kontoens egenskaber under > .
  2. Sæt sikkerheden til SSL/TLS med port 993 til indgående mail eller 465 til udgående mail.
  3. Klik på .

Hvis intet andet virker, kan serveren ikke bruges sikkert.

»the server takes the password only over an encrypted connection«

Den udgående server er sat til . Din adgangskode er i orden. Skift til STARTTLS med port 587 eller SSL/TLS med port 465.

Advarslen om en forbindelse uden kryptering

Når du vælger , advarer Inbox Classic om, at alle, der opsnapper din netværkstrafik, kan læse din adgangskode og dine meddelelser. Fortsæt kun for en server på din egen computer eller dit lokale netværk.
