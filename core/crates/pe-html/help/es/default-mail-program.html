Usar Inbox Classic como programa de correo

Abra en Inbox Classic los enlaces de correo de las páginas web y de otros programas.

Los enlaces de correo (mailto:) abren un mensaje nuevo en su programa de correo predeterminado.

Para que ese programa sea Inbox Classic, elija > . Windows abre su configuración de Aplicaciones predeterminadas, donde se elige Inbox Classic para los vínculos MAILTO. Solo aparece allí una copia instalada. Inbox Classic pasa a ser el programa de correo predeterminado de inmediato.

Cuando después haga clic en un enlace de correo, se abrirá un mensaje nuevo con las direcciones, el asunto y el texto del enlace ya rellenos. No se usa nada más del enlace.

Si todavía no tiene ninguna cuenta, Inbox Classic le pide que agregue una primero. Haga clic de nuevo en el enlace cuando la haya agregado.
