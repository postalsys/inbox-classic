Usar Inbox Classic como programa de correo

Abra en Inbox Classic los enlaces de correo y los archivos de mensajes de las páginas web y de otros programas.

Los enlaces de correo (mailto:) abren un mensaje nuevo en su programa de correo predeterminado.

Para que ese programa sea Inbox Classic, elija > . Si Inbox Classic aún no es el programa predeterminado, Windows abre la configuración de Aplicaciones predeterminadas para que lo elija para los vínculos MAILTO. Solo aparece allí una copia instalada. Inbox Classic solicita al sistema que lo establezca como programa de correo predeterminado. Si el cambio falla, revise las aplicaciones predeterminadas del sistema.

Cuando después haga clic en un enlace de correo, se abrirá un mensaje nuevo con las direcciones, el asunto y el texto del enlace ya rellenos. No se usa nada más del enlace.

Si todavía no tiene ninguna cuenta, Inbox Classic le pide que agregue una primero. Haga clic de nuevo en el enlace cuando la haya agregado.

Archivos de mensajes

Para que los archivos .eml se abran en Inbox Classic al hacer doble clic, haga clic en en . Si es necesario, Windows abre la configuración de Aplicaciones predeterminadas para que elija Inbox Classic para los archivos .eml. Inbox Classic solicita al sistema que lo establezca como aplicación predeterminada para estos archivos. Si no se aplica el cambio, revise la asociación de archivos del sistema.
