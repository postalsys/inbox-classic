No se muestra un mensaje

Qué hacer cuando un mensaje todavía se está descargando, no se puede descargar o no se puede mostrar.

«Descargando el mensaje…»

Si el mensaje aún no está descargado, Inbox Classic lo solicita al abrirlo. Justo después de agregar una cuenta, la mayoría de los mensajes aún no están en su equipo. El remitente y el asunto se muestran enseguida, mientras se descarga el contenido.

«No se pudo descargar el mensaje»

El panel indica el motivo, por ejemplo que no se pudo conectar con el servidor de correo. Si el mensaje sigue abierto, Inbox Classic vuelve a intentar la descarga después de sincronizar la cuenta. Para intentarlo enseguida, haga clic en en la barra situada sobre el mensaje.

Si se rechazó el inicio de sesión, consulte . Si no se pudo establecer una conexión segura, consulte .

«Este mensaje no se puede mostrar»

Algunos mensajes están dañados o tienen una estructura que Inbox Classic no puede interpretar. Inbox Classic muestra este aviso en lugar del mensaje. El resto de su correo no se ve afectado. Para ver lo que contiene el mensaje, elija > .

«»

Inbox Classic muestra los mensajes con Microsoft Edge WebView2. Su entorno de ejecución puede necesitar una instalación aparte. Si falta, instale WebView2 Runtime de Microsoft y vuelva a iniciar Inbox Classic.
