Opciones de la línea de comandos

Opciones para iniciar Inbox Classic desde un terminal, para pruebas y para agentes de IA.

Inicie el programa InboxClassic.exe"Inbox Classic.app/Contents/MacOS/Inbox Classic"inbox-classic con estas opciones:

OpciónFunción
--store <archivo>Usa otro almacén de correo, por ejemplo uno de pruebas
--memory-passwordsGuarda las contraseñas solo durante esta ejecución, nunca en el almacén de contraseñas del sistema
--pin-certificate <archivo>Acepta solo el certificado de servidor de este archivo (PEM o DER), para un servidor de pruebas con un certificado autofirmado
--sign-in-page-file <archivo>Escribe la página de un inicio de sesión por navegador en este archivo en lugar de abrir el navegador
--language <código>Muestra las ventanas en este idioma durante esta ejecución, por ejemplo de
--backgroundSe inicia sin su ventana
--mcpConecta un agente de IA a Inbox Classic. Lo inicia el programa del agente, no usted
--versionMuestra la versión y termina

Un enlace mailto: pasado como argumento abre un mensaje nuevo, como lo hace un enlace de correo.
