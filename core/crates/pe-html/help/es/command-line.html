Opciones de la línea de comandos

Opciones para iniciar Inbox Classic desde un terminal, para pruebas y para agentes de IA.

Inicie el programa InboxClassic.exe"Inbox Classic.app/Contents/MacOS/Inbox Classic"inbox-classic con estas opciones:

OpciónFunción
--store <archivo>Usa la base de datos de correo indicada en lugar de la ubicación predeterminada, por ejemplo para realizar pruebas
--memory-passwordsGuarda los datos de acceso, incluidos los obtenidos al iniciar sesión por navegador, solo durante esta ejecución, sin usar el almacén de secretos del sistema
--pin-certificate <archivo>Limita los certificados de servidor aceptados a los de este archivo: puede contener varios certificados PEM o uno DER. Sirve, por ejemplo, para probar un servidor con un certificado autofirmado
--sign-in-page-file <archivo>Escribe en este archivo la dirección de la página de inicio de sesión, en lugar de abrir el navegador
--language <código>Muestra las ventanas en este idioma durante esta ejecución, por ejemplo de
--backgroundSe inicia sin su ventana
--mcpConecta un agente de IA a Inbox Classic. Lo inicia el programa del agente, no usted
--versionMuestra la versión y termina

Un enlace mailto: pasado como argumento abre un mensaje nuevo si ya hay una cuenta configurada, como lo hace un enlace de correo.
