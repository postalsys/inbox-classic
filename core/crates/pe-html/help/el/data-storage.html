Πού φυλάσσονται η αλληλογραφία και οι κωδικοί σας

Τι κρατά το Inbox Classic στον υπολογιστή σας και πού.

  • Η αλληλογραφία που έχει ληφθεί και οι ρυθμίσεις των λογαριασμών βρίσκονται στο %LOCALAPPDATA%\InboxClassic\store.db~/Library/Application Support/Inbox Classic/store.db~/.local/share/inbox-classic/store.db. Η αλληλογραφία σας μένει και στον διακομιστή. Το αντίγραφο εδώ υπάρχει για γρήγορη ανάγνωση, ανάγνωση χωρίς σύνδεση και αναζήτηση.
  • Οι κωδικοί πρόσβασης, οι συνδέσεις μέσω προγράμματος περιήγησης και τα μυστικά των εφαρμογών σύνδεσης βρίσκονται στη Διαχείριση διαπιστευτηρίων των Windows, στο InboxClassic, κρυπτογραφημένα για τον λογαριασμό σας στα Windows.στην κλειδοθήκη σύνδεσής σας, στο InboxClassic, κρυπτογραφημένα για τον λογαριασμό σας στο Mac. Τα δείχνει η εφαρμογή Πρόσβαση στην κλειδοθήκη.στην κλειδοθήκη σας (GNOME Keyring), στο InboxClassic, κρυπτογραφημένα για τη σύνδεσή σας. Χωρίς κλειδοθήκη, κρατούνται μόνο μέχρι να κλείσει το Inbox Classic. Δεν βρίσκονται ποτέ στην αποθήκη αλληλογραφίας.
  • Τα κλειδιά κρυπτογράφησης φυλάσσονται μαζί με την αλληλογραφία που έχει ληφθεί. Τα ιδιωτικά σας κλειδιά είναι εκεί κρυπτογραφημένα με ένα κλειδί που φυλάσσεται δίπλα στους κωδικούς πρόσβασής σας, οπότε το αρχείο της αλληλογραφίας μόνο του δεν μπορεί να τα ανοίξει.

Η αναζήτηση, η εξήγηση των μηνυμάτων που επιστράφηκαν, η ομαδοποίηση σε συζητήσεις και η εύρεση κωδικών σύνδεσης εκτελούνται όλα στον υπολογιστή σας. Τίποτα από την αλληλογραφία σας δεν στέλνεται πουθενά γι’ αυτά.
