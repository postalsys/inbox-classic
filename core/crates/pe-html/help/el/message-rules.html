Ταξινόμηση νέας αλληλογραφίας με κανόνες

Μετακινήστε, επισημάνετε ως αναγνωσμένα, προσθέστε σημαία ή αρχειοθετήστε αυτόματα τα εισερχόμενα μηνύματα που πληρούν τα κριτήριά σας.

Ένας κανόνας συνδυάζει κριτήρια αναζήτησης με ενέργειες που εφαρμόζονται στα μηνύματα που ταιριάζουν καθώς φτάνουν στα Εισερχόμενα. Για παράδειγμα, ένας κανόνας με from:news@example.com μπορεί να μετακινεί τα ενημερωτικά δελτία από αυτή τη διεύθυνση σε ξεχωριστό φάκελο και να τα επισημαίνει ως αναγνωσμένα.

Για να δημιουργήσετε έναν κανόνα:

  1. Επιλέξτε > και κάντε κλικ στο .
  2. Εισαγάγετε ένα όνομα και συμπληρώστε το πεδίο με τους ίδιους όρους όπως στο πλαίσιο αναζήτησης, όπως from:, subject: ή list:. Η γραμμή από κάτω δείχνει πόσα υπάρχοντα μηνύματα των Εισερχομένων ταιριάζουν με αυτά τα κριτήρια.
  3. Επιλέξτε μία ή περισσότερες ενέργειες για τα μηνύματα που ταιριάζουν: μετακίνηση σε φάκελο, επισήμανση ως αναγνωσμένων, σημαία, αρχειοθέτηση, μετακίνηση στην Ανεπιθύμητη αλληλογραφία, διαγραφή ή χωρίς ειδοποιήσεις.
  4. Κάντε κλικ στο .

Μπορείτε επίσης να δημιουργήσετε έναν κανόνα από ένα μήνυμα ή μια αναζήτηση. Επιλέξτε > για να συμπληρωθεί ο αποστολέας ή η λίστα αλληλογραφίας του επιλεγμένου μηνύματος. Κάντε κλικ στο πάνω από τα αποτελέσματα αναζήτησης για να χρησιμοποιήσετε τα τρέχοντα κριτήρια αναζήτησης.

Πώς λειτουργούν οι κανόνες

Οι κανόνες επεξεργάζονται τα νέα μηνύματα των Εισερχομένων όσο εκτελείται το Inbox Classic, ακόμη κι όταν είναι ελαχιστοποιημένο στην περιοχή ειδοποιήσεων. Τα υπάρχοντα μηνύματα επηρεάζονται μόνο αν επιλέξετε . Οι κανόνες που ταιριάζουν εκτελούνται με τη σειρά της λίστας. Μόλις ένας κανόνας μετακινήσει ένα μήνυμα έξω από τα Εισερχόμενα, δεν εφαρμόζονται άλλοι κανόνες σε αυτό. Καταργήστε την επιλογή ενός κανόνα στη λίστα για να τον απενεργοποιήσετε χωρίς να τον διαγράψετε.

Αλλαγή κανόνων

Για να επεξεργαστείτε έναν κανόνα, επιλέξτε τον στη λίστα και κάντε κλικ στο ή κάντε διπλό κλικ σε αυτόν. Χρησιμοποιήστε τα και για να αλλάξετε τη σειρά ή το για να διαγράψετε τον κανόνα. Στον επεξεργαστή κανόνων, κάντε κλικ στο για να δείτε στο κύριο παράθυρο τα μηνύματα που ταιριάζουν αυτή τη στιγμή.

Οι κανόνες εφαρμόζονται στα νέα μηνύματα των Εισερχομένων, οπότε τα φίλτρα φακέλου και ημερομηνίας δεν υποστηρίζονται. Αν χρησιμοποιήσετε in:, before:, after:, older_than: ή newer_than:, ένα μήνυμα εξηγεί γιατί αυτά τα φίλτρα δεν μπορούν να χρησιμοποιηθούν. Οι κανόνες δεν μπορούν να στέλνουν μηνύματα ή να τα διαγράφουν οριστικά: η ενέργεια τα μετακινεί στα .

Οι κανόνες εκτελούνται σε αυτόν τον υπολογιστή. Για να ταξινομείται η αλληλογραφία όσο είναι κλειστός, χρησιμοποιήστε τα φίλτρα του παρόχου αλληλογραφίας σας.
