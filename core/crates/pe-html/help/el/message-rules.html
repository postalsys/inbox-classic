Οργάνωση νέας αλληλογραφίας με κανόνες

Μετακινήστε, επισημάνετε ως αναγνωσμένα, προσθέστε σημαία ή αρχειοθετήστε αυτόματα τα εισερχόμενα μηνύματα που πληρούν τα κριτήριά σας.

Ένας κανόνας συνδυάζει κριτήρια αναζήτησης με ενέργειες που εφαρμόζονται στα μηνύματα που πληρούν αυτά τα κριτήρια μόλις φτάσουν στα Εισερχόμενα. Για παράδειγμα, ένας κανόνας με from:news@example.com μπορεί να μετακινεί τα ενημερωτικά δελτία από αυτή τη διεύθυνση σε ξεχωριστό φάκελο και να τα επισημαίνει ως αναγνωσμένα.

Για να δημιουργήσετε έναν κανόνα:

  1. Επιλέξτε > και κάντε κλικ στο .
  2. Εισαγάγετε ένα όνομα και συμπληρώστε το πεδίο χρησιμοποιώντας όρους αναζήτησης, όπως from:, subject: ή list:. Η γραμμή από κάτω δείχνει πόσα από τα υπάρχοντα μηνύματα των Εισερχομένων πληρούν τα κριτήρια.
  3. Επιλέξτε μία ή περισσότερες ενέργειες για τα μηνύματα που πληρούν τα κριτήρια: μετακίνηση σε φάκελο, επισήμανση ως αναγνωσμένων, προσθήκη σημαίας, αρχειοθέτηση, μετακίνηση στην Ανεπιθύμητη αλληλογραφία, διαγραφή ή απόκρυψη ειδοποιήσεων.
  4. Κάντε κλικ στο .

Μπορείτε επίσης να δημιουργήσετε έναν κανόνα από ένα μήνυμα ή μια αναζήτηση. Επιλέξτε > για να συμπληρωθεί ο αποστολέας ή η λίστα αλληλογραφίας του επιλεγμένου μηνύματος. Κάντε κλικ στο πάνω από τα αποτελέσματα αναζήτησης για να χρησιμοποιήσετε τα τρέχοντα κριτήρια αναζήτησης.

Πώς λειτουργούν οι κανόνες

Οι κανόνες επεξεργάζονται τα νέα μηνύματα των Εισερχομένων όσο εκτελείται το Inbox Classic, ακόμη κι όταν είναι ελαχιστοποιημένο στην περιοχή ειδοποιήσεων. Τα υπάρχοντα μηνύματα επηρεάζονται μόνο αν επιλέξετε . Οι κανόνες εξετάζονται με τη σειρά της λίστας και εφαρμόζονται όταν το μήνυμα πληροί τα κριτήριά τους. Μόλις ένας κανόνας μετακινήσει ένα μήνυμα έξω από τα Εισερχόμενα, δεν εφαρμόζονται άλλοι κανόνες σε αυτό. Καταργήστε την επιλογή ενός κανόνα στη λίστα για να τον απενεργοποιήσετε χωρίς να τον διαγράψετε.

Αλλαγή κανόνων

Για να επεξεργαστείτε έναν κανόνα, επιλέξτε τον στη λίστα και κάντε κλικ στο ή κάντε διπλό κλικ σε αυτόν. Χρησιμοποιήστε τα κουμπιά και για να αλλάξετε τη σειρά ή το για να διαγράψετε τον κανόνα. Στον επεξεργαστή κανόνων, κάντε κλικ στο για να δείτε στο κύριο παράθυρο τα μηνύματα που πληρούν αυτή τη στιγμή τα κριτήρια.

Οι κανόνες εφαρμόζονται στα νέα μηνύματα των Εισερχομένων, οπότε τα φίλτρα φακέλου και ημερομηνίας δεν υποστηρίζονται. Αν χρησιμοποιήσετε in:, before:, after:, older_than: ή newer_than:, ένα μήνυμα εξηγεί γιατί αυτά τα φίλτρα δεν μπορούν να χρησιμοποιηθούν. Οι κανόνες δεν μπορούν να στέλνουν μηνύματα ή να τα διαγράφουν οριστικά: η ενέργεια τα μετακινεί στα .

Οι κανόνες εκτελούνται σε αυτόν τον υπολογιστή. Για να εφαρμόζονται κανόνες στην αλληλογραφία όσο ο υπολογιστής είναι κλειστός, χρησιμοποιήστε τα φίλτρα του παρόχου αλληλογραφίας σας.
