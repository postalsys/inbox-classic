Το Inbox Classic δεν μπορεί να συνδεθεί

Τι να κάνετε όταν ο διακομιστής αλληλογραφίας δεν είναι προσβάσιμος ή δεν απαντά.

Μπορεί να δείτε ένα από τα εξής στη γραμμή κατάστασης ή στο παράθυρο ανάγνωσης:

  • «connection error: …»
  • «the server did not answer in time»
  • «η σύνδεση με τον διακομιστή απέτυχε (…)»
  • «Ο διακομιστής αλληλογραφίας δεν ήταν προσβάσιμος (…).»

Για να το διορθώσετε:

  1. Ελέγξτε τη σύνδεσή σας στο διαδίκτυο.
  2. Ανοίξτε τις ιδιότητες του λογαριασμού από το > και ελέγξτε τα ονόματα και τις θύρες των διακομιστών.
  3. Αν η αποστολή αποτυγχάνει, χρησιμοποιήστε τη θύρα 465 ή 587 για τα εξερχόμενα. Ορισμένα δίκτυα αποκλείουν τις θύρες αλληλογραφίας, ιδίως τη θύρα 25.

Το Inbox Classic δοκιμάζει ξανά στον επόμενο έλεγχο αλληλογραφίας. Για να δοκιμάσετε τώρα, κάντε κλικ στο .

Ένα μήνυμα που στέλνετε χωρίς σύνδεση περιμένει στα Εξερχόμενα και φεύγει μόλις ο διακομιστής γίνει προσβάσιμος. Τίποτα από όσα γράψατε δεν χάνεται.
