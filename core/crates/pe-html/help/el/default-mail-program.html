Ορισμός του Inbox Classic ως εφαρμογής αλληλογραφίας

Ανοίξτε στο Inbox Classic τους συνδέσμους ηλεκτρονικού ταχυδρομείου και τα αρχεία μηνυμάτων από ιστοσελίδες και άλλα προγράμματα.

Οι σύνδεσμοι ηλεκτρονικού ταχυδρομείου (mailto:) ανοίγουν νέο μήνυμα στην προεπιλεγμένη εφαρμογή αλληλογραφίας σας.

Για να γίνει το Inbox Classic αυτή η εφαρμογή, επιλέξτε > . Τα Windows ανοίγουν τις ρυθμίσεις Προεπιλεγμένες εφαρμογές, όπου επιλέγετε το Inbox Classic για τους συνδέσμους MAILTO. Εκεί εμφανίζεται μόνο ένα εγκατεστημένο αντίγραφο. Το Inbox Classic γίνεται αμέσως η προεπιλεγμένη εφαρμογή αλληλογραφίας.

Όταν στη συνέχεια κάνετε κλικ σε έναν σύνδεσμο ηλεκτρονικού ταχυδρομείου, ανοίγει νέο μήνυμα με συμπληρωμένες τις διευθύνσεις, το θέμα και το κείμενο του συνδέσμου. Τίποτα άλλο από τον σύνδεσμο δεν χρησιμοποιείται.

Αν δεν έχετε ακόμη λογαριασμό, το Inbox Classic σάς ζητά να προσθέσετε πρώτα έναν. Κάντε ξανά κλικ στον σύνδεσμο μόλις προστεθεί.

Αρχεία μηνυμάτων

Για να ανοίγουν τα αρχεία .eml στο Inbox Classic όταν κάνετε διπλό κλικ σε αυτά, κάντε κλικ στο στο . Τα Windows ανοίγουν τις ρυθμίσεις Προεπιλεγμένες εφαρμογές, όπου επιλέγετε το Inbox Classic για τα αρχεία .eml. Το Inbox Classic γίνεται αμέσως η εφαρμογή τους.
