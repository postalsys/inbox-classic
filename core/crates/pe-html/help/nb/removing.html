Fjern Inbox Classic

Fjern Inbox Classic fra datamaskinen, med eller uten de lokale dataene.

Avinstaller Inbox Classic fra Innstillinger > Apper > Installerte apper. Du blir spurt om hele den lokale datamappen også skal fjernes, med meldinger, utkast, sendekø, kontakter, regler, innstillinger og krypterte nøkkeldata.

Avslutt Inbox Classic, og flytt programmet fra Programmer til papirkurven. Lokale data ligger som standard i ~/Library/Application Support/Inbox Classic til du sletter også den mappen.

Fjern pakken med sudo apt remove inbox-classic, med sudo dnf remove inbox-classic på Fedora, eller med sudo pacman -R inbox-classic på Arch Linux og Omarchy. Lokale data ligger som standard i ~/.local/share/inbox-classic til du sletter også den mappen.

Avinstallering fjerner ikke e-posten på serverne dine. Passord og andre hemmeligheter i systemets separate lagring blir heller ikke slettet bare fordi du fjerner programmet eller datamappen.

Fjern først hver konto i > for å fjerne de lagrede påloggingsopplysningene. Se for å fjerne bare én konto.
