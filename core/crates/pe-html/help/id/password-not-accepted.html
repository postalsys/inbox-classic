Kata sandi tidak diterima

Yang perlu dilakukan jika server email menolak kata sandi atau proses masuk Anda.

Anda mungkin melihat salah satu dari berikut ini:

  • Di bilah status: “server tidak menerima proses masuk (…)”
  • Di panel baca: “Server email tidak menerima proses masuk (…). Periksa kata sandi atau masuk lagi di pengaturan akun.”
  • Jendela yang meminta Anda memasukkan kata sandi akun lagi

Untuk mengatasinya:

  1. Ketik kata sandi lagi saat Inbox Classic memintanya, atau ubah kata sandi di properti akun di > .
  2. Jika penyedia Anda mewajibkan kata sandi aplikasi untuk program email, buat kata sandi aplikasi di pengaturan keamanan akun Anda dan gunakan sebagai pengganti kata sandi biasa.
  3. Untuk Gmail, masuk melalui browser, atau gunakan kata sandi aplikasi jika akun Anda mengizinkannya dan Verifikasi 2 Langkah aktif. Untuk Outlook.com dan Microsoft 365, masuk melalui browser: di Inbox Classic, kata sandi aplikasi tidak dapat menggantikan masuk melalui browser untuk akun ini. Lihat .

Akun yang masuk melalui browser

Saat penyedia mengakhiri sesi masuk, Inbox Classic menampilkan “Proses masuk ke … ditolak atau sesinya telah berakhir.” Inbox Classic bertanya “” Pilih dan masuk sekali lagi di browser.
