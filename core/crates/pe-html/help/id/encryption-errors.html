Kesalahan enkripsi

Yang harus dilakukan jika server tidak menawarkan enkripsi, atau memintanya padahal enkripsi dinonaktifkan.

“the server does not offer STARTTLS”

Akun diatur ke STARTTLS, tetapi server tidak menawarkan enkripsi. Inbox Classic menghentikan upaya koneksi ini sebelum mengirim kata sandi.

  1. Buka properti akun di > .
  2. Periksa pengaturan dari penyedia Anda. Jika didukung, gunakan SSL/TLS dengan port 993 untuk email masuk atau 465 untuk email keluar.
  3. Klik .

Jika tidak ada cara lain yang berhasil, server tersebut tidak dapat digunakan dengan aman.

“the server takes the password only over an encrypted connection”

Server email keluar diatur ke . Kesalahan ini tidak memastikan bahwa kata sandinya benar. Sesuai pengaturan dari penyedia Anda, ubah ke STARTTLS dengan port 587, atau SSL/TLS dengan port 465.

Peringatan tentang koneksi tanpa enkripsi

Saat Anda memilih , Inbox Classic memperingatkan bahwa siapa pun yang menyadap lalu lintas jaringan Anda dapat membaca kata sandi dan pesan Anda. Jaringan lokal tidak dengan sendirinya mengenkripsi lalu lintas. Lanjutkan hanya jika Anda menerima risiko ini untuk server di komputer Anda sendiri atau di jaringan lokal.
