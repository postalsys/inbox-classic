Pengaturan keamanan akun

Pengaturan keamanan server suatu akun, dan arti masing-masing.

Setiap akun memiliki untuk server masuk dan untuk server keluar. Inbox Classic mengisinya saat menemukan pengaturan penyedia Anda. Untuk mengubahnya, buka properti akun di > .

PengaturanArti
SSL/TLSKoneksi dienkripsi sejak awal. Biasanya port 993 untuk email masuk dan 465 untuk email keluar.
STARTTLSKoneksi dimulai tanpa enkripsi, lalu beralih ke TLS sebelum kredensial masuk dikirim. Biasanya port 143 untuk email masuk dan 587 untuk email keluar. Inbox Classic berhenti jika server tidak menawarkan enkripsi.
Kata sandi dan email Anda dikirim tanpa enkripsi dan dapat dibaca oleh siapa pun yang menyadap koneksi.
Gunakan hanya jika koneksi dilindungi dengan cara lain. Jaringan lokal saja tidak menyediakan enkripsi. Inbox Classic memperingatkan Anda sebelum menggunakannya.

Untuk koneksi terenkripsi, Inbox Classic memeriksa bahwa setiap server memang server yang diakuinya, berdasarkan sertifikat yang dipercaya sistem Anda. Tidak ada pilihan untuk menerima sembarang sertifikat.

Secara default, kata sandi Anda disimpan di Manajer Kredensial Windowsrantai kunci login Andakeyring Anda, tidak pernah di penyimpanan email. Masuk melalui browser menyimpan token di sana, bukan kata sandi Anda. Mode khusus memori, atau penyimpanan sistem yang tidak tersedia, dapat membatasi kredensial masuk hanya untuk sesi saat ini.
