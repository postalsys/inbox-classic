Menyimpan, mencetak, dan mengimpor pesan

Simpan pesan sebagai file, buka dan masukkan file pesan, cetak pesan, serta lihat header dan sumbernya.

Menyimpan pesan sebagai file

Pilih > () untuk menyimpan pesan yang ditampilkan sebagai file .eml, yang dapat dibuka program email lain. Jika beberapa pesan dipilih, aplikasi meminta sebuah folder dan menyimpan setiap pesan di sana, dinamai sesuai subjeknya. Saat menyimpan beberapa pesan, file yang sudah ada dipertahankan dan file baru diberi nama yang belum dipakai. Untuk satu pesan, penggantian file bergantung pada dialog simpan sistem.

Anda juga dapat menyeret pesan dari daftar ke desktop atau ke folder di File ExplorerFinderpengelola file.

Mengimpor file pesan

Pilih folder lalu pilih > , atau seret file .eml ke folder di daftar folder. Pesan-pesan tersebut diantrekan untuk diimpor ke folder server itu dan muncul setelah operasi selesai. File yang bukan pesan tidak diimpor.

Membuka file pesan

Klik dua kali file .eml di File ExplorerFinderpengelola file, atau klik kanan file tersebut dan buka dengan Inbox Classic. File terbuka di jendela pesan dengan , , , , dan . Jika aplikasi lain yang membukanya, lihat .

Mencetak

  1. Pilih > (). Pratinjau cetak terbuka.Dialog cetak sistem terbuka.
  2. Pilih printer, jumlah salinan, dan halaman, atau simpan sebagai PDF.
  3. Klik tombol cetak. Pesan dicetak beserta pengirim, tanggal, penerima, dan subjeknya.

Header dan sumber

> () menampilkan header Internet pesan: siapa yang mengirimnya, melalui server mana, dan kapan. Paling banyak 256 KiB pertama dari header ditampilkan. > () menampilkan sumber pesan sebagai teks, hingga 4 MiB pertama. Sebuah pemberitahuan muncul jika tampilannya terpotong. di jendela itu menyimpannya sebagai file .eml.
