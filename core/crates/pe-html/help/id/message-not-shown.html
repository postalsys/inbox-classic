Pesan tidak ditampilkan

Apa yang harus dilakukan jika pesan masih diunduh, tidak dapat diunduh, atau tidak dapat ditampilkan.

“Mengunduh pesan…”

Pesan diunduh saat pertama kali Anda membukanya. Segera setelah Anda menambahkan akun, sebagian besar pesan belum ada di komputer Anda. Pengirim dan subjek dapat muncul sebelum isinya selesai diunduh. Waktu unduh bergantung pada koneksi dan ukuran pesan.

“Pesan tidak dapat diunduh”

Panel menyebutkan alasannya, misalnya server email tidak dapat dijangkau. Pesan terbuka yang gagal diunduh akan dicoba lagi setelah akun disinkronkan. Untuk langsung mencoba, klik di bilah di atas pesan.

Jika proses masuk ditolak, lihat . Jika koneksi tidak dapat diamankan, lihat .

“Pesan ini tidak dapat ditampilkan: …”

Inbox Classic tidak dapat membaca pesan tersebut, misalnya karena pesan rusak atau menggunakan struktur yang tidak didukung. Program email lain mungkin masih dapat membacanya. Email Anda yang lain tidak terpengaruh. Untuk melihat isi pesan tersebut, pilih > .

“”

Inbox Classic menggunakan Microsoft Edge WebView2 Runtime untuk menampilkan pesan. Jika runtime ini tidak ada, instal dari Microsoft lalu mulai ulang Inbox Classic. Browser Edge yang terinstal tidak dengan sendirinya berarti runtime tersedia.
