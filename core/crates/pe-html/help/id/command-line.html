Opsi baris perintah

Opsi untuk memulai Inbox Classic dari terminal, untuk pengujian dan untuk agen AI.

Jalankan program InboxClassic.exe"Inbox Classic.app/Contents/MacOS/Inbox Classic"inbox-classic dengan opsi berikut:

OpsiFungsi
--store <file>Menggunakan penyimpanan email lain, misalnya untuk pengujian
--memory-passwordsMenyimpan kredensial masuk hanya untuk sesi ini, bukan di penyimpanan kredensial sistem
--pin-certificate <file>Hanya menerima sertifikat dalam file ini untuk server pengujian: satu sertifikat DER, atau satu atau beberapa sertifikat PEM
--sign-in-page-file <file>Menulis URL masuk browser ke file ini alih-alih membuka browser
--language <code>Menampilkan jendela dalam bahasa ini untuk sesi ini, misalnya de
--backgroundMemulai tanpa jendelanya
--mcpMenghubungkan agen AI ke Inbox Classic. Program agen yang menjalankan ini, bukan Anda
--versionMencetak versi lalu berhenti

Tautan mailto: yang diberikan sebagai argumen membuka pesan baru jika sebuah akun telah dikonfigurasi, seperti halnya tautan email.
