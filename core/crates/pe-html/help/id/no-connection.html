Inbox Classic tidak dapat terhubung

Apa yang harus dilakukan jika server email tidak dapat dijangkau atau tidak menjawab.

Anda mungkin melihat salah satu pesan berikut di bilah status atau panel baca:

  • “connection error: …”
  • “the server did not answer in time”
  • “koneksi ke server gagal (…)”
  • “Koneksi ke server email tidak dapat dibuat atau terputus (…).”

Untuk mengatasinya:

  1. Periksa koneksi internet Anda.
  2. Buka properti akun di > dan periksa nama server serta portnya.
  3. Jika pengiriman gagal, periksa keamanan dan port server keluar: biasanya SSL/TLS di port 465 atau STARTTLS di port 587. Beberapa jaringan memblokir port email, terutama port 25.

Inbox Classic mencoba lagi pada pemeriksaan email berikutnya. Untuk mencoba sekarang, klik .

Pesan yang Anda kirim tanpa koneksi tetap berada di Kotak Keluar lokal. Inbox Classic mencoba lagi saat dapat terhubung; server masih dapat menolak pesan tersebut.
