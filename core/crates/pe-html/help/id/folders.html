Bekerja dengan folder

Buat, ganti nama, dan hapus folder Anda sendiri di server email.

Untuk membuat folder:

  1. Untuk membuat subfolder, pilih folder induknya. Untuk membuat folder tingkat atas dengan satu akun, pilih Kotak Masuk atau . Jika ada beberapa akun, klik kanan nama akun tersebut.
  2. Pilih > > > , atau klik kanan lalu pilih .
  3. Ketik nama lalu klik . Inbox Classic membuat folder di server dan melaporkan jika gagal.

Untuk mengganti nama folder yang dipilih, pilih > > > . Untuk menghapusnya, pilih > > > . Keduanya juga ada di menu klik kanan folder.

Menghapus folder akan menghapus pesan dan folder di dalamnya, juga di server. Inbox Classic menanyakannya terlebih dahulu.

Kotak Masuk dan folder khusus, seperti , dan , tidak dapat diganti namanya atau dihapus.

Untuk membuka folder tanpa mouse, pilih > () dan ketik sebagian namanya.

Daftar folder mengingat folder mana yang Anda buka dan tutup.
