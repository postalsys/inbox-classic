Menjadikan Inbox Classic aplikasi email Anda

Buka tautan email dan file pesan dari halaman web dan program lain di Inbox Classic.

Tautan email (mailto:) membuka pesan baru di aplikasi email default Anda.

Untuk menjadikan Inbox Classic aplikasi tersebut, pilih > . Windows membuka pengaturan Aplikasi default, tempat Anda memilih Inbox Classic untuk tautan MAILTO. Hanya salinan yang terinstal yang tercantum di sana. Inbox Classic meminta sistem menjadikannya aplikasi email default; perubahan ini bergantung pada izin dan pengaturan sistem.

Saat Anda kemudian mengeklik tautan email, pesan baru terbuka dengan alamat, subjek, dan teks dari tautan itu sudah terisi. Bagian lain dari tautan tidak digunakan.

Jika Anda belum memiliki akun, Inbox Classic meminta Anda menambahkannya terlebih dahulu. Klik tautan itu lagi setelah akun ditambahkan.

File pesan

Untuk membuka file .eml di Inbox Classic saat Anda mengekliknya dua kali, klik di . Windows membuka pengaturan Aplikasi default, tempat Anda memilih Inbox Classic untuk file .eml. Membatalkan pengaturan Inbox Classic tidak membatalkan perubahan yang sudah dibuat di Windows. Inbox Classic meminta sistem menggunakannya untuk file ini.
