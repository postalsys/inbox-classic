Gmail dan Outlook.com

Gunakan proses masuk melalui browser untuk Gmail, Outlook.com, dan Microsoft 365; akun Google yang memenuhi syarat juga dapat menggunakan kata sandi aplikasi.

Google dan Microsoft tidak mengizinkan program email menggunakan kata sandi biasa Anda. Di Inbox Classic, gunakan proses masuk melalui browser untuk Outlook.com dan Microsoft 365. Kata sandi aplikasi Google hanya dapat digunakan jika akun Anda mengizinkannya.

Jika Google atau Microsoft mengakhiri sesi masuk, Inbox Classic menampilkan “Proses masuk ke … ditolak atau sesinya telah berakhir.” Inbox Classic menanyakan apakah Anda ingin masuk lagi di browser. Pilih dan masuk sekali lagi.
