Lampiran

Buka atau simpan file yang dilampirkan pada pesan, dan lampirkan file ke pesan yang Anda tulis.

Melihat gambar dan file PDF di dalam pesan

Pratinjau gambar dan hingga lima halaman setiap PDF muncul setelah teks pesan, beserta nama dan ukurannya. Klik salah satunya untuk membuka file tersebut. File PDF yang lebih panjang memiliki tautan untuk membukanya. Hingga 20 gambar dan halaman muncul secara otomatis; baris di bawahnya menghitung file lainnya.

Semua ini adalah salinan yang digambar sendiri oleh Inbox Classic: tidak ada isi file yang dijalankan, dan tidak ada yang dimuat dari internet. File yang tidak dapat digambarnya tampil sebagai ubin dengan nama, ukuran, dan alasannya, misalnya gambar HEIC atau file PDF yang dilindungi kata sandi; klik ubin itu untuk membuka file. Selama pesan besar masih diunduh, file-filenya tampil sebagai ubin sampai tiba. Dalam pesan yang ditandatangani atau terenkripsi, setiap bagian menampilkan filenya sendiri di dalam bingkainya sendiri. Pratinjau dari bagian terenkripsi tetap berada di memori, bukan di file pratinjau. Saat Anda membuka atau menyimpan lampiran secara terpisah, salinan yang tidak terenkripsi dibuat.

Untuk menampilkan file di dalam pesan, atau mengeluarkannya, klik kanan file tersebut di daftar file dan pilih . Ini berlaku selama pesan tersebut ditampilkan.

Untuk hanya melihat daftarnya, nonaktifkan di . Jika Inbox Classic berhenti saat menampilkan pratinjau file, aplikasi akan menonaktifkan pratinjau PDF pada saat dimulai berikutnya dan menjelaskan hal ini. Ini tidak membuktikan bahwa file tersebut penyebab gangguannya; aktifkan untuk menampilkannya lagi.

Saat Anda mencetak pesan, pratinjau gambar yang ditampilkan di dalamnya ikut dicetak. File PDF tidak: sebuah baris menyebutkan masing-masing, dan Anda mencetaknya dari programnya sendiri. Dalam pesan yang ditandatangani atau terenkripsi, gambar setiap bagian muncul tepat setelah teks bagian itu, masing-masing disertai nama bagiannya.

Membuka lampiran

File sebuah pesan tercantum di bawah header-nya, masing-masing dengan nama dan ukurannya. Klik dua kali file untuk membukanya dengan program yang digunakan komputer Anda untuk file itu. Dengan keyboard, tekan Tab sampai daftar file terpilih, pilih satu dengan tombol panah, lalu tekan Enter.

Klik kanan file untuk , , dan . Klip kertas di sebelah kanan header juga mencantumkan file-file tersebut.

Inbox Classic memblokir pembukaan program, skrip, penginstal, pintasan, image disk, halaman web, dan dokumen Office dengan makro yang dikenalinya. Perintah untuk file seperti itu tidak aktif; simpan file tersebut, dan buka sendiri hanya jika Anda memercayai asalnya.

Untuk membuka file, Inbox Classic menyimpan salinannya di folder sementara untuk akun pengguna Anda. Saat dimulai, aplikasi mencoba menghapus salinan sementara yang berumur lebih dari satu hari. Di Windows dan macOS, file ditandai sebagai berasal dari internet. Lampiran dari pesan terenkripsi disimpan di sana tanpa enkripsi; Inbox Classic menjelaskan hal ini saat pertama kali Anda membukanya.

Menyimpan lampiran

Klik kanan file dan pilih , atau pilih untuk menyimpan semuanya ke dalam satu folder. Inbox Classic menyarankan nama yang aman, tanpa karakter yang dapat membuat nama tampak seperti hal lain. Saat menyimpan semua lampiran, file yang sudah ada dipertahankan dan file baru dengan nama yang sama diberi nomor. Menyimpan satu file mengikuti dialog simpan sistem, yang mungkin menawarkan untuk mengganti file.

Buka lampiran hanya dari orang yang memang Anda harapkan mengirimnya. Program, atau dokumen yang meminta Anda untuk “mengaktifkan konten”, dapat mengambil alih komputer Anda. Program termasuk file .exe, .msi, .js, .vbs, .bat, dan .scr..app, .pkg, .dmg, dan .command..sh, .deb, .rpm, .AppImage, dan .desktop.

Melampirkan file

Untuk melampirkan file ke pesan yang Anda tulis:

  1. Klik .
  2. Pilih file-filenya. File tersebut tercantum di beserta ukurannya.

Anda juga dapat menyeret file dari File ExplorerFinderpengelola file ke kolom alamat. File yang bukan gambar juga dapat diletakkan di teks.

Untuk melepas file, pilih file tersebut dan tekan Delete, atau klik kanan dan pilih . File dibaca saat pesan dikirim, jadi biarkan file tetap di tempatnya sampai saat itu.
