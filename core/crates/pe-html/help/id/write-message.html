Menulis pesan

Tulis dan kirim pesan baru, dengan format, tautan, dan gambar.

Untuk menulis pesan:

  1. Klik , atau tekan . Pesan baru terbuka di jendelanya sendiri.
  2. Ketikkan alamat di . Pisahkan beberapa alamat dengan koma. Saat Anda mengetik, Inbox Classic menyarankan kontak, alamat, dan grup yang cocok. Tekan EnterReturn atau Tab untuk menerima saran; memilih grup akan menambahkan anggotanya.
  3. Masukkan , lalu tulis pesannya.
  4. Klik , atau tekan Ctrl+Enter, atau tekan ⌘Return.

Untuk menambahkan Cc atau Bcc, klik atau di ujung baris Kepada. Orang di Bcc menerima pesan, tetapi penerima lain tidak melihat mereka.

Kolom menunjukkan akun yang digunakan untuk mengirim pesan. Jika Anda memiliki beberapa akun, Anda dapat memilih akun lain di sana. Pesan kemudian dikirim dengan akun tersebut dan disimpan di akun itu. Untuk memulai dari akun tertentu, gunakan panah di samping .

Jika subjek atau teks berisi kata lampiran yang dikenali, seperti “attached”, tetapi tidak ada file yang dilampirkan, Inbox Classic bertanya sebelum mengirim. Aplikasi mengenali kata-kata tertentu dalam bahasa Inggris, Jerman, Estonia, Spanyol, dan Prancis.

Untuk menandatangani atau mengenkripsi pesan, klik atau pada bilah alat. Lihat .

Format

Bilah di atas teks berisi font, tebal, miring, garis bawah, warna, daftar, inden, perataan, tautan, garis pemisah, dan gambar. Untuk menyisipkan gambar ke dalam teks, klik atau seret file gambar dari File ExplorerFinderpengelola file ke dalam teks.

Pesan tanpa format dikirim sebagai teks biasa, yang dapat dibaca program email tanpa format HTML. Pesan berformat dikirim sebagai HTML disertai salinan teks biasa.
