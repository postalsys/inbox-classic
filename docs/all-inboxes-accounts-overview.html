All Inboxes by account, account names, the account menu

All Inboxes gets a row per account, as Apple Mail has: the same Inbox the account section has, a second way to it. Accounts get a short name of their own ("Gmail", "Postal Support") in place of "Your Name (address)", and the account's row a right-click menu worth having. Plan: docs/all-inboxes-accounts-plan.md.

  • Send and Receive: this account's server only.
  • Mark All Read: every folder of the account; off when nothing in it is unread.
  • New Folder...: as now.
  • Properties...: the account's Properties, the dialog and the word of File > Accounts.
  • Remove Account stays in File > Accounts, where its confirmation is.

Decisions

A row has a placeEach tree row is (folder, under All Inboxes), not only a folder id, in all three apps.
Where an outside selection goesA notification's message, Next Unread, the message window and the start pick the row under All Inboxes when the selection was already there; the account's row otherwise.
CountsEach row its Inbox's count; All Inboxes the sum only while closed, the rule the tree has for closed folders.
CommandsThe row is the Inbox: Mark All Read, Properties, dropping messages moves them to that Inbox. No Rename or Delete, as for any Inbox.
Two accounts or moreAs All Inboxes now; with one account it is not shown.
One Inbox rule, in the corepe_special_folders(core, use) gives each account's Inbox (Sent and Drafts later), name and count; the apps stop deciding it from special use.
Open rows rememberedAll Inboxes and each account stay open or closed between starts, in each app's preferences.

Improvements beyond the request

  • One Inbox rule fixes a quiet mismatch: the store finds Inboxes by path (INBOX), the Windows and Mac trees by special use.
  • All Sent, All Drafts, Flagged later, Apple's next rows, on the same place model and the same pe_special_folders.
  • The narrow Linux window shows the same rows in its folder popover; its button reads "Inbox - Gmail".
  • Screen readers hear "Inbox, Gmail", not only "Gmail".
