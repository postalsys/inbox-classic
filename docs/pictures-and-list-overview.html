Trusted senders' pictures, unread only, badges, .eml files and future dates

Five changes in all three apps: pictures that load for senders you trust (only when the provider confirms the sender) or always, an unread-only filter for the list, an unread badge on the Windows taskbar, .eml files opened from Finder and File Explorer, and future-dated spam no longer on top. Plan: docs/pictures-and-list-plan.md.

Your decisions

Address or domainThe pictures bar offers both; one list in Options with Remove.
Only when verifiedDKIM or DMARC must confirm the From domain; a forged sender still asks. Never in Junk E-mail.
Contacts not trustedThe Address Book fills itself, so only the list counts.
Always: off by defaultAn Options checkbox with a line on what it tells senders.
Unread only: all foldersOne remembered toggle; a message read stays until you leave the folder.
.eml: register and offer defaultOpen With everywhere; Options sets the default where the system allows.
Future dates cappedSorted and shown by its own date, never later than its arrival.
Windows taskbar badgeThe unread count on the taskbar button; the Mac and Ubuntu docks already have it.

2. Unread only

PlatformWhere the toggle is
WindowsView > Hide Read Messages (Outlook Express's name) and a toolbar button with a filter icon
MacThe toolbar's filter button (line.3.horizontal.decrease.circle, filled when on), as Mail has it, and the View menu
LinuxA toggle in the header bar (funnel-symbolic) and the primary menu

The core filters folders, All Inboxes, searches and conversations, keeps a message read under the filter until you leave the folder, and gives the counts and "No unread messages".

3. The Windows taskbar badge

ITaskbarList3::SetOverlayIcon with the unread count drawn as a small red badge (99+ past 99), cleared at none, from the count the tray already gets. Windows' setting to hide badges still applies.

4. Opening .eml files

PlatformRegistered"Open .eml files with Inbox Classic"
WindowsThe installer: ProgID, OpenWithProgids, Capabilities\FileAssociations (per user)Opens Default Apps at Inbox Classic (Windows lets no program set itself)
MacCFBundleDocumentTypes for com.apple.mail.emailNSWorkspace.setDefaultApplication

A file opens in the same message window as a double-click in the list (handed to the running app), with Reply, Forward, Print and Save As; moving, flags and deleting are off, as it is in no mailbox.
