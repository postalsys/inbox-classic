# Where each feature lives on each platform

The three apps are thin windows on the same Rust core (`core/`). A feature that changes what the user sees changes all three, in the same pull request (`scripts/check-shells.sh` checks it); this table says where. The screenshots of the UI end-to-end tests (`scripts/feature-map.mjs`, with `--check <platform>`) show that each one is there.

Shared by all three, in the core: the help (the topics of `core/crates/pe-html/help/<lang>/`, with `<!--os:...-->` parts, `pe-html/src/help.rs`), the commands (`core/commands.toml`, generated into `core/include/commands.h`, `mac/Sources/InboxClassic/Generated/Commands.swift` and `linux/src/generated/commands.rs`), the words for sizes and the account and folder names (`pe-core/src/text.rs`), the address book with its vCard and CSV files and the completion of addresses (`pe-core/src/book.rs`, `vcard.rs`), the documents of the web views and their content rules (`pe-html`), the MCP server and its tools (`pe-mcp`) with the rules for AI agents and their words (`pe-core/src/agents.rs`), and everything that touches mail data.
