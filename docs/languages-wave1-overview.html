Five more languages

Brazilian Portuguese, Turkish, Norwegian, Catalan and Serbian: the next languages that need nothing but translation, about 300 million speakers. They run alongside the current work, as the 19 did.

The five

Português (Brasil) pt-BR

  • Its own catalog beside Portugal's; the list shows both, with the country
  • Started from Portugal's: arquivo, tela, salvar, você
  • Brazilian systems get it; other Portuguese systems get Portugal's

Türkçe tr

  • A core test that search, sorting and address completion treat İ/i and I/ı as Turkish users expect

Norsk bokmål nb

  • Completes the Nordic languages
  • A system set to no or nb gets it; Nynorsk is not in this plan

Català ca

  • Apostrophe contractions around placeables (l', d') handled by rephrasing

Srpski sr-Latn

  • Latin script; a Serbian system gets it whichever script it uses

The order

1Region tags SThe language list takes pt-BR and sr-Latn; a system's tag matched by language, then region or script; every generated list writes them as its platform expects.
2Translations MFive translators in parallel, the same brief and checker as the 19; Brazilian Portuguese from Portugal's catalog.
3Registration SThe list, the sign-in buttons, the glossary, the builds.
4Tours and review SThe three platforms' language tours, cut-offs fixed; then ready for your review.

Checked by

  1. check-language.mjs for each language; the core's catalog, plural and help tests over every language.
  2. Tests of matching a system's language to pt-BR, pt, nb and sr-Latn.
  3. The Turkish matching test (İ/i, I/ı) for search, sorting and address completion.
  4. The language tours on Windows, the Mac and Linux, with the longest words looked at.
  5. /simplify and /security-review per pull request; the board post asks for native reviewers. No release until you have reviewed the translations.
